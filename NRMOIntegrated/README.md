# NRMO Integrated System v7.2 FULL

This package is a **self-contained research reference implementation** of NRMO
Integrated v7.2 FULL.

It includes:
- NRMO governance / execution **separation contract**
- StrongEngine Ω Full (Wolf Pursuit / anti-stagnation / momentum exploitation)
- Loom (control core) / Loom v3.1 + Sociable Shadow
- MAPLayer / Shinobi / Norn-Skuld
- OS/SOP modules: DAG, Parallel OODA, HST-N, Aallowed, APCSO, Secretary Console,
  Shutdown Guard, TTM/PPS, Defensive-Offense, Investment SOP, Hare-no-Hi,
  Life SOP, Mode Selector, Non-Ergodic Monitor, Time Horizon, Situation Params,
  Meta Governance, OS Integrator
- Self-contained domain harness (store / investment / romance — **proxy dynamics**)
- Validation harnesses + official one-shot entry

It is **not**:
- a commercial / production-ready product
- a claim of empirical proof beyond the included simulations
- a replacement for human judgement
- a value system or doctrine
- a model of any real person or market (the investment/romance harnesses are
  abstract proxy dynamics, not real-world dynamics)

Type ZERO / Passive Pattern are implemented as **operational proxy adapters**:
they provide input/output stabilization and passive-risk detection, not full
cognitive/personality emulation.

## 2. Quick validation (one command)
```bash
python validate_nrmo_integrated_v72.py
```
Run from the package root after unzipping. No extra path setup is needed.

### Expected output
```

============================================================
PASS: OS/SOP validation (...s, required)
PASS: OS/SOP boundary+property (...s, required)
PASS: v8 integrity (...s, required)
PASS: Omega subsystem alive (...s, required)
PASS: NRMO separation contract (...s, required)
PASS: domain harness (self-contained, light) (...s, required)
PASS: C++ syntax (...s, required)
PASS: no-pipe audit (active runners) (...s, required)
------------------------------------------------------------
FINAL: ALL REQUIRED VALIDATIONS PASS WITH NO SKIPS
```
Total runtime is well under 5 minutes (about 15s typically). The run also writes
`validation_results.json` with per-step status, timing, and output tails.

## 3. Interpretation of PASS / SKIP / FAIL
- **PASS** - step exited 0 and required output markers were present.
- **FAIL** - step failed, errored, or output markers were missing.
- **TIMEOUT** - step exceeded its per-step timeout -> treated as FAIL.
- **SKIP** - an optional step was not run.
Final rule:
```
any FAIL or TIMEOUT or required-SKIP -> FINAL: FAIL
optional SKIP only                   -> FINAL: PARTIAL PASS / OPTIONAL SKIPS PRESENT
all required PASS, no SKIP            -> FINAL: ALL REQUIRED VALIDATIONS PASS WITH NO SKIPS
```
SKIP or TIMEOUT is **never** reported as ALL PASS.

## 5. Optional long-run validations (separated from the entry)
```bash
python run_long_validations.py
```

For the official 3-consecutive check (with orphan-process cleanup and JSON evidence):
```bash
python scripts/validate_three_runs.py   # writes validation_three_runs.json
```
Heavier / longer checks kept out of the lightweight one-shot entry:
- real nrmo_core adapter (bundled v52_codebase) — exercises the real NRMO governance filter
- run_all_validations (full) and v7_validate 3-domain (full): steps >= 150, seeds >= 10, horizon >= 20
The official entry is intentionally lightweight so that repeated/3-consecutive runs stay fast and stable.

## 6. Architecture invariants (must hold)
- NRMO builds the admissible set; StrongEngine searches only within it.
- Engine never reads veto thresholds; never mutates the NRMO boundary.
- NRMO never rewrites the Engine objective; NRMO holds no Vision (the human does).
- selected_action is always in admissible_set.
See `docs/AUTHORITY_BOUNDARIES.md`.

## 7. Known limitations
- The store/investment/romance dynamics are **proxy** models for exercising the
  engine, not validated real-world models.
- Type ZERO / Passive Pattern are proxy adapters, not full cognitive emulation.
- "Validated" means reproduced by the included tests / reference simulations,
  not a mathematical proof of guaranteed survival.
