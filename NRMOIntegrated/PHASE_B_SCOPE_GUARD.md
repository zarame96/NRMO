# Phase B Scope Guard

This phase is documentation/specification repair only.

Allowed changes:
- provenance labels;
- supersession notes;
- terminology typing;
- historical-to-canonical mapping notes;
- authority wording corrections where required to avoid semantic contradiction.

Forbidden changes in this phase:
- implementation behavior;
- numerical thresholds;
- algorithmic policy changes;
- archive rewriting;
- deleting historical text;
- changing the Normative Canon merely to match existing code.

Any implementation delta discovered during Phase B must be deferred to Phase E under Issue #6 or to a separate implementation issue.
