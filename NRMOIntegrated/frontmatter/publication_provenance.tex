\nrmobox{Baseline and repair overlay}{
Parts originate from different historical baselines. A Part's baseline
version records lineage and does not override the current Normative Canon.

overlay to preserved material while retaining historical provenance.
Accordingly, older statements that Parts ``carry forward unchanged'' are
baseline-lineage statements, not claims that the current source tree has
received no Canon/provenance repairs.
}
