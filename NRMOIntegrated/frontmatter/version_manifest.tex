\noindent
\textbf{Version semantics.} The monograph version (cover page) is
$v7.2$: the static text architecture descends from v5.5
(thirteen Parts, four Appendices), and v7.2 is
the current development frontier reflected in the Part~XIII development
chapters and the accompanying \texttt{world\_sim} suite. A reader who
only requires the static monograph content can read Parts~I--XII at
the v5.5 reconstruction baseline; a reader interested in the simulation pipeline should
focus on Part~XIII and \texttt{world\_sim\_v50/}.

\noindent
\textbf{NRMO naming convention} (introduced v6.4, see
Section~\ref{sec:renaming-v64}):
\begin{itemize}
\item \texttt{NRMO\_Origin}: original veto-only formulation
  (Parts~I--II), 4-rule fixed-threshold;
\item \texttt{NRMO}: current strengthened operational form
  (Parts~VIII, IX, XIII), 7-rule + Adaptive Tuning + $\Omega$ Full;
\item \texttt{NRMO\_Collective}: v7.0/v7.1 sibling theory incorporating
  collective governance. v7.0 = P--U fixed-rule layer.
  v7.1 = + Collective Strong Engine (W--AB) for search-driven configuration.
  Sibling to \texttt{NRMO}, not replacement.
\item \texttt{NRMO\_vNext} (output label): retained as the strategy
  identifier in simulator CSVs for backward compatibility.
\item \texttt{Loom v3.1} (introduced v7.2, see Part~XIV): empirically
  frozen \emph{Behavioral Core} achieving 9/9 cells in the Top-3 of
  the canonical chaotic/drifting/noisy $\times$ mild/moderate/severe
  benchmark. The current operational identity of the system is
  $\text{Loom v3.1} + \text{Sociable Shadow Layer}$.
\end{itemize}
