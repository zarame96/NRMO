\subsection{Execution Procedure}
\label{sec:action-space-execution}

\begin{enumerate}
\item Determine state labels ($\mathrm{LOAD}$ / $\mathrm{VOL}$ /
$\mathrm{IRREV}$).
\item Determine mode ($\mathrm{CORE}$ / $\mathrm{VENTURE}$ /
$\mathrm{MISSION}$ / $\mathrm{SHUTDOWN}$).
\item Identify permitted category ($A$ / $B$ / $C$ / $D$).
\item Execute reversible categories first ($A \to B \to C$ when
permitted).
\item Category $D$ requires explicit confirmation (decision
procedure / audit / human-in-the-loop).
\item After execution, update state labels.
\end{enumerate}
