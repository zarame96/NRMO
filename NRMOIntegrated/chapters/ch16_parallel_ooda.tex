\section{Definition of Activeness}
\label{sec:parallel-ooda-activeness}

\textit{Activeness} means only: reacting to conditions and
generating a proposal set.

\begin{itemize}
\item \textbf{Does not perform}: judgement / recommendation /
action promotion / ranking / $\varepsilon$ proposal.
\item APCSO is an \emph{active generator}, not a decision-maker.
\end{itemize}

% =====================================================================
\section{Auto-Proposal Generation Trigger}
\label{sec:parallel-ooda-trigger}

Generate a proposal set even without explicit request if all of the
following are met:

\begin{itemize}
\item Passive Pattern Gate is SAFE.
\item At least one of the following holds:
\begin{itemize}
\item Irreversibility is present.
\item Non-Zero Ruin Risk cannot be denied.
\item Option degeneration (binary framing / forced choice)
detected.
\end{itemize}
\end{itemize}

\noindent
After generation, APCSO performs no additional action.

% =====================================================================
\section{Output Constraints}
\label{sec:parallel-ooda-output}

\begin{itemize}
\item Number of proposals: always exactly 3.
\item At least 1 proposal must be Hold / Exit.
\item No ranking, recommendation, or emphasis attached.
\item Each proposal satisfies $\varepsilon$ constraint.
\item Narrative / Ethics is post-hoc only.
\end{itemize}

% =====================================================================
\section{Relationship with Upper-Level Grammar}
\label{sec:parallel-ooda-grammar}

APCSO is responsible only for generation. Display intensity,
abstraction level, and grammar selection
(INFO / HOLD / APCSO / HALT) are the responsibility of
\emph{Upper-Level Grammar}. APCSO has no display format.

% =====================================================================
\section{Prohibitions}
\label{sec:parallel-ooda-prohibitions}

\begin{itemize}
\item APCSO judging ``should use.''
\item Hurrying decision under reason of auto-generation.
\item Expressions that cause active generation to be misread as
autonomous judgement.
\end{itemize}
