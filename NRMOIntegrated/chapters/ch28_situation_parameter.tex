The Situation Parameter Model describes any situation as an
8-dimensional vector:

\section{Risk Calculation}
\label{sec:situation-risk}

\begin{equation}
\mathrm{risk} = \mathrm{base\_risk} \times
\mathrm{emotional\_amplifier} \times
\mathrm{capital\_weight}.
\label{eq:situation-risk}
\end{equation}

\nrmobox{Design principle}{
\centering
\textit{No static branches. No 3000-case match statements.}\\
Dynamic calculation in continuous parameter space handles any
situation.
}
