\section{$A_{\mathrm{allowed}}$ v1.2 --- MISSION-DEFENSE Extension}
\label{sec:mission-defense-c2}

\nrmobox{Update purpose}{
\textbf{Update}: 2026-01-01 \\
\textbf{Scope}: Type ZERO / $A_{\mathrm{allowed}}$ \\
\textbf{Purpose}: Permit HST-N (operational) and TTM/PPS (training)
references in MISSION mode under \emph{defensive use only}. The new
configuration is named MISSION-DEFENSE.
}

This extension adds three categories
(\texttt{hst\_map}, \texttt{ttm\_lookup}, \texttt{ttm\_debrief}) to
the MISSION mode profile. Their use is restricted to defensive
output (HST-N state read / TTM pattern recognition / END-of-TTM
debriefing); operational use is prohibited.

\subsection{Activation Conditions (Non-Negotiable)}
\label{sec:mission-defense-conditions}

The MISSION-DEFENSE configuration activates when both:

\begin{enumerate}
\item \textbf{TTM/PPS detects a recognised pattern} (incoming
pressure / coercion / structural-irreversibility-pattern); AND
\item One of:
\begin{itemize}
\item Irreversibility (load, volatility, governance pressure)
imminent.
\item Observation (HST-N state) approaching boundary.
\end{itemize}
\end{enumerate}

\noindent
Outside these conditions, MISSION-DEFENSE is \textbf{not} active.

\subsection{Non-Negotiable Restrictions}
\label{sec:mission-defense-restrictions}

\begin{enumerate}
\item TTM/PPS must not produce scripts, dependency designs, or
persuasion patterns.
\item PP and $A_{\mathrm{allowed}}$ separation is preserved.
\item Output is filtered through SOP for defensive use only.
\item SHUTDOWN conditions (load / volatility / irreversibility /
pressure-saturation) override MISSION-DEFENSE.
\end{enumerate}

\subsection{Forbidden Categories (MISSION Prohibited)}
\label{sec:mission-defense-forbidden}

\begin{itemize}
\item Training (\texttt{training}, \texttt{adversarial\_role\_play})
output.
\item Script (\texttt{persuasion\_script}, \texttt{shaping\_script}).
\item Dependency design (\texttt{dependency\_design}).
\item Pressure escalation (\texttt{pressure\_escalation}).
\end{itemize}

\noindent
TTM/PPS pattern recognition is permitted in MISSION-DEFENSE; pattern
\emph{application} is forbidden in any mode.

\subsection{Operational Procedure (5 Steps)}
\label{sec:mission-defense-procedure}

\begin{enumerate}
\item \textbf{Z.mode = MISSION} (set explicitly).
\item $A_{\mathrm{allowed}}$ categories: \texttt{hst\_map},
\texttt{ttm\_lookup}, \texttt{ttm\_debrief} added.
\item HST-N state $\ge 1$ (observation provided).
\item TTM (ID / category / detection-signature) requested.
\item SOP A/B response (hold / split / confirm / third-party check
/ slow tempo) issued under \texttt{defense\_only\_output}.
\end{enumerate}

\subsection{SHUTDOWN Override}
\label{sec:mission-defense-shutdown}

\paragraph{Conditions.}
SHUTDOWN takes precedence over MISSION-DEFENSE when:

\begin{itemize}
\item Load / volatility / irreversibility at threshold.
\item Strong pattern detected with no reversible defence available.
\item END\_TTM (3-line) recommended; system halts further engagement.
\end{itemize}

\paragraph{Behaviour on SHUTDOWN override.}
TTM / hst\_map / ttm\_debrief outputs are suspended. Only \texttt{A}
category actions (confirm, defer, rest, third-party check) remain
permitted.

\subsection{Output Format (MISSION-DEFENSE)}
\label{sec:mission-defense-output}

\paragraph{Fixed structure.}

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
State (HST-N):  load = ?, volatility = ?
Detection (TTM): TTM-0xx (category C or D)
Defence (SOP):
  (1) hold / pause
  (2) confirm with third party
  (3) condition (slow tempo)
Boundary:       irreversibility close --> (1)
Closing:        END_TTM (3 + defensive)
\end{lstlisting}

\paragraph{Anti-contamination.}
TTM output is structurally restricted to defensive analysis. Direct
application to operations remains prohibited.

\subsection{Mode-Specific Profiles (NORMAL / VENTURE / MISSION /
SAFE)}
\label{sec:a-allowed-mode-profiles-c2}

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize,frame=single]
NORMAL:
  categories: ["info", "analysis", "proposal", "execute"],
  caps: {
    max_irreversible_steps: 0,
    public_scope:           "limited",
    reversibility_min:      "Med"
  },
  required_checks: ["log_reason"]

VENTURE:
  categories: ["info", "analysis", "proposal",
               "execute", "commit"],
  caps: {
    max_irreversible_steps: 1,
    public_scope:           "limited",
    money:                  { per_action: "small" }
  },
  required_checks: ["write_down_exit", "loss_cap",
                    "cooldown_10m", "log_reason"]

MISSION:
  categories: ["info", "analysis", "proposal",
               "execute", "commit", "public"],
  caps: {
    max_irreversible_steps: 2,
    public_scope:           "public"
  },
  required_checks: ["mission_deadline",
                    "success_criteria",
                    "exit_criteria",
                    "second_opinion",
                    "log_reason"]

SAFE:
  categories: ["info", "analysis", "proposal"],
  caps: {
    max_irreversible_steps: 0,
    public_scope:           "none"
  },
  required_checks: ["cooldown_30m",
                    "sleep_or_break",
                    "log_reason"]
\end{lstlisting}

\paragraph{Profile semantics.}

\begin{itemize}
\item NORMAL: standard operation; no irreversible steps; limited
public scope.
\item VENTURE: single irreversible step permitted with explicit
exit-rule; small monetary action; cooldown required.
\item MISSION: up to two irreversible steps; explicit
mission-deadline / success-criteria / exit-criteria mandated;
second opinion required.
\item SAFE: information and analysis only; no commitment; cooldown
plus rest required.
\end{itemize}

\paragraph{Profiles version.}
$A_{\mathrm{allowed}}$ Profiles v1.1.

\subsection{Type ZERO Gate Logic (Simplified)}
\label{sec:a-allowed-gate-logic-c2}

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
if load == "High":
    mode = SAFE
elif buffer == "Low" and (irreversibility == "High"
                          or observability == "Low"):
    mode = SAFE
elif mission_flag == True:
    mode = MISSION
elif buffer == "High" and observability == "High" \
     and irreversibility != "High":
    mode = NORMAL or VENTURE
else:
    mode = NORMAL
\end{lstlisting}
