\chapter{$A_{\mathrm{allowed}}$ Dictionary --- Permitted Action Set
Base Schema}
\label{ch:a-allowed-dictionary}

\nrmobox{Document role}{
This chapter is the authoritative \emph{base schema reference} for
the permitted action set dictionary used by Type ZERO and all
operational modes.\\[0.3em]
\textbf{Purpose}: Dictionarise the ``categories'' and ``caps'' of
$A_{\mathrm{allowed}}$ generated by Type ZERO. Adding to this
dictionary does not break the OS (because the SOP layer is fixed).
}

This chapter defines the base schema used by Type ZERO and all
modes. See Extension v1.2 (MISSION-DEFENSE,
Section~\ref{sec:a-allowed-extension}) for domain-specific
extensions.

% =====================================================================
\section{Base Schema}
\label{sec:a-allowed-dict-schema}

The dictionary is a JSON-style schema of three blocks:
\texttt{categories}, \texttt{caps}, and \texttt{required\_checks}.

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
{
  categories: ["info", "analysis", "proposal", "commit",
               "execute", "public", "training", ...],
  caps: {
    money: {
      per_action: "...",
      per_day:    "...",
      total:      "..."
    },
    time: {
      per_action: "...",
      per_day:    "..."
    },
    reversibility_min:        "Low | Med | High",
    max_irreversible_steps:   0..N,
    public_scope:             "none | private | limited | public"
  },
  required_checks: [
    "cooldown_10m",  "second_opinion",
    "write_down_exit", "log_reason", ...
  ]
}
\end{lstlisting}

\paragraph{Schema integrity.}
The schema is a base contract. Extensions may add categories, caps,
or required-checks; they may not modify the base block names. The
$A_{\mathrm{allowed}}$ Profile v1.1 (Section~\ref{sec:a-allowed-mode-profiles})
and the v1.2 MISSION-DEFENSE Extension
(Section~\ref{sec:a-allowed-extension}) both adhere to this schema.

\section{Action Category List (Recommended)}
\label{sec:a-allowed-dict-categories}

The recommended action category set is reproduced in
Section~\ref{sec:a-allowed-categories}. Definitions are repeated here
for self-containment of this reference chapter:

\begin{table}[ht]
\centering
\small
\begin{tabularx}{\linewidth}{lXXX}
\toprule
\textbf{Category} & \textbf{Meaning} & \textbf{Typical example} & \textbf{Main risk} \\
\midrule

\texttt{info} & Information gathering / confirmation
& Read primary info; confirm status
& Low; primarily time-limited risk \\

\texttt{analysis} & Analysis / estimation
& Scenarios, calculations, hypothesis verification
& Medium (over-confidence) \\

\texttt{proposal} & Proposal (reversible)
& Options A/B/C, trial design, ToDo
& Medium (over-specification) \\

\texttt{commit} & Irreversible commit
& Contract, public statement, capital fixation
& High (irreversibility) \\

\texttt{execute} & Execution (action)
& Purchase, send, move, implement
& Medium--High (execution error) \\

\texttt{public} & Public diffusion
& SNS posts, external sharing, public announcements
& High (reputation, irreversible) \\

\texttt{training} & Training (external system)
& Role-play, load training
& Variable (ethics-dependent) \\

\bottomrule
\end{tabularx}
\caption[Action category recommended list]{Recommended action
category list (mirrors Table~\ref{tab:a-allowed-categories}).}
\label{tab:a-allowed-dict-categories}
\end{table}

\section{Mode-Specific Templates (Examples)}
\label{sec:a-allowed-dict-templates}

\paragraph{NORMAL example.}

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
{
  categories: ["info", "analysis", "proposal", "execute"],
  caps: {
    max_irreversible_steps: 0,
    public_scope:           "limited",
    reversibility_min:      "Med"
  },
  required_checks: ["log_reason"]
}
\end{lstlisting}

\paragraph{VENTURE example.}

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
{
  categories: ["info", "analysis", "proposal",
               "execute", "commit"],
  caps: {
    max_irreversible_steps: 1,
    public_scope:           "limited",
    money: { per_action: "small" }
  },
  required_checks: ["write_down_exit",
                    "loss_cap",
                    "cooldown_10m",
                    "log_reason"]
}
\end{lstlisting}

\paragraph{MISSION example.}

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
{
  categories: ["info", "analysis", "proposal",
               "execute", "commit", "public"],
  caps: {
    max_irreversible_steps: 2,
    public_scope:           "public"
  },
  required_checks: ["mission_deadline",
                    "success_criteria",
                    "exit_criteria",
                    "second_opinion",
                    "log_reason"]
}
\end{lstlisting}

\paragraph{SAFE example.}

\begin{lstlisting}[basicstyle=\ttfamily\small,frame=single]
{
  categories: ["info", "analysis", "proposal"],
  caps: {
    max_irreversible_steps: 0,
    public_scope:           "none"
  },
  required_checks: ["cooldown_30m",
                    "sleep_or_break",
                    "log_reason"]
}
\end{lstlisting}
