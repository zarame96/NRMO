\chapter{$A_{\mathrm{allowed}}$: Permitted Action Set}
\label{ch:a-allowed}

\nrmobox{Chapter scope}{
$A_{\mathrm{allowed}}$ defines the categories and caps (upper limits)
of actions permitted by Type ZERO. Extending this dictionary does not
break the OS (because the SOP is fixed). Concrete values are defined
as ratios / counts / time --- not currency amounts --- to avoid
environment-dependent values.
}

% =====================================================================
\section{$A_{\mathrm{allowed}}$ Dictionary --- Action Category
Templates}
\label{sec:a-allowed-dictionary}

The Type ZERO governance layer determines, for each operational mode,
the set of permitted action categories and their associated caps
(upper limits). This dictionary defines the schema; specific concrete
values are defined separately (Section~\ref{sec:a-allowed-concrete-values}).

\section{$A_{\mathrm{allowed}}$ Concrete Values v1.1 ---
Investment / Work / Relationship}
\label{sec:a-allowed-concrete-values}

``Concrete Values'' are defined as asset ratios, limit counts, and
time durations (avoiding environment-dependent currency amounts).

\paragraph{Investment-figure conventions.}

\begin{itemize}
\item \texttt{per\_action\_pct\_portfolio}: percentage of total
investable assets (highest-precision unit).
\item \texttt{max\_single\_name\_pct}: maximum ratio of a single
name after the new addition.
\item For finer precision, expand to absolute amounts by entering
current assets (JPY/USD, cash, securities, DC) into the SP layer.
\end{itemize}

\section{Type ZERO Gate Logic (Mode Selector)}
\label{sec:a-allowed-gate-logic}

\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small,frame=single]
if load == "High":
    mode = "SAFE"
elif buffer == "Low" and (irreversibility == "High"
                          or observability == "Low"):
    mode = "SAFE"
elif mission_flag == True:
    mode = "MISSION"
elif buffer == "High" and observability == "High" \
     and irreversibility != "High":
    mode = "NORMAL or VENTURE"
else:
    mode = "NORMAL"
\end{lstlisting}

\paragraph{Note.}
The mode designation ``NORMAL or VENTURE'' indicates that either is
acceptable; a default of NORMAL with explicit VENTURE-flag override
is the standard implementation.

\section{$A_{\mathrm{allowed}}$ Extension v1.2 --- MISSION-DEFENSE
(HST-N / TTM-PPS Limited)}
\label{sec:a-allowed-extension}

\nrmobox{Update purpose}{
\textbf{Update}: 2026-01-01 \\
\textbf{Scope}: Type ZERO / $A_{\mathrm{allowed}}$ \\
\textbf{Purpose}: Permit HST-N (operational) and TTM/PPS (training)
references in MISSION mode under \emph{defensive use only}. The new
configuration is named MISSION-DEFENSE.
}

\subsection{Activation Conditions (Non-Negotiable)}
\label{sec:a-allowed-mdef-conditions}

The MISSION-DEFENSE configuration activates when both:

\begin{enumerate}
\item \textbf{TTM/PPS detects a recognised pattern} (incoming
pressure / coercion / structural-irreversibility-pattern); AND
\item One of:
\begin{itemize}
\item Irreversibility (load, volatility, governance pressure)
imminent.
\item Observation (HST-N state) approaching boundary.
\end{itemize}
\end{enumerate}

\noindent
Outside these conditions, MISSION-DEFENSE is \textbf{not} active.

\subsection{Non-Negotiable Restrictions}
\label{sec:a-allowed-mdef-restrictions}

\begin{enumerate}
\item TTM/PPS must not produce scripts, dependency designs, or
persuasion patterns.
\item PP and $A_{\mathrm{allowed}}$ separation is preserved.
\item Output is filtered through SOP for defensive use only.
\item SHUTDOWN conditions (load / volatility / irreversibility /
pressure-saturation) override MISSION-DEFENSE.
\end{enumerate}

\subsection{Operational Procedure (5 Steps)}
\label{sec:a-allowed-mdef-procedure}

\begin{enumerate}
\item \textbf{Z.mode = MISSION} (set explicitly).
\item $A_{\mathrm{allowed}}$ categories: \texttt{hst\_map},
\texttt{ttm\_lookup}, \texttt{ttm\_debrief} added.
\item HST-N state $\ge 1$ (observation provided).
\item TTM (ID / category / detection-signature) requested.
\item SOP A/B response (hold / split / confirm / third-party check
/ slow tempo) issued under \texttt{defense\_only\_output}.
\end{enumerate}
