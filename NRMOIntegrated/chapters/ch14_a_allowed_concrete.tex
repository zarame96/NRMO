Investment / Work / Relationship}
\label{ch:a-allowed-concrete}

\nrmobox{Document role}{
``Concrete values'' are defined by \emph{asset ratio}, \emph{maximum
count}, and \emph{time} rather than currency amounts. This avoids
environment-dependent values while keeping operations firm.\\[0.3em]
\textbf{Investment-figure conventions}: \texttt{per\_action\_pct\_portfolio}
is ``\% of total investable balance (including cash)'';
\texttt{max\_single\_name\_pct} is the guideline for ``maximum
ratio of single name after new addition.'' For greater precision,
expand to absolute amounts by entering current assets (JPY / USD,
cash, securities, DC) into the SP layer.
}

\section*{Connections to Other Parts}

\begin{itemize}
\item Investment domain values implement the position limits of the
Investment SOP (Chapter~\ref{ch:investment-sop}, especially
Section~\ref{sec:invest-position-limits}). The 5\% / 2\% / 24h /
no-new-positions caps mirror the SOP's max-single-name and
cooling-off rules.
\item Work and relationship domains correspond to NRMO+Z+PP
secretary-console operations
(Section~\ref{sec:secretary-G}); the
\texttt{public\_scope} caps map directly to the
boundary / agreement / log outputs of the [G] module.
\item These concrete values are the parameter set the Type ZERO
Gate logic
(Section~\ref{sec:a-allowed-gate-logic}) consults when computing
the active mode.
\end{itemize}
