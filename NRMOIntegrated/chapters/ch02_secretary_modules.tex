This interface is the \emph{Secretary Console}, not a decision
engine. It operates exclusively in the Observe / Orient phases and
strictly enforces non-execution guarantees. The chapter is composed
of:

\begin{itemize}
\item Sections 2.1--2.5: the five secretary modules
([R] Reconstruction, [W] Drafting, [Z] Zero-State, [G] Governance,
and the hidden [ORIENTATION] mode);
\item Defensive-Offense and Carryback specifications (a sub-document
governing how training-context outputs interface with operations);
\item Section 2.6: Type ZERO Mode Definitions;
\item Section 2.7: Action Space and Permission Determination;
\item Section 2.8: Logic Gates System (the DAG-based logical
governance layer);
\item Section 2.9: State Labels (HST-N to SOP interface);
\item the $A_{\mathrm{allowed}}$ v1.2 MISSION-DEFENSE extension; and
\item the embedded \emph{Passive Pattern} peer-review paper.
\end{itemize}
