\nrmobox{Preserved baseline / Normative Canon precedence}{
This Part preserves or reconstructs an earlier NRMO specification baseline
for provenance. Where preserved terminology, role descriptions, mode names,
or authority statements conflict with the current NRMO Normative Canon, the
\textbf{Normative Canon controls}. The conflicting older wording remains
historical/non-normative for that meaning.\\[0.5em]

In particular, do not infer current Operational Modes, MISSION semantics,
HOLD typing, SAFE/SHUTDOWN relationship, Norn role, Type ZERO actuator
authority, or sovereign/governance authority boundaries solely from older
wording in this preserved Part. Current meanings are those stated by the
Normative Canon and the repaired current Operational Specification.
}
