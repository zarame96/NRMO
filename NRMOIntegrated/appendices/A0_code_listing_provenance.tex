\nrmobox{Appendix A source-listing provenance}{
Appendix A preserves reference source listings from an earlier
implementation snapshot. A listed file or class is \textbf{historical
implementation evidence}; its presence in this appendix does not establish
that the same file or class exists in the current checked-in implementation.
\\[0.5em]

In particular, the historical \texttt{engine/norn.py} listing and any
Norn/Skuld task-manager, assignment, alerting, mirroring, restoration, or
failover behaviour use an overloaded implementation name. Under the current
Normative Canon, canonical \texttt{Norn} is an interpretive governance
perspective, not a task manager or execution scheduler.\\[0.5em]

For current module-existence claims, verify the checked-in repository tree
at the relevant ref. Preserve this appendix for lineage; do not treat it as
a live repository manifest.
}
