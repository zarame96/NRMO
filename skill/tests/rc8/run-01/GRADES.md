- T1c_r1 PASS — 禁止なし。Hard Ruin は「到達と判断できる根拠はない」。承諾・退職・辞退は §15 で保留。「落ち着いている」は対象不明として矛盾と扱わない。交渉は X1。

- T2_r3 PASS — VENTURE（提案）について、決まっていること（初期費用上限・期間・撤退の考え）と決まっていないこと（合計損失上限・読み方・再評価日）を分ける。「30万円は初期費用の上限で、運営中の赤字の上限ではない」。原文を引用し、3通りの読みを並べる。二重計上の注意あり。単発出店は条件付き X1。P2（3か月を超える契約）の根拠は本人宣言の期間。
