## 3. 破綻境界

- **Hard Ruin**：今回このラインに届くと判断できる根拠はありません。起こりうるのは「条件が確定する前に退職の意思を伝え、その後に条件が悪くなるか、話が消える」という経路です。ただ、生活資金・収入が途切れる期間・退職手続きがわからないため、どこまで深刻になるかは判断できません。
- **Soft Ruin / Passive Ruin**：迷いが長引くと、判断疲れや機会損失につながる可能性があります。ただ、迷っている期間が1週間というだけでは破綻とは言えません。
- **Active Ruin**：条件が変わり続けている最中に承諾や退職を決めてしまうことです。
