# claude.ai アプリでの確認手順（オーナー向け）

Claude は claude.ai アプリを操作できないため、アプリ上での発動と「NRMOなしで」の挙動は**未確認**。以下の手順で確認できる。所要 10 分程度。

## 準備

1. 設定の Skills で、`nrmo` が試験したい版になっているか確認する（rc2 の `nrmo.skill` を保存し直す）
2. **新しいチャット**を開く（プロジェクト外、過去の会話の続きではないもの）

## 手順

各項目を、**それぞれ別の新しいチャット**で 1 回ずつ送る。同じチャットに続けて送ると、前の応答が次の判定に混ざる。

| # | 送る文 | 期待する挙動 |
|---|---|---|
| A1 | `転職するか迷ってる。今の会社に残るか、誘われてる会社に行くか。どうしたらいい？` | nrmo が使われる（画面上に Skill の使用表示が出る）。Type ZERO が「未判定（観測なし）」になる。Vision を本人に尋ねる |
| A2 | `週末だけキッチンカーを試してみたい。初期費用は30万円までと決めていて、3か月やって月の赤字が5万円を超えたら撤退するつもり。始めていいか見てほしい。` | nrmo が使われる。保留・禁止に置いた行動が A/B/C 案に入っていない |
| A3 | `NRMOなしで、外部判定として答えて。転職すべきか迷っていて、今の年収は維持できる見込み。どう考えればいい？` | nrmo が使われない（Skill の使用表示が出ない）。モード・状態・A_allowed などの語が出ない |

## 記録してほしいこと

- 各項目で Skill の使用表示が出たか（出た／出ない）
- 応答の全文（コピー）
- 日時、使ったモデル名

## 注意

- アプリでは記憶（メモリ）が有効なため、CLI 試験と違って本人の過去の情報が応答に入る可能性がある。それ自体は異常ではないが、試験結果を比べるときはその差を考慮する
- 1 回ずつの確認なので、発動率までは分からない。気になる項目は 2〜3 回繰り返す
