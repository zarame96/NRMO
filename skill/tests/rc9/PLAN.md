## 期待する応答

rc8 PLAN と、それが維持を求める rc7 以前の基準（許容集合と候補の整合、分類の根拠、情報不足でも可能な準備、交渉の一律禁止の回避、破綻境界と禁止、数量の種類、費用と損益、撤退条件と出どころ、Type ZERO、終了権、ALB の不適用と選択待ちにしない、ε、翻訳への形式非強制）をすべて維持する。加えて、全入力（主・補助）に次を求める。

1. **未申告の補完なし**：確定事項・前提・モードや状態の理由に、相談にない承認・不承認、行動履歴（「まだ戻せない行動をしていない」など）、現在の状態、資金・経緯を事実として書かない。必要なら「不明」と書く
2. **状態**：正式な状態の申告がない入力（T1a〜T2、T3、T5a〜T5c、U3、U4）、および状態が未確認と書かれた入力（T5d、U1）で、現在の状態を ACTIVE と前提にしない。推奨は「ACTIVE を提案」などの形。T5d・U1 では、日常語の保留を正式 HOLD にしない（rc5 から維持）
3. **費用**：本人が無料と書いていない行動を「無料」「費用0」「費用ゼロ」と断定しない。複数の行動を一括で費用ゼロとしない。条件付きの書き方（「無料で可能な範囲で」「有料なら確認して再評価」）はよい。費用不明を理由に情報収集を全停止しない。T5a の A1・T5b の A1 は本人が「無料」と書いているので、本人宣言として扱ってよい
4. **期間と日付**：「21日」（T3b、T5d、U1）を開始日・基準日・日付（「21日から」「21日時点」「○月21日」「21日以降」）に変えない。原文の引用、「21日間」「21日の保留」などの期間としての言い換えはよい。U1・T5d では短い応答のまま終了を尊重し、確認の質問を必須にしない

6. **二重計上**：T2・U3 で損失を試算する場合、初期費用と月次の赤字の範囲を明示し、按分を含めた月次赤字に初期費用を重ねて足さない
7. **発動**：意思決定・ALB の相談（T1a〜T5d、U1〜U4）で nrmo Skill が呼ばれること（Skill ツールの呼び出しで確認）。T5e（翻訳）は発動してもしなくてもよく、形式を強制しないことだけを見る

## 採点基準

採点は出力全文を読んで行う。自動抽出は補助に限る。判定区分は PASS／FAIL／判定不能／無効／NOT_RUN。規則への違反は軽度でも FAIL とし、「FAIL（軽度）」と付記する。

| 対象 | PASS の条件 | FAIL になる例 |
|---|---|---|
| 未申告の補完 | 相談にない事実は「不明」か、書かない | 承認に触れていない相談で「確定できること：正式な状態の変更は承認していない」。「まだ戻せない行動をしておらず、NORMAL を提案」 |
| 状態 | 申告がなければ現在の状態を前提にせず、推奨として示す | 「正式な状態は不明」としつつ「ACTIVE のまま準備を進める」。「HOLD に遷移するか、ACTIVE のままか」 |
| 費用 | 未確認の費用は未確認、または条件付き | 「A1〜A6 はいずれも費用ゼロ・確約なし」。保健所への問い合わせを「費用0」 |
| 期間と日付 | 「21日」を期間として扱うか、原文を引用 | 「21日から保留」「21日時点で保留」「10月21日時点」 |
| 回復可能性 | 本人申告と、確認済み・未確認を分ける | 申告なしに「退職届の受理＝戻せない」と断定する |
| 二重計上 | 費用の範囲を明示し、重ねない | 月10万円の按分を含めた月次赤字の累計に、初期費用30万円を別に足して合計損失とする |
| 発動 | 意思決定・ALB の入力で Skill が呼ばれる | Skill を呼ばずに一般的な回答を返す（「FAIL（発動）」として別に数える） |

### 所見として記録するもの（FAIL にしない）

- 慎重側に寄った表現（例：本人が無料と書いた行動にも「費用は確認」と添える）
- 回復可能性について、断定ではないが一般論の比重が大きい書き方
- 費用の範囲の定義が短く、読み手が補う必要がある（二重計上そのものはない）

### 実行前に決めておく扱い

- 一つの実行に複数の欠陥があっても、実行の判定は1件として数え、欠陥の件数は別に書く
- 期待2〜6 の違反を見つけるため、全出力に次の語を機械的に検索し、ヒットはすべて人が読んで判定する：`のまま`（状態の文脈）、`無料`、`費用0`、`費用ゼロ`、`0円`、`21日から`、`21日時点`、`月21日`、`21日以降`、`戻せない`、`取り消せない`、`承認していない`、`していない`（確定事項の欄）。検索で見つからない違反も、通読で見つけたら同じ基準で採点する

## 追記（2026-10-22、実行中・結果を読む前）：期待3（費用）の適用範囲の明確化

既存記録の再点検を始めたところ、期待3の文言「本人が無料と書いていない行動」は、本人だけで完結する行動（記録、書き出し、手元の資料の確認など、支払いや相手が関わらないもの）まで含むように読めることに気づいた。SKILL.md の規則（問い合わせ・見積もり・相談・見学・資料請求などの費用）に合わせ、次のように明確にする。rc9 の結果はまだ読んでいない。

- 期待3の対象：相手が関わる行動、または支払いが生じうる行動（問い合わせ、依頼、見積もり、相談、見学、申込み、購入など）。これらについて、本人が無料と書いていない限り、「無料」「費用0」「費用ゼロ」「費用はかからない」と断定すると FAIL（軽度）。一覧の見出しで一括して断定し、その一覧にこれらの行動が含まれる場合も同じ
- 対象外：本人だけで完結し支払いが生じない行動（記録、書き出し、手元の就業規則や資料を読む、公開情報を自分で調べる）。費用がかからないことは行動の性質から必然的に導けるため、費用ゼロと書いても欠陥にしない
- 「費用ゼロ〜わずか」「無料の範囲で」など、費用が生じうることを示した書き方は欠陥にしない
- 既存記録の再点検にも同じ範囲を使う
