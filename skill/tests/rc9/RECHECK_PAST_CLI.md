# 既存の Claude Code 記録（rc3〜rc8）の再点検：rc8-upload1 のアプリ欠陥と同じ型

rc8-upload1 のアプリ応答で見つかった型を、rc3〜rc8 の CLI 出力全文（各33件、計198件）で再点検した。元の採点・報告は書き換えず、各版の `run-01/REPORT.md` 末尾に要約を追記した。

## 方法

- 対象の型：①未申告の補完（承認・行動履歴）②現在の状態を ACTIVE と前提にする ③相手が関わる行動・支払いが生じうる行動の費用を、未確認のまま「無料」「費用0」「費用はかからない」と断定する ④期間「21日」を日付に変える ⑤回復可能性の一般化（所見の型）
- 検索語で候補行を抜き出し（`ACTIVE のまま／を維持／継続`、`費用ゼロ／費用0／0円／無料／費用はかからない／費用なし`、`21日から／21日時点／月21日／21日以降`、`承認していない／しておらず／まだ…していない`、`戻せない／取り消せない`）、前後の文脈を読んで判定した。費用の範囲は rc9 PLAN の追記（`PLAN.md` 末尾）と同じ：本人だけで完結する記録・書き出し・手元資料の確認は対象外、「費用ゼロ〜わずか」など費用の発生を示した書き方も対象外、本人が「無料」と書いた行動（T5a の A1、T5b の A1）も対象外
- **当時の規則で違反と言えるか**：rc3〜rc8 の SKILL.md はすべて「未確認の条件は未確認と明記し、未知を許可やゼロ費用と解釈しない」と「正式な状態が不明なら不明のまま示す」「情報不足なら推測で埋めない」を含む。①〜③はそれぞれの版の規則への違反として訂正する。④は rc3〜rc8 の CLI 出力に該当なし。⑤は rc8-upload1 のレビューと同じく所見として扱い、訂正しない
- 限界：検索語に掛からない言い回しは、通読の範囲でしか拾えていない。採点者は Claude で、当時これらを見落とした
