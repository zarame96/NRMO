## 1. 結論

**今は退職を伝えないでください。情報収集と記録を進めてください。** 転職すべきかどうかは、まだ判断できる材料がありません。
退職の意思表示は、あなた自身が「取り消せない」と言っています。誘いの条件、回答期限、生活資金、何を一番大事にしたいか（Vision）が分からないまま、戻せない一手を打つことになります（正典 §15「情報不足のまま大きく固定化する行動」）。いっぽう、決めないまま負荷の高い状態が続くことも、それ自体がリスクです（§13.2・§13.4）。止めるのは戻せない一手だけにして、確認は今日から進めます。

## 3. 破綻境界

- **戻せない損失（本人申告）**：退職の意思表示
- **Hard Ruin**：当てはまるかどうかは判定できません。
  - 経路①：条件が書面で確定する前に退職を伝え、収入が途切れる。ただし生活資金の規模が不明なので、生活基盤の崩壊に当たるかは不明です。
  - 経路②：高い負荷が続いて健康が大きく悪化する。今回、体調についての申告はありません。
- **Soft Ruin**：高い負荷と決めきれない状態が長引くと、判断疲労や機会損失につながりえます。誘いの期限は不明です。
- **Active Ruin**：負荷から逃れたい勢いで、条件を確認しないまま退職や承諾をしてしまうこと
- **Passive Ruin**：確認もしないまま時間が過ぎ、誘いが流れるか、負荷だけが続くこと

## 4. 可逆性
