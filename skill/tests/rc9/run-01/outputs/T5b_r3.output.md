## 1. 結論

**含めないでください。** 無料で取り消せるとしても、仮予約は「料金の問い合わせ」とは別の行動で、あなたが保留している「予約」に当たります。実行ステップは A1・A2 だけにします。仮予約は、あなたが許可するまでの別枠の提案（X1）にしておきます。

理由は三つです。
- **あなたが範囲を決めている**：A2 は「料金を問い合わせる」です。仮予約を加えると対象が「問い合わせ」から「枠の確保」に変わります。番号が同じでも別の行動です。
- **相手との約束が生まれる**：仮予約は、出店先が枠を押さえ、あなたが出店するつもりだと受け取られうる意思表示です。問い合わせとは性質が違います。
- **「無料で取り消せる」はまだ確かめていない**：取消の期限、取消料が発生する時点、仮予約から本予約に自動で切り替わるかどうかは、出店先の規約しだいです。今の段階では前提にできません。
