## 出力全文

## 1. 結論

まだ「残る／移る」を決められるだけの情報がありません。分かっているのは「誘われている会社から内定が出た」ことだけです。

今やることは、**内定条件を書面で受け取ること、回答期限を確かめること、自分の判断軸を書き出すこと**の三つです。内定の承諾・辞退と、退職を伝えることは、材料が揃うまで保留を提案します。保留しても止まるのは決断だけで、準備は進められます。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL を提案（情報収集が中心で、攻めや守りに寄せる根拠がまだないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の状態は不明 → ACTIVE を提案（確定するのは本人）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告はない）
```

## 3. 破綻境界

- **Hard Ruin（起こりうる経路）**：退職を伝えた後で、内定条件が想定と違ったり内定が取り消されたりして、収入が途切れる。ただし、生活資金も退職の取り消しができるかも分からないため、今回これが破綻境界に当たるかは判定できません。
- **Passive Ruin（起こりうる経路）**：回答期限を過ぎて選択肢そのものがなくなる。期限は分からないので、確認が最優先です。
- **Soft Ruin（起こりうる経路）**：判断が長引いて疲れる。どちらの職場でも、関係がぎくしゃくする。

## 4. 可逆性

- **戻せる**：情報収集、比較、期限の確認
- **戻しにくい可能性がある**：内定の承諾・辞退、退職の意思表示。法的に撤回できるか、相手がどう対応するかは確認していません。法的な判断が必要な場合は専門家に確認してください。

## 5. A_allowed

**今やってよいこと**（こちらで整理した一覧）
- **A1**：内定先に、労働条件を書面（労働条件通知書など）で出してもらうよう依頼する。確約にはならない
- **A2**：内定先に回答期限を確認する
- **A3**：自分の判断軸を書き出す（譲れない条件、5年後にどうなっていたいか）
- **A4**：現職と内定先を同じ項目で並べた比較表を作る（年収、業務内容、裁量、勤務地・働き方、成長性、不安な点）
- **A5**：現職の就業規則で、退職の手続き（申し出の期限など）を確認する。会社には伝えない

**保留すべきこと**
- **P1**：内定の承諾、**P2**：内定の辞退。どちらも判断が大きく固まる行動で、材料が揃っていないため（正典 §15）
- **P3**：退職の意思表示。書面での条件確認と承諾より先にしない（前提：上の Hard Ruin の経路を避けるため）

**条件付き候補（今は A_allowed の外）**
- **X1**：内定先との条件交渉。交渉するかどうか、何を交渉するかが決まっていない
- **X2**：現職に相談する／引き止め条件を聞く。転職を考えていると現職に伝わるため、本人の判断が必要です

**禁止すべきこと**：今の時点で根拠のある禁止はありません。

## 6. Strong Engine 候補

- **A案（最小限）**：A2＋A1。期限と条件を押さえて、選択肢を失わないようにする
- **B案（標準）**：A1＋A2＋A3＋A4。条件と自分の判断軸を突き合わせて、比べられる状態にする
- **C案（前進寄り）**：A1〜A5。比較に加えて退職の手続きも把握し、「移る」と決めた場合にすぐ動ける状態にする

## 7. 推奨判断

**hold**：承諾・辞退・退職（P1〜P3）
**recommend**：B案またはC案。どちらにするかは本人が決めてください。

## 8. 実行ステップ

- **今日**：A2（回答期限の確認）とA1（条件書面の依頼）
- **次に確認すること**：書面を受け取ったら、A3とA4で比較する
- **記録すること**：期限、提示された条件、比較表、迷っている理由

## 9. 撤退条件と再評価条件

- **再評価するタイミング**：条件の書面と回答期限が揃ったとき。ただし、期限が近ければその前に再評価します
- **見直すべき兆候**：書面が出てこない、または条件が口頭の説明と違う。判断を急がされる
- **再評価の日付**：期限が分かってから、本人が決めてください
