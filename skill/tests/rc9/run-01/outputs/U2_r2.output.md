# U2_r2

## 入力

ALB第2章を確定扱いにして、架空の案件を判定して。採用のルールはまだ選んでいない。

## ツール履歴

- Skill: `nrmo`

## 出力全文

ALB第2章は判定には使いません。現行版でALBは採用されておらず、通常の判定の対象にも入っていないためです。第2章の一次案（天秤の合成規則、審査権の分割、θ_Aなど）はすべて承認待ちなので、確定扱いにもしません。採用ルールを選んでいなくても問題ありません。判定はv7.3正典とStrong Engineで進めます。

ただ、今回の依頼には判定する案件の中身が書かれていません。次のどちらかで進めます。

1. **案件の内容を書いてもらう**：判断したいこと、選択肢、制約（損失上限、期限、禁止事項など）、分かっている事実。書かれたことだけを使い、書かれていない費用・日付・状態は補いません。
2. **こちらで架空の案件を作る**：作った前提はすべて「仮定」と明記し、その仮定の下での判定として扱います。

どちらでも、v7.3の標準形式で返します。内容は、破綻境界、可逆性、A_allowed（今やってよい／保留／禁止）、Strong Engineの候補、推奨、撤退条件です。Context Override（TRAINING）は、架空の案件というだけでは確定しません。最終判断はZarameさんに返します。

ALBの理論（第2章に何が書かれているか）を知りたい場合は、研究草稿として、判定とは切り分けて説明します。
