ただ、今回のメッセージには架空案件の中身が書かれていません。こちらで案件を作ると、相談にない事実で判定することになるので、§12 の形式で現状を返します。

```text

1. 何を決めたいか（選択肢）
2. 本人の制約（許容できる最大損失、期限、禁止していること）
3. 既にしたこと、現在の状態（ACTIVE/HOLD など。不明なら不明で構いません）
4. 分かっていれば IRREV / VOL / LOAD に当たる観測（なくても進めます）

暫定判断：
- 案件が届いたら、v7.3 §14 の順序で評価し、§6 の形式で返す
```
