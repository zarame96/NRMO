### 仮定すれば言えること
- 次の収入が書面で確定していない状態で現職を離れる場合は、生活資金によっては大きな損失につながる可能性があります。ただし今回それに当たるかは、資金がいくらあるか分からないので**判定できません**。

### 追加で必要な情報
1. **判断軸**：転職で得たいもの、今の会社で失いたくないもの
2. **相手の条件**：職種、年収、勤務地、雇用形態。カジュアルな打診なのか、正式なオファーなのか
3. **回答期限**の有無
4. **生活資金**：収入が途切れたら何か月持つか
5. **すでにしたこと**：面談、応募、現職への相談など
6. **心身の負荷**：今の職場で消耗しているかどうか
