## 出力全文

## 1. 結論

**転職するかどうかは、まだ決めなくて大丈夫です。** ただ、そのための準備は今から進められます。

- 先方の条件がまだ固まっていない、というのが現状です。何と何を比べればいいのかが決まっていないので、今「残るか・移るか」を決めようとしても判断材料が足りません。
- 先にやるのは次の2つです。①条件を書面でもらう（または、いつ書面になるかを確かめる）、②自分にとって譲れない条件を書き出しておく。
- 先方への承諾と、今の会社への退職の申し出は、条件が書面で固まってからにすることを提案します。最終的に決めるのはご本人です。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案）— 負荷が低く、急ぐ理由が相談からは読み取れないため
Context Override：なし
Type ZERO Mode  ：未判定（IRREV 不明、VOL の対象が未確定）
状態            ：現在の状態は不明。ACTIVE を提案（確定は本人）
MISSION-DEFENSE 拡張：非発動（圧力や誘導があるとの申告がないため）
```

Type ZERO の判定材料は次のとおりです。
- **VOL（変動）**：「誘ってくる会社の条件が毎日のように変わる」という申告があります。これを変動が大きいと読むのは、こちらの解釈です。
- **「状況は落ち着いていて、ほとんど変化はない」**：何についての話か書かれていません（今の会社のことか、自分の状況全体のことか）。誘ってくる会社とは別の話であれば、上の話と矛盾はしません。どちらの話か決まらないので、VOL の判定に使っていません。
- **LOAD（負荷）**：低い（本人の申告）。
- **IRREV（不可逆性）**：観測がありません。§8.3 の割り当て規則はどれも IRREV か現在のモードが分からないと使えないため、今は割り当てられません。

## 3. 破綻境界

- **Hard Ruin**：起こりうる経路は、条件が書面で確定する前に退職を伝え、その後に先方の条件が悪くなったり話がなくなったりして、収入が途切れることです。ただし、生活資金も退職の撤回ができるかも分からないので、今回これが Hard Ruin に当たるかは判定できません。
- **Soft Ruin / Passive Ruin**：毎日変わる条件に振り回されて判断疲れが続くことや、判断材料がないまま先延ばしが長引くことが、経路としてありえます。今その兆しが出ているという申告はありません。
- **Active Ruin**：条件が動いている途中で、その時点の条件で承諾してしまうことです。

## 4. 可逆性

- **戻せる**：記録をつけること、自分の判断軸を書き出すこと、先方に書面や期限を問い合わせること。
- **戻しにくい**：先方への承諾、今の会社への退職の申し出。法律上・契約上どこまで撤回できるかは確かめていません。相手がどう受け止めるかにも左右されます。
- **戻せない**：今回の相談からは確定できません。

## 5. A_allowed

**今やってよいこと**
- **A1**：先方の条件が変わるたびに、「何が・どう変わったか・誰が言ったか」を自分用に記録する。相手への約束は生まれません（正典 §15）。
- **A2**：先方に、現時点の条件を書面（オファーレターなど）でもらえるか、またはいつ確定するかを問い合わせる。条件を聞くだけで、承諾の意思表示はしません。費用は確かめていません。
- **A3**：自分が何を得たくて転職を考えているのか、最低限ゆずれない条件は何かを書き出す。比較のものさしを先に作るためです（§14 の 1 と 5）。
- **A4**：先方に、返事の期限があるかを問い合わせる。期限を確かめるだけで、約束はしません。

**保留すべきこと**
- **P1**：先方への承諾。根拠：条件が固まっていないまま大きく決めてしまうことになるため（§15）。
- **P2**：今の会社への退職の申し出。根拠：P1 が決まる前で、どこまで撤回できるかも確かめていないため（§15）。

**禁止すべきこと**
- 該当なし。ご本人が禁止していることや、確認できた制約がないためです。

**追加提案（現時点では A_allowed の外）**
- **X1**：条件の交渉。どこまでなら飲めるか（A3）と、確定した条件（A2）が揃ってから再評価します。

## 6. Strong Engine 候補

C案が合うのは、急かされているように感じる場合や、期限が分からないことが負担になっている場合です。
