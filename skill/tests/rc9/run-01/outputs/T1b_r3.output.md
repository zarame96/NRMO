## 1. 結論

退職を伝えるのは、まだ先にしてください。いまは、取り消しのきく準備だけを先に進めるのがよいと思います。
- 退職の通知は、あなた自身が「取り消せない」と言っています。一方で、それを決めるための材料（相手先の条件、回答期限、生活資金、何を重視するか）は、相談の中にまだ出ていません。
- 負荷が高い状態がこのまま続くこと自体も、リスクです。何もしないのではなく、比較の材料集めと負荷の記録は今日から始められます。
