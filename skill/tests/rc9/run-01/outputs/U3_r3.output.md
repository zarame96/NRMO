## 1. 結論

ご提示の3つ（保健所、出店場所、車両見積もり）は、どれも**今すぐ着手できます**。今の段階で問い合わせ・見積もり依頼をしても、契約や申込みをしなければ戻せる行動です。
避けたいのは、営業許可の条件と出店料が分かる前に、**車両の契約や出店の申込みをしてしまうこと**だけです。

順番には注意が要ります。保健所が求める設備（車両の仕様）によって見積もり額が変わる可能性があります。そのため、保健所への確認を先にするか、少なくとも同時に進めることをすすめます。

## 3. 破綻境界

**Hard Ruin（取り返しのつかない損失）につながりうる経路**
- 許可の条件を確認する前に車両を購入・製作すると、条件に合わない場合に大きな費用が無駄になる可能性があります。生活基盤に響くほどかどうかは、資金の規模が不明なので判定できません。
- 必要な許可がないまま販売すると、法的な損失になる可能性があります（§13.1）。何が必要かは保健所で確認してください。

**Soft Ruin / Passive Ruin（動かないことで生じる損失）**
- 問い合わせを先延ばしにすると、判断材料が揃わないまま検討だけが続きます。3つとも期限を区切って動くことで、これを防げます。

## 4. 可逆性評価

- **戻せる行動**：問い合わせ、見積もり依頼、記録、自分の上限の書き出し
- **戻しにくい行動**：出店の申込み・予約、手付金の支払い（取消の条件は相手によって違い、未確認です）
- **戻せない行動か未確認**：車両の購入・製作契約。解約できるかは契約条件次第で、確認していません。

## 6. Strong Engine 候補

候補のあいだで意味のある違いは「順番」だけなので、2案にしています。

- **候補A（順番に進める）：A1 → A2 → A3 ＋ A4・A5**
  - 保健所の回答を受けてから、それに合わせた見積もりを取ります。
  - 見積もりの取り直しが減る一方、時間はかかります。
- **候補B（並行して進める）：A1・A2・A3 を同時に ＋ A4・A5**
  - 早く進みます。
  - 車両の見積もりは「保健所の条件次第で変わりうる概算」として扱い、回答が届いたら更新します。

## 7. 推奨判断

**recommend（候補B）**。理由は、どの問い合わせも確約を生まず、並行して進めることで停滞のリスクを下げられるためです。ただし、順番どおりに進めたい場合は候補Aでも問題ありません。最終判断はご本人です。

## 8. 実行ステップ

**今日やること**
1. **A5**：初期費用の上限、合計損失の上限、試行期間を数字で書き出す（暫定で構いません）。
2. **A4**：記録シートを作る（相手 / 日付 / 回答 / 費用 / 条件 / 未確認点）。

**次に確認すること**

**記録すべきこと**
- 回答者と日付、口頭で答えたのか書面で答えたのか、未確認として残った点。
