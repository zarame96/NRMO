## 出力全文

## 1. 結論

今の時点で「残る」「移る」のどちらかに決める必要はありません。誘いの条件がこの1週間、毎日のように変わっているので、比べる相手の中身がまだ定まっていません。

- **オファーの承諾と退職の表明は保留をおすすめします。** 条件が定まらないうちに大きな決定を固めることは、NRMO の許容行動に入らないためです（正典 §15）。
- **条件を書面でもらう、変化を記録する、自分の判断基準を書き出す、の3つは今すぐ進めてよい行動です。** 何もしないまま迷い続けると判断疲労になり、機会も逃しかねないので、止めずに進めます（§13.2・§13.4）。

## 2. 現在モードと状態

```
Operational Mode：NORMAL を提案（負荷は低いが、情報が足りないため、守りにも攻めにも寄せずに情報を集める段階）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV は観測なし。VOL は対象ごとに値が異なり、どれを採るか未確定）
状態            ：現在の状態は不明。ACTIVE を提案（確定は本人）
MISSION-DEFENSE 拡張：非発動（相手から圧力や誘導を受けているという申告はない）
```

Type ZERO を判定しなかった理由：
- 「ここ1週間、毎日のように状況が変わる」は誘ってくる会社の条件についての話です（本人申告）。
- 「状況は落ち着いていて、ほとんど変化はない」が何を指すかは書かれていません。今の会社のことか、ご自身の生活全体のことかは決めつけていません。
- 二つは別のものについての発言なので、矛盾とはみなしていません。
- 「負荷は低い」は本人申告として LOAD に当たると読みました。これはこちらの解釈です。
- IRREV（不可逆性）は観測がないので、§8.3 のどの規則も当てはめられません。

## 3. 破綻境界

- **Hard Ruin**：今回、回復できない損失に当たると判断できる根拠は手元にありません。退職を伝えたあとに取り消せるか、生活資金がどれだけあるかなどは分からないので、断定しません。
- **起こりうる経路**：条件が固まっていないオファーを承諾し、そのうえで今の会社に退職を伝える。その後で条件がさらに変わる、またはオファーが取り消される。法律上・契約上どうなるかは確かめていません。
- **Soft Ruin と Passive Ruin**：相手の条件が変わるたびに迷いがリセットされ、判断疲労と停滞が続く経路です。
- **Active Ruin**：条件の一部だけを見て勢いで決める経路です。

## 5. 許容行動集合 A_allowed

**今やってよい**（ご本人は行動を限定していないので、この一覧はこちらで整理しました）

- **A1** 条件の変化を記録する。日付、変わった項目、変わる前と後、誰の発言か。行うのはご本人で、誰にも何も約束しません。
- **A2** 誘ってくる会社に、条件を書面（オファーレターや労働条件の書面）で出してほしいと頼む。あわせて、回答期限がいつかを聞く。
  - 頼むのは確認だけで、承諾も交渉もしません。
  - 関心があることは相手に伝わりますが、承諾の意思表示にはなりません。
- **A3** 自分の判断基準（年収、仕事内容、勤務地、成長、安定など）を書き出し、今の会社と誘ってくる会社を同じ基準で比べる。
- **A4** 今の会社の就業規則で、退職の手続きと予告期間を読んで確かめる。読むだけで、誰にも伝えません。

**保留**
- **P1** オファーの承諾。根拠：条件がこの1週間毎日変わっているという本人申告と、正典 §15「情報不足のまま大きく固定化する行動」。
- **P2** 今の会社に退職を伝えること。根拠：P1 と同じ。加えて、書面の条件がまだないという前提です。

**禁止**
- 該当なし。根拠になる本人の宣言も、確認できた制約もありません。

**条件付き候補（現時点では A_allowed の外）**
- **X1** 条件の交渉。交渉を望んでいるか、何をどこまで求めるかが分かりません。書面の条件と A3 の判断基準がそろってから改めて検討します。

## 7. 推奨判断

- **承諾と退職表明（P1・P2）：hold**
- **B 案：recommend**

この1週間の一番の問題は、相手の条件が定まらないことです。B 案は、その揺れを相手の側で止めてもらうための行動です。書面を頼んだときの相手の対応そのものも、判断材料になります。

## 8. 実行ステップ

- **今日**

  - A3 で比べ終えている。
  - 回答期限が分かっている。
- **再評価のタイミング**
  - 書面を受け取った時点。
  - 回答期限が分かれば、その数日前。
