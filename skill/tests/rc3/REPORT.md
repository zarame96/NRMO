# rc3 引継ぎ実装記録

## 何を確認したか

起点は da4027075a7b4625b4e98c3d7004defe1e0652b1。rc2 の報告・採点・問題となった出力、本人の要件変更、共有された個人版の補助資料を確認した。

## 問題があったか

rc2 の12実行中4件で、候補に許容列の外の行動が入った。番号を付けるだけでは、同じ番号へ交渉・予約・確約を足す抜け道が残る。T3b_r2 では日常語の「21日保留」を正式 HOLD としていた。現行の専用非発動切替は本人の最新要件に合わない。

## 何を直したか

- 個人版 rc3 の許容行動に出力内の番号を付け、意味・範囲と組合せの制約も照合する。候補、推奨、実行ステップを対象とし、列外行動を追加するための形式的な許容列の書換えを禁じる。
- 日常語の保留と正式な統治状態、相談終了と承認を区別する。
- 専用非発動切替を現行 Skill から除去。旧 T4 は要件変更で対象外とし、原記録を保持する。
- 個人版の用途を維持。共有 PDF 注意事項を対象版・実装確認の限界付きで追加。正典、既存の同梱資料、ALB 本文は変更しない。
- rc2 を archive/v1.0.0-rc2/ に保存。現行パッケージは対象コミットを固定して CI または同じスクリプトで生成し、全ファイルのハッシュと一緒に提供する。旧 rc2 パッケージを rc3 として配らない。
- rc3 の11入力×3回の試験計画と、アプリ確認手順を用意した。

## 検証結果

実装時の環境にはシェル／Claude Code の実行環境がない。rc3 の実モデル試験33件、claude.ai のアプリ試験は **NOT_RUN**。rc2 の実行結果を新版の合格とは扱わない。パッケージ CI の実行結果は PR #22 に対象コミットと run URL を添えて別途記録する。CI が成功しても実モデルの合格を意味しない。

## 次へ進める状態か

候補版のコード・文書・パッケージ検証へ進める。実動作の合格、正式版承認、ALB 第2章採用、T3 採用ルール、マージはいずれも未決。T3 は選択されるまで草稿を判定に使わない暫定動作を保つ。監査最終報告書の欠落部分は新たな原ログがなく未回収で、推定復元していない。
