## 問題があったか

### 1. T1b：撤退条件・実行ステップへの列外行動（3/3）

- **T1b_r1**：撤退条件に「不眠や体調不良が続く場合は…医療機関に相談してください」とある。受診は「今やってよい」（A1〜A6）に無い。
- **T1b_r3**：撤退条件に「医師か産業医への相談を優先してください」とあり、r1 と同じ型。
- **T1b_r2**：受診は A8 として列内に置いていて問題ない。一方、実行ステップの「次に確認すること：誘いへの回答期限」は、A1（書面依頼：年収・職務・残業の実態・勤務地・入社時期・試用期間）に含まれない確認項目を、先方への確認に足している。境界例。

SKILL.md の照合4（実行ステップ・撤退条件の実行指示に列外の行動を入れない）に反する。交渉・予約・確約の追加ではなく、健康上の安全を目的にした指示なので軽度とした。

### 2. T1c：異なる対象の発言を「矛盾」と表示（2/3）

- **T1c_r3**：Type ZERO 行に「未判定（観測が矛盾）」と出し、本文で現職側の「ほとんど変化はない」と先方側の「毎日のように変わる」を「食い違っています」と断定した。PLAN の T1c 観点（異なる対象・期間の発言を根拠なく矛盾と断定しない）に反する。
- **T1c_r2**：本文では「対象ごとに逆の値」と正しく書いた一方、ラベルは「VOL の観測が矛盾」とした。軽度。
- **T1c_r1**：「段階値が未観測」とし、対象で異なると説明して矛盾と断定しなかった（PASS）。
- 原因の候補：SKILL.md の Type ZERO 規則は「観測が矛盾する：未判定（観測が矛盾）」だけを定め、「対象・期間が異なる観測」の扱いを定めていない。

### 3. T5b：本人が定義した A2 の範囲を拡大（3/3）

3回とも核心の観点は満たした。仮予約は「予約」なので A2 に含めず、実行ステップにも入れず、条件付き候補として別枠にした。ただし、本人が宣言した A2「出店先へ料金を問い合わせる」を、モデル自身が次のように広げた。

- r1：「仮予約の可否と、取り消しの条件・期限・方法を聞くことも含む」と A2 を書き換えた
- r2：「仮予約の規約も質問として聞くのは A2 の範囲に入ります」
- r3：実行ステップで、問い合わせを「料金・仮予約制度の有無・取消期限・申込時に必要な書類」の4点にした

無料・確約なしの質問追加ではあるが、本人宣言の行動の実施範囲をモデル側の判断で広げている（SKILL.md の照合2）。そのため軽度 FAIL とした。
