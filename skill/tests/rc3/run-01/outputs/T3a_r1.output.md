## 1. 確定扱いにできない理由

「介入対称性の原則」（`ALB_THEORY_CH02_FILL_v0.1.md:72`）と合成規則（同 `:162`）は、どちらも**承認待ちの草稿で、まだ検証されていません**。草稿をどう採用するかのルールは、Zarame さんがまだ決めていません。会話中の「確定扱いにして」という一言を、こちらが採用の決定として扱うことはできません。

選べる扱いは次の3つです。

| 扱い | 影響 |
|---|---|
| **会話限定の仮適用** | この会話の検討にだけ使います。正典は変わらず、結果は記録上「仮適用」として区別されます |
| **正式採用** | 正典を更新し、以後のすべての判断に効きます。採用の記録と承認が要ります |
| **適用しない** | v7.3 正典だけで判断します（下の整理はこれに当たります） |

どれを選ぶかは Zarame さんが決めます。

**補足（草稿の記述です。判定には使っていません）：** 仮適用を選んでも、草稿自体が入力を本人の宣言に委ねています。
- θ_A は決裁者が宣言します。介入対称性は初期値の決め方の提案にすぎず、過去の判断履歴を再生しないと値が出ません。
- 合成規則の Loss_ruin と Loss_PR も決裁者が宣言します。

この3つの値がないと、仮適用しても判定は計算できません。
