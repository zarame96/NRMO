## 1. 結論

今は退職を伝える段階ではありません。先に、誘ってくれている会社の条件を書面でもらうことを勧めます。取り消せない行動は「退職を伝える」ことです。その前に、取り消せる確認作業で判断材料を揃えます。負荷が高い時期の判断は「今の会社から逃げたい気持ち」に引っ張られやすいので、それと「新しい会社の魅力」を分けて比べる必要があります。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案。負荷が高く、取り消せない一手が控えているため）
Context Override：なし
Type ZERO Mode  ：未判定（VOL 不明）
状態            ：本人の申告なし。推奨する状態は HOLD（確定は本人）
MISSION-DEFENSE 拡張：非発動（誘導や圧力を受けているという申告はないため）
```

- Type ZERO の観測値：
  - IRREV：「退職を伝えたら取り消せない」はご本人の申告です。これを I1 とみなすのは私の解釈です。
  - LOAD：「負荷がかなり高い」はご本人の申告です。L2 に当たるかは不明です。
  - VOL：観測がありません。
  - §8.3 の割り当て規則は、どれも VOL がないと成立しません。
- HOLD を推奨する理由：情報が足りず、負荷が高く、取り消せない一手に近づいているためです（§8.4）。止めるのは退職の通知と入社の確約だけで、情報集めは進めます。

## 3. 破綻境界

| 種類 | 内容 |
|---|---|
| Hard Ruin | 転職先が決まる前に退職を伝え、収入が途切れる。高負荷が続いて健康を大きく崩す |
| Soft Ruin | 負荷で判断力が落ちたまま決めてしまう。比較できないまま迷い続け、判断疲れになる |

## 4. 可逆性

- **戻せる**：条件の確認、情報集め、記録、就業規則を読むこと
- **戻しにくい**：内定の承諾、誘いの辞退（関係と機会を失う）
- **戻せない**：今の会社に退職を伝えること

## 5. A_allowed

**今やってよいこと**（すべてご本人が行う。費用はかからない前提。確約は伴わない）

- A1：誘ってくれている会社に、条件を書面でもらうよう頼む（年収、職務、残業の実態、勤務地、入社時期、試用期間）
- A2：誘ってくれている会社の現場の人と話す機会を頼む。働き方の実態を確かめるため
- A3：今の負荷を1〜2週間記録する（残業時間、睡眠、休日に働いたか）。一時的な負荷か、ずっと続くものかを見分けるため
- A4：今の上司に、負荷そのものについて相談する。転職の話は出さない
- A5：判断基準を書き出す。「残る理由／移る理由」と「今の会社が嫌な理由／新しい会社の魅力」を分けて書き、ご自身の Vision と照らし合わせる
- A6：就業規則を読み、退職の予告期間、有給の残り、賞与の支給条件を確かめる（読むだけ）
- A7：生活資金が何か月分あるかを確かめる
- A8：眠れない、体調が崩れているといった兆候があれば、医師か産業医に相談する（兆候がある場合だけ）

**保留すべきこと**

- P1：退職の意思を誰かに伝えること（上司にも同僚にも）
- P2：内定の承諾や入社の確約
- P3：誘いを断る連絡
- P4：今の会社に転職先の話を出して、引き止め交渉をすること

**禁止すべきこと**

- F1：書面の条件を受け取る前に退職を伝えること
- F2：負荷のピークの日に、その日のうちに決めること

## 6. Strong Engine 候補

- **A案（安全寄り）：A3＋A5＋A6＋A7**　外部には一切接触せず、判断材料だけを揃えます。
- **B案（標準）：A1＋A3＋A5＋A6**　条件を書面で受け取り、今の会社の実態と並べて比べます。
- **C案（攻め）：A1＋A2＋A4＋A5**　両方の会社から同時に情報を取り、比べる時期を早めます。ただし負荷が高い時期にやることが増えます。

A8 は兆候がある場合に、どの案にも優先して行います。

## 7. 推奨判断

- **recommend**：B案
- **hold**：P1 と P2（書面の条件と負荷の記録が揃うまで）
- **reject**：F1（書面の条件を受け取る前に退職を伝えること）

## 8. 実行ステップ

- **今日やること**：A1（条件を書面でもらう依頼）、A3（記録を始める）
- **次に確認すること**：誘いへの回答期限、A6 の就業規則の内容
- **記録すべきこと**：A5 の比較表。とくに「今の会社が嫌な理由」と「新しい会社の魅力」の区別

## 9. 撤退条件と再評価

- **止める・方向を変える条件**
  - 誘ってくれている会社が、条件の書面提示を断る、または内容があいまい → 移る案の評価を下げます。
  - 睡眠や体調の悪化が続く → A8 を優先し、転職の判断はさらに後にします。
- **HOLD を解く条件**：書面の条件と2週間分の負荷の記録が揃い、比較表で判断できる状態になること。解くかどうかはご本人が決めます。
- **再評価日**：誘いの回答期限が分かった時点で決めます。目安として2週間後としましたが、これは私が置いた仮定で、ご本人が決めた期限ではありません。
