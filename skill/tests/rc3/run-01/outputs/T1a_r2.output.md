## 3. 破綻境界（一般的な構造です。あなたの状況にどれが当てはまるかは未確認）

- **Hard Ruin**
  - 次の会社が確定する前に退職し、収入が途絶える
  - 機密の持ち出しや競業避止義務への違反で、法的・信用上の損失が出る
- **Soft Ruin**
  - 判断を先延ばしし続けて疲れる
  - 不満を抱えたまま今の会社にとどまり、長く停滞する
- **Active Ruin**:
  - 条件を確かめないまま勢いで承諾する
  - 撤退条件を決めないまま動く
- **Passive Ruin**
  - 検討しないまま誘いの期限が切れる
  - 適応が遅れて機会を失う
