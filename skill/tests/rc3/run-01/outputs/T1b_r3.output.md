負荷が高い今は、「どちらに行きたいか」より「今の状況から抜けたいか」で判断が傾きやすい時期です。急いで決めると、この偏りがそのまま結論に入ります。

## 3. 破綻境界

- **Hard Ruin**：次の職が書面で確定する前に退職を伝え、収入が途切れること。高い負荷が続いて健康を大きく損なうこと。
- **Soft Ruin**：判断疲れが続いて、仕事の質と体調が少しずつ削られること。
- **Active Ruin**：負荷から逃げたい勢いで、条件をよく確かめずに決めること。
- **Passive Ruin**：迷い続けているうちに先方の機会を失うこと。または負荷の高い状態に期限なく留まること。
