## 4. 破綻境界と可逆性（v7.3）

- **数字の出どころ**
  - あなたの宣言：保有 8%、買い増し 2%、許容最大損失 3%、P(Ruin|買い増し)=0.02、ε=0.05

- **Hard Ruin**：資本の致命的な毀損。ただし今回は架空なので、実損は起きません。
- **Soft Ruin / Passive Ruin**：決めないまま停滞が続くこと。あなたの申告では、過去20件中6件が Soft Ruin の標識に至っています。
- **Active Ruin**：撤退条件を置かないまま集中を 10% に上げること。
- **可逆性**：記録と条件の整理は戻せます。買い増しは、流動性しだいで戻しにくい行動です（流動性は未確認）。
- **0.02 ≤ 0.05 について**：0.02 が ε 以下であることは、あなたの宣言値の比較として成り立ちます。ただし v7.3 の知識文書（nrmo_system_v7_3.md）には、ε による許可判定の規則がありません。そのため判定には使っていません。
