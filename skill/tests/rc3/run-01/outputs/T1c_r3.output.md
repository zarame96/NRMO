## 1. 結論

**今は転職するかどうかを決めず、先方に条件を書面で出してもらうのが先です。**
先方の条件が毎日変わっている今の時点では、比べる相手が決まっていません。今の会社は落ち着いていて負荷も低いので、急いで決める理由も見当たりません。条件が書面で固まってから、判断軸と照らして本人が決めてください。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案）
  理由：今の会社は落ち着いていて負荷も低く、急いで守る理由も攻める理由もないため
Context Override：なし
Type ZERO Mode  ：未判定（観測が矛盾）
状態            ：HOLD を推奨（確定は本人）
MISSION-DEFENSE 拡張：非発動
```

- **Type ZERO が未判定の理由**
  - VOL（変動）について、二つの申告が食い違っています。「ほとんど変化はない」（本人申告・現職側）と「毎日のように状況が変わる」（本人申告・先方側）です。どちらか一方を選んで確定はしていません。
  - LOAD（負荷）は「低い」（本人申告）です。
  - IRREV（不可逆性）は申告がありません。「転職は戻しにくい」というのはこちらの解釈で、観測値ではありません。
- **HOLD を推奨する理由**：先方の条件が確定していないので、情報不足（§8.4）に当たります。ただし「迷っている」は日常語の保留で、正式な HOLD はまだ承認されていません。

## 3. 破綻境界

| 区分 | 内容 |
|---|---|
| Hard Ruin | 書面で条件が確定する前に退職し、その後オファーが取り消し・変更される。収入と生活基盤を失う |
| Soft Ruin | 毎日変わる条件を追い続けて判断疲労がたまる |
| Active Ruin | 口頭の好条件だけで承諾や退職を決める |
| Passive Ruin | 比較しないまま惰性で残り、機会を失う。逆に、情報が揃う前に反射的に断るのも同じ |

**戻れなくなる境目**は、現職に退職の意思を伝えることと、先方への入社承諾に署名することです。

## 5. 許容行動集合 A_allowed

**今やってよいこと**（すべて本人が行い、費用はほぼゼロ、何も確約しません）

- **A1**：先方に、最新の条件を書面（オファーレター／労働条件通知書）で出してほしいと依頼する。依頼だけで、交渉や承諾は含みません。
- **A2**：この1週間の条件の変化を、日付ごとに記録する（年収、役職、勤務地、入社日、業務内容など）。
- **A3**：自分の判断軸を書き出す。「譲れない条件」「最低ライン」「何のために転職を考えたか」の三つです。
- **A4**：現職の条件を、手元の資料や社内規程で確認する（年収、昇給見込み、退職金、退職申告の期限）。上司への相談や意思表明は含みません。
- **A5**：先方に回答期限があるかを確認する。質問だけです。

**保留すべきこと**

- **P1**：入社承諾への署名（書面で条件が確定し、A3 と照合するまで）
- **P2**：現職への退職意向の表明（P1 が済むまで）
- **P3**：先方との条件交渉（書面の条件と A3 が揃うまで）
- **P4**：誘いを断ること（情報が揃う前に断るのは Passive Ruin 側に当たるため）

**禁止すべきこと**

- **F1**：書面で条件が確定する前に退職届を出す
- **F2**：口頭の条件を前提に、生活基盤に関わる確約をする（転居やローンなど）

## 9. 撤退条件

- **止める判断材料にする指標**
  - 書面を依頼しても出てこない
  - 書面が出た後も条件が変わる
  これは先方の意思決定が不安定だというシグナルなので、本人が検討を打ち切るかどうかの材料になります。
- **待つ期間の目安**
  計算上の仮定として1週間（**2026-10-27**）を置いています。本人が決めた期限ではないので、変えて構いません。
- **再開の条件**
  条件が書面で確定し、A3 の判断軸ができていること。この二つが揃えば、P1〜P4 を評価し直せます。
- **再評価の時期**
  書面を受け取った時点か、2026-10-27 のどちらか早い方です。
