- **Hard Ruin**：信用取引・レバレッジ・生活資金を使った集中投資で、資本が致命的に傷つくこと
- **Soft Ruin / Passive Ruin**：根拠なく見送りを続けた結果、資本成長が停滞すること。これも評価の対象です
- **Active Ruin**：決算直前に撤退条件を決めないまま集中して買うこと
- **可逆性**：現物の少額買いは売却で戻せます（ただし損失は確定します）。決算をまたぐ大口の建玉は戻しにくい行動です
