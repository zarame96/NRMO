**撤退ルールの穴（本人宣言を読んだうえでの指摘）**

1. **判定のタイミングが決まっていません。** 3か月後に1回だけ判定するのか、毎月判定するのかで、出うる損失の大きさが変わります。
2. **赤字の定義が決まっていません。** 初期費用の按分や自分の作業時間を赤字に含めるかが未定です。
3. **合計損失の上限が決まっていません。** 「月5万円を超えたら撤退」は、1か月の赤字そのものに上限をかけていません。悪い月が1回あれば、5万円を大きく超えることもありえます。
   - 計算上の仮定として、毎月判定、初期費用は別、各月の赤字が5万円ぎりぎり、とします。この場合、3か月の最悪値はおよそ **30万＋15万＝45万円に、解約違約金を加えた額** です。
   - この数字はこちらの試算で、あなたが決めた上限ではありません。
