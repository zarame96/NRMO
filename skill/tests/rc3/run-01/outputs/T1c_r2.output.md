## 出力全文

## 1. 結論

**転職するかどうかは、今は決めない（推奨：hold）。** 理由は、判断材料になる先方の条件がまだ固まっていないからです。今の会社は落ち着いていて、急いで動く理由が手元にありません。なので「条件を書面で固めてもらう」ことを先にやるのが妥当です。

先方の条件がこの1週間ずっと変わっていること自体も、相手の会社を判断する材料になります。

---

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案）— 今の会社が安定していて負荷も低く、攻めも守りも急ぐ理由がないため
Context Override：なし
Type ZERO Mode  ：未判定（IRREV 不明／VOL の観測が矛盾）
状態            ：推奨する状態は ACTIVE（情報収集を続ける）。確定は本人
MISSION-DEFENSE 拡張：非発動（圧力や誘導を受けているという申告はない）
```

- **LOAD**：低い（本人の申告）
- **VOL**：今の会社は「ほとんど変化なし」、誘ってくる会社は「毎日変わる」（どちらも本人の申告）。対象ごとに逆の値なので、こちらでどちらか一方に決めることはしません。
- **IRREV**：観測していません。退職の意思を伝えると戻しにくくなる、というのはこちらの解釈で、まだ観測値ではありません。
- 「迷っている」は日常語として保留している状態で、正式な HOLD とは違います。

## 3. 破綻境界

| 区分 | 内容 |

| Hard Ruin | 今の会社に退職を伝えた後で、先方の条件が崩れたり内定が取り消されたりして、収入の基盤を失うこと |

- **戻しにくい**：内定を受諾する、今の会社に転職の話をする

## 6. Strong Engine 候補

- **A案（安全寄り）：A1＋A4** 先方とはやり取りせず、記録と判断軸の整理だけをする
- **B案（標準）：A1＋A2＋A4** 書面での提示を頼み、届いた条件を自分の判断軸と照らし合わせる
- **C案（攻め）：A1＋A2＋A3＋A4** 条件が変わる理由と期限まで聞いて、先方の状態を早めに見極める

どの案も、受諾・退職・交渉は含みません。

## 9. 撤退条件と再評価

- **見る指標**：書面を頼んだ後も条件が変わり続けるか。期限を短く切られたり、決断を急かされたりするか
- **止める目安**：書面での提示を断られる、または書面が出た後でまた条件が変わる場合。このときは「この話から降りる」ことを考える材料になります（降りるかどうかはあなたが決めます）
- **再評価のタイミング**：書面が届いた時点。届かない場合は、書面を頼んでから7日後を目安にします（この日数はこちらが置いた仮定で、あなたが決めた期限ではありません）
- **再開の条件**：書面で条件が確定して、自分の判断軸と比べられる状態になったら、残るか移るかの比較に進む

### 追加で必要な情報（推測では埋めていません）
