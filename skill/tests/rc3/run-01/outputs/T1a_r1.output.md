## 破綻境界（仮定すれば言えること）
- **Hard Ruin**：辞めると伝えた後に内定がなくなる、または条件が違う。収入が途切れ、生活が崩れる。
- **Soft Ruin**：迷い続けて判断に疲れる。どちらの会社でも仕事に身が入らなくなる。
