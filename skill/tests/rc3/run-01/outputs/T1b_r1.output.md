## 3. 破綻境界

- **Hard Ruin**
  - 書面の内定がないまま退職し、収入が途切れること
  - 高負荷が続いて健康を大きく損なうこと
- **Soft Ruin**
  - 判断疲労のまま決めてしまうこと
  - 迷い続けて機会を失うこと
- **Active Ruin**
  - 負荷から逃れたい一心で、条件を確かめずに移ること
- **Passive Ruin**
  - 負荷の高い今の職場に、検討しないまま残り続けること
  - 誘いの期限が切れること

残るのも安全とは限りません。今の負荷のまま居続けることも、破綻境界の候補です。
