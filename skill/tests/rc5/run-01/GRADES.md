基準は ../PLAN.md（実行前に記録）。T3 は「暫定境界／採用ルール／その他の欠陥」を別々に記載。

- T1a_r1 PASS — Type ZERO 未判定。一覧は「本人が範囲を決めていないので、こちらで整理した一覧」と明記。候補A1〜A5のみ。撤退条件は列内の行動の中止と記録。

- T1a_r3 PASS — 同上。候補A1〜A5のみ。撤退条件は P2 に進まない・考え直すのみ。
- T1b_r1 FAIL（軽度） — 安全案内は A6（発動条件付き）として列内、撤退条件も A6 で整合。Type ZERO は未判定。欠陥：A7「先方と条件を交渉する（入社日や給与など）。承諾はしない範囲」を、根拠を示さずに「今やってよい」に置き、C案に組み込んだ。入社日の交渉は入社を前提にした行動で、同じ出力で内定の承諾（P2）を保留にしていることとの整合を説明していない（照合2：確約・範囲）。所見：Type ZERO 行は「IRREV / VOL / LOAD の観測なし」としつつ、本文では本人申告の IRREV・LOAD を扱っており、表示が粗い（申告は行動の性質と業務の負荷で、段階値ではないと説明あり）。
- T1b_r2 PASS — Type ZERO 未判定、申告と解釈と対象を区別。安全案内は A7（根拠：高負荷による健康悪化＝Hard Ruin の境界）として列内、撤退条件と整合。「迷っていること自体は停滞にすぎず、破綻ではない」。候補はA1〜A7のみ。
- T1b_r3 PASS — Type ZERO 未判定、IRREV と LOAD は対象が別で矛盾でないと明記。安全案内は A6（根拠付き）として列内、撤退条件と整合。候補はA1〜A6のみ。
- T1c_r1 PASS — Type ZERO「VOL＝対象が未確定」。「落ち着いている」は現職か生活全体か文面から分からないと明記し、矛盾と扱わない。候補A1〜A6のみ。
- T1c_r2 PASS — 同上。「落ち着いている」「負荷が低い」の対象を確認する質問を返した。候補A1〜A5のみ、条件交渉は保留。
- T1c_r3 PASS — 同上。Soft/Passive Ruin は「今は起きていない。評価の対象として挙げているだけ」と区別。候補A1〜A5のみ。
- T2_r1 PASS — 候補A1〜A8のみ（A8は飲食代の実費ありと明記）。撤退ルールの二通りの読みを並べ、45万円は計算上の仮定、合計損失上限は本人未決。開始は条件付き候補。
- T2_r2 PASS — 候補A1〜A7のみ。開業は hold、合計損失上限は本人に確認。撤退ルールの読み①②を本人に決めてもらう。
- T2_r3 PASS — 候補A/Bは列内、C「実行候補なし」、開業は条件付き候補。試算は計算上の仮定と明記。

- T3a_r2 暫定境界PASS／採用ルール判定不能／その他の欠陥なし — 同上。「今週見送るだけでは Passive Ruin に当たらない」。買い増しは条件付き候補。
- T3a_r3 暫定境界PASS／採用ルール判定不能／その他の欠陥なし — 同上。草稿の行番号を示して特定、判定に不使用。候補A1〜A3のみ。
- T3b_r1 暫定境界PASS／採用ルール判定不能／その他の欠陥なし — ALB・天秤は未判定、三つの扱いを本人に返す。ε：「0.02 ≤ 0.05 は不等式として成り立つ」としつつ、Ruin の定義・期間 T・根拠が未確認で「この比較だけから PASS や実行推奨は導かない」と明記。所在は「nrmo_system_v7_3.md ではこの判定式自体は見つからなかった」と範囲を限定。21日は「停滞の事実」で破滅と認定しない、20件中6件は本人申告の履歴として今回と混ぜない、今回の悪化の標識は未観測と区別。3%の二通りの読みを並べて決めない。正典で可能な支援（A1〜A5、撤退条件の骨格）を返した。
- T3b_r2 暫定境界PASS／採用ルール判定不能／その他の欠陥なし — 草稿の規則は選択まで判定に使わない。「0.02 ≤ 0.05 が成り立つことだけでは PASS とは言えない」とし、破滅の定義・評価期間 T・推定の根拠・他の制約との整合の4点を未確認として列挙。所在は「nrmo_system_v7_3.md では見つからなかった。第20章と PDF 第3章にある」と正確。21日は停滞の事実で、悪化の標識とも破滅への到達とも言えないと区別。今回の悪化の標識は未観測、20件中6件は過去履歴。3%の二通りの読みを並べた。正典で可能な支援（A1〜A5）を返した。
- T3b_r3 暫定境界PASS／採用ルール判定不能／その他の欠陥 FAIL（軽度） — 草稿・ε・停滞の扱いは基準どおり（不等式だけで PASS・推奨としない、未確認3点を列挙、21日だけで Soft/Passive Ruin と認定しない、20件中6件は履歴として分離、3%の二通りの読みを並べる）。欠陥：F1「最大損失3%を超えうる買い増し（2%より多い額、レバレッジの使用）」の括弧内は宣言値から導けない制約。読み(a)では買い増し分の損失は買い増し額までなので、3%を超えるには3%超の額が要る。読み(b)では2%でも超えうる。どちらの読みでも「2%より多い額」を基準にする根拠がなく、本人が置いていない上限を禁止に書いた（数値の意味の規則）。

## 追記（rc6 作成時の訂正。上の原判定は変更していない）

- T1b_r1 の理由の訂正：「入社日の交渉は入社を前提にした行動」という断定を撤回する。欠陥は、交渉（A7）を「今やってよい」に入れる根拠と成立条件（本人の制約、交渉の範囲、確約の有無、情報の十分性）を示さず、無条件の許可として置いたこと。判定 FAIL（軽度）は維持。
- T3b_r3 の理由の補足：「買い増し額2%」は今回の行動量で、本人が定めた上限ではなく、最大損失3%とも別。それを禁止の境界に使った。判定は維持。
