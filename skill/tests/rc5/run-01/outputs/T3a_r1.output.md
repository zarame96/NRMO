## 2. ALB 第2章の扱い：どれにするか選んでください

確認した範囲は `ALB_THEORY_CH02_FILL_v0.1.md` §2.2(3) と天秤の節です。θ_A の「介入対称性の原則」も、合成規則 `recommendation = 期待損失の小さい側` も、**承認待ちの一次案（草稿、未検証）**です。

| 扱い | 影響 |
|---|---|
| **会話限定の仮適用** | この会話の検討にだけ使います。正典は変わらず、結果は「仮適用」と区別して記録されます |
| **正式採用** | 正典を更新し、以後の判断すべてに効きます。採用の記録と承認が必要です |
| **適用しない** | v7.3 正典だけで判断します（今回の出力はこれに相当します） |

参考までに、草稿の記述では θ_A、Loss_ruin、Loss_PR の値はどれもあなたが宣言するものです。P_PR はあなた自身の過去の停滞履歴から推定し、履歴が足りなければ INSUFFICIENT_HISTORY で ALB は介入しません。そのため、仮適用を選んでもこれらの値がないうちは判定を計算できません。
