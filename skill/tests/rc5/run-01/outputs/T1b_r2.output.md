## 出力全文

## 1. 結論

まだ決めなくて大丈夫です。今の時点で「残る」「移る」のどちらかを選ぶ材料はありません。
戻せないのは退職を伝えることだけです。その手前の情報集めと準備は、どれもやり直しがききます。おすすめは、まず約2週間で比べる材料をそろえること（B案）です。退職を伝えるかどうかは、そのあとで決めればよい話です。

順番が大事です。**誘われている会社から条件を書面でもらう → 内定を承諾する → 退職を伝える**。この順を逆にしないでください。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案）— 負荷が高い状態で、戻せない一手が控えているため
Context Override：なし
Type ZERO Mode  ：未判定（VOL の観測なし。LOAD は「負荷がかなり高い」という本人の申告を
                  こちらが高い側と読んだだけで、段階は未確定）
状態            ：推奨は ACTIVE（戻せる準備だけ進める）。確定は本人
MISSION-DEFENSE 拡張：非発動（先方からの圧力の申告なし）
```

観測値の出どころは次のとおりです。
- IRREV：「退職を伝えたら取り消せない」は本人の申告です。対象は退職を伝える行為です。
- LOAD：「負荷がかなり高い」は本人の申告で、対象は今の会社の仕事です。心身の状態についての申告ではありません。
- VOL：観測なし。

## 3. 破綻境界

- **Hard Ruin**
  - 次が決まる前に退職して、収入が途切れること
  - 高い負荷が続いて、健康を大きく損なうこと
- **Soft Ruin**
  - 判断疲れで動けなくなること
  - 誘いの期限が切れて機会を失うこと
- **Active Ruin**
  - 負荷のピークで、勢いのまま退職を伝えてしまうこと
- **Passive Ruin**
  - 高い負荷のまま決めずに消耗が続き、誘いもなくなること

迷っていること自体は「停滞」にすぎず、破綻ではありません。今回は期間も申告されていません。

## 4. 可逆性

- **戻せる**：条件の確認、先方との面談、負荷の記録、比較表づくり、家計の確認
- **戻しにくい**
  - 内定承諾：承諾後に断った場合の扱いは確認が必要です。ここでは断定しません。
  - 今の会社の人に転職を考えていると伝えること
- **戻せない**：退職の意思を伝えること（本人の申告どおり）

## 5. A_allowed

**今やってよいこと**
- **A1**：誘われている会社に、条件を書面で出してもらうよう頼む。オファーレターや労働条件通知書で、年収・職務・勤務地・試用期間・入社日・回答期限を確認します。問い合わせだけで、何も約束しません。
- **A2**：誘われている会社と面談し、業務の実態・チーム・残業の実態を聞く。約束はしません。
- **A3**：今の仕事の負荷を1〜2週間記録する。労働時間・睡眠・負荷の原因・一時的なものかどうか、を書きます。
- **A4**：判断の軸を本人が書き出し、両社の比較表を作る。
- **A5**：生活防衛資金が生活費の何か月分あるかを確認する。
- **A6**：上司に業務量だけを相談する。転職を考えていることには触れません。
- **A7**：睡眠・食欲・体調の悪化が2週間以上続く場合は、産業医か医療機関に相談する。これは「高負荷による健康悪化」という Hard Ruin の境界にあたるために置いています。

**保留すべきこと**
- **P1**：内定の承諾（A1 で書面の条件が確認できるまで）
- **P2**：退職の意思を伝えること（P1 が済むまで）
- **P3**：今の会社に転職を考えていると伝えること
- **P4**：今の会社に引き止め条件を出させる交渉

**禁止すべきこと**
- **F1**：書面の内定がないうちに退職を伝えること
- **F2**：負荷のピークで、その場の勢いで退職を表明すること

## 6. Strong Engine 候補

- **A案（安全寄り）**：A3＋A4＋A5＋A7
