## 出力全文

## 1. 結論

今の時点では、転職するか残るかを決めなくて大丈夫です。先に**誘っている会社の条件を書面で固めてもらってください**。

- 内定の承諾も、現職への退職の申し出も、条件が固まるまで待つ（hold）。
- 一方で、書面の依頼・変化の記録・自分の判断基準の整理はすぐ進める（recommend）。

理由：条件が毎日変わっている今決めると、まだ決まっていない条件で戻しにくい選択をすることになります（§15「情報不足のまま大きく固定化する行動」）。ただ、何もしないのも機会損失なので、止めずに情報を集めます。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。負荷が低く、急いで決める理由も申告されていないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV＝観測なし／VOL＝対象が未確定／LOAD＝低い〔本人申告〕）
状態            ：推奨は ACTIVE（情報収集を続ける）。確定するのは本人
MISSION-DEFENSE 拡張：非発動（圧力の申告なし）
```

- 「落ち着いている」と「毎日のように変わる」は、対象が違う観測なので矛盾ではありません。変わっているのは「誘っている会社の条件」です。一方、「落ち着いている」が現職のことなのか、生活全体のことなのかは、いただいた文面からは分かりません。
- §8.3 の割り当て規則はどれも IRREV（不可逆性）が要るので、Type ZERO は割り当てていません。
- 「迷っている」という日常語の保留は、正式な状態 HOLD とは扱っていません。
