# 転職相談：A1・A2 の範囲での整理（NRMO v7.3）

## 1. 結論

- **「A1 を使って最終面接と入社日の交渉まで進める」案は、今の実行候補に入れられません。** A1 はあなたが決めたとおり「人事への給与条件の問い合わせ（返信を読むまで、確約なし）」です。最終面接と入社日の交渉は、保留中の「面接」と「条件交渉」そのものです。入社日を決めると退職日も決まるので、「退職」の保留にも関わります。そのため、この案は**条件付き候補（現時点では A_allowed の外）**として別枠に置きます。
- 今できる候補は A1 と A2 で作れる2案だけです。推奨は **recommend（候補B：A1＋A2）** です。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。可逆な情報収集だけで前に進める段階のため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：ACTIVE を推奨（確定はあなた）
MISSION-DEFENSE 拡張：非発動（圧力・誘導の申告なし）
```

応募などを「保留」と言っているのは日常語の保留で、正式な状態 HOLD の承認ではありません。A1・A2 は実行できるので、HOLD にはしていません。

## 3. 破綻境界

| 区分 | この相談で該当しうるもの |
|---|---|
| Hard Ruin | 転職先が決まる前に退職し、収入が途絶えて生活基盤が崩れる。入社日を確約した後に撤回して、信用を大きく損なう |
| Soft Ruin | 情報収集だけを続けて判断に疲れ、動けなくなる |
| Active Ruin | 給与水準も生活費の下限も分からないまま、面接や入社日の交渉に進んで条件を固めてしまう |
| Passive Ruin | 問い合わせも集計もせず、機会を逃す |

戻れなくなる地点は「入社日・退職日の確約」と「退職の意思表示」です。

## 4. 可逆性

- **戻せる**：A2（自分だけで完結）。A1 は、確約しないと明記すれば実質的に戻せます。
- **戻しにくい**：応募、面接（先方に記録が残る）、条件交渉
- **戻せない（実質的に）**：入社日の確約、退職の意思表示

## 5. A_allowed

**今やってよい（あなたの定義のまま）**
- **A1**：人事に給与条件をメールで問い合わせる。行うのはあなた、費用は無料、期間は返信を読むまで、応募・交渉の確約はなし。質問は給与条件だけで、他の項目は足しません。
- **A2**：自分の生活費を集計する。行うのはあなた、費用は無料、確約はなし。

**保留**
- **P1** 応募
- **P2** 条件交渉
- **P3** 面接
- **P4** 退職

**禁止**
- **F1** 収入の見通しがないまま退職を先に決めること

**追加提案（許可待ち。候補には入れていません）**
- **X1**：人事の返信に応答すること。A1 の範囲は「返信を読むまで」なので、返信への応答は含まれません。

**条件付き候補（現時点では A_allowed の外）**
- **あなたの案：A1 の後、最終面接と入社日の交渉まで進める**
  - 実際に含まれる行動：P1 応募、P3 面接、P2 交渉。入社日を決めるので P4 退職の時期にも関わります。
  - 満たされていない条件：P1〜P3 の許可（とくに入社日の交渉に進むなら P4 退職の時期の判断も）、A1 の返信で分かる給与水準、A2 で分かる生活費の下限
  - 再評価できる時期：A1 の返信と A2 の集計がそろい、あなたが保留の一部を解除したとき

## 6. Strong Engine 候補

- **B案（標準）：A1＋A2**
  - 問い合わせと集計を並行して進め、返信が来たら給与と生活費を突き合わせます。

## 7. 推奨判断

**recommend：B案（A1＋A2）**

理由：どちらも無料で、確約がなく、戻せます。二つの結果がそろえば、条件付き候補を再評価するための判断材料（給与水準と生活費の下限）がそろいます。
