## 出力全文

## 1. 結論

**いまは、転職するかどうかを決めない方がいいです（hold）。** ただ、何もせず待つ必要もありません。先方の条件を書面で確定させるための、取り消しのきく準備を進めるのがおすすめです（B案を recommend）。

先方の条件が毎日変わっている以上、比べる相手の中身がまだ決まっていません。この状態で決めると、どちらを選んでも、すぐに変わってしまう条件をもとに判断することになります。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。負荷は低いと本人が申告しており、差し迫った圧力の申告もないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV 観測なし／VOL の対象が未確定）
状態            ：転職判断について HOLD を推奨（§8.4 の「情報不足」に当たるため。確定は本人）
MISSION-DEFENSE 拡張：非発動（先方からの圧力・期限の押し付けは申告されていない）
```

Type ZERO の内訳です。
- **LOAD**：低い（本人の申告）。
- **VOL**：対象によって違います。誘われている会社の条件は、この1週間毎日のように変わっています（本人の申告）。「状況は落ち着いていて、ほとんど変化はない」は、何についての話か分かりません（現職のことか、本人の生活全体のことか）。対象が違うので、矛盾とは扱っていません。
- **IRREV**：観測がありません。退職や内定承諾は戻しにくい、というのはこちらの解釈で、観測値ではありません。
- §8.3 の遷移規則はどれも IRREV が必要か、VENTURE からの遷移を前提にしています。そのため、ここでは割り当てていません。

## 3. 破綻境界

- **Hard Ruin**：先方の条件が書面で確定しないまま現職を辞め、そのあと条件が下がるか、話自体がなくなること。収入が途絶え、生活基盤が崩れるおそれがあります。
- **Active Ruin**：口頭で聞いた「今日の条件」で、その場で承諾すること。
- **Soft / Passive Ruin**：先方の変更に付き合い続けて判断に疲れ、保留がいつまでも続くこと。逆に、現職に残る場合の見通しを確かめないまま、なんとなく残ることによる機会損失。どちらも今は起きていません。評価の対象として挙げているだけです。

## 4. 可逆性評価

- **戻せる**：記録すること、条件を質問すること、書面での提示を頼むこと、自分の判断基準を書き出すこと。
- **戻しにくい**：現職の上司や同僚に転職を検討していると話すこと（情報は回収できません）。
- **戻せない、またはそれに近い**：内定承諾書への署名、退職の意思表示。

## 5. 許容行動集合 A_allowed

**今やってよいこと**（すべて本人が行うもので、費用は時間だけ、確約はありません）
- **A1**：先方の条件変更を日付つきで記録する（何がどう変わったか）。1日5〜10分ほど。
- **A2**：先方に、最終条件を書面（オファーレターなど）で出してもらうよう頼む。承諾の確約はしません。
- **A3**：先方に、条件が変わる理由と、条件が確定する見込みの時期を質問する。
- **A4**：先方の最終条件を見る前に、自分の判断基準を書き出す。譲れない条件、最低ライン、いつまでに確定しなければ見送るかの期限です。期限の値は本人が決めます。
- **A5**：現職に残った場合の1〜3年の見通しを自分の中で整理する。社内には話しません。

**保留すべきこと**
- **P1**：内定承諾・署名（書面の条件が確定し、A4 の基準と照らし合わせるまで）。
- **P2**：現職への退職の意思表示。
- **P3**：現職での転職相談や引き留め交渉（露出が戻せないため）。

**禁止すべきこと**
- **F1**：書面のない口頭の条件をもとに、退職届を出すことや退職日を確定させること。

## 6. Strong Engine 候補

- **A案（安全寄り）**：A1＋A4。記録と基準づくりだけ行い、先方が自分から確定させるのを待ちます。
- **B案（標準）**：A1＋A2＋A3＋A4。基準を固めたうえで、こちらから書面での確定を求めます。
- **C案（攻め）**：A1＋A2＋A3＋A4＋A5。両方の選択肢を同時に具体化し、書面が届いた時点ですぐ比べられるようにします。

どの案も、保留・禁止の行動は含みません。

## 7. 推奨判断

- 転職するかどうかの決定：**hold**（比べる対象が確定していないため）
- 準備：**B案を recommend**。負荷が低いと申告されているので、A5 まで広げた C案も選べます。

## 8. 実行ステップ

- **今日やること**：A4（判断基準と見送り期限を書き出す）、A1（ここ1週間の変更をさかのぼって記録する）
- **次に確認すること**：A2・A3（書面での提示の依頼と、確定時期の質問）
- **記録すべきこと**：先方の回答内容と回答日、書面が出たかどうか、A4 の基準からどれだけずれているか

## 9. 撤退条件

- **止める指標**：書面で提示されたあとも条件が変わる、または A4 で本人が決めた期限までに確定しない場合。そのときは、この話を見送るかどうかを本人が判断します。
- **再開できる状態**：書面の条件が確定し、それ以降変わっていないこと。
- **再評価日**：書面を受け取った時点、または A4 の期限のうち早い方。
- **再評価条件**：書面の条件を A4 の基準と A5 の見通しに並べ、P1・P2 を保留から外すかどうかを本人が判断します。
