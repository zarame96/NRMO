## 3. 破綻境界

**本人が宣言した数値**
- 保有比率 8%
- 買い増し額 資金の2%
- 許容できる最大損失 資金の3%
- ε=0.05、P(Ruin|買い増し)=0.02（本人の見積もり）

**計算上の仮定**
- 買い増しすると X の比率は 8%＋2%＝10%（資金総額は変わらない前提）。

**3% の読み方は二通りあり、どちらかに決めていません**
- (a) **X 全体（10%）の損失上限**の場合：X が約30%下がると上限に届きます（計算上の仮定）。
- (b) **買い増し分（2%）だけの損失上限**の場合：買い増し分が全損しても2%なので、上限の内側です。ただし既存の8%分の損失は対象外になります。

**破綻の区分**
- **Hard Ruin**：資本の致命的な毀損。X に固有の閾値は宣言されていません。
- **Active Ruin**：集中が 8%→10% に上がることと、撤退条件がないまま建てることが経路になります。
- **Soft Ruin / Passive Ruin**：
  - 21日間止まっていることは**停滞の事実**です。これだけで破滅とは認定しません。
  - 「20件中6件が標識に至った」は本人申告の履歴として記録します。今回の案件の認定には混ぜません。
  - 今回の悪化の標識は観測されていません。

**ε との比較**：0.02 ≤ 0.05 は不等式として成り立ちます。ただし、§1 の3番（Ruin の定義、期間 T、根拠）が未確認です。この比較だけから PASS や実行推奨は導きません。また、`nrmo_system_v7_3.md` ではこの判定式自体は見つかりませんでした。
