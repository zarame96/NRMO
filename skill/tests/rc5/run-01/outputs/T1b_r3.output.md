# T1b_r3

## 入力

転職するか迷ってる。今の会社に残るか、誘われてる会社に行くか。退職を伝えたら取り消せないのは分かってる。最近は仕事の負荷がかなり高い。どうしたらいい？

## 出力全文

## 1. 結論

**今は退職を伝える段階ではありません。** ただし「迷ったまま何もしない」のも危険です。退職を伝えるのは戻せない一手なので、その前に**戻せる確認作業を2週間ほどで済ませる**ことを勧めます（B案）。どちらの会社にするかは、確認がそろった時点であなたが決めることです。

一番避けたいのは、「負荷がつらいから」という理由だけで、誘い先の条件が書面で固まる前に退職を伝えることです。こうなると、現職と誘い先の両方を失う可能性があります。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案）— 負荷が高い状態で、戻せない判断が目の前にあるため
Context Override：なし
Type ZERO Mode  ：未判定（VOL の観測なし）
状態            ：不明。「迷っている」は日常語で、正式な HOLD ではない
MISSION-DEFENSE 拡張：非発動
```

Type ZERO を未判定にした理由：
- IRREV：「退職を伝えたら取り消せない」はあなたの申告です。対象は退職の意思表示です。
- LOAD：「負荷がかなり高い」もあなたの申告です。対象は現職の業務です。L1／L2 のどちらに当たるかは決められません。
- VOL：観測がありません。遷移規則はどれも VOL か I0 を必要とするため、割り当てられません。

IRREV と LOAD は対象が別なので、矛盾ではありません。

## 3. 破綻境界

| 種類 | 内容 |
|---|---|
| Hard Ruin | ① 退職を伝えた後に誘いがなくなり、収入が途絶える（生活基盤）<br>② 高負荷が続いて健康を大きく損なう |
| Soft Ruin | 迷い続けることによる判断疲労。両方の職場で力を出せなくなる |
| Active Ruin | 負荷から逃れたい衝動で、条件を確認しないまま退職を伝える |
| Passive Ruin | 誘いの期限が切れて失われる。高負荷を放置して体調を削り続ける |

戻れなくなる線は「退職の意思表示」と「内定承諾」の2つです。

## 4. 可逆性

- **戻せる**：情報収集、条件の質問、記録、資金の計算、体調の相談
- **戻しにくい**：現職の上司に業務量を相談する（関係や評価に多少の影響があり得ます）
- **戻せない**：退職の意思表示。条件確認前の内定承諾

## 5. A_allowed

**今やってよい**
- **A1**：誘い先に質問する。内容は、書面での条件（年収・職務・勤務地・入社日）、回答期限、選考や手続きが残っているか。質問だけで、承諾はしません。
- **A2**：現職の負荷を2週間記録する（労働時間、睡眠、体調、休日に回復できているか）。
- **A3**：無収入でも生活が何か月持つかを計算する（貯蓄÷月の支出）。
- **A4**：転職とは別の話として、上司に業務量の調整を相談する（転職の話は出しません）。
- **A5**：判断軸を書き出す。「何が満たされれば行く／残る」をあなた自身の言葉で書きます。
- **A6**：不眠、食欲の低下、休日も回復しない状態が続く場合は、産業医か医療機関に相談する。根拠は、申告された高負荷と、Hard Ruin②です。

**保留**
- **P1**：退職の意思表示。条件の書面、資金の月数、判断軸の3つがそろうまで。
- **P2**：内定の承諾。書面で条件を確認するまで。

**禁止**
- **F1**：誘い先の条件が書面で確定する前に退職を伝えること。

## 6. Strong Engine 候補

- **A案（安全寄り）**：A2＋A3＋A6。まず自分の状態と資金を把握し、誘い先への連絡は後にします。期限がある場合は失うリスクがあります。
- **B案（標準）**：A1＋A2＋A3＋A5。誘い先の条件と自分の側の情報を並行して集め、比べられる状態をつくります。
- **C案（攻め）**：A1＋A2＋A3＋A4＋A5。B案に加えて、現職の負荷が調整できるかも試します。「残る」という選択肢の中身も確かめられます。

どの案にも退職の意思表示は入っていません。

## 7. 推奨判断

- **B案：recommend**。現職の負荷を下げられる見込みがあるなら、C案もあり得ます。
- **退職の意思表示（P1）：hold**

## 8. 実行ステップ

- **今日**：A3（生活資金の月数を計算）。A2の記録を始める。
- **今週**：A1（誘い先に書面の条件と回答期限を質問）。A5（判断軸を3〜5行で書く）。
- **記録すること**：毎日の労働時間・睡眠・体調、誘い先の回答内容と日付。

## 9. 撤退・再評価条件

- **再評価日**：2週間後。誘い先の回答期限がそれより早ければ、その前日です（期限はまだ分かっていません）。
- **再評価で比べるもの**：誘い先の書面条件、現職の負荷が調整できる見込み、資金の月数、判断軸。この4つで「行く」か「残る」かを比べます。
- **書面が出ない、または条件が口頭と大きく違う場合**：転職の検討を止めます。
- **体調の兆候が続く場合**：転職の判断より先に A6 を行います。
- **退職を伝えてよい条件**：書面での条件確認が済み、承諾の手続きを確認し、資金の月数を把握していること。
