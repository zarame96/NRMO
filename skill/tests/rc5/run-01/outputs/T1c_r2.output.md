# 転職判断：NRMO v7.3 による整理

## 1. 結論
先方の条件が書面で固まるまでは、転職するかどうかを決めないことを勧めます。
条件が毎日変わっている今は、残るか移るかを比べられる状態ではありません。比べる前に、条件を書面で固めてもらう必要があります。最終判断はあなたが行ってください。

## 2. 現在モードと状態
```text
Operational Mode：NORMAL（提案。急ぐ理由が示されておらず、負荷も低いと申告されているため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV の観測なし。VOL は対象ごとに異なる。下記参照）
状態            ：転職判断について HOLD を推奨（理由は情報不足。確定はご本人）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告がないため）
```
観測値の扱い：
- 「落ち着いていて、ほとんど変化はない」：どれのことか不明です（現職か、生活全体か）
- 「条件が二転三転、毎日変わる」：先方の会社の話で、期間はここ1週間です（ご本人の申告）
- 「負荷は低い」：ご本人の申告です。ただし何の負荷かは確認していません

この二つは対象が違うので、矛盾ではありません。ただ、どちらを VOL とするかが決まらないため、Type ZERO は割り当てません。

## 3. 破綻境界
- **Hard Ruin**：口頭条件のまま現職に退職を伝え、その後に先方が条件を撤回する。収入と生活基盤が崩れます。
- **Soft Ruin**：揺れる条件を追い続けて判断疲労がたまる。現職側に停滞があるかどうかは未確認です。
- **Active Ruin**：条件が定まらないまま、期限の圧力だけで承諾する。
- **Passive Ruin**：書面化を求めずに待ち続け、機会を判断しないまま失う。
- **戻れない境界**：退職の意思表示と内定承諾。

## 4. 可逆性
- **戻せる**：記録、自分の判断軸の整理、先方への確認依頼
- **戻しにくい**：条件交渉（先方との関係に影響します）
- **戻せない**：退職の意思表示、内定承諾後の辞退（信用に影響します）

## 5. A_allowed
**今やってよいこと**
- **A1**：先方の条件変化を日付ごとに記録する（あなたが行う。費用ゼロ）
- **A2**：先方に、確定した条件を書面（オファーレター等）で出してほしいと依頼する。依頼だけで、交渉や約束はしない
- **A3**：あなた自身の判断軸を書き出す。譲れない条件と、何のために移るのか
- **A4**：先方に回答期限を確認する
- **A5**：現職の就業規則で退職予告期間を確認する。誰にも伝えずに行う

**保留すべきこと**
- **P1**：内定承諾
- **P2**：現職への退職意向の表明
- **P3**：条件交渉。書面を受け取ってから再評価する

**禁止すべきこと**
- **F1**：書面のない条件を前提に、承諾や退職の手続きを進める
- **F2**：期限の圧力だけを理由に即決する

## 6. Strong Engine 候補
- **A案（安全寄り）**：A1＋A3。先方には連絡せず、記録と判断軸の整理だけ行う
- **B案（標準）**：A1＋A2＋A3＋A4。書面化と期限の確認を求め、比べる材料を揃える
- **C案（攻め）**：A1＋A2＋A3＋A4＋A5。書面が届いたらすぐ動けるよう、現職側の手続き条件も調べておく

## 7. 推奨判断
- 転職するかどうか：**hold**
- 進め方：**B案を recommend**。早く動きたい場合は C案
- 理由：B案はすべて取り消しのきく行動だけでできています。さらに、先方の条件がどこまで定まるかを確かめる材料になります。

## 8. 実行ステップ
- **今日やること**：A1（この1週間の変化を日付つきで書き出す）、A3
- **次に確認すること**：A2、A4。書面の有無と回答期限
- **記録すべきこと**：条件が変わるたびに、何がどう変わったか、誰が言ったか

## 9. 撤退条件と再評価
- **再評価日の案**：書面を受け取った時点。届かなければ 2026-10-28（1週間後の仮置き）
- **再評価の条件**：書面の条件が、A3 で書いた判断軸に照らして比べられる状態になっていること
- **見る指標**：書面化を依頼したあとも条件が変わり続けるかどうか。その場合に先方への信頼をどう評価するかは、あなたが決めてください。
- **再開できる状態**：条件が書面で固まり、期限が分かっていること。その時点で、残るか移るかを比べ直します。
