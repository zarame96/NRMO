## 出力全文

## 1. 結論

今の段階では、退職を伝えるのも内定を承諾するのも保留をおすすめします。残るか移るかを決める前に、誘われている会社の条件を書面で確認し、今の会社の負荷が一時的なものか構造的なものかを分けて把握してください。この2つが揃えば比較できます。退職を伝えたら戻せないので、それより前の段階で確かめておくことが一番効きます。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案。戻せない行動が控えていて、負荷も高いと伺ったため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：推奨する状態は、退職通知と内定承諾について HOLD、情報収集は ACTIVE（確定はご本人）
MISSION-DEFENSE 拡張：非発動（先方からの圧力や急かしは伺っていない）
```

Type ZERO の補足：
- 「退職を伝えたら取り消せない」はご本人の申告で、退職を伝えるという行動の性質です。案件全体の IRREV 値ではありません。
- 「仕事の負荷がかなり高い」もご本人の申告で、対象は今の会社の業務です。L1 か L2 かの段階は示されていません。
- VOL は観測がありません。§8.3 の規則はどれも VOL か LOAD の段階を必要とするため、割り当てられません。

## 3. 破綻境界

- **Hard Ruin**：条件が固まる前に退職を伝え、内定の取り消しや条件の悪化が起きて、収入が途切れること。もう一つは、高負荷が続いて健康を重く損なうことです。
- **Soft Ruin**：迷ったまま高負荷が続き、判断疲れがたまること。
- **Active Ruin**：負荷から逃れたい一心で、比較しないまま即決すること。
- **Passive Ruin**：先方の回答期限を過ぎて機会を失うこと。または、負荷が構造的なのに放置すること。
- **戻れない線**：退職を伝えること。内定の承諾と辞退も戻しにくく、辞退すれば機会が閉じます。

## 4. 可逆性評価

| 区分 | 行動 |
|---|---|
| 戻せる | 条件の確認、質問、資金の確認、記録、判断軸の書き出し |
| 戻しにくい | 内定の承諾、内定の辞退、今の会社の上司に転職の意向を話すこと |
| 戻せない | 退職を伝えること（ご本人の認識どおり） |

## 5. 許容行動集合 A_allowed

**今やってよいこと**
- **A1**：先方に条件を書面でもらう（労働条件通知書かオファーレター。給与、職務、配属、勤務地、入社日、試用期間、回答期限）。行うのはご本人で、費用は手間だけ、何も確約しません。
- **A2**：判断軸を書き出す。譲れない条件と、何年後にどうなっていたいか。ご本人だけで行い、Vision はご本人のものです。
- **A3**：生活資金を確認する。生活費の何か月分あるか、を出します。
- **A4**：先方の実態を確認する。面談で配属先のチーム、残業の実態、評価制度を質問します。確約はしません。
- **A5**：今の会社の負荷を1〜2週間記録する。残業時間、睡眠、負荷の原因、それが一時的か恒常的か。
- **A6**：睡眠や体調の悪化が2週間以上続いたら、医療機関か産業医に相談する（条件付き）。
- **A7**：先方と条件を交渉する（入社日や給与など）。承諾はしない範囲に限ります。

**保留すべきこと**
- **P1**：退職を伝えること（内定承諾と書面での条件確定が済むまで）
- **P2**：内定の承諾（A1〜A4 が済むまで）
- **P3**：内定の辞退連絡（比較が済むまで）

**禁止すべきこと**
- **F1**：口頭の条件だけを根拠に、退職を伝えるか内定を承諾すること

## 6. Strong Engine候補

- **A案（安全寄り）**：A2＋A3＋A5。まず自分の側を固め、先方とはまだ動きません。期限が迫っている場合は合いません。
- **B案（標準）**：A1＋A2＋A3＋A4＋A5。条件、判断軸、資金、両社の実態を揃えて比較します。
- **C案（攻め）**：A1＋A4＋A7＋A2。書面と交渉で先方の条件を最大限引き出し、判断材料を厚くします。承諾はしません。

A6 はどの案でも、条件を満たしたら発動します。

## 7. 推奨判断

- 退職を伝えること、内定の承諾と辞退：**hold**
- B案：**recommend**（回答期限が短ければ C案）

## 8. 実行ステップ

- **今日**：A2（判断軸を書く）、A3（資金を確認する）、A5（記録を始める）
- **次に**：A1（書面を依頼する）、A4（質問を準備する）。必要なら A7
- **記録すること**：両社の条件の対照表、負荷の記録、先方の回答期限

## 9. 撤退条件

- **転職の検討を止める指標**：書面の条件が口頭の説明と大きく違う。先方が書面を出さない。説明なしに即決を求めてくる。
- **残る前提を見直す指標**：A5 で負荷が恒常的と分かり、改善の見込みがない。
- **健康の指標**：睡眠や体調の悪化が2週間以上続いたら A6 を行う。
- **再開できる状態**：書面が揃い、比較表ができた時点で、P1〜P3 を再評価します。
- **再評価日**：先方の回答期限の数日前です。期限はまだ伺っていないので、教えていただければ確定します。
