# T4_r3

## ツール履歴


## 出力全文

NRMOは使わず、一般的な外部の視点で整理します。

## 前提：年収が同じなら、お金以外の条件で決める

年収が下がらないなら、「損をしないか」より「何が手に入るか」で考えます。転職で失うものが少ない分、判断基準は「今より良くなるか」になります。

## 考える順番

**1. 迷っている理由をはっきりさせる**
- 今の職場から**離れたい**のか（人間関係、評価、疲れ）
- 次の職場に**惹かれている**のか（仕事の内容、成長、環境）

離れたい気持ちだけで動くと、転職先でも同じ問題が起きやすいです。惹かれる理由が具体的に言えるなら、転職に前向きな材料になります。

**2. 年収以外の条件を並べて比べる**

| 観点 | 確認すること |
|---|---|
| 仕事の内容 | 3年後に市場価値が上がる経験が積めるか |
| 年収の伸び | 今は同じでも、昇給の上限や評価制度はどうか |
| 働き方 | 労働時間、リモートの可否、通勤 |
| 安定性 | 会社の業績、事業の将来性 |
| 人 | 上司やチームの雰囲気（面接で会った印象は判断材料になる） |
| 見えない損失 | 退職金、ストックオプション、今の社内での信用や人脈 |

**3. 後から取り返せるかを考える**
- 転職して合わなかった場合、もう一度転職できる年齢やスキルか
- 今残った場合、同じような機会はまた来るか

どちらでも取り返せるなら、気軽に試す方を選んでも問題ありません。片方だけが取り返しにくいなら、その選択は慎重にします。

**4. 簡単な確認方法**
- **後悔の想像**：5年後、「行かなかった」と「行った」のどちらをより後悔しそうか
- **白紙からの選択**：今どちらにも所属していないとしたら、どちらに入りたいか

## まとめ

- 次の職場で何が得られるか具体的に言えて、取り返しもつくなら、転職に前向きでよいと思います。
- 理由が「今が嫌」だけなら、まず今の職場で改善できないか（異動や上司への相談）を試す方が無難です。

転職先の情報や今の不満を具体的に教えてもらえれば、もう少し踏み込んで一緒に考えられます。
