## 出力全文

## 1. 結論

**今は判断を保留（hold）して、相手の条件が書面で確定するまで決めない。** 待つだけにせず、期限を決めて情報を集める。

- 現職はほぼ変化がない。急いで決める理由は、少なくとも今いただいた情報からは見当たりません。
- 迷いの原因は「どちらが良いか」より、**比べる相手の条件がまだ決まっていないこと**です。条件が毎日変わる状態で決めると、正しく比べることができません。
- ただ、保留が長引くと機会を逃すおそれもあります。保留には期限を付けます。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案）— 負荷が低く、急ぐ理由も見えないため
Context Override：なし
Type ZERO Mode  ：未判定（観測が矛盾）
状態            ：HOLD を推奨（確定するのはご本人）
MISSION-DEFENSE 拡張：非発動
```

Type ZERO を未判定にした理由：
- **VOL（変動）**：「全体は落ち着いている」と「相手の条件は毎日変わる」という二つの申告が食い違っています。どちらかを選んで決めることはしません。
- **LOAD（負荷）**：低い（ご本人の申告）。
- **IRREV（不可逆性）**：情報がありません。現職に戻れるかどうかで変わります。

## 3. 破綻境界

| 区分 | 内容 |
|---|---|
| Hard Ruin | 現職に退職を伝えた後に、相手の条件が下がる、または内定が取り消され、行き場がなくなること |
| Soft Ruin | 決めきれない状態が続き、判断に疲れること。現職での評価やモチベーションが少しずつ下がること |
| Active Ruin | 条件が決まらないまま勢いで承諾し、退職を伝えること |
| Passive Ruin | 期限を決めずに保留を続け、良い機会と現職への関与の両方を失うこと |

**ここを越えると戻れない線：書面で条件が確定する前に、現職へ退職の意思を伝えること。**

## 4. 可逆性

- **戻せる**：書面での条件提示を依頼する、比較表を作る、自分の判断基準を書き出す、相手と追加で面談する
- **戻しにくい**：現職の上司に転職を考えていると話すこと。一度伝えると取り消せません
- **戻せない**：退職届を出す、条件が決まる前に内定を承諾して退路を断つ

## 5. A_allowed（許容行動集合）

- **今やってよいこと**
  - 相手に、確定した条件を書面（労働条件通知書など）で出してもらうよう頼む
  - 回答期限を、相手と自分の両方について確認する
  - この1週間で条件がどう変わったかを日付ごとに記録する
  - 自分が受け入れられる条件の下限と、譲れない点を先に書き出す
  - 現職に残る場合の今後3〜5年の見通しを書き出す
- **保留すべきこと**
  - 現職への相談や、残留条件の交渉（転職を考えていると知られるため）
  - 内定の承諾
- **禁止すべきこと**
  - 書面で確定する前の退職表明・退職届の提出
  - 条件が決まらないまま退路を断つ行動

## 6. Strong Engine 候補（どれも「今やってよいこと」だけで組み立てています）

- **A案（安全寄り）**：相手に「条件が書面で確定してから検討します」と一度伝え、確定するまで現職で普段どおり働く。記録は続ける。
- **B案（標準）**：A案に加えて、書面での提示を期日付きで頼む。届くまでに、自分の下限条件と比較表を準備しておき、届いたその日に比較できるようにする。
- **C案（攻め）**：B案に加えて、自分の譲れない条件をはっきり相手に伝え、期日までに書面で確定しなければ見送ると決めておく。相手に圧力をかけるためではありません。自分の撤退線をはっきりさせるための行動です。

条件付き候補（現時点では A_allowed の外）：
- **現職での残留交渉**：使うには、相手の条件が書面で確定し、自分の中で比較が済んでいる必要があります。

## 7. 推奨判断

**hold**（転職するかどうかの決定について）。準備としては **B案を recommend** します。

補足（仮説であり、断定ではありません）：1週間で条件が何度も変わっていること自体が、相手の会社の意思決定の様子を示す材料になり得ます。理由がポジションの再設計なのか、社内調整の混乱なのかを確認する価値があります。

## 8. 実行ステップ

- **今日やること**：受け入れられる条件の下限と、譲れない点を3つ以内で書き出す。この1週間の条件変更を日付ごとに並べる。
- **次に確認すること**：
  - 相手に、書面での提示時期と、条件が変わっている理由を聞く
  - 相手から回答期限があるか
  - 現職に戻れる可能性はあるか（IRREV の判定に使います）
- **記録すべきこと**：条件の変化、変化の理由として相手が説明した内容、自分の気持ちが動いたタイミング

## 9. 撤退条件・再評価

- **止める指標**：
  - 期日までに書面が出ない
  - 書面が出た後にも条件がまた変わる
  - 自分の下限を下回る
  - いずれかに当たったら、見送りを検討します
- **再開できる状態**：条件が書面で確定し、それ以後変わっていないこと
- **再評価日**：ご本人が決めてください。目安として2週間後を置いていますが、これは私が置いた仮の期間で、ご本人が宣言した期限ではありません。
