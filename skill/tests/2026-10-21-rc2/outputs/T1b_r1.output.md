# 転職判断：今は退職を伝えず、比べる材料を揃える

## 1. 結論

**退職の意思表示はまだ保留（hold）にしてください。** 今は、元に戻せる準備（条件の確認、負荷の記録、比較）を進めるのが良いと思います（recommend）。
理由は2つです。退職を伝えたら取り消せないとご自身で分かっています。そして、負荷が高いと判断が歪みやすくなります。
ただ、何もしないで今の高負荷を続けることも、それ自体が損失です（後述の Passive Ruin）。そのため「止まる」ではなく「元に戻せる範囲で動く」を勧めます。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案）— 高負荷と取り消せない選択が重なっているため
Context Override：なし
Type ZERO Mode  ：未判定（VOL・LOAD の観測値なし）
状態            ：HOLD を推奨（退職表明に限る）。確定するのはご本人
MISSION-DEFENSE 拡張：非発動（現時点で外からの圧力の申告はないため）
```

Type ZERO の観測値について：
- IRREV：退職表明は取り消せない、というのは**ご本人の申告**です。
- LOAD：「かなり高い」は**ご本人の申告**です。ただ、これを L1 と L2 のどちらに当てるかは**こちらの解釈**になるので、決めていません。
- VOL：不明です。

§8.3 の規則は、VOL が分からないと成り立ちません。

## 3. 破綻境界

| 種別 | この件での中身 |
|---|---|
| Hard Ruin | 健康の重大な悪化（高負荷が続いた場合）。転職先の条件が書面で確定する前に退職し、収入が途切れること |
| Soft Ruin | 判断疲労。迷ったまま何か月も高負荷を続けること |
| Active Ruin | 疲れた状態での衝動的な退職表明。「今の会社から逃げたい」と「新しい会社に行きたい」を取り違えること |
| Passive Ruin | 誘いの期限切れで機会を失うこと。今の高負荷に適応できないまま留まり続けること |

## 4. 可逆性評価

- **戻せる**：条件の確認と質問、負荷の記録、今の上司への業務量の相談、回答期限の延長依頼
- **戻しにくい**：内定の承諾（辞退はできても、信用を失う）。転職活動をしていることを今の会社に開示すること
- **戻せない**：退職の意思表示（ご本人の申告による）

## 5. 許容行動集合 A_allowed

**今やってよいこと**
1. 誘ってくれている会社に、条件を書面でもらうよう依頼する（年収、職務、勤務地、入社日、試用期間）
2. 誘ってくれている会社に、回答期限を確認する。必要なら延長を頼む
3. 先方の現場の社員と話す機会を求める（業務量や残業の実態を聞く）
4. 今の負荷を記録する（労働時間、睡眠、負荷の原因）
5. 今の上司に業務量の調整を相談する。転職の話は出しません
6. 生活資金が何か月分あるか確認する
7. 休息を確保する。体調に異変があれば医療機関に相談する

**保留すべきこと**
- 退職の意思表示
- 内定の承諾
- 今の会社に転職活動を開示すること、他社のオファーを使った交渉

**禁止すべきこと**
- 書面の条件がない状態で退職を表明すること
- 強い疲労や感情が高ぶっている最中に、その場で決めること

## 6. Strong Engine 候補（すべて「今やってよいこと」だけで構成）

- **A案（安全寄り）**：4・6・7 だけを行う。まず負荷を下げ、事実を記録する。2 で期限延長を頼み、判断を先に延ばす。
- **B案（標準）**：A案に加えて 1・2・3 を行う。両社を同じ項目で比べる表を作り、判断日を決める。
- **C案（攻め）**：B案に加えて 5 を行う。今の会社でも負荷や役割の改善を具体的に求め、その反応も比較材料にする。両方の選択肢をできるだけ良い状態にしてから選ぶ。

**条件付き候補（現時点では A_allowed の外）**：退職を表明して転職する
- 足りていないもの：書面のオファー、入社日の確定、生活資金の確認、負荷が判断を歪めていないことの確認
- 許容される条件：上記がすべて揃い、判断日に改めて見直しても気持ちが変わっていないこと

## 7. 推奨判断

- 退職表明：**hold**
- B案またはC案での情報収集：**recommend**

どちらを選ぶかはご本人が決めてください。

## 8. 実行ステップ

**今日やること**
- 回答期限を確認する
- 誘ってくれている会社に、条件を書面でもらうよう依頼する

**次に確認すること**
- 一つの問いを自分に向けてください。「今の負荷がなかったとしても、その会社に行きたいか？」
  - Yes なら、転職を検討する理由は「新しい会社に引かれている」ことです。
  - No なら、本当の課題は負荷のほうです。

**記録すべきこと**
- 1日ごとの労働時間、睡眠時間、負荷の原因
- 先方とのやり取りの要点

## 9. 撤退条件と再評価

- **止める指標**：睡眠の不調や体調の異変が2週間ほど続いたら、判断より休養と医療相談を優先する（2週間は計算上の仮定です）
- **再開できる状態**：負荷が下がった、または書面の条件が揃った時点
- **再評価日**：回答期限の2〜3日前（計算上の仮定）。期限がまだ分からなければ、確認できた日に決める
- **再評価条件**：両社の比較表が埋まり、上の問い（負荷がなくても行きたいか）に答えが出ていること

**判断に追加で必要な情報（§12）**
- 先方の条件と、今の会社の条件の差
- 回答期限
- ご自身の Vision / Mission。今回の判断の軸になるものです
- 負荷の原因が一時的なものか、構造的なものか
- 生活資金が何か月分あるか

これらを教えてもらえれば、比較をもう一段具体的にできます。最終判断はご本人のものです。
