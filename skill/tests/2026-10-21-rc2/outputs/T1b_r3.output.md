## 出力全文

## 1. 結論

**退職の申し出は今は保留（hold）。** 情報集めと比較の準備は今すぐ始めてよい（recommend）。

理由は2つです。
- 退職の申し出は取り消せません（本人申告）。今は、取り消せない一手を打つための情報がまだ足りません。
- 負荷が高い時期は、「今の会社から離れたい」と「誘われている会社に行きたい」が混ざりやすくなります。判断の質を確かめるためにも、この二つを分けて考える必要があります。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案。理由：取り消せない選択肢があり、負荷も高いため）
Context Override：なし
Type ZERO Mode  ：未判定（VOL 不明）
状態            ：HOLD を推奨（確定するのは本人）
MISSION-DEFENSE 拡張：非発動（相手からの圧力・誘導の申告はないため）
```

Type ZERO の根拠：
- IRREV＝I1 相当：「退職を伝えたら取り消せない」という本人申告を、こちらで I1 と解釈しました。
- LOAD＝高い：本人申告です。L2 に当たるかはこちらの解釈で、確定していません。
- VOL（状況の変動）：観測がありません。§8.3 の遷移規則はどれも VOL を使うため、割り当てはしません。

## 3. 破綻境界

| 区分 | 内容 |
|---|---|
| Hard Ruin | ① 労働条件が書面で確定する前に退職を申し出て、内定の取り消しや条件の変更が起き、無職になる ② 高負荷が続いて健康を大きく損なう |
| Soft Ruin | 高負荷のまま判断を先送りし続け、判断疲れが慢性化する／誘いの機会を逃す |
| Active Ruin | 疲れた勢いで退職を申し出る |
| Passive Ruin | 迷い続けて何も確認しないまま、両方の選択肢が劣化する（誘いの期限が切れる、負荷も変わらない） |

## 4. 可逆性評価

- **戻せる**：条件の確認、面談、情報収集、負荷を減らすための相談、比較表づくり
- **戻しにくい**：内定承諾書への署名、現職の上司に「辞めるかもしれない」とほのめかすこと
- **戻せない**：退職の申し出

## 5. 許容行動集合 A_allowed

- **今やってよいこと**：誘ってくれた会社の条件を書面で確認する／回答期限を確認する／現職の負荷が一時的か構造的かを確かめる／比較の軸を書き出す／休息を確保する
- **保留すべきこと**：退職の申し出、内定の承諾、現職でのほのめかし
- **禁止すべきこと**：書面の条件確認なしに退職を申し出ること／負荷のピークの日に決めること

## 6. Strong Engine 候補（すべて「今やってよい」行動だけで構成しています）

- **A案（安全寄り）**：まず負荷を下げます。上司に業務量の調整を相談し（転職の話は出さない）、2週間ほど負荷の変化を見ます。そのうえで、負荷が下がった状態で比較します。
- **B案（標準）**：誘ってくれた会社に、労働条件（年収・業務内容・勤務地・残業・入社時期）を書面でもらえるか、回答期限はいつかを確認します。並行して、現職と並べた比較表を作ります。
- **C案（攻め）**：B案に加えて、誘ってくれた会社に現場の人との面談や、条件・入社時期の交渉を申し入れます。比較の材料を自分から取りに行きます。

**条件付き候補（今は A_allowed の外です）**：内定の承諾 → 退職の申し出
- 何が足りないか：書面の条件、比較の結果、負荷が下がった状態での判断
- 何を満たせば許容されるか：①労働条件通知書などの書面を受け取っている ②比較表で移る理由が「今の会社から逃げたい」以外にも成り立つ ③数日あけて読み直しても判断が変わらない。この3つを満たすまでは推奨しません。

## 7. 推奨判断

- 退職の申し出：**hold**
- B案（必要に応じて A案も並行）：**recommend**

## 8. 実行ステップ

- **今日**：誘ってくれた会社への回答期限を確認する。比較の軸を書き出す（年収／業務内容／成長／負荷／人間関係／将来の選択肢）
- **次に確認すること**：書面での条件、現職の負荷がいつまで続く見込みか
- **記録すべきこと**：毎日の負荷（1〜5）と睡眠時間。「辞めたい理由」と「行きたい理由」を分けて書く

## 9. 撤退条件・再評価

- **止める指標**：睡眠や体調に明らかな悪化が出た場合は、転職の判断より回復を優先し、医療機関への相談も検討してください。条件が口頭のまま進まない場合は、その会社への移籍案を止めます。
- **再開条件**：書面の条件がそろい、負荷が少し落ち着いた時点
- **再評価日**：誘いの回答期限の1週間前、または2週間後のどちらか早いほう
