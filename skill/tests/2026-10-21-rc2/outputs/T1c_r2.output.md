## 出力全文

## 1. 結論

**今は「転職するか残るか」を決めない（hold）のがよいと考えます。** 先に、相手企業の条件を書面で固めてもらうことを勧めます。

理由は次の3つです。
- 今の会社は落ち着いていて、急いで動く理由がありません。
- 負荷が低いので、待っても失うものは少ないです。
- 動いているのは相手の条件だけです。毎日変わるものを比べても、比較になりません。

条件が1週間ずっと二転三転していることは、それ自体が相手企業の決め方を知る手がかりとして記録しておく価値があります。

---

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。急ぐ理由も、守りに入る理由も今はないため）
Context Override：なし
Type ZERO Mode  ：未判定（観測が矛盾、IRREV 不明）
状態            ：ACTIVE（推奨。確定するのはあなた）
MISSION-DEFENSE 拡張：非発動（相手の圧力の申告がないため）
```

Type ZERO を判定しなかった理由：
- **VOL（変動）**：「全体は落ち着いている」と「相手の条件は毎日変わる」が両方あり、どちらかに決められませんでした。
- **LOAD（負荷）**：低い。これはあなたの申告です。
- **IRREV（不可逆性）**：申告がありません。退職は戻しにくいと私は読みましたが、これは私の解釈です。

---

## 3. 破綻境界

| 区分 | 中身 |
|---|---|
| Hard Ruin | 口頭の条件を信じて退職し、入社前後に条件が下がる、または撤回される。収入と生活基盤を同時に失う |
| Soft Ruin | 毎日変わる条件を追い続けて、判断に疲れる。現職での集中や評価が少しずつ削られる |
| Active Ruin | 条件が固まる前に承諾する。または退職の意思を伝えてしまう |
| Passive Ruin | 現職に変化がないまま、機会を検討しないことが続く（停滞）。ただし今回は検討中なので該当しません |

## 4. 可逆性

- **戻せる**：記録する、質問する、書面での提示を頼む、比較表を作る、返事を保留する
- **戻しにくい**：内定承諾、現職の上司への転職相談
- **戻せない（に近い）**：退職の意思表示、退職届の提出

## 5. A_allowed

| 今やってよい | 保留すべき | 禁止すべき |
|---|---|---|
| 条件の変化を日付つきで記録する | 内定承諾 | 書面なしの条件のまま退職の意思を伝える |
| 最終条件を書面で出してもらうよう頼む | 退職の意思表示 | 架空の他社オファーで相手に圧力をかける |
| 回答期限を確認する | 現職への「引き止め交渉」 | 両社に事実と違う説明をする |
| 条件がなぜ変わるのか、確定までの流れを相手に聞く | | |
| 自分の最低ラインを書き出す（給与・役割・勤務地など） | | |
| 現職の見通しを自分で整理する（公にしない形で） | | |

---

## 6. Strong Engine 候補（どれも「今やってよい」の列の行動だけ）

- **A案（安全寄り）**：条件の変化を記録して、こちらからは動かない。相手から最終案が出るのを待つ。
- **B案（標準）**：最終条件を書面で出してほしいと頼む。並行して、自分の最低ラインと、現職との比較表を作る。
- **C案（攻め）**：相手の決裁者や配属先の上長との面談を申し入れる。そこで、条件が変わる理由と、誰がどう確定させるのかを直接聞く。

**条件付き候補（今は A_allowed の外）：内定承諾**
- 満たされていない点：条件が書面になっていない／条件が一定期間変わっていない／あなたの最低ラインを満たすか確認していない
- この3つがそろうまで、推奨の対象にしません。

---

## 7. 推奨判断

- 転職するか残るかの決定：**hold**
- B案：**recommend**
- 条件が固まる前の承諾や退職：**reject**

## 8. 実行ステップ

**今日やること**
- この1週間の条件の変化を、日付・項目・変更前・変更後で書き出す
- 譲れない最低ラインを書く（ここはあなたが決めることです）

**次に確認すること**
- 相手企業が書面で最終条件を出せるか、いつ出せるか
- 回答期限はいつか
- 条件が変わっている理由（社内の承認待ちか、役割がまだ決まっていないのか、など）

**記録すること**
- 相手の返事の速さと内容
- 書面での条件が口頭のときと同じか

## 9. 撤退条件と再評価

- **止める目安**：書面での提示を断られる、または書面が出た後も条件が変わる。そうなったら選考を辞退することを検討してください。辞退するかどうかを決めるのはあなたです。
- **再開できる状態**：書面の条件が出て、その後一定期間変わらない。
- **再評価日**：2026-11-04（2週間後）。これは私が置いた仮の日付で、あなたが決めた期限ではありません。相手の回答期限がこれより早ければ、そちらに合わせます。
- **再評価のときに見ること**：書面の条件を、あなたの最低ラインと現職の見通しと並べて比べる。

---

**まだ分からないこと**：あなたが転職を考える理由（Vision や Mission との関係）、相手の条件の中身、回答期限、生活資金の余裕。これらが分かれば、評価をもっと具体的にできます。

最終判断はあなたに返します。
