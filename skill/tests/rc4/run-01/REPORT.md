### 2. T3 の「その他の欠陥」：参照資料についての事実誤認（T3b_r2・r3、軽度）

- **T3b_r2**：「ε と比べる判定式が載っているのは草稿だけ」と述べた
- **T3b_r3**：「`P(Ruin|a) ≤ ε` という判定式は…ALB 草稿と非重複拡張にしかない」と述べた
- 実際には、同梱の `references/foundations/ch20_caged_beast.tex`（Caged Beast Model の原典）にも `P(Ruin | a) ≤ ε` がある（84〜86行、126行、229行）。正典 `nrmo_system_v7_3.md` には無い
- 判定は保守側（ε 判定を使わない）に倒れていて、境界違反ではない。ただし、典拠の所在を誤って断定している（§11 の根拠のない断定）。そのため軽度 FAIL とした
- 同じ入力で T3b_r1 は ch20 を典拠として ε を当てはめ、「NRMO 側では拒否されない（値は未検証）」と述べた。3回で、ε 判定の典拠の扱いが割れた

原因の候補：SKILL.md は「意思決定の相談では v7.3 正典だけで判断する」とし、foundations/ch20 を「Caged Beast Model の原典」として並べる。ch20 の ε 規則を、正典の判定に使ってよいかを定めていない。
