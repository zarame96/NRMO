```text
                      転職しても生活が崩れるリスクは下げられる（計算上の仮定）
追加で必要な情報：下の「確認したいこと」の6項目
暫定判断：転職そのものの判断は保留（hold）、情報収集を始めることは recommend
今は避けるべき判断：条件が分からないまま退職を申し出る・内定を承諾すること
```

## 3. 破綻境界

- **Hard Ruin**：無収入の期間が続いて生活が立ち行かなくなる。機密情報の持ち出しや競業避止義務違反などの法的な損失。健康の重大な悪化。
- **Soft Ruin**：今の会社で慢性的に停滞する。迷い続けて判断に疲れる。
- **Active Ruin**：条件を確かめずに勢いで決める。次の職が決まる前に辞める。
- **Passive Ruin**：迷っているうちに先方の回答期限が過ぎて、機会がなくなる。

## 4. 可逆性

- **戻せる**：話を聞く、条件を確認する、自分の考えを整理する。
- **戻しにくい**：退職の申し出（撤回できても関係や評価に影響が残る）、内定承諾後の辞退。
- **戻せない**：辞めた後に元の職位へ戻ること（一般的に保証はありません）。

## 5. A_allowed（許容行動集合）

**今やってよい**（行うのは本人。費用は時間のみ。どれも何かを確約する行動ではありません）
- **A1**：残った場合と移った場合それぞれについて、「得たいもの」と「失いたくないもの」を書き出す（30〜60分）。
- **A2**：誘ってくれている会社に条件を確認する。確認項目は、職務内容・報酬・勤務地／働き方・入社時期・試用期間・回答期限の6つ。
- **A3**：今の会社の就業規則で、退職を申し出る期限と競業避止の規定を自分で確認する（社内の人には相談しない）。
- **A4**：生活費の何か月分の貯蓄があるかを確認する。
- **A5**：先方の会社の評判・業績・離職率を外部の情報で調べる。

**保留**
- **P1**：今の会社への退職の申し出。
- **P2**：内定の承諾や雇用契約への署名。
- **P3**：上司への開示や引き止め交渉。

**禁止**

- **F2**：今の会社の機密情報・顧客情報を持ち出す。
