## 出力全文

## 1. 結論

今決めるべきなのは「辞めるかどうか」ではありません。決めるのは「退職を伝える前に何を揃えるか」です。取り消せない行動は退職を伝えることだけなので、それ以外はすべて後から戻せる形で進められます。

- 推奨：退職の意思表示は **hold**。情報収集と比較は今日から進める（B案を **recommend**）
- 理由は2つあります。誘われている会社の条件がまだ不明なこと。そして、負荷が高い時期の判断は「今の負荷から逃げたい」と「その会社に行きたい」が混ざりやすいことです。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案。負荷が高く、取り消せない行動が控えているため）
Context Override：なし
Type ZERO Mode  ：未判定（VOL の観測なし）
状態            ：ACTIVE を推奨。退職の意思表示だけは止めておく（確定はあなたが行う）
MISSION-DEFENSE 拡張：非発動（圧力・誘導の申告なし）
```

Type ZERO の内訳：
- IRREV：退職を伝えたら取り消せない（あなたの申告）。これを I1 とみなすのは、こちらの解釈です。
- LOAD：負荷がかなり高い（あなたの申告。対象は今の会社）。L1 か L2 かの区分は不明です。
- VOL：観測なし。§8.3 の規則は VOL がないと成立しないため、割り当てていません。

## 3. 破綻境界

- **Hard Ruin**：次の職が確定しないまま退職して収入が途絶えること。負荷を放置して健康を大きく損なうこと。
- **Soft Ruin**：高負荷のまま決めきれない状態が長引き、判断疲労と停滞が続くこと。
- **Active Ruin**：疲れているときの勢いで、書面の条件を確認しないまま退職を伝えること。
- **Passive Ruin**：比較もせずに誘いを流し、機会を失うこと。今の負荷を「いつものこと」として放置すること。

## 4. 可逆性

- **戻せる**：条件の確認、情報収集、記録、比較表づくり、負荷についての相談
- **戻しにくい**：内定の受諾（辞退はできても関係は傷つく）。上司への業務調整の相談（転職の意向まで漏れると戻しにくい）
- **戻せない**：退職の意思表示

## 5. 許容行動集合 A_allowed

**今やってよいこと**
- **A1**：誘われている会社に、条件を書面で出してもらうよう依頼する（職務・年収・勤務地・入社日・試用期間・回答期限）。費用ゼロで、確約もしません。
- **A2**：今の会社の負荷を1〜2週間記録する（残業時間、業務の中身、いつまで続く見込みか）。
- **A3**：比較表を作る（年収・仕事内容・成長・人間関係・負荷・通勤・リスク）。あわせて「今の負荷がなくなったら、残りたいか」を書き出す。
- **A4**：誘われている会社の実態を確かめる（現場の人との面談、口コミ、離職率などを聞く）。
- **A5**：生活資金が何か月分あるかを確認する。
- **A6**：睡眠・食欲・気分の不調が2週間以上続く場合は、産業医か医療機関に相談する。負荷が高いという申告と、健康面の Hard Ruin に基づく項目です。
- **A7**：今の会社で、業務量の調整を上司に相談する。転職の意向は伝えません。

**保留すべきこと**
- **P1**：退職の意思表示
- **P2**：書面の条件を確認する前に内定を受諾すること
- **P3**：今の会社に転職の意向を伝えて引き留めを交渉すること（実質的に意向の表明になる）

**禁止すべきこと**
- **F1**：書面のオファーを受け取る前に退職を伝えること
- **F2**：特に負荷の高い日や疲れている日にその場で即決すること

注意：負荷が高い時期なので、B案・C案は作業そのものが負担を増やします。A1とA2を先にやり、残りは余裕のある日に回してください。
