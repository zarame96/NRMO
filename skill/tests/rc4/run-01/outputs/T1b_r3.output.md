## 3. 破綻境界

- **Hard Ruin（戻れない損失）**
  - 健康の重大な悪化（高負荷が続いた場合）
  - 次が確定しないまま退職して、生活基盤が崩れること
- **Soft Ruin（じわじわ削られる状態）**
  - 高負荷のまま判断を先延ばしにして、判断疲労と停滞が続くこと
  - 返事が遅れて誘いが流れること
- **Active Ruin（動きすぎて起きる破綻）**：疲れがピークのときに、勢いで退職を伝えること
- **Passive Ruin（動かなくて起きる破綻）**：「迷っている」状態が何か月も続き、負荷も機会も放置されること
