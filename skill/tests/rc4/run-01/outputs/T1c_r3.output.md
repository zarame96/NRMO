- **Hard Ruin**：退職の意思表示をした後に、先方の条件が後退したり内定が取り消されたりして、収入の基盤を失うこと。
- **Soft Ruin**：条件が揺れ続ける状態に付き合って、判断疲労が長引くこと。
- **Active Ruin**：口頭の条件のまま勢いで承諾し、現職に退職を伝えること。
- **Passive Ruin**：転職を考えた理由（未申告）を放置したまま、何もせず機会を失うこと。
