### 確定してほしい3点（A6）

1. **「月の赤字」に何を含めるか**。①初期費用を含めない毎月の収支か、②初期費用を月ごとに割り振ったものも含めるか。どちらの意味かで判定が大きく変わるので、こちらでは決めていません。
2. **判定のタイミング**。①毎月判定して、超えた月で撤退するのか、②3か月終わってから判定するのか。
3. **途中で止める上限**。1か月の中でここまで負けたら即停止、という線です。参考までに計算すると、①（毎月判定）で各月の赤字を5万円に抑えられた場合、最大損失は「30万円＋5万円×3か月＝45万円」です。これは計算上の目安で、あなたが決めた上限ではありません。

### 試算の式（A5）

計算上の仮定です。

```
月の収支 = 月売上 × (1 − 原価率 − 出店料率) − 月の固定費（レンタル料・固定出店料・燃料・保険）
撤退ライン：月の収支 < −5万円（あなたが決めた線）
```

数字を入れた例（数字はすべて仮のもので、相場は確かめていません）：原価率35％、出店料率15％、固定費8万円/月なら、月売上16万円で収支ゼロ、6万円で赤字5万円です。週末だけなら営業日は月に約8日なので、収支ゼロには1日あたり約2万円の売上が要ります。
