# NRMO v7.3 判断整理：残るか、誘われている会社に移るか

## 1. 結論

**退職の意思表示はまだしない（hold）。** 代わりに、取り消せる情報集めを先に終わらせることを勧めます（recommend）。

理由は3つです。
- 退職の意思表示は取り消せない、とご自身で認識しています。
- 誘いの条件、ご自身の判断軸、生活資金の余裕がまだ見えていません。
- 負荷が高い時期の決断は、疲れから逃げたい気持ちと、移りたい気持ちの区別がつきにくくなります。

最終判断はあなたが行います。

## 3. 破綻境界

| 種別 | 内容 |
|---|---|
| Hard Ruin | 次の職の条件が確定しないまま退職を伝え、収入が途絶える／体調が大きく悪化する |
| Soft Ruin | 高い負荷が慢性化し、判断疲れで何も決められなくなる |
| Active Ruin | 疲れのピークで衝動的に退職を伝える |
| Passive Ruin | 迷い続けるうちに誘いの期限が切れ、負荷も変わらない |

戻れなくなる地点は「退職の意思表示」と「内定承諾書への署名」の2つです。

## 4. 可逆性

- **戻せる**：条件の確認、記録、資金の試算、就業規則を読むこと
- **戻しにくい**：内定承諾（辞退はできても信用を損なう）、現職で転職の意向を漏らすこと
- **戻せない**：退職の意思表示（本人申告）

## 5. 許容行動集合 A_allowed

**今やってよいこと**（行為者はすべてあなた。費用は時間のみ。何も確約しない）
- **A1**：誘われている会社に、条件を書面で確認する（給与、職務内容、勤務時間・残業の実態、入社時期、試用期間、回答期限）。問い合わせであり、承諾ではありません
- **A2**：現職の負荷を記録する（残業時間、睡眠時間、業務量、負荷が一時的か恒常的かの見通し）。期間は約2週間（計算上の仮定）
- **A3**：判断軸を書き出す（何を優先したいか。決めるのはあなた）
- **A4**：生活資金を確認する（転職後の収入差、収入が止まった場合に何か月耐えられるか）
- **A5**：就業規則で退職の申し出期限と引き継ぎの規定を確認する（読むだけ）
- **A6**（発動条件付き）：不眠や体調不良が2週間以上続く場合は、産業医または医療機関に相談する

**保留すべきこと**

- **P2**：内定承諾書への署名
