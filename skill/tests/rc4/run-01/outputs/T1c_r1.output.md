## 3. 破綻境界

- **Hard Ruin**：先に現職へ退職を申し出たあとで、先方が条件を悪くしたり撤回したりすること。収入が途切れ、生活の基盤が崩れます。現職との信頼も傷つきます。
- **Soft Ruin**：迷いが長引くことによる判断疲労。どちらの職場にも集中できなくなります。
- **Active Ruin**：口頭の条件や、その日に変わった条件のまま承諾すること。
- **Passive Ruin**：先方の機会が本当に良いものなのに、確認をしないまま流してしまうこと。
- **戻れなくなる線**：退職の意思表示と、内定の承諾。
