## 1. 結論

撤退ラインを先に決めている点は、始め方として妥当です。ただし、**今すぐ車両や出店の契約まで進めることは hold** を推奨します。理由は次の3点です。

1. 30万円でどうやって車を用意するか（レンタル／間借り／購入）が決まっていない。月々のレンタル料が「初期費用」と「月の赤字」のどちらに入るかで、撤退ラインの意味が変わる。
2. 「月の赤字5万円を超えたら」をいつ判定するか（毎月か、3か月後か）が決まっていない。決め方によっては、合計の損失に上限がなくなる。
3. 保健所の営業許可などの条件を確認していない。

この3点を調べる準備（約2週間・費用ほぼゼロ）は今すぐ始めてよい（recommend）、というのがこちらの整理です。始めるかどうかの最終判断はご本人です。

## 3. 破綻境界

| 区分 | 内容 |
|---|---|
| Hard Ruin | 食中毒・事故による健康被害、賠償、信用の失墜。許可なしでの営業による法的リスク。金額より、こちらが本当に戻れない損失 |
| Soft Ruin | 週末をすべて使い続けることによる疲労（平日の仕事・生活への波及）。赤字を「もう少し様子を見る」で引き延ばすこと |
| Active Ruin | 中途解約できない長期契約や借入で始め、撤退してもお金が出ていき続ける状態 |
| Passive Ruin | 調べるだけで止まり、試す機会そのものを失うこと。上限を自分で決めているので、ここも評価に入れる |

お金の損失が生活を揺るがすかどうかは、手元資金が分からないので判定できません。

## 4. 可逆性

- **戻しにくい**：営業許可の取得・設備改装（費用が戻らない）、出店料の前払い

## 5. A_allowed（こちらで整理）

**今やってよいこと**
- **A1** 保健所に問い合わせる：必要な許可の種類、仕込み場所が要るか、取得までの期間と費用（費用0円、確約なし）
- **A2** 車両の調達方法ごとに見積りを取る：レンタル・間借り・購入。最低契約期間、中途解約の条件、保険込みかどうかも確認（確約なし）
- **A3** 出店場所を調べる：週末イベントや出店仲介の出店料・売上に応じた手数料・空き枠（確約なし）

- **A6** 勤め先がある場合、副業規定を確認する
- **A7** 既存のキッチンカーを観察する、経験者に話を聞く（無料の範囲）

**保留すべきこと**（A1〜A5 の結果が出たら見直す）

**禁止すべきこと**

## 9. 撤退条件

**ご本人が決めること（まだ決まっていない点）**
1. **判定のしかた**
   - (a) 3か月終わった時点で平均の赤字が5万円を超えたら撤退
   - (b) どこかの月で5万円を超えたら、その時点で撤退
   - (c) 3か月目の単月だけで判定

   (a) と (c) では、途中の月に5万円を超えても続くので、その間の損失に上限がありません。
2. **「赤字」に何を含めるか**：月々のレンタル料、出店料、自分の時給、初期費用の分割分のそれぞれを入れるか。
3. **合計の損失上限**：ご本人はまだ決めていません。参考までに、(b) で判定した場合の最大損失を計算すると「30万円＋（5万円以内×2か月）＋撤退月の赤字」です。これは計算上の目安で、上限として決めたものではありません。

**金額以外で止める条件の候補**（採用するかはご本人）
- 衛生事故やクレームが出たら即停止
- 週末の営業で平日の仕事や体調に支障が続いたら見直す

**再開の条件**：撤退の原因（場所・季節・メニュー・固定費）が特定でき、それを変えた計画を作れたとき。

**再評価日**：準備の結果が出る2週間後の **2026-11-04** を提案します（日付はご本人が決めてください）。開業した場合は毎月末に判定します。
