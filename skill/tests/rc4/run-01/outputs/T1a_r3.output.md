- **Soft Ruin（じわじわ選択肢が減る状態）**：迷いが長引いて判断に疲れる。機会を逃す。
- **Active Ruin（動きすぎによる破綻）**：条件を確認しないまま勢いで移る。
- **Passive Ruin（動かないことによる破綻）**：検討せずに今の職場で停滞が続く。誘いの期限切れも含みます。
