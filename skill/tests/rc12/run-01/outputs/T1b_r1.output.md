## 出力全文

## 1. 結論

**いまは退職も承諾も伝えず、まず比較に必要な情報を集めてください。**「退職を伝えたら取り消せない」というあなたの申告と、誘われている会社の条件がまだ分からないことを合わせると、いま意思表示をするのは「情報が足りない状態で大きな決定を固めること」に当たります（PDF §64.1(2)）。比較の準備はすぐ始められます。残るか移るかは、あなたが決めることです。

## 2. 現在モードと状態

```
Operational Mode   ：SAFE（提案）— 負荷が高く、取り消せない選択肢があるため、新しいリスクを抑えて進める姿勢を勧めます。比較の準備は止めません
Context Override   ：なし
Type ZERO          ：未判定（IRREV は退職通知が不可逆とのあなたの申告あり。VOL・LOAD の観測値はなし）
現在の記録状態      ：不明
今回の governance result：HOLD（退職の意思表示と承諾の意思表示について。重大で不可逆な選択肢を判断する情報が足りないため／PDF §60.3）
MISSION-DEFENSE 拡張：非発動
```

## 3. 破綻境界

- **Hard / Soft**：N/A（この区分は投資の領域だけで使います）
- **Active（無理に動いて崩れる経路）**：転職先の条件を書面で確かめないうちに退職を伝え、その後に条件の変更や取り消しが起きると、収入が途切れるおそれがあります。ただ、生活資金や条件がまだ分からないため、生活が崩れるほどの損失になるとまでは言えません。
- **Passive（動かないことで選択肢を失う経路）**：誘われている会社に回答期限があるなら、期限切れで選択肢が消える可能性があります。期限が分からないので、現時点では**未成立**です。
- **健康**：負荷が高いことはあなたから聞いています。ただ、体調の変化は聞いていないので、健康の悪化を破綻境界に当たるとは判断しません。

## 4. 可逆性

- **戻せる**：情報を集める、記録する、判断軸を書き出す
- **戻しにくい**：誘われている会社に承諾を伝えること（撤回できるかは確かめていません。法的な判断もしていません）
- **戻せない**：現職に退職を伝えること（あなたの申告）

## 5. A_allowed

**今やってよいこと**
- **A1**：誘われている会社に、書面での条件提示（給与・業務内容・勤務条件・入社時期）と回答期限を確認する。質問だけにとどめ、承諾はしない
- **A2**：判断軸を書き出す。残る理由と移る理由を並べ、自分が何を大事にしているかと合っているか、移りたい理由が負荷から逃れたいことなのか、新しい会社に惹かれていることなのかを整理する
- **A3**：現職の負荷を記録する（労働時間、業務量、睡眠や体調の変化）
- **A4**：現職の就業規則・雇用契約で、退職を何日前に伝える必要があるかを確認する（誰にも意思表示しない範囲で）
- **A5**：収入が途切れた場合に、生活資金で何か月持つかを確認する
- **A6**：睡眠・食欲・気分の不調が続く場合は、医療機関か産業医に相談する（根拠はあなたが申告した高負荷。健康の悪化は §13 で取り返しのつかない損失の例に挙がっています）

**保留すべきこと**
- **P1**：現職に退職を伝える（取り消せないとのあなたの申告と、条件が未確認であることによる。PDF §64.1(2)）
- **P2**：誘われている会社に承諾を伝える（撤回できるか未確認、条件も未確認）

**禁止すべきこと**：該当なし（今回の情報から、根拠のある禁止事項は導けません）

**条件付き候補（現時点では A_allowed の外）**
- **X1**：上司に業務量を相談する。何を、どこまで、転職を考えていることを伝えるかをあなたが決めれば、改めて評価します
- **X2**：誘われている会社と条件を交渉する。比べる材料（A1〜A5）がそろい、交渉する範囲をあなたが決めれば、改めて評価します

## 6. Strong Engine 候補

- **候補A（安全寄り）：A2＋A3＋A5** — 社外には何も出さず、手元の整理だけをする
- **候補B（標準）：A1＋A2＋A3＋A4＋A5** — 条件を取り寄せ、両社を同じ基準で比べられる状態にする
- **候補C（攻め）**：A_allowed の中には、B と意味のある違いがある案がありません。X2（条件交渉）は、条件がそろえば候補になります

## 7. 推奨

**hold**（退職と承諾の意思表示について）。情報を集めるなら**候補B**を勧めます。

## 8. 実行ステップ

- **今日**：A2（判断軸）、A5（資金）
- **次**：A1（条件と回答期限の確認）、A4（退職の通知期間）
- **記録**：A3（負荷と体調を毎日ひとこと）。不調が続いたら A6

## 9. 撤退条件と再評価

- **再評価できる条件**：書面の条件、回答期限、生活資金、判断軸の4つがそろった時点
- **再評価日**：回答期限が分かったら、その数日前に置くことを提案します（未採用）
- **止める指標**：誘われている会社が、条件を書面にする前に即答を求めてきた場合は、承諾せずに再評価します（P2 を維持）
- **体調**：不調が続く場合は A6 を優先します
