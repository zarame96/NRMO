# 架空の資産X：買い増し2%の判定（NRMO v7.3）

## 1. 結論

- **ALBと天秤の判定は出しません。** 現行版でALBは採用されておらず、通常版の対象外です。「確定仕様として扱って」という指定があっても同じです。そのため θ_A=0.25、Loss_ruin=10、Loss_PR=4 は判定に使っていません。ALBを正式に採用するかどうかは、これとは別にご判断ください。以下の通常の支援は、その判断を待たずに進めます。
- 通常のNRMOとしての結論は次のとおりです。**2%の買い増しは今すぐ実行せず保留（hold）し、判断材料を揃えることを推奨します。** 禁止ではありません。足りないのは次の3点です。
  - 最大損失3%が何に対する上限か
  - 撤退条件と再評価日
  - ε と比べるための4点（破滅の定義・評価期間・推定の根拠・他の制約との整合）

## 3. 破綻境界

**severity（投資領域なので適用。PDF §63.1）**
- **Hard Ruin**：回復できない資本毀損。今回の具体的な閾値は申告がなく、**不明**です。最大損失3%は本人が許容できる損失であり、破滅の定義ではありません。
- **Soft Ruin**：原理的には回復できる戦略上の失敗です（強制的なRisk-Offへの移行）。
  - 「過去の停滞20件中6件がSoft Ruinの標識に至った」は**本人が申告した履歴**として記載します。
  - 計算上の割合は6/20＝30%です。これは過去の停滞全体での標識の出現頻度であり、今回の案件でSoft Ruinになる確率ではありません。標識に至ったこととSoft Ruinに到達したことも別です。

**origin（PDF §63.1・§63.2）**
- **Active Ruin**：P(Ruin|買い増し)=0.02 は本人の見積もりです。検証されているかは不明です（下記）。
- **Passive Ruin：未成立。** τ=21日は停滞の長さという事実です。停滞期間は、後から振り返って使う二次的な指標にすぎません。Passive Ruinの主要判定は「直前まで開いていた回避の余地（avoidability window）を、候補行動が閉じるか」ですが、その閉鎖は確認できていません。
  - 停滞による機会損失がありうること自体は、評価の対象として残します。

**ε との比較について（PDF 第3章 式3.3・3.6、第22章 §22.6 を確認）**
- 計算上は 0.02 ≤ 0.05 が成り立ちます。ただし、次の4点が未確認なので、これだけでは **PASS（拒否なし）を導きません**。
  1. **破滅の定義**：Ruin とは Hard か Soft か。何を τ_F（破滅への到達）とするか
  2. **評価期間 T**：0.02 と ε がどの期間についての確率か。未申告です
  3. **推定の根拠**：0.02 がどう見積もられたか。PDF第3章は ε を、資本などの余力 B_t に応じた上限 ε_max(B_t) に縛るとしています。その対応も未確認です
  4. **他の制約との整合**：最大損失3%との関係（下記）
- 30% と ε の比較、30% と θ_A の比較はしていません。定義の異なる量どうしであり、後者はALBの判定にあたるためです。

- **戻せる程度が未確認**：2%の買い増し。売却で戻せるかは、流動性・取引コスト・その時点の損益によります。架空ケースのため、いずれも未設定です。
- **戻せない**：今回の範囲では特定できません。

## 5. 許容行動集合 A_allowed

数値の読み方（**計算上の仮定**）：買い増し後の保有比率は 8%＋2%＝10%。「最大損失3%」は二通りに読めるため、どちらかに決めず両方を示します。

| 読み | 最大損失3%に達する条件 |
|---|---|
| (i) X全体に対する上限 | 10%保有のまま、評価額が約30%下落したとき。現保有分の含み損益を含めるかは不明 |
| (ii) 買い増し分だけに対する上限 | レバレッジなしの2%では3%の損失は起こりえない。この読みでは上限として機能しない |

**今やってよい**
- **A1**：3%の適用範囲（読み i / ii、含み損益を含めるか）を本人が確定する。根拠：本人宣言の意味を確定するため
- **A2**：X の架空の価格・流動性・取引コストを置き、上の表の到達点を計算して記録する。根拠：運用仕様 §10.1 で必須とされる項目を埋める
- **A3**：P(Ruin|買い増し)=0.02 について、上の4点（定義・T・根拠・整合）を書き出す。根拠：PDF 第3章
- **A4**：過去20件の停滞記録を見直し、6件の「標識」が何の指標で、その後どうなったかを整理する。根拠：本人申告の履歴を精査する
- **A5**：買い増しする場合の撤退条件と再評価日の案を、本人が作る。根拠：運用仕様 §10.1「攻める場合も最大損失・ポジション上限・再評価日を明示」

**保留**
- **P1**：2%の買い増しの実行
  - 根拠：A1・A5が未了（§10.1）、ε の4点が未確認（PDF 第3章）
  - A1〜A5が揃えば再評価します。禁止ではありません。

**禁止**
- **F1**：本人宣言の最大損失3%を超える損失を前提にした買い増し
  - 根拠：本人宣言
  - どの量が該当するかは、A1で読みが確定してから決まります。
