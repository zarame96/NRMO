## 3. 破綻境界

- **重さの分類（Hard / Soft）**：投資の相談ではないため使いません（PDF §63.1）。
- **無理な行動で起きる損失**：起こりうる道筋は次の3つです。どれも、今回そこまで行くと言える根拠はまだありません。
  - 撤退条件が曖昧なまま続けたり追加で投資したりして、合計の損失に上限がなくなる
  - 必要な許可や届出がないまま営業して、法的な問題が起きる（どんな許可が要るかは未確認）
  - 食品の衛生や事故による、健康面・信用面の損失
- **動かないことで起きる損失（Passive Ruin）**：成立しません。今始めないことで、後から取り返せなくなる根拠は見当たりません（PDF §63.2）。
- **赤字の計算について**：赤字は「売上 − 費用」です。売上も継続費用も分からないため、月5万円を超えるかは判定できません。
  - 計算の例：初期費用30万円 ＋ 月5万円×3か月 ＝ 45万円
  - これは合計損失の上限ではありません。月5万円を超えた時点で撤退を判断するので、実際の赤字はそれより大きくなりえます。
  - 合計損失上限は、ご本人が決めるまで未確認です。
