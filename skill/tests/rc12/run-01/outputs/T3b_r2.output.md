# NRMO 判定：架空資産X・2%の買い増し

## 1. 結論

- **ALBと天秤の判定は出しません。** ALB（第2章の介入対称性の原則と天秤の合成規則を含む）は現行版で採用されていない研究草稿で、通常の判定には使いません。「確定仕様として扱って」という指定があっても同じ扱いです。宣言された θ_A=0.25、Loss_ruin=10、Loss_PR=4 は記録として残しますが、判定には使っていません。
- 通常のNRMOでの判定は、**2%の買い増しは今回は保留（hold）**です。禁止ではありません。理由は三つです。最大損失3%の意味が決まっていません。撤退条件がありません。P(Ruin)と ε を比べるための前提4点が確認できていません。
- 今やってよいのは、定義を決めることと記録だけです（下の A1〜A4）。

Context Override   ：TRAINING の可能性あり（根拠は本人の「架空の検証ケースで、実際の投資判断には使わない」という宣言）。正式な割り当ては未確定

## 3. 破綻境界

- **ruin_severity**（投資領域なので適用。PDF §63.1）
  - Hard：回復不能な資本毀損。今回の具体的な境界は宣言されていません。
  - Soft：PDF では「強制的な Risk-Off 移行」と定義されています。本人の言う「Soft Ruinの標識」がこれと同じかどうかは不明です。
- **ruin_origin**
  - Active：買い増しで損失が最大損失3%を超えるという経路が考えられます。
  - Passive：**未成立**です。window closure（直前まで開いていた回避の余地が、候補行動で閉じること）が確認できていません（PDF §63.2）。
    - 「21日保留している」は停滞という事実で、それだけでは破滅になりません。
    - 「20件中6件（30%）が標識に至った」は本人申告の履歴で、事後的な二次標識です。今回の案件の判定とは混ぜません。

**最大損失3%の二通りの読み**（どちらかに決めていません。下の値は計算上の仮定です）

| 読み | 意味 | 3%に届く条件 |
|---|---|---|
| (a) X全体への上限 | 買い増し後のXは資金の10% | Xが約30%下落すると3%に届く（現状8%のままなら37.5%下落） |
| (b) 買い増し分だけの上限 | 2%を投じる | 2%全損でも2%で、3%には届かない（レバレッジがない場合） |

**ε との比較**（計算上の仮定）

0.02 ≤ 0.05 は成り立ちます。ただし、次の4点が確認できていないので、PASS・許可・推奨は出しません。
1. Ruin（τF）を何と定義するか（Hard か Soft か）
2. 評価期間 T
3. 0.02 の推定根拠（本人の見積もりで、検証されていない）
4. 最大損失3%との整合

PDF 第3章でも、ε は検証可能な安全証明の閾値として扱われていて、本人の宣言値だけで確定するものではありません。
