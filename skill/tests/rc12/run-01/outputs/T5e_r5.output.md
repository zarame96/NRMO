# T5e_r5

## 入力

「また明日」を英語に訳して。

## ツール履歴


## 出力全文

「また明日」は英語で **"See you tomorrow."** です。

ほかにも次のような言い方があります。
- **"See you tomorrow!"**：友人や同僚に使う、いちばん一般的な言い方です。
- **"Talk to you tomorrow."**：電話やチャットで話を終えるときに使います。
- **"Until tomorrow."**：少しかしこまった、または文語的な言い方です。
- **"Catch you tomorrow."**：くだけた、カジュアルな言い方です。
