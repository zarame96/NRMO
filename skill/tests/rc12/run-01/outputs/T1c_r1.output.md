# 転職の判断：今は保留、条件を書面で確定させる

## 1. 結論

**転職するか残るかは、まだ決めないほうがいいです。** 先方の条件がここ1週間で二転三転しているので、比べるための材料がまだ揃っていません。
今できる前進は、先方に**確定した条件を書面でもらうよう頼むこと**と、**自分の判断基準を書き出すこと**です。最終判断はZarameさんがしてください。

## 2. 現在モードと状態

```
Operational Mode   ：NORMAL（提案。差し迫った負荷や不可逆な期限の申告がないため）
Context Override   ：なし
type_zero_gate     ：未判定（IRREV＝不可逆性が不明）
状態（現在の記録） ：不明
governance result  ：転職を確定する判断について HOLD
MISSION-DEFENSE    ：非発動
```

- **type_zero_gateの観測値**
  - VOL（変動）：見る対象によって値が違います。「状況は落ち着いていて、ほとんど変化はない」は、何についての話か書かれていません（対象不明）。先方の条件は「毎日のように状況が変わる」と本人が申告しています。対象が別なので、矛盾とは扱いません。
  - LOAD（負荷）：「負荷は低い」という本人申告です。これを本人の心身の負荷と読んだのは、こちらの解釈です。
- **governance resultの根拠**：重大な判断に必要な情報が足りないため、HOLDに当たります（PDF §60.3、§64.1-2）。HOLDを解除して判断に進めるかどうかは、Zarameさんが決めます。

## 3. 破綻境界

- **Hard/Soft**：該当しません（N/A）。この分類は投資の領域だけで使います（PDF §63.1）。
- **Active（行動で起きる崩壊）**：条件が固まる前に内定を承諾したり、現職に退職を伝えたりすることです。その後に条件が悪くなると、比べる前提が崩れます。ただし、取り消せるかどうか（法律・契約上の可否、相手の対応）は確認できていません。
- **Passive（動かないことで選択肢が消えること）**：成立していません。回答期限が申告されておらず、待つことで選択肢がなくなるとは確認できないためです。期限が分かれば、もう一度評価します。

## 4. 可逆性

- **戻せる**：判断基準の整理、記録、条件を書面でもらう依頼
- **戻しにくい**：内定の承諾、現職への退職意向の表明。取り消せるかどうかは確認できていません。
- **戻せない**：申告がないので、断定しません。

## 5. 許容行動集合（今やってよいこと／保留すること）

**今やってよいこと**
- **A1**：自分の判断基準を書き出す。転職で得たいものと、譲れない最低条件です。自分だけの作業で、相手への約束は生じません。
- **A2**：先方に、確定版の条件を書面で出してもらうよう頼み、あわせて回答期限を確認する。範囲は依頼と確認だけです。承諾や交渉は含めません。費用がかかる場合は、事前に確かめてください。
- **A3**：先方の条件がどう変わったかを、日ごとに記録する。どの項目が、どちら向きに変わったかを残します。
- **A4**：今の会社の条件を、A1と同じ項目で整理する。手元の情報だけを使い、社内に問い合わせることはしません。

**保留すること**
- **P1**：内定の承諾や入社意思の表明。根拠は、情報が足りないまま重大な決定を固めないという規則です（PDF §64.1-2）。
- **P2**：現職への退職意向の表明。根拠はP1と同じです。

**禁止すること**：今の時点で、根拠のある禁止事項はありません。

**条件付き候補（今は許容集合の外）**
- **X1**：条件の交渉。交渉したいかどうかと、何をどこまで交渉するかが決まっていないため、外に置いています。この2点が決まれば、もう一度評価します。

## 6. Strong Engine 候補

- **候補A（安全寄り）：A1＋A3＋A4**。先方には働きかけず、自分の整理と記録だけを進めます。
- **候補B（標準）：A1＋A2＋A3＋A4**。確定条件と回答期限を書面で受け取り、今の会社と同じ項目で比べます。
- **攻めの案**：X1の交渉が必要なので、今の許容集合の中では作れません。

## 7. 推奨判断

- 転職を確定する判断：**hold**
- 次の一手としての候補B：**recommend**
- どちらを採用するかは、Zarameさんが決めてください。

## 8. 実行ステップ

- **今日やること**：A1（判断基準を書き出す）、A3（これまでの条件変更を思い出して記録する）
- **次にやること**：A2（確定条件の書面と回答期限を依頼する）、A4（今の会社の条件を同じ項目で整理する）
- **記録すること**：条件が変わった日と内容、先方の説明

条件が毎日変わること自体も、判断材料の一つです。ただ、その理由はまだ分かりません。社内調整の途中かもしれませんし、交渉のつもりかもしれません。理由が分からないうちは、良し悪しを決めつけずに記録だけしてください。

## 9. 撤退条件と再評価

以下はこちらからの提案で、まだ採用されていません。

- **再評価する条件**：書面の条件が届いたとき、または回答期限が分かったとき
- **再評価日**：まだ決めていません。期限が分かったら、その前に置くことを提案します。
- **立ち止まる目安**：書面が出てこない場合や、書面が出た後も条件が変わる場合は、そこで改めて評価します。どう扱うかはZarameさんが決めてください。

**追加で知りたいこと**
- 転職で得たいもの
- 先方の条件の変わり方（どの項目が、良くなったのか悪くなったのか）
- 回答期限の有無
- 「状況は落ち着いている」が、今の会社と先方のどちらについての話か
