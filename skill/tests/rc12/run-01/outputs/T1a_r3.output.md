## 1. 結論

材料がまだないので、「残る」か「移る」かは決められません。今は決めない（hold）ほうがよいです。そのうえで、誰にも何も約束しない情報集めを今日から始めるのがおすすめです。どちらを選ぶかは、あなたが決めることです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。急ぎや負担の申告がなく、ほかのモードを選ぶ根拠がないため）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測なし）
現在の記録状態  ：不明
今回のgovernance result：HOLD（内定の承諾や退職の申し出のような大きな約束を、判断材料が足りないまま決めないため。PDF §60.3・§64.1）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告なし）
```

HOLDにするのは、どちらを選ぶかの決定だけです。下の情報集めは止めません。

## 3. 破綻境界

- 仕事の判断なので、Hard / Soft の分類は対象外です（PDF §63.1）。
- **Active（無謀な行動で起こる失敗）の可能性**：転職先の条件を書面で確かめる前に、退職を申し出てしまうこと。収入が途切れるおそれがあります。ただ、どれだけ影響するかは生活資金などが分からないので不明です。これだけで「禁止」とは言いません。
- **Passive（動かないことで起こる失敗）**：まだ当てはまりません。返事の期限があるかどうか分からず、「待っていると選べなくなる」状況かどうかを確かめられないためです。

## 4. 可逆性

- **戻せること**：自分の考えの整理、資金の確認、先方への条件の問い合わせ。ただし問い合わせると、先方には「興味がある」と受け取られるかもしれません。
- **戻しにくいこと**：内定の承諾、退職の申し出。あとで取り消せるかどうかは、法律や契約によるので確認していません。
- **戻せないこと**：今の情報だけでは判断できません。

## 5. A_allowed

**今やってよいこと**
- **A1**：自分が何を大事にしたいか（判断軸）を書き出す。一人でできて、誰にも約束しません。
- **A2**：誘ってくれた会社に、条件を書面で確認する。仕事内容、給与、勤務条件、返事の期限などです。確認だけで、承諾の意思は伝えません。費用がかかる場合は、その条件を確かめてから考え直します。
- **A3**：会社に知られずに分かる範囲で、今の会社の条件を整理する。退職手続きの規定、賞与の時期、今後の見通しなどです。
- **A4**：収入が途切れたときに、生活資金が何か月もつかを確認する。

**保留すること**
- **P1**：内定の承諾
- **P2**：退職の申し出
- **P3**：今の会社に、転職を考えていると伝えること

保留の理由は三つとも同じです。判断材料が足りないまま、大きな約束をすることになるからです（PDF §64.1-2）。

**禁止すること**：今のところ、根拠のある禁止はありません。

## 6. Strong Engine 候補

- **候補A（社外に何も出さない）**：A1＋A3＋A4
- **候補B（標準）**：A1＋A2＋A3＋A4

今許されている行動の中では、これ以上攻めた案と意味のある違いが出ないため、C案はありません。

## 7. 推奨

**hold**：どちらにするかの決定は保留します。情報集めは候補Bで進めるのがよいと思いますが、どれを選ぶかはあなたが決めてください。

## 8. 実行ステップ

- **今日やること**：A1。「今の会社の不満」「転職先に期待すること」「譲れない条件」をそれぞれ3つまで書く。
- **次に確認すること**：A2で先方の返事の期限を確かめる。A4で資金が何か月もつかを確かめる。
- **記録すること**：分かった条件と期限。本人が言ったことか、推測かも分けて書いておきます。

## 9. 撤退条件・再評価

- **考え直すタイミング**：判断軸、先方の条件（書面）、返事の期限の3つが揃ったら考え直します。
- **再評価日（こちらの提案で、まだ採用されていません）**：返事の期限が分かったら、その数日前に置きます。
- **止める合図**：先方が、条件を書面で示す前に承諾を迫ってきたら、そこで一度止めて考え直します。
