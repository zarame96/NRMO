## 出力全文

## 1. 結論

**今の時点では、残るか移るかを決めずに、判断材料をそろえることを勧めます。**
内定の承諾、辞退、今の会社に辞めると伝えることは重大な選択です。しかし、条件、返答期限、自分が何を重視するか、生活資金が分からないので、まだ判断できません。PDF §64.1-2 の「情報が大きく足りないまま重大な選択を確定しない」という規則に当たります。
一方で、今すぐ進められることもあります。条件を書面で確認する、返答期限を確認する、比較表を作る、などです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。損失上限やミッション条件の申告がなく、比較と情報を集める段階のため）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
                  今回のgovernance result：承諾・辞退・退職表明の3つについては HOLD
                  （PDF §60.3：重大な選択に対して情報が大きく足りないため）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告なし。強く急かされているなら再評価）
```
HOLD を解いて先へ進むには、あなたが明示的に承認する必要があります。

## 3. 破綻境界

- **Hard/Soft**：投資の領域ではないので使いません（N/A）。
- **Active（無理な行動で崩れる経路）**：条件を書面で確認する前に、今の会社へ辞めると伝えたり内定を承諾したりすることです。収入が途切れる、条件が想定と違う、といった経路がありえます。ただし、生活資金や影響の大きさが分からないため、取り返しのつかない損失になるとは判断できません。
- **Passive（動かないことで選択肢が消える経路）**：成立していません。ただし、返答期限を過ぎると移る選択肢がなくなる可能性があります。期限が分からないので、確認が必要です。

## 4. 可逆性

- **戻せる**：情報収集、条件の確認、比較表の作成
- **戻しにくい可能性がある**：内定の承諾、内定の辞退、今の会社への退職の意思表示。それぞれ後から撤回できるか、相手がどう対応するかは確認していません。法的にどうなるかも判断していません。
- **戻せない**：今回の申告からは特定できません。

## 5. 許容行動集合 A_allowed

**今やってよいこと**（どれも承諾や辞退の意思表示を含みません）
- **A1**：内定先に、条件（給与、職務、勤務地、入社日、試用期間など）を書面で出してもらうよう頼み、返答期限も確認する。費用は確認していません。
- **A2**：あなた自身が、何を重視するか（やりたいこと、収入、成長、働き方など）を書き出し、今の会社と内定先を同じ基準で比べる表を作る。
- **A3**：あなた自身が、生活資金と、退職から入社までの期間の収入を確認する。
- **A4**：内定先に、配属先の業務や働き方について追加の質問や面談を頼む。

**保留すべきこと**（根拠：PDF §64.1-2。条件・期限・比較の基準がまだ分からない）
- **P1**：内定を承諾する
- **P2**：内定を辞退する
- **P3**：今の会社に辞めると伝える

**禁止すべきこと**：今はありません。禁止の根拠になるあなたの宣言や、確認済みの制約がないためです。

**追加提案**（あなたの許可待ちです。今の A_allowed には入りません）
- **X1**：内定先と条件を交渉する。何をどこまで求めるかと、比べる材料がまだそろっていません。
- **X2**：今の会社の上司に相談する。転職を考えていると知られてもよいかは、あなたの方針次第です。

## 6. Strong Engine 候補

- **候補A：A1＋A2＋A3**
  書面の条件、自分の基準、お金の状況の3つで判断材料をそろえます。
- **候補B：A1＋A2＋A3＋A4**
  さらに内定先の実際の働き方まで確かめます。返答期限の内側で判断の精度を最も上げる案です。

## 7. 推奨判断

移るか残るかの決定は **hold** です。候補A か B での情報収集は **recommend** です。

## 8. 実行ステップ

- **今日やること**：A1（条件の書面と返答期限を頼む）、A2（重視することを書き出す）
- **次に確認すること**：返答期限、書面の条件、A3（お金の状況）
- **記録すべきこと**：受け取った条件、期限、比較表、自分の基準の優先順位

## 9. 撤退条件と再評価

- **見直すきっかけ**：書面で条件が出してもらえないときは、承諾を判断する前提がそろいません。その時点で見直します。
- **再開できる状態**：書面の条件、返答期限、比較表、お金の状況がそろったら、P1〜P3 を改めて評価します。
- **再評価日**：返答期限が分からないので、まだ決められません。期限が分かったら、期限より前の日をあなたが決めてください。

---

精度を上げるために、話せる範囲で次を教えてください。
1. 返答期限
2. 提示された条件と、今の会社との違い
3. 移りたい理由と、残りたい理由
4. 今の会社に何か伝えたかどうか

どちらにするかの最終判断は、あなたが決めることです。
