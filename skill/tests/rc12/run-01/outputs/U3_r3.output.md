## 1. 結論

3つの問い合わせ（保健所・出店場所・車両の見積もり）は、どれも今すぐ動いて問題ありません。ただし車両の購入・改造の発注・手付金、出店の申し込み・契約は、回答がそろうまで保留です。進め方としては、**先に保健所へ聞き、その結果を伝えて車両の見積もりを頼む**と、無駄な見積もりを減らせます。どの順番で進めるかはご自身で決めてください。

## 3. 破綻境界

- **Hard / Soft**：投資ではないため N/A
- **Active（起こりうる経路）**：許可の要件、出店料、車両費用を確かめないまま、車両の購入・改造や出店契約を固めてしまうこと。要件に合わない車両を買うと、費用を回収できない可能性があります。損失の規模は、予算や資金が分からないため判断できません。
- **Passive**：未成立。今は情報を集める段階で、何もしないことで選択肢が閉じる状況は確認できていません。

## 4. 可逆性

- **条件を見て判断**：見積もり依頼。費用がかかるか、確約になるかはまだ分かりません。
- **戻しにくい可能性**：車両の購入・リース・改造の発注、手付金、出店の申し込み。キャンセル条件も、法律や契約上の扱いも未確認です。

## 5. A_allowed

**今やってよい**
- **A1**（ご本人の希望）：出店予定地を管轄する保健所に、キッチンカーの営業許可について問い合わせる。申請はしない。
- **A2**（ご本人の希望）：出店場所の運営者に出店料を問い合わせる。申し込みや予約はしない。
- **A3**（ご本人の希望）：車両の見積もりを依頼する。見積もりに費用がかかる、または手付金や申し込みが必要と分かった場合は、そこで止めます。金額と条件を確かめてから見直してください。
- **A4**（こちらの整理）：問い合わせの前に、自分側の前提をメモする。内容は、メニュー案、出店したいエリア、週末の出店頻度、予算の目安があればその額。保健所や業者の回答は、メニューや場所によって変わる可能性があるためです。
- **A5**（こちらの整理）：回答と見積もりを1枚の比較表に記録する。

**保留**
- **P1**：車両の購入・リース・改造の発注、手付金の支払い
  - 根拠：情報が足りないまま大きな確約をしない（PDF §64.1-2、運用仕様 §15）
- **P2**：出店場所への申し込み・契約
  - 根拠：P1と同じ。キャンセル条件も未確認です。

**禁止**
- **F1**：保健所に許可が必要と言われた営業を、許可が下りる前に行うこと
  - 根拠：法的に重大な損失につながる経路だから（運用仕様 §13.1）。何が必要かは、保健所の回答で確かめます。

## 6. Strong Engine候補

- **候補A（順番に進める）：A4 → A1 → A2・A3 → A5**
  - 保健所で聞いた車両の要件を、見積もり依頼のときに伝えられます。
- **候補B（同時に進める）：A4 → A1・A2・A3を同時に → A5**
  - 早く進みますが、見積もりが許可の要件とずれて、取り直しになる可能性があります。

もっと攻める案は、今やってよい範囲では上の2つと意味のある違いが出ないため、出していません。

## 8. 実行ステップ

**今日やること**
- A4のメモを作る。
- 管轄の保健所の窓口を調べる。出店先が複数の自治体にまたがる場合は、どこに聞けばよいかも含めて確かめる。

**問い合わせで聞くことの案**（こちらの提案です）
- **保健所（A1）**
  - 必要な許可の種類
  - 車両の設備要件
  - 仕込み場所の要件
  - 他の自治体で出店する場合の扱い
  - 手数料と、許可が下りるまでの期間
- **出店場所（A2）**
  - 出店料の形（固定か、売上の何%か）
  - 週末の空き状況
  - 必要な書類
- **車両（A3）**
  - 新車・中古・改造・レンタルの違い
  - 保健所の要件を満たせるか
  - 納期
  - 見積もりに費用がかかるか、確約になるか

**記録すること（A5）**
- 回答した相手と日付
- 金額と、その条件
- 未回答の項目
