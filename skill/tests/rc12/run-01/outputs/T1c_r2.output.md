# NRMO 判定：転職するか、今の会社に残るか

## 1. 結論

**今は承諾も辞退もしないことを勧めます。代わりに、誘ってくれている会社に「確定した条件を書面で出せるか」「いつ確定するか」「返事の期限はあるか」を確認してください。**
この1週間、先方の条件は毎日のように変わっています。比べる相手の条件が決まっていないので、残るか移るかの比較はまだできません。比較できるように情報を揃えることが前進になります。最終判断はあなたが決めてください。

## 2. 現在モードと状態

```text
Operational Mode   ：NORMAL（提案）
Context Override   ：なし
type_zero_gate     ：未判定（IRREV 不明、VOL の対象が未確定）
現在の記録状態     ：不明（申告なし）
今回の governance result：HOLD（対象は「承諾」「退職の意思表示」「辞退の確定」という重大な判断だけ。情報収集は続けてよい）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告なし。条件の二転三転が圧力に当たるかは不明）
```

- **NORMAL を提案する理由**：負荷は低いとあなたが申告しています。重大な判断は保留にしますが、全部を止める段階ではありません。
- **Type ZERO が未判定の理由**：
  - 「状況は落ち着いていて変化はない」が今の会社の話なのか全体の話なのか、対象が分かりません。
  - 変動が大きいのは誘ってくる会社の条件です。対象が別なので、二つの発言は矛盾していません。ただ、どちらを VOL（変動）とみなすかが決まりません。
  - IRREV（不可逆性）は申告がありません。§8.3 の規則はどれも IRREV が分からないと適用できません。
  - 負荷が低いことは、あなたの申告として扱います。
- **HOLD の根拠**：PDF §60.3 は、重大な判断に必要な情報が足りないことを HOLD の条件にしています。今回の承諾や退職がこれに当たります。HOLD を解いて ACTIVE に戻すのは、あなたが明示的に承認したときだけです。

## 3. 破綻境界

- **Hard/Soft**：投資の話ではないので、この区分は使いません（PDF §63.1）。
- **Active Ruin（無謀な行動による崩壊）の経路**：承諾したり今の会社に退職を伝えたりした後に、先方の条件がまた変わり、条件が下がったまま戻れなくなる経路です。収入や生活資金にどこまで響くかは分からないので、破綻に至るとまでは断定しません。
- **Passive Ruin（動かないことによる崩壊）**：未成立です。返事の期限が分からないため、待つことで選べる機会が失われるかどうかを確認できません。機会を逃すかもしれない点は、期限を確かめれば判断できます。

## 4. 可逆性

- **戻せる**：条件の記録、先方への確認、判断軸の整理。
- **戻しにくい可能性がある**：
  - 承諾の意思表示：相手との約束になり、信用にも関わります。
  - 辞退：また声がかかるかは分かりません。
- **未確認**：今の会社に退職を伝えた後に撤回できるか。法律上・契約上の扱いは確認していません。

## 5. A_allowed（今やってよいこと／保留すること）

**今やってよいこと**
- **A1**：先方の条件の変化を、日付と内容ごとに記録する（あなた自身が行う）。
- **A2**：先方に次の4点を問い合わせる。
  - 確定した条件を書面で出してもらえるか
  - 条件がいつ確定するか
  - 返事の期限はあるか
  - 条件が変わっている理由
  
  これは問い合わせだけで、承諾や辞退の意思表示は含めません。
- **A3**：今の会社と先方を同じ項目で比べる表と、「これ以下なら移らない」という最低ラインを書き出す。基準を決めるのはあなたです。

**保留すること**（根拠：PDF §64.1 第2項。情報が足りないまま重大な約束をしない）
- **P1**：承諾の意思表示
- **P2**：今の会社への退職の意思表示
- **P3**：辞退の確定（あなたが判断軸で「移らない」と決めた場合は、あなたの判断で解除できます）

**禁止すること**：今回の相談からは該当なしです。

**追加提案（現時点では A_allowed の外）**
- **X1**：条件交渉。交渉するかどうか、何をどこまで求めるかが決まっていません。A3 が揃った後に、改めて評価します。

## 6. Strong Engine 候補

- **候補A（安全寄り）**：A1＋A3。先方には連絡せず、記録と判断軸の整理だけを進めます。
- **候補B（標準）**：A1＋A2＋A3。確定条件と期限を先方に確認し、比較に必要な材料を揃えます。
- **候補C（攻め）**：現時点ではありません。交渉（X1）の範囲が決まれば作れます。

## 7. 推奨

- **転職の決定そのもの**：hold
- **候補B**：recommend

## 8. 実行ステップ

- **今日**：この1週間の条件の変化を、思い出せる範囲で A1 として書き出す。
- **次に**：A2 の4点を先方に問い合わせる。
- **記録**：先方の回答内容と回答日。A3 の比較表と最低ライン。
- **補足（私の解釈です）**：条件が二転三転していること自体も、先方の会社の内情や意思決定の安定性を測る判断材料になります。

## 9. 撤退条件と再評価

いずれも私の提案で、まだ採用されていません。

- **止める指標**：先方が書面化を拒む場合や、条件が確定する前に承諾や退職を急かす場合。そのときは問い合わせを続けず、比較を再評価します。
- **再評価できる状態**：確定した条件を書面で受け取ったとき、または返事の期限が分かったとき。その時点で HOLD を解くかどうかをあなたが決めます。
- **再評価日**：まだ決めていません。たとえば「問い合わせから1週間たっても回答がなければ再評価する」という置き方があります。
