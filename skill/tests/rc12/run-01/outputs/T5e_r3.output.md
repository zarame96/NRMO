# T5e_r3

## 入力

「また明日」を英語に訳して。

## ツール履歴


## 出力全文

「また明日」の英訳は、使う場面によって変わります。

- **See you tomorrow.**：いちばん一般的な言い方です。
- **See you tomorrow, then.**：「じゃあ、また明日」のように、会話を締めくくるときに使います。
- **Talk to you tomorrow.**：電話やチャットで別れるときの言い方です。
- **Until tomorrow.**：少しかしこまった、または文学的な言い方です。

カジュアルな場面では、短く **"See ya tomorrow!"** と言うこともよくあります。
