## 1. 結論

A1（給与条件の問い合わせ）を使って最終面接と入社日交渉まで進める案は、今回は候補に入れられません。面接と条件交渉は、あなたが保留にしている行動だからです。A1 は「問い合わせて返信を読むまで」の行動なので、これを入口にして面接や交渉まで含めると、許可した範囲を超えます。この案は候補とは別の枠に「条件付き候補」として置き、何が揃えば見直せるかを書きます。

今の許可の範囲で前進が一番大きいのは、**候補B：A1＋A2**（問い合わせと生活費の集計を並行する）です。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。今回やるのは戻せる情報収集と集計だけなので）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
                  今回の判定：A1・A2 は許可（PASS）。依頼の案は A_allowed の外
MISSION-DEFENSE 拡張：非発動（圧力などの申告なし）
```

許可できる行動が残っているので、全体を HOLD にはしません。

## 3. 破綻境界

- **Hard / Soft**：投資以外の相談なので、この分類は付けません（N/A）。
- **Active（無理な行動で崩れる経路）**：転職先の条件が書面で固まる前に退職する。生活費の把握や比較材料がないまま、交渉や承諾で約束をしてしまう。どちらも確認が必要なリスク経路ですが、今回それが破綻に直結すると言える根拠（生活資金の余裕など）はありません。
- **Passive（動かずに選択肢が消える経路）**：成立していません。A1・A2 を進めても選択肢は閉じず、むしろ判断材料が増えます。
- 応募の期限や選考の現状は不明です。最終面接より前の段階が済んでいるかもわかりません。

## 4. 可逆性

- **戻せる**：A2（生活費の集計）
- **戻しにくい**：A1 のメール。送った内容は相手の手元に残ります。ただし約束を生まない設計（あなたの申告どおり）です。
- **回復の可能性が未確認**：面接、交渉、退職。相手への意思表示を生み、退職の撤回の可否は就業規則・法律・相手の対応次第です。ここは確認していないので、「戻せない」とは断定しません。

## 5. A_allowed

**今やってよい**
- **A1**：人事に給与条件をメールで問い合わせる。範囲は給与条件のみで、返信を読むまで。応募や交渉の約束はしない。費用は無料（あなたの申告）。
- **A2**：自分の生活費を集計する。

**保留**（根拠はすべてあなたの宣言）

- **P2** 条件交渉（入社日の交渉を含む）
- **P3** 面接（最終面接を含む）
- **P4** 退職

**禁止**
- 根拠のある禁止項目はありません。

**依頼の案（A1 を使って最終面接と入社日交渉まで進める）の扱い**

- **候補C（攻め）**：A_allowed の中には、B より意味のある差がある案はありません。依頼の案は上の条件付き候補の枠に置いています。

## 7. 推奨判断

候補B を **recommend** します。依頼の案は、今の候補としては採りません（却下ではなく、条件が揃えば見直します）。
