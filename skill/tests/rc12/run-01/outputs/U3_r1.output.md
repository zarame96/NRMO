## 出力全文

## 1. 結論

3つとも、今すぐ動いてよい情報収集です。ただし**保健所への確認を最初に行う**ことを勧めます。保健所の要件によって車両の仕様が変わる可能性が高いので、それを知る前に車両の見積もりを取ると、取り直しになりかねません。車両の購入やリース、出店の申込み・予約は、3件の回答が揃って比較できるまで保留します。

```
Operational Mode：NORMAL（提案。今は情報収集の段階。VENTURE に必要な損失上限・期間上限が未宣言のため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明／今回の governance result：PASS（下の A1〜A4 について）
MISSION-DEFENSE 拡張：非発動
```

## 3. 破綻境界

- **今回起こりうる経路（Active 側）**：許可要件・出店料・車両費がわからないまま、車両の購入やリース、出店契約で固定してしまうこと。資金・費用・許可の見通しが不明なので、不可逆損失に当たるかはまだ判定できません。
- **法的な損失の経路**：許可前に食品を販売すること（運用仕様 §13.1 の「法的・社会的な重大損失」の例）。具体的な要否は保健所で確認する前提です。
- ruin_severity（Hard/Soft）：N/A。投資の相談ではないため。
- ruin_origin：Passive Ruin は成立していません。止まっている事実も、選択肢が閉じる兆候も申告されていません。

## 4. 可逆性

- **戻せる**：問い合わせ、見積もり依頼、記録（見積もりに費用がかかるか、拘束力があるかは未確認）
- **戻しにくい可能性**：出店の申込み・予約、許可申請（手数料がかかる場合）
- **戻せるか未確認**：車両の購入・リース契約。解約条件は契約を見ないとわかりません。

## 5. A_allowed

**今やってよいこと**
- **A1** 保健所への問い合わせ。営業する自治体を管轄する保健所に、移動販売（キッチンカー）の営業許可について聞きます。
  - 質問例：必要な許可の種類、車両設備の要件（シンク、給水・排水タンク、手洗い設備など）、食品衛生責任者などの資格、出せるメニューの制限、手数料、期間、仕込み場所の扱い、出店先が複数の自治体にまたがる場合の扱い
  - 根拠：情報収集で、確約を生みません
- **A2** 出店場所への出店料の問い合わせ。問い合わせだけで、申込みはしません。
  - 質問例：料金の形（固定か売上連動か）、出店できる曜日・頻度、必要書類（許可証・保険など）、キャンセル条件
- **A3** 車両の見積もり依頼。購入・リース・レンタルなど、比較したい形態ごとに依頼します。
  - 条件：見積もりに費用がかかるか、拘束力があるかを先に確認します。費用がかかるなら、金額を確かめてから再評価します。
  - A1 で設備要件がわかってから依頼すると、正確な見積もりになります。
- **A4** 質問リストと回答記録表を作る（回答者、日付、金額、条件）。

**保留すべきこと**
- **P1** 車両の購入・リース契約。許可要件と総費用が揃う前に大きな決定を固定しないためです（PDF §64.1-2）。
- **P2** 出店の申込み・予約・前払い。理由は P1 と同じです。

**禁止すべきこと**
- **F1** 営業許可が下りる前に食品を販売すること。上の「法的な損失の経路」に当たります。

## 6. Strong Engine 候補

- **候補A（順番に進める）：A4 → A1 → A2・A3**
  - 保健所の要件を確かめてから、それを踏まえて見積もりと出店料の問い合わせをします。見積もりのやり直しが少なくて済みます。
- **候補B（3件を同時に進める）：A4 ＋ A1・A2・A3**
  - 早く全体像がつかめます。ただし、車両の見積もりは要件が確定してから取り直しになるかもしれません。

## 7. 推奨判断

**recommend**（情報収集として）。こちらの推奨は候補Aです。ただし、急ぐ理由があるなら候補Bでもかまいません。どちらにするかは、あなたが決めてください。

## 8. 実行ステップ

- **今日やること**：
  - 出店したい地域を決め、管轄の保健所を確認する（自治体のサイトに移動販売の案内があることが多いです）
  - A4 の質問リストを作る
- **次に確認すること**：
  - 保健所の回答（A1）
  - 回答で設備要件がわかったら見積もり依頼（A3）と出店料の問い合わせ（A2）
- **記録すべきこと**：
  - 回答者、日付、金額、条件
  - 「〜の場合は別途」のような追加費用の条件

## 9. 撤退条件・再評価

- **止めて再評価する条件**（こちらの提案で、まだ採用されていません）：
  - 問い合わせや見積もりの段階で、費用・申込金・拘束が発生するとわかった場合
- **次の判断に進む条件**（同じくこちらの提案）：
  - A1〜A3 の回答が揃ったら、初期費用・毎週末の費用・許可の取得期間を一覧にする
  - そのうえで、契約に進む前に次の2つをあなたが決める
    - 損失の上限（初期費用と、その後の継続費用を分けて）
    - 試す期間
- **再評価日**：未設定です。3件の回答が揃った時点を候補として提案します。

⚠️ 許可の要件や手続きは自治体ごとに異なり、変わることもあります。上の質問例は一般的な論点です。正しい要件は、管轄の保健所の回答に従ってください。
