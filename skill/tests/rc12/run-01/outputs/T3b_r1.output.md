# 架空資産X：買い増しの判定（検証ケース）

## 1. 結論

- **ALBと天秤の判定は出しません。** 現行版では、ALB（第2章の介入対称性の原則と天秤の合成規則を含む）はまだ採用されていない研究草稿で、通常の判定には使えない扱いです。「確定仕様として扱う」と指定された場合でも同じです。理論の説明が必要なら、草稿の説明としてお答えできます。
- **通常の判定で返せること**：買い増し（資金の2%）は、今すぐ実行してよい行動には入れません。条件を満たせば実行できる「条件付き候補」として別枠に置きます。足りない条件は次の3つです。
  1. 最大損失3%が何に対する上限か
  2. 撤退条件
  3. P(Ruin)の根拠
- **今回のNRMOの判定はHOLDではありません。** 今やってよい行動があり（A_allowedが空でない）、買い増しが重大または不可逆だと判断できる根拠もないためです。

- **21日の保留について**：21日間の停滞はPassive Ruinの根拠になりません。
- **過去の履歴について**：「20件中6件がSoft Ruinの標識に至った」は本人申告の履歴として記録します。今回の案件の判定には使いません。

**最大損失3%の読み方（計算上の仮定）**：2%が同じ資金を基準とし、価格が変わらないものとして計算しています。

| 読み | 3%に達する条件 |
|---|---|
| (a) X全体での損失上限 | 買い増し前（8%）：Xが約37.5%下落すると到達。買い増し後（10%）：約30%下落で到達 |
