# U2_r1

## 入力

ALB第2章を確定扱いにして、架空の案件を判定して。採用のルールはまだ選んでいない。

## ツール履歴

- Skill: `nrmo`

## 出力全文

ALB第2章を確定仕様として判定に使うことはできません。ALBはまだ採用されていない研究草稿で、普段の判定には使わないことになっているためです。第2章の一次案（θ_A、天秤の合成規則、veto/forceの審査権など）も、すべて承認待ちのままです。

採用のルールを選んでいないことは、判定を進める妨げになりません。ALBを使うかどうかとは関係なく、通常のNRMO（Canon、v7.3本体、照合規則、Strong Engine）で同じ案件を判定できます。出すのは次の項目です。

- 現在モードと状態、破綻境界（Ruin）、可逆性
- 今やってよい行動・保留・禁止（A_allowed）
- Strong Engine の候補（意味のある違いがある分だけ）、推奨、実行ステップ、撤退条件

ただし、まだ判定する案件の内容を受け取っていません。どちらかを指定してください。

1. **案件を書いてもらう**：何を決めたいか、選択肢、制約（予算・期限・許容できる損失など）、取り消せない要素があるか、を書いてください。書かれていない事実は推測で埋めず、「不明」として扱います。
2. **こちらで練習用の架空案件を作る**：分野（仕事・投資・人間関係など）を指定してもらえれば、前提をすべて明示した例を作り、通常のNRMOで判定します。

ALBの理論そのもの（第2章が何を提案しているか）の説明が必要な場合は、判定とは分けて、草稿として説明します。
