## 出力全文

## 1. 結論

**今は会社に退職を伝えないでください。** 転職先の条件がまだ分からないからです。あなたは「伝えたら取り消せない」と書いています。分からないことが多いまま取り消せない決断をするのは、NRMOでは保留の対象です（PDF §64.1(2)）。

そのかわり、**誘いの条件を書面で確かめることと、今の負荷を記録することは、今日から始められます**。これで次の判断の材料が揃います。転職そのものを止めるという意味ではありません。

## 2. 現在モードと状態

```
Operational Mode：SAFE（提案）— 負荷が高い（本人申告）うえに、取り消せない選択肢がある（本人申告）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV は退職通知について「取り消せない」と申告あり。VOL は観測なし。
                  LOAD は「負荷が高い」と申告あり、ただし L1/L2 などの水準には当てはめられない）
状態            ：現在の記録状態は不明
                  今回の governance result：HOLD（対象は「退職を伝える」「誘いを承諾する」の2つだけ。
                  重大な選択を判断する情報が実質的に不足、PDF §60.3）
                  情報を集める行動は下の A_allowed で許可しているので、空ではない
MISSION-DEFENSE 拡張：非発動
```

## 3. 破綻境界

- **Hard/Soft：N/A**。この区分は投資の領域でだけ使うためです（PDF §63.1）
- **Active 側で起こりうる経路**：条件を確かめないまま退職を伝え、そのあと転職先の条件が違っていたり、話がなくなったりする。その結果、収入が途切れる可能性がある。ただし、どれくらいの影響になるかは生活資金などが分からないので**不明**。今の段階で「生活基盤が崩れる」とは言えません
- **Passive 側で起こりうる経路**：
  - 誘いに回答期限があるなら、決めないまま期限が過ぎて選択肢が消えるかもしれない
  - 高い負荷が続いて、体調が悪くなるかもしれない
- **Passive Ruin：未成立**。回答期限も体調の変化も申告されていないので、選択肢が実際に閉じつつあるとは確認できません（PDF §63.2）

## 4. 可逆性

- **戻せる**：情報を集める、記録する、比べる、業務量について相談する
- **戻しにくい可能性がある**：誘いを承諾する（撤回できるかどうかは未確認です）
- **戻せない**：退職を伝える（本人申告。法律や契約の上でどうなるかは確認していません）

## 5. A_allowed

**今やってよいこと**

| 番号 | 何をするか | 範囲・確約・費用 |
|---|---|---|
| A1 | 誘っている会社に、条件を書面で示してもらうよう頼む | 職務、年収、勤務条件、入社時期、回答期限、正式な内定かどうか。承諾や辞退の意思は伝えない |
| A2 | 自分の判断軸を書き出して、2社を比べる | 自分だけで行う作業。どんな軸にするかは自分で決める |
| A3 | 自分の側の条件を確かめる | 就業規則にある退職の申し出時期、生活資金が何か月分あるか |
| A4 | 今の負荷を記録する | 残業時間、休日に休めているか、睡眠、体調。毎日記録する |
| A5 | 上司に業務量や優先順位を相談する | 転職の話は出さない（根拠：前提。転職の意思を出すかどうかは P1 とつながるため） |
| A6 | 眠れない・体調不良などが出たり続いたりする場合は、医師や産業医に相談する | 根拠は、高い負荷が本人申告であること。兆候そのものはまだ申告されていない。費用は事前に確かめる |

**保留すべきこと**

- **P1：退職を伝える。**
  - 根拠：取り消せないこと（本人申告）、重大な情報が不足していること（PDF §64.1(2)）
- **P2：誘いを承諾する。**
  - 根拠：同じく PDF §64.1(2)
- **再評価の条件**：次の3つが揃ったら見直します
  - A1 で条件と回答期限が書面で揃う
  - A3 の確認が済む
  - A2 の比較ができる

**禁止すべきこと**：今の時点では、根拠のある禁止はありません。

**追加提案 X1（今はまだ A_allowed の外）：条件交渉**

保留していても交渉はできます。ただ、何をどこまで求めるかを決めるには、A1 と A2 の結果が必要です。それが揃ったら改めて評価します。

## 6. Strong Engine 候補

- **候補A（安全寄り・今の会社を立て直す）：A4＋A5（＋A6、条件を満たす場合）**
  - 今の会社の負荷が下がるかどうかを確かめます
- **候補B（標準・比べる材料を揃える）：A1＋A2＋A3＋A4**
  - 回答期限までに、2社を同じ軸で比べられる状態にします

**候補C（攻め）は別に作っていません。** 攻める本体は承諾（P2）と退職の通知（P1）で、どちらも保留中だからです。

AとBは同時に進めることもできます。ただし負荷が高いので、両方を抱えて無理にならないかは自分で判断してください。

## 7. 推奨判断

- 退職を伝えること・承諾すること（P1・P2）：**hold**
- その間に進める行動：**候補Bを recommend**

最終的に決めるのはあなたです。

## 8. 実行ステップ

- **今日**：
  - A2：比べる軸を3〜5個書き出す。迷っている本当の理由が「負荷」なのか「誘いの魅力」なのかも書く
  - A4：負荷の記録を始める
- **次に**：
  - A1：誘ってくれた会社に、条件と回答期限を書面で示してもらうよう頼む
  - A3：就業規則と生活資金を確かめる
- **記録すること**：考えた選択肢、それぞれ保留か実行か、その理由

## 9. 撤退条件・再評価

- **止める・切り替える指標**：
  - 体調の不調が出た、または続いている → A6 を優先し、比べる作業は後回しにする
  - 条件が書面で出てこない → P1 の保留を続ける
- **再評価の条件**：上の P1 の再評価条件が揃ったとき
- **再評価日**：回答期限が分かったら、その数日前に判断日を置くことを提案します（こちらの提案で、まだ採用されていません）
