# 転職判断：今の会社に残るか、誘われた会社に移るか

## 1. 結論
今の情報では、「残る／移る」のどちらがよいかは判断できません。決め手になる事実（条件、回答期限、生活資金、何を重視するか）がまだ分かっていないためです。

- **内定の承諾と退職の意思表示は、今は保留**します（HOLD）。
- **情報集めと比較の準備は、今日から進めてかまいません。** 保留は全部止めるという意味ではありません。

## 2. 現在モードと状態
```
Operational Mode   ：NORMAL（提案）
                     理由：期限・負荷・圧力の申告がなく、標準の姿勢から始めるのが妥当なため
Context Override   ：なし
type_zero_gate     ：未判定（IRREV / VOL / LOAD の観測なし）
現在の記録状態     ：不明
governance result  ：HOLD（承諾・退職という重い判断だけが対象）
MISSION-DEFENSE    ：非発動（圧力・誘導の申告なし）
```
- HOLD の根拠：PDF §60.3、§64.1-2。重い判断に必要な情報が大きく欠けているためです。
- HOLD を解いて決定に進めるのは、あなたが明示的に承認したときだけです。

## 3. 破綻境界
- **重大度（Hard／Soft）**：投資以外の領域なので N/A です。
- **ありうる経路（今回そこに達するかは未確認）**
  - 移る側：書面の条件や内定がないまま退職を伝えると、収入が途切れる可能性があります。どこまで耐えられるかは、生活資金が分からないため不明です。
  - 移る側：承諾したあとに取り消すと、信用を損なう可能性があります。
  - 残る側：誘いの回答期限が過ぎると、この選択肢そのものが消えます。
- **Passive Ruin（動かないことによる破綻）：未成立**
  - 回答期限が分からないため、「選べる期間が閉じる」ことを確認できません。
  - 期限が判明すると、ここが一番の監視点になります。

## 4. 可逆性
- **戻せる**：判断軸の整理、条件の問い合わせ、面談、資金の計算
- **戻しにくい**：内定の承諾、退職の意思表示
  - 撤回できるかどうか（法的にも、相手の対応としても）は確認していません。
- **戻せない**：今の情報からは特定できません。

## 5. A_allowed（今やってよいこと／保留／禁止）
**今やってよい**

| 番号 | 行動 | 補足 |
|---|---|---|
| A1 | 判断軸を書き出す | 何を得たいか、何は譲れないか。本人だけで行う作業 |
| A2 | 生活資金が収入なしで何か月もつかを計算する | 本人だけで行う作業 |
| A3 | 誘ってくれた会社に、条件の書面提示と回答期限を問い合わせる | 承諾の意思は示さない。相手に約束を生まない |
| A4 | 誘ってくれた会社の人と面談・見学をする | 承諾を前提にしない。勤務時間との調整はご自身で |

**保留**
- P1：内定の承諾（PDF §64.1-2。情報不足のまま重い判断を固定しないため）
- P2：現職への退職の意思表示（同上）

**禁止**
- 現時点では、根拠のある禁止項目はありません。承諾と退職は「禁止」ではなく「保留」です。

**追加提案（今の A_allowed の外）**
- X1：現職の上司に相談する、または待遇を交渉する
  - 転職の意向が伝わる可能性があります。伝わってよいか、何を交渉するかをあなたが決めた時点で見直します。

## 6. Strong Engine 候補
- **A（安全寄り）**：A1＋A2
  - 社外には動かず、自分の判断軸と資金だけを固めます。
- **B（標準）**：A1＋A2＋A3
  - 書面の条件と回答期限を手に入れ、比較できる状態にします。
- **C（攻め）**：A1＋A2＋A3＋A4
  - 面談まで進めて、相手の職場の実態も比較材料に加えます。

## 7. 推奨判断
**hold**：承諾と退職は保留です。

候補の中では、B が最小限の動きで比較材料が揃う標準的な選択肢です。どれを選ぶかはあなたが決めてください。

## 8. 実行ステップ
- **今日**
  - A1：次の問いに答えて書き出す
    - 転職で得たいものは何か
    - 現職の不満は、残ったまま解決できるか
    - 譲れない条件は何か
  - A2：生活資金が何か月もつかを計算する
- **次に**
  - A3：条件の書面提示と回答期限を確認する
- **記録すること**
  - 回答期限
  - 書面で示された条件
  - 判断軸ごとの、両社の比較

## 9. 撤退条件・再評価
- **再評価の条件**：書面の条件と回答期限がそろった時点
- **再評価日**：回答期限が分かった時点で、その前に置きます。今は日付を決められません。
- **再評価前に止める指標（こちらの提案で、まだ採用されていません）**：相手が書面を出さないまま、承諾だけを急がせる場合
