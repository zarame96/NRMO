## 3. 破綻境界（投資の領域）
- **Hard（severity）**：取り戻せない資本の損失。今回の買い増しがここに届くかは、**買い増し額・AMDの保有比率・信用取引の有無が不明なため判定できません**。
- **Soft（severity）**：損失が膨らみ、リスクを落とす方向へ追い込まれる状態。上と同じ理由で判定できません。
- **Active（origin）**：起こりうる経路は、一つの銘柄に資金が集中しすぎることです。今そうなっているかは未確認です。
- **Passive（origin）**：**成立していません**。今週買わないことで回避の窓が閉じる、という根拠は確認できていません（PDF §63.2）。

**保留すべきこと**
- **P1**：今週の買い増しの実行。根拠は二つです。一つは、規模が分からず重大な案件か判定できないことです（PDF §64.1-2：重要な情報が不足したまま大きな決定を固定しない）。もう一つは、投資で必須とされる項目（最大損失、ポジション上限、撤退条件、再評価日）がまだ決まっていないことです（運用仕様 §10.1）。A1〜A3が揃えば再評価できます。

**禁止すべきこと**
