## 3. 破綻境界（投資の領域なので、重さ Hard/Soft と原因 Active/Passive の二軸で見ます：PDF §63.1）

  - (b) 今回の買い増し分の損失を3%までとする（現物で2%を買うだけなら損失は最大2%なので、レバレッジを使わない限りこの上限に届きません）

  - 21日（τ）は停滞していた期間として記録します。
  - 「20件中6件（30%）でSoft Ruinの標識に至った」は本人申告の履歴で、今回の案件の認定には使いません。θ_Aとの比較もALBの判定に当たるので行いません。

**εとの比較（計算上の仮定）：** 0.02 ≤ 0.05 は数字の上では成り立ちます。ただし、次の4点が確認できていないので、許可にも停止にも使いません。
