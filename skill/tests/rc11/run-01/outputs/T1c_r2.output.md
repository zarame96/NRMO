## 出力全文

## 1. 結論

**今の時点では、転職するかどうかを決めないでください。** 先に、誘っている会社に条件を書面で確定してもらってください。この1週間、条件が毎日のように変わっています。この状態でオファーを受けたり退職を伝えたりすると、比べる材料が固まらないまま大きな決定をすることになります。決定は保留にしますが、確認と整理はすぐ始められます。

## 2. 現在モードと状態

```
Operational Mode   ：NORMAL（提案）— 負荷は低いと申告あり。急ぎの事情は申告なし
Context Override   ：なし
Type ZERO          ：未判定（IRREV の観測なし）
現在の記録状態      ：不明
governance result  ：「受諾・退職」の決定について HOLD
MISSION-DEFENSE    ：非発動（急かされている・圧力を受けているという申告なし）
```

- **観測値の整理**
  - VOL（変動）：誘っている会社の条件が高い。本人の申告で、この1週間、毎日のように変わっています。
  - LOAD（負荷）：低い。本人の申告です。
  - 「状況は落ち着いていて、ほとんど変化はない」：何についての話か（現職か、本人の生活全体か）は書かれていません。対象が別なら、上の VOL と矛盾しません。
- **HOLD の理由**：重大な決定に必要な情報が実質的に足りていないためです（PDF §60.3、§64.1(2)）。今やってよい行動は残っているので、全体を止めるわけではありません。

## 3. 破綻境界

- **Hard/Soft**：N/A。これは投資の領域でだけ使う区分です。
- **Active 側の経路**：条件が確定しないまま退職を伝え、そのあと条件が下がる、またはオファー自体がなくなる経路です。収入が途切れる可能性があります。ただし、生活資金や撤回できるかどうかが不明なので、取り返しのつかない損失だとは断定しません。
- **Passive Ruin**：未成立です。待つことでオファーの機会が閉じるかどうかは、回答期限が申告されていないため確認できません。

| 戻せない | 現時点では特定できません |

## 5. A_allowed

**今やってよいこと**
- **A1**：誘っている会社に、最新の条件を書面（オファーレターやメール）で出してもらうよう依頼する。承諾の意思表示は含みません。
- **A2**：この1週間の条件の変化を時系列で記録する（いつ・誰から・何が・どう変わったか）。本人だけで行います。
- **A3**：自分の判断軸を書き出す（譲れない条件、最低ラインの条件）。本人だけで行います。
- **A4**：現職の条件を、A3 と同じ判断軸で書き出す。社内には伝えません。
- **A5**：誘っている会社に次の3点を質問する。
  - 条件が変わる理由
  - 誰が決めているのか
  - いつ確定するのか、回答期限はあるか

  関心があることは伝わりますが、承諾にはなりません。

**保留すべきこと**
- **P1**：オファーの受諾。根拠は PDF §64.1(2)（条件が確定していないため）。
- **P2**：現職への退職の申し出。根拠は P1 と同じです。

**禁止すべきこと**
- 現時点で、根拠のある禁止項目はありません。

**追加提案（条件付きで、今やってよいことの外）**
- **X1**：条件交渉。A3 の判断軸と A1 の書面条件がそろってから、何をどこまで求めるかを決めたうえで再評価します。

## 6. Strong Engine 候補

- **候補A（相手に連絡しない）**：A2＋A3＋A4。自分の側の比較材料だけを固めます。
- **候補B（標準）**：A2＋A3＋A4＋A1＋A5。比較材料を固め、相手に書面での提示と確定時期を求めます。
- **候補C（攻め）**：今やってよい範囲には該当する案がありません。交渉（X1）や受諾（P1）は、今やってよいことの外にあります。

## 7. 推奨判断

**recommend：候補B**
転職の決定そのものは **hold** です。

条件が二転三転していること自体が、相手の会社の意思決定のしかたを示す情報です。書面を出してもらえるか、確定時期を答えられるか。その反応も比較材料になります。

## 8. 実行ステップ

- **今日**
  - A2：条件の変化を記録する
  - A3：判断軸を書き出す
- **次に**
  - A1：最新の条件を書面で依頼する
  - A5：変わる理由・決めている人・確定時期・回答期限を質問する
  - A4：現職の条件を同じ判断軸で並べる
- **記録すべきこと**
  - 相手の回答内容と、回答までにかかった日数
  - 書面が出たか、口頭のままか

## 9. 撤退条件（こちらの提案で、まだ採用されていません）

- **止める目安**：書面での提示を依頼しても条件が確定しない、または書面の条件が A3 の最低ラインを下回る場合は、転職の検討を打ち切る選択肢を本人に返します。
- **再評価のタイミング**：書面の条件を受け取った時点です。回答がない場合に、依頼から何日待つかは本人が決めてください。
- **再開の条件**：書面の条件と A3・A4 の比較がそろえば、P1・P2・X1 を再評価できます。
