## 出力全文

## 1. 結論

今の情報では、残るか移るかを決められません。両社の条件、あなたが重視すること、生活資金の余裕、回答期限がどれも分からないためです。

- **転職の確定（承諾や退職の表明）は保留にします。**
- **情報を集める行動は止めずに進めます。** 何を確かめるかは下にまとめました。
- 最終的に決めるのはあなたです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。強い負荷や急な変化の申告がないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
今回のgovernance result：HOLD（転職の確定について。重大な判断に必要な情報が実質的に足りない：PDF §60.3）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告なし）
```

HOLD を解いて ACTIVE に戻すには、あなたの明示的な承認が必要です。

## 3. 破綻境界

- **Ruin severity（Hard/Soft）**：N/A（投資の領域ではないため）
- **Active 側の経路（起こりうるもの）**：転職先の条件を書面などで確かめる前に退職を伝えると、収入が途切れる可能性があります。ただし規模や回復のしやすさは、生活資金などが分からないため判断できません。
- **Passive Ruin**：未成立。誘いに回答期限があるか（機会が閉じるか）が分からないためです。動かずにいることの損失は、期限が分かってから評価します。

## 4. 可逆性

- **戻せる行動**：考えを整理する、条件を問い合わせる、資金を確認する
- **戻しにくい可能性がある行動**：承諾の意思表示、退職の意思表示。撤回できるかどうか（法的な扱い、相手の対応、契約条件）は未確認です。専門家の判断の代わりにはなりません。

## 5. A_allowed（許容行動集合）

**今やってよいこと**

- **A1**：判断軸を書き出す。あなたが重視すること（仕事内容、収入、成長、働き方、人間関係など）と、譲れない条件です。
- **A2**：誘ってくれた会社に条件を問い合わせる。職務内容、報酬、勤務条件、回答期限、条件を書面で出してもらえるか、を聞きます。質問するだけで、承諾の意思表示は含めません。問い合わせ自体が関心ありと受け取られる可能性はあります。
- **A3**：今の会社に残った場合の見通しを整理する。不満が変えられるものか、今後どうなりそうかを自分でまとめます。
- **A4**：生活資金を確認する。収入が一時的に途切れても何か月持つかを把握します。

**保留すべきこと**

- **P1**：転職先への承諾。情報が足りないまま重い決定をすることになるためです（PDF §64.1-2）。
- **P2**：今の会社への退職の表明。理由は P1 と同じで、撤回できるかも未確認です。
- **P3**：今の会社に誘いのことを伝えて引き留め条件を交渉する。あなたがそれを望むかどうか、関係にどう影響するかが分からないためです。

**禁止すべきこと**

- 今の時点では、根拠のある禁止事項はありません。

## 6. Strong Engine 候補

- **候補 A（社外に動かない）：A1＋A3＋A4**
  自分の中で整理を済ませてから相手に連絡します。外に何も伝えずに進められますが、回答期限があると間に合わないおそれがあります。
- **候補 B（並行して進める）：A1＋A2＋A3＋A4**
  相手から条件と期限を早く得られるので、比べる材料がそろいます。

意味のある違いがあるのはこの2案だけです。

## 7. 推奨判断

- 転職するかどうかの確定は **hold** です。
- 情報集めは候補 B を **recommend** します。回答期限が分からないと、急ぐ必要があるかどうかも判断できないためです。

## 8. 実行ステップ

- **今日**：A1（判断軸を書き出す）と A4（生活資金の確認）
- **次に**：A2 で条件と回答期限を問い合わせる。並行して A3 を進める
- **記録すること**：両社を同じ判断軸で並べた比較表、相手の回答内容、回答期限

## 9. 撤退条件と再評価

- **止める指標**：問い合わせの途中で、即答を迫るなどの圧力が出てきた場合。そのときは MISSION-DEFENSE（境界を保つ、保留する、退避する）に切り替えて再評価します。
- **再開（ACTIVE）できる状態**：A1〜A4 の情報がそろい、あなたが承認したとき
- **再評価日**：回答期限が分かったら、その前にあなたが決めて設定してください（現時点では日付を置きません）。
