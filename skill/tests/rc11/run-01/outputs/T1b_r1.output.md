## 1. 結論

**今は退職を伝える判断をしない（hold）。** 一方で、比べるための材料集めは今日から始めてよいです。

あなたは「退職を伝えたら取り消せない」と書いています。それに対して、判断に必要な情報（誘い先の条件が書面で出ているか、回答期限、生活資金、何を重視するか）がまだ分かりません。取り消せない決定をこの状態で固めることは、NRMOの規則（PDF §64.1-2）で許容行動から外れます。退職と承諾は、材料が揃った時点で改めて判断します。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案）— 取り消せない選択肢があり、負荷も高いとの申告があるため
Context Override：なし
Type ZERO       ：未判定（IRREV＝退職の意思表示は取り消せないとの本人申告あり／VOL・LOADの区分は観測なし）
状態            ：現在の記録状態は不明
                  今回のgovernance result：HOLD（対象は「退職を伝える」「誘い先に承諾する」の2つ。重大で取り消せない候補に対して情報が足りないため）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告がないため）
```

- 「負荷が高い」はあなたの申告です。これをType ZEROのLOADの区分に当てはめることはしていません。
- 情報収集などの行動は許容集合に残っているので、全体を止めるわけではありません。
- HOLDを解いて判断に戻るのは、あなたが明示的に承認したときです。

## 3. 破綻境界

- **Hard / Soft**：投資の領域ではないので N/A です。
- **Active側（自分から動いて起きる損失）**：転職先の条件を書面で確かめる前に退職を伝えた場合、話が崩れると収入が途切れる経路があります。ただし、どれだけの損失になるか、どれだけ回復できるかは、生活資金が分からないので判定できません。
- **Passive側（動かないことで選択肢を失う）**：未成立です。
  - 誘い先に回答期限があれば、何もしないうちにその選択肢が消える可能性があります。ただし期限があるかどうかが分かりません。
  - 高い負荷が続いた場合に健康が損なわれる可能性はあります。ただし、体調の悪化は申告されていないので、損失の境界に達しているとは判定しません。

## 4. 可逆性評価

- **戻せる**：情報を集める、比較表を作る、負荷を記録する、就業規則を読む。
- **戻しにくい**：誘い先への承諾の意思表示。法的に撤回できるかは確認していません。必要なら専門家に確かめてください。
- **戻せない**：現職に退職の意思を伝えること（あなたの申告）。

## 9. 撤退条件

- **体調**：A6の記録で睡眠や体調の悪化が続いたら、比較作業より先にA7を行います。
- **誘い先の対応**：書面の提示を断られた、または即答を迫られた場合は、その事実を比較表に記録したうえで再評価します。
- **P1・P2を再評価する条件**：書面の条件、回答期限、生活資金が何か月もつか、判断軸の4つが揃ったとき。
- **再評価日**：回答期限が分かったら、その数日前に置くことを提案します（こちらの提案で、まだ採用されていません）。
