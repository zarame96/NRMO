## 3. 破綻境界（PDF §63.1・§63.2）

- **ruin_severity**：投資領域なので使えます。
  - Hard Ruin は回復不能な損失（破産、永久的な資本損失）。
  - Soft Ruin は原理的に回復可能な戦略的失敗（強制的な Risk-Off）。
  - 今回どちらに当たるかは、まだ判断できません。
- **ruin_origin**：
  - Active：過大な集中や撤退条件のない拡大で崩れる経路です。
  - Passive：**未成立**です。
    - 21日は停滞の期間です。保留が見込みのある選択肢を閉じたかどうか（avoidability window の閉鎖）は確認できていません。
    - 「20件中6件が Soft Ruin の標識に至った」は本人申告の履歴として記録します。今回の案件の認定には使いません。
- **本人宣言の数値**：保有比率8%、買い増し額2%（今回の行動量で、上限ではない）、許容できる最大損失3%。
- **最大損失3%の読みは二通りあり、決まっていません**（以下の比率は計算上の仮定。レバレッジなし、評価基準は資金に固定）。
  - (a) **X の保有全体の損失**とする読み：買い増し後の保有は約10%なので、X が約30%下落すると3%に達します。現状の8%なら約37.5%の下落です。
  - (b) **買い増し分だけの損失**とする読み：買い増し分は2%なので、レバレッジがなければ3%には届きません。この読みでは、既存の8%にかかる上限は決まっていないことになります。
