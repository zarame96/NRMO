# 週末キッチンカー開始判定

## 1. 結論

**まだ「始める」と決めて、お金を払ったり契約したりする段階ではありません（hold）。ただし、準備はすぐ進めて構いません。**

初期費用は30万円までと決めていて、撤退の考えもすでにあります。足りないのは次の3点です。

- 撤退条件の意味がまだ一つに決まっていない
- 合計でいくらまで損してよいかが決まっていない
- 営業に必要な許可や、車をどう用意するかが確認できていない

この3点が埋まれば、開始を判断できます。

## 2. 現在モードと状態

```text
Operational Mode   ：VENTURE（提案）
Context Override   ：なし
Type ZERO Mode     ：未判定（不可逆性・変動・負荷の観測値がない）
状態               ：現在の記録状態は不明
今回の判定結果      ：全体は HOLD ではない。開始の確約（P1）だけ保留
MISSION-DEFENSE 拡張：非発動
```

VENTURE（上限を決めたうえでの試行）を提案する理由は、上限を決めて試す相談だからです。運用仕様 §8.1.3 の条件の充足状況は次のとおりです。

| 条件 | 状況 |
|---|---|
| 損失上限 | 初期費用の上限（30万円）だけ決まっています。合計損失の上限はまだ決まっていません |
| 時間上限 | 「3か月」とあります。ただし、どの時点で判定するかは決まっていません |
| 撤退条件 | あります。ただし、2通りに読めます（§9） |
| 再評価日 | まだ決まっていません |

このモード提案は、開始してよいという許可でも、損失上限を決めたことでもありません。

## 3. 破綻境界

| 項目 | 内容 |
|---|---|
| 損失の深刻さ（Hard / Soft） | 対象外です。この分類は投資の場面に限るためです（PDF §63.1） |
| 自分の行動から生じる破綻（Active Ruin） | 起こりうる経路は3つです。①初期費用が30万円を超える。②月の赤字に上限がなく、撤退判定まで膨らみ続ける。③必要な許可を満たさないまま営業する。ただし、生活資金や本業の状況が分からないので、どれかが不可逆な損失になるとは言い切れません |
| 動かないことによる破綻（Passive Ruin） | 成立しません。準備しながら様子を見ても、取り返しのつかない状態にはなりません |

## 4. 可逆性

- **戻せる**：試算、問い合わせ、見積もりの取得
- **戻しにくい可能性がある**：車両の購入やリース、出店の契約、設備の購入
  - 解約できるか、売り直せるか、違約金がいくらかは契約しだいで、まだ確認できていません

## 5. 許容行動集合 A_allowed

### 今やってよいこと

| 番号 | 行動 |
|---|---|
| A1 | 撤退条件の読み方を一つに決める（§9の(a)・(b)、按分を含むかどうか） |
| A2 | 合計でいくらまで損してよいか（合計損失の上限）を決める |
| A3 | 自治体や保健所に、キッチンカー営業に必要な許可・届出・設備の要件を問い合わせる。法令の判断は先方の回答に従います |
| A4 | 車両の調達方法（購入、リース、レンタル、シェア）ごとに見積もりと解約条件を集める。契約はしません |
| A5 | 出店場所の候補に、出店料・歩合・出店頻度の条件を問い合わせる。申し込みはしません |
| A6 | 1日あたりの損益の試算表を作る（下の式を参照） |

A3〜A5 は、料金がかかる場合は金額を確認してから行ってください。

A6 の式：月の赤字 ＝ 月の費用（材料費＋出店料＋燃料・駐車代＋保険など）− 月の売上
- 初期費用の按分を費用に入れるかどうかは、A1 で決めた定義に合わせます
- 結果は、何食売れれば赤字にならないかで表します

### 保留すること

- **P1**：初期費用の支払い、車両・出店・仕入れの契約
  - 根拠：大きな確約を情報不足のまま行わない（PDF §64.1-2）
  - 再評価の条件：A1〜A3 が埋まったら見直します

### 禁止すること

- **F1**：初期費用が30万円を超える支出（ご自身で決めた上限）
- **F2**：A3 で必要と分かった許可・届出を満たさないままの営業（法的な損失につながる経路、運用仕様 §13.1・§11-14）

## 6. Strong Engine 候補

- **候補A（安全寄り）**：A1＋A2＋A3＋A6
  - 自分で決めるべき定義と許可の要件を先に固めます。そのうえで、開始するかを見直します
- **候補B（標準）**：A1〜A6 すべて
  - 見積もりや出店条件も並行して集めます。見直しのときに、実際の数字で損益分岐を確かめられます

許容範囲の中で、攻めの候補Cとして意味のある違いが出せる案はありません。まだ契約を前提とした試行はできないためです。

## 8. 実行ステップ

- **今日やること**：A1・A2 を決めて、文章にしておく
- **次に確認すること**：A3（許可の要件）、A4（車両の解約条件）、A5（出店条件）
- **記録しておくこと**：
  - 問い合わせた先、日付、回答
  - 見積もり額
  - A6 で出した、赤字にならない食数

## 9. 撤退条件

ご自身で決めた条件の原文は「3か月やって月の赤字が5万円を超えたら撤退」です。これは次の2通りに読めます。

- **(a)** 3か月が終わった時点で判定する（3か月目の月の赤字で見るのか、3か月の平均で見るのかも決める必要があります）
- **(b)** 3か月の間に、どれか1か月でも赤字が5万円を超えたら、その時点で撤退する

さらに、「月の赤字」に初期費用の按分（30万円÷3＝月10万円）を含めるかどうかも決まっていません。

- 含める場合：売上が少し足りないだけで、ほぼ確実に5万円を超えます
- 含めない場合：初期費用30万円は、月の赤字とは別に損失として扱います

**(a) の読みでは、判定までの月の赤字に上限がありません。** そのため「30万円＋5万円×3か月＝45万円」という数字は計算例にすぎず、損失の上限にはなりません。

こちらから追加で提案する条件（まだ採用されていないもの）：

- 合計損失の上限を決める（A2）
- 再評価日を決める。たとえば初回出店から4週間後など、日付はご自身で決めてください
- 初期費用が30万円を超えそうになったら、支払う前に止まる

**開始を見直す条件**：A1〜A3 が埋まり、30万円以内に収まる車両の調達方法と、必要な許可が確認できたとき。
