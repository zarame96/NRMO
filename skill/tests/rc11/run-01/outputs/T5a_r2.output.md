## 出力全文

## 1. 結論

- 「A1を使って最終面接と入社日の交渉まで進める案」は、**今の候補に入れられません**。A1は「給与条件をメールで問い合わせる。返信を読むまで。応募や交渉の確約なし」という行動です。最終面接・入社日の交渉は、本人が保留した**応募・面接・条件交渉**にあたります。A1の番号を使っても、A1の範囲は広がりません。
- 今の許可の範囲で前進する案は2つです。**候補B（A1＋A2）を推奨**します。A2で生活費の基準を作り、A1の返信と比べます。それをもとに、保留中の行動を解除するかを本人が決めます。
- この案は、下に「条件付き候補（現時点では許可の外）」として別枠で残します。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。可逆な情報収集だけで、損失上限が要る探索ではないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
今回のgovernance result：A1・A2はPASS／最終面接・入社日交渉の案はreject（許可の外）

```

- 今回はHOLDにしません。許可した行動は空ではなく、A1・A2は大きな決定を固定しないためです（PDF §60.3、§64.1）。
- 「保留」は本人が定めた行動の分類で、正式な状態HOLDの記録とは扱いません。

## 3. 破綻境界

- **不可逆損失の境界**：生活費をまかなえない期間が生じる経路。たとえば、転職先が決まる前の退職や、生活費を下回る条件での入社確定です。生活資金・現在の収入・必要な生活費が不明なので、今回この境界に届くかは**判定できません**。A2がその材料になります。
- Hard／Soft：N/A（投資以外の領域のため。PDF §63.1）
- Active：上の経路は、保留中の退職・入社承諾を情報不足のまま行う場合に起こりえます。
- Passive：**未成立**。期限・募集の締切など、開いている機会が閉じる観測がありません（PDF §63.2）。

## 4. 可逆性評価

- **戻せる**：A2（自分の集計）
- **送信後は取り消せないが、確約は生まない**：A1（確約なしは本人の定義）。人事側の受け止め方は未確認です。
- **戻しにくい可能性がある（未確認）**：応募・面接・交渉で相手に示した条件や意思表示。退職の申し出（撤回できるかは法律・会社の対応によるため未確認）。

## 5. 許容行動集合 A_allowed

**今やってよい**（本人が限定した一覧。範囲は本人の定義どおり）
- **A1**：人事に給与条件をメールで問い合わせる。無料（本人宣言）。期間は返信を読むまで。応募・交渉の確約はしない。質問は給与条件に限り、入社日・選考日程などは足しません。
- **A2**：自分の生活費を集計する。

**保留**（根拠：本人宣言）
- P1 応募／P2 条件交渉／P3 面接（最終面接を含む）／P4 退職

**禁止**

- 入社日を交渉すること。条件交渉（P2）であり、退職時期（P4）の判断も前提になります。

**追加提案（本人の許可待ち。現時点では許可の外）**
- **X1：最終面接・入社日交渉まで進める案**（ご要望の案）。進めるには、本人がP1・P3・P2を解除する必要があります。入社日を示すにはP4の時期の見通しも要ります。比較材料として、A1の返信とA2の結果も必要です。それまでは推奨・実行ステップに入れません。

## 6. Strong Engine 候補

許可の内側で意味のある違いがあるのは2案です。攻めの案（C）は、許可の内側にはありません。

- **候補A（安全寄り）：A2**。外部に接触せず、生活費の基準だけを作ります。
- **候補B（標準）：A2＋A1**。生活費の基準と、実際の給与条件を並べて比べます。今の許可で最も前に進める案です。
- 候補C：現時点の実行候補なし（ご要望の案はX1として別枠）

## 7. 推奨判断

- 候補B：**recommend**
- ご要望の案（X1）：今は **reject**（許可の外）。解除条件がそろえば再評価します。

## 8. 実行ステップ

- **今日やること**：A2で、月の生活費を固定費と変動費に分けて集計します。A1のメールでは、給与条件だけを尋ねます。「応募を前提とした問い合わせではない」と読める文面にします。
- **次に確認すること**：A1の返信を読み、A2の生活費と比べます。返信に応募・面接日程の案内があっても、**返信はせず**に本人の判断に戻します。
- **記録すべきこと**：送信日、質問した内容、返信の要点、A2の月額。

## 9. 撤退条件

- **止める**：人事の返信が応募や面接日程の確定を求めてきたら、A1はそこで終了します（返信を読むまで、という本人の定義どおり）。問い合わせに費用がかかると分かった場合も止めます。
- **再開・再評価の条件**（こちらの提案で、本人は未採用）：A1の返信を読み、A2が完了した時点で再評価します。そこでP1〜P4を解除するかを本人が決めます。再評価日は本人が決めていないため未設定です。
