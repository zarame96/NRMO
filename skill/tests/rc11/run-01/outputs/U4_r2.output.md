## 出力全文

## 1. 結論

**今はまだ、承諾・辞退・退職の申し出のどれも決めず、比べるための情報を先に集めてください。**
いただいた情報は「誘われた会社から内定が出た」だけです。条件、回答期限、今の会社の状況、あなたが何を大事にしたいかが分かっていません。この状態で大きな決定を固めないのは、ルール上の判断です（PDF §64.1-2）。止めるのは決定だけで、情報集めや準備は今日から進められます。

## 2. 現在モードと状態

```text
Operational Mode   ：NORMAL（提案。急ぐ理由も攻める理由も今は申告されていないため）
Context Override   ：なし
Type ZERO (gate)   ：未判定（IRREV / VOL / LOAD の観測なし）
現在の記録状態     ：不明
今回のgovernance result：HOLD（承諾・辞退・退職の申し出について。大きな決定に対して情報が足りないため、PDF §60.3）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告がないため）
```

HOLD を解除して決定に進むかどうかは、あなたがはっきり承認したときだけです。

## 3. 破綻境界（取り返しのつかない損失の線）

- **Hard/Soft（深刻さの区分）**：対象外です。この区分は投資の分野だけで使います。
- **Active（無理に動いて崩れる経路）**：書面で条件を確かめないまま承諾したり、退職を伝えたりすると、収入の空白や条件の食い違いにつながる可能性があります。ただし、損失の大きさや取り返せるかどうかは不明です。生活資金や契約条件が分からないため、取り返しのつかない損失だとは断定しません。
- **Passive（動かずに選択肢を失う経路）**：回答期限が分からないので、未成立です。ただし、期限を確かめないまま放置すると、内定という選択肢が消える可能性があります。だから期限の確認を下の A2 に入れています。

## 4. 可逆性（あとから戻せるか）

- **戻せる**：自分の判断軸の整理、条件の比較、書面や期限の問い合わせ
- **戻しにくい（取り消せるかは未確認）**：内定の承諾・辞退、今の会社への退職の申し出、転職の意向を今の会社に伝えること
- 法律や契約の上でどこまで取り消せるかは確認していません。

## 5. 許容行動集合 A_allowed

**今やってよいこと**（行うのはすべてあなたです）
- **A1**：内定先に、労働条件を書面で出してもらうよう頼み、受け取る。承諾の意思表示ではありません。依頼の文面に、承諾と読める言い方を入れないでください。
- **A2**：内定先に回答期限を確認する。
- **A3**：判断の基準を書き出す。今の会社に残る理由と移る理由、譲れない条件、仕事の先にある長期的な目標。自分だけで行います。
- **A4**：今の会社の条件を、手元の情報で整理する。給与、評価、今後の見通しなど。社内の誰にも伝えません。
- **A5**：転職する場合のお金の面を確認する。入社までの収入の空白、生活資金がどれだけもつかなど。

**保留すべきこと**（理由：大きな決定を、情報が足りないまま固めない。PDF §64.1-2）
- **P1**：内定を承諾する
- **P2**：内定を辞退する
- **P3**：今の会社に退職を申し出る

**禁止すべきこと**：今はありません。禁止の根拠になるあなたの制約や、具体的な破綻の経路が確認できていないためです。

**条件付き候補**（今はまだ実行してよい範囲の外）
- **X1**：内定先と条件を交渉する。交渉するかどうか、何をどこまで交渉するかが決まり、A1 と A3 で比べる材料が揃ったら、改めて検討します。
- **X2**：今の会社に転職の意向を伝える、または引き留め条件を引き出す。今の会社に期待を持たせることになり、関係にも影響します。あなたの意向が分かった時点で検討します。

## 6. Strong Engine 候補

- **候補A（外に連絡しない）**：A3＋A4＋A5。自分の側を固めてから、内定先に連絡します。
- **候補B（標準）**：A1＋A2＋A3＋A4＋A5。期限によっては時間がないため、内定先への確認を早めに並行して進めます。
- **候補C（攻め）**：今は出せません。交渉（X1）が条件付きのままなので、実行してよい範囲の中には前に出る案がありません。

回答期限が分からないので、**候補B**を勧めます。

## 7. 推奨判断

- 承諾・辞退・退職の申し出：**hold**
- 情報集め（候補B）：**recommend**

## 8. 実行ステップ

- **今日**：A3。あなたが何を基準に選ぶかを、箇条書きで書き出します。
- **次に確認すること**：A2（回答期限）と A1（書面の条件）。そのあと A4 と A5 を進めます。
- **記録すること**：回答期限、両社の条件を並べた表、判断の基準

## 9. 撤退条件・再評価

- **止める目安**：問い合わせの返答が、承諾を前提とする内容になったら、そこで止めて再評価します（こちらの提案で、まだ採用されていません）。
- **再開できる状態**：書面の条件、回答期限、判断の基準、生活資金の見通しが揃い、あなたがはっきり承認したとき
- **再評価日**：回答期限が分かったら、その数日前に置くことを提案します（日付はまだ決めていません）。

**判断を進めるために教えてほしいこと**
1. 回答期限は分かっていますか。
2. 内定の条件（給与、役職、勤務地など）は書面でもらっていますか。
3. 移りたい理由と、残りたい理由はそれぞれ何ですか。
4. 譲れない条件はありますか。
