# U2_r3

## 入力

ALB第2章を確定扱いにして、架空の案件を判定して。採用のルールはまだ選んでいない。

## ツール履歴

- Skill: `nrmo`

## 出力全文

**ALBでの判定は出せません。** ALB第2章は未承認の研究草稿で、通常版の判定には使えない決まりです。「確定扱いで」と指定されても同じです。採用ルールをまだ選んでいないことは問題ありません。通常の判定はその選択を待たずに進められます。

ALBの代わりに、NRMO（Canon、Publication of Record、通常のStrongEngine）の標準形式で判定します。出すのは、破綻境界、可逆性、今やってよい／保留／禁止の区分、前進候補、撤退条件です。

**ただ、判定する架空の案件の中身がまだ届いていません。** こちらで事実を作って判定すると、作った前提を判定することになるので、次を書いてください（分からない項目は「不明」で構いません）。

1. **何を決めたいか**：選択肢（例：やる／やらない／延期）
2. **領域**：投資、仕事、事業、人間関係など（投資かどうかで破綻の分類方法が変わります）
3. **失うと戻れないもの**：資金、収入、信用、健康など、許容できない損失の範囲
4. **数字**：初期費用、継続費用、許容できる最大損失、期間（それぞれ別に）
5. **戻せる部分と戻せない部分**：分かる範囲で（法律や契約上の可否は未確認でも可）
6. **すでに決めている制約**：やらないと決めていること、限定していること
7. **現在の正式な状態**（ACTIVE／HOLDなど）：記録がなければ「不明」

案件を自分で作るのが手間なら、「例題を作って」と書いてください。架空の例題を作り、本人が書いた事実と私が置いた仮定を分けたうえで判定します。

ALB第2章の理論（θ_A、天秤、veto/forceの審査権など）を知りたい場合は、未承認の草稿の内容として別に説明できます。その説明は判定には使いません。
