# 転職相談：給与条件の問い合わせ（A1）と生活費の集計（A2）

## 1. 結論

- いま実行できる候補は2つです。A2を先に済ませてからA1を送る案と、A1とA2を並行して進める案です。
- 「A1を使って最終面接と入社日の交渉まで進める案」は、候補として出せません。面接と条件交渉は本人が保留しています。A1は「返信を読むまで・交渉の確約なし」と定義されているので、その範囲に収まりません。
- この案は「条件付き候補（現時点では A_allowed の外）」として別枠に置き、何が揃えば再評価できるかを示します。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。情報収集と可逆な準備が中心で、損失上限・時間上限を伴う探索段階ではないため）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
今回の governance result：A1・A2 は PASS。最終面接・入社日交渉案は A_allowed の外（本人による保留）
MISSION-DEFENSE 拡張：非発動（圧力・誘導などの申告なし）
```

A_allowed は空ではありません。A1とA2は固定化を伴わない行動なので、全体をHOLDにする条件は成立していません（PDF §60.3、§64.1）。

## 3. 破綻境界

- **severity（Hard/Soft）**：投資領域ではないため N/A です（PDF §63.1）。
- **origin：Active の経路（一般的な例です。今回の該当は未確認）**
  - 転職先の条件が書面で確定する前に退職を伝えると、収入が途切れるリスク経路になり得ます。
  - ただし、生活資金・退職の撤回可否・相手の対応はいずれも不明なので、不可逆損失とは断定しません。
- **origin：Passive**：未成立です。avoidability window（今なら避けられる損失の窓）が閉じつつあるという観測はありません（PDF §63.2）。
- **停滞のリスク**：申告がないため評価できません。

## 4. 可逆性

| 区分 | 行動 |
|---|---|
| 戻せる | A2（生活費の集計） |
| 戻しにくい部分がある | A1（送ったメールは取り消せません。ただし本人宣言で確約はなし。相手がどう受け止めるかは未確認） |
| 回復可能性が未確認 | 応募・面接・条件交渉・退職（相手の対応や契約・法的な扱いを確かめていないため、ここでは断定しません） |

## 5. 許容行動集合 A_allowed

**今やってよいこと**（本人が限定した一覧。範囲は広げていません）

- **A1**：人事に給与条件をメールで問い合わせる。
  - 行為者は本人、費用は無料（本人宣言）。
  - 範囲は返信を読むまでで、応募・交渉の確約はしません。
  - 質問は給与条件だけです。返信への再返信はA1に含みません。
- **A2**：自分の生活費を集計する。

**保留すべきこと**（根拠はすべて本人宣言）

- **P1**：応募
- **P2**：条件交渉（入社日の交渉を含む）
- **P3**：面接（最終面接を含む）
- **P4**：退職

**禁止すべきこと**：今回の材料からは、根拠のある禁止は導けません。

**追加提案**（本人の許可待ち。A_allowed の外なので、候補・推奨・実行ステップには入れていません）

- **X1**：A1の質問に、選考の流れや入社時期の目安を加える。
- **X2**：人事の返信に応答する（確約しない範囲で）。

## 6. Strong Engine 候補

| 案 | 内容 |
|---|---|
| **候補A（安全寄り）：A2 → A1** | 先に生活費を集計し、自分の下限を把握してから問い合わせます。返信を自分の数字と比べられます。 |
| **候補B（前進寄り）：A1 ＋ A2 並行** | 返信を待つ間に集計を終わらせます。情報が揃うまでの時間が短くなります。 |

C案（攻め）は、A_allowed の内側では作れません。A1とA2の組み合わせはA案・B案で尽きているからです。

**条件付き候補（現時点では A_allowed の外）：最終面接・入社日交渉まで進める案**

- 参照先が保留中です。最終面接はP3、入社日交渉はP2で、通常は応募（P1）が前提です。入社日を決めるには、実質的に退職（P4）の時期も決める必要があります。
- 再評価に必要なもの：
  1. 本人がP1〜P3（必要ならP4の時期の検討も）を解除すること
  2. A2の結果（生活費の下限）
  3. A1の返信内容
  4. 現職の退職条件（未確認）
- これらが揃った時点で、改めて A_allowed を判定し直します。

## 7. 推奨判断

- 候補A・B：**recommend**。どちらを採るかは本人の判断です。
- 最終面接・入社日交渉案：現時点では **reject**（候補にしません）。上の条件が揃えば再評価します。

## 8. 実行ステップ

- **今日やること**
  - A2：生活費を月単位で集計します。
  - A1：給与条件だけを尋ねるメールを送ります。応募や交渉を約束する表現は入れません。
- **次に確認すること**
  - 返信を読み、提示額とA2の結果を並べます。返信には応答しません（A1の範囲外のため）。
- **記録すべきこと**
  - 送信日、返信の要点、A2の月額。

## 9. 撤退条件

- 返信が応募・面接・意思表示を求める内容だった場合は、読んだ時点で止めます。それ以上の対応はP1〜P3の解除を本人が判断してからです。
- A1に費用がかかると分かった場合は、送らずに止めて再評価します。
- **再開できる状態**：本人が保留項目のどれかを明示して解除したとき。
- **再評価のタイミング**：A1の返信を読み終え、A2が完成した時点（日付は置いていません）。

最終判断はご本人に返します。
