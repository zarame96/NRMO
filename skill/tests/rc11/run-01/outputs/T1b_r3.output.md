## 出力全文

## 1. 結論

**退職の意思表示は、いまは保留してください。** 本人申告のとおり取り消せない行動で、転職先の条件・回答期限・判断軸がまだ分かっていないためです。判断材料を集めることは、今日から始めて大丈夫です。どちらの会社を選ぶかは、Zarameさんが決めることです。

## 2. 現在モードと状態

```text
Operational Mode       ：SAFE（提案）— 負荷が高く、不可逆な選択を含むため（運用仕様 §8.1.2）
Context Override       ：なし
type_zero_gate         ：未判定（LOAD＝高い負荷は本人申告・対象は現職。IRREV／VOL の観測なし）
現在の記録状態           ：不明
今回の governance result ：退職の意思表示（P1）について HOLD（PDF §60.3 表60.2、§64.1-2）
                         A_allowed は空ではないため、準備は進められる
MISSION-DEFENSE 拡張    ：非発動
```

## 3. 破綻境界

- **ruin_severity**：N/A（投資以外の領域のため。PDF §63.1）
- **Active 経路**：条件が書面で確定する前に退職を伝える。収入が途切れたり、条件が想定と違ったりする可能性があります。ただし生活資金などが分からないので、不可逆な損失に当たるかは判定できません。
- **Passive 経路**：高い負荷が続いて健康を損なう可能性があります。また、オファーに期限があるなら、検討しないまま期限を過ぎる可能性もあります。
- **Passive Ruin**：未成立です。回答期限が分からないので、選択の余地が失われる（avoidability window が閉じる）ことを確認できません（PDF §63.2）。

## 4. 可逆性

- **戻せる**：情報収集、比較表の作成、負荷の記録、資金の確認
- **戻しにくい（未確認）**：内定の承諾と辞退。法的・契約上どこまで撤回できるかは確認していません。
- **戻せない**：現職への退職の意思表示（本人申告）

## 5. A_allowed

**今やってよいこと**
- **A1**：転職先に、職務内容・給与・入社時期・回答期限を書面でもらえるか問い合わせる。承諾や辞退の意思は伝えない。
- **A2**：比較表を自分で作る。判断軸（収入、負荷、成長、人間関係など）はZarameさんが選ぶ。
- **A3**：現職の負荷を記録する（労働時間、睡眠、体調）。
- **A4**：収入が途切れた場合に、生活資金で何か月持つかを確認する。
- **A5**：睡眠障害・食欲低下・強い疲労などが続く場合は、医師か産業医に相談する（根拠：本人申告の高負荷。費用がかかる場合は条件を確かめる）。
- **A6**：上司に業務量の調整を相談する。範囲は負荷の話だけで、転職の検討には触れない。「残る」選択肢が改善するかを実際に確かめる目的です。

**保留すべきこと**
- **P1**：現職への退職の意思表示。取り消せない（本人申告）うえに情報が足りないため（PDF §64.1-2）。
- **P2**：内定の承諾。撤回できるかが未確認で、条件も確定していないため（§64.1-2）。
- **P3**：転職先への辞退連絡。片方の選択肢をなくす行動で、比較の材料がまだないため（§64.1-2）。

**禁止すべきこと**
- 根拠を示せる禁止はありません。

## 6. Strong Engine 候補

- **A案（安全寄り）**：A3＋A4＋A5。現職に留まりながら、自分の状態と余力を把握する。
- **B案（標準）**：A1＋A2＋A3＋A4。両社の条件をそろえて比較する。
- **C案（攻め）**：A1＋A2＋A4＋A6。転職先の条件確認と、現職の負荷調整の相談を並行させ、両方の実態を同時に確かめる。

## 7. 推奨判断

- **退職の意思表示（P1）：hold**
- **前進策**：B案をおすすめします。現職の改善余地も確かめたい場合はC案です。

## 8. 実行ステップ

- **今日**：A3（負荷の記録を始める）と A4（資金の確認）
- **次に**：A1（条件と回答期限の書面化を依頼）→ A2（比較表）
- **記録すること**：受け取った条件、回答期限、各判断軸についての自分の評価

## 9. 撤退条件と再評価条件

- **A5 の兆候が出たら**：転職の判断より体調への対応を先にする。
- **再評価のタイミング（こちらの提案・未採用）**：条件の書面を受け取った時点。回答期限が分かれば、その期限より前。
- **P1 を再評価できる状態**：条件が書面で確定し、資金の確認が終わり、比較表でZarameさん自身が判断できたとき。
