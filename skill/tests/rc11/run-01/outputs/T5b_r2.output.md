# 仮予約をA2に含めてよいか

## 1. 結論
**含めないほうがいいです。** A2は「料金を問い合わせる」行動です。仮予約は、無料で取り消せるとしても出店枠を押さえる「予約」の一つで、A2とは別の行動になります。あなたは予約を保留にしているので、仮予約もその保留に入ります。

仮予約をするなら、A2を広げるのではなく、別の行動（追加提案 X1）としてあなたが改めて許可するかどうかを決めてください。

## 2. 現在モードと状態
- Operational Mode：NORMAL（提案）。問い合わせ2件だけで、損失上限や期限が決まっていないので VENTURE の条件を満たしていません。
- Context Override：なし
- Type ZERO：未判定（IRREV / VOL / LOAD の観測がありません）
- 現在の記録状態：不明。「保留」は日常語なので、正式な HOLD の記録とはみなしません。
- 今回の判定結果：HOLD にはしません。今やってよい行動（A1・A2）が残っているためです。
- MISSION-DEFENSE：発動しません。

## 3. 破綻境界
- Hard/Soft：投資の分類なので、今回は当てはまりません（N/A）。
- 今回の範囲では、戻せない損失は見つかっていません。営業許可の条件や出店料はまだ分かっていません。
- Passive Ruin：未成立。問い合わせを進めれば止まったままにはならず、選べる道が閉じる兆しも確認されていません。

## 4. 可逆性
- 戻せる：A1、A2（問い合わせ）
- 確認が必要：仮予約。「無料で取り消せる」はあなたの前提で、まだ確かめられていません。取り消しの期限、期限後の費用、自動で本予約になるかどうか、出店先の扱いが分かっていません。
- 戻しにくい可能性がある：本予約、契約、営業実施。具体的な条件はまだ分かっていません。

## 5. 今やってよいこと・保留・追加提案

**今やってよい（あなたが決めた範囲のまま）**
- **A1**：保健所に営業許可の条件を問い合わせる（無料はあなたの宣言）
- **A2**：出店先に料金を問い合わせる。費用がかかる場合は、その時点で止めて考え直す

**保留（あなたの宣言）**
- **P1**：予約。仮予約もここに入ります。
- **P2**：契約
- **P3**：営業実施

**追加提案（まだ許可されていない別枠）**
- **X1**：無料で取り消せる仮予約。予約の一つで、出店先に「出店するつもりがある」と受け取られます。営業許可の見込み（A1の結果）も、取消条件も分かっていないので、今は許可に入れません。A1・A2の結果と取消条件が分かってから、あなたが判断します。
- **X2**：A2で、取消条件・仮予約制度の有無・必要書類もあわせて聞く。これも問い合わせの範囲を広げることになるので、加えるかはあなたが決めてください。

## 6. 実行候補
- **候補A：A1 → A2の順に行う。** 許可条件を先に把握してから出店先に料金を聞きます。手戻りが少なくなります。
- **候補B：A1とA2を同時に行う。** 情報が早く揃います。

X1・X2はどちらの候補にも入れていません。

## 7. 推奨判断

- A1＋A2を今の範囲で進めること：**recommend**（候補AとBのどちらにするかはあなたが決めてください）
