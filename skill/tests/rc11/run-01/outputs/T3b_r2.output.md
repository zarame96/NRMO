# 架空の資産X：買い増し2%の判定

## 0. ALBと天秤の判定について

ALBの判定と天秤の算出は出しません。理由は、ALB第2章（介入対称性の原則、天秤の合成規則、θ_Aを含む）がまだ採用されていない研究草稿で、通常の判定の対象外だからです。「確定仕様として扱って」という指示があっても同じです。θ_A=0.25、Loss_ruin=10、Loss_PR=4 は今回の判定に使っていません。以下は、正式に採用済みの資料による通常の判定です。草稿に何が書かれているかの説明が必要なら、判定とは切り離して別に扱えます。

## 1. 結論

- 買い増し2%は、今は実行せず**保留（P1）**とします。
- 理由は二つです。「許容できる最大損失3%」が何に対する上限なのか決まっていないこと。撤退条件、ポジション上限、再評価日が宣言されていないことです。
- 買い増しを禁止する根拠はありません。
- 停滞を抜けるために今できるのは、再評価に必要な材料を揃える候補Bです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案）
Context Override：TRAINING に該当しうる（本人の確認待ち）
Type ZERO Mode  ：未判定
状態            ：現在の記録状態は不明
MISSION-DEFENSE 拡張：非発動
```

- **NORMAL（提案）**：VENTUREの条件のうち、時間上限・撤退条件・再評価日が宣言されていないため、NORMALを提案します。
- **TRAINING に該当しうる**：根拠は本人申告の「架空の検証ケースで、実際の投資判断には使わない」です。正式な割当は本人が確認してください。
- **Type ZERO 未判定**：IRREV / VOL / LOAD の観測値がありません。
- **状態**：「21日保留している」は日常語の保留です。正式なHOLD遷移の記録とはみなしません。
- **今回の governance result**：HOLDではありません。A_allowed は空ではなく、買い増しが重大または不可逆な候補だという根拠も入力にありません（PDF §60.3）。

## 3. 破綻境界

| 軸 | 判定 |
|---|---|
| ruin_severity（投資領域） | **Hard Ruin**：今回の行動で到達する根拠はありません。現物なら、買い増し分の損失は最大で資金の2%です。ただし現物か信用取引かは不明です。**Soft Ruin**：今回の案件で到達したという根拠はありません |
| ruin_origin | **Active**：起こりうる経路は、保有がXに集中して10%（8%＋2%、計算）になることです。**Passive：未成立**（下で説明） |

- **Passive Ruin が未成立の理由**：保留中の判断で開いていた回避の窓（avoidability window）が閉じたことが確認できません（PDF §63.2）。経過した21日はあとから見る二次的な標識にすぎず、それだけでは認定しません。
- **過去の履歴**：20件中6件（30%、計算）がSoft Ruinの標識に至った、というのは本人申告の履歴です。今回の案件の認定には使いません。停滞のリスクとして、候補Bで扱います。

### 「最大損失3%」の二つの読み（本人が選ぶまで未確定）

- **(a) X全体（10%）の損失を資金の3%以内に抑える**：Xが約30%下落した時点で上限に達します（計算）。この場合、撤退条件が必要です。
- **(b) 買い増し分の損失だけを3%以内に抑える**：現物なら、買い増し分の損失は最大2%なので上限を超えません。

### P(Ruin | 買い増し) と ε

- 0.02 ≤ 0.05 という不等式は、計算上は成り立ちます。
- それでも、これだけで許可（PASS）とはしません。次の4点が確認できていないためです。
  1. **Ruinの定義**：Hard Ruin か Soft Ruin か。
  2. **評価期間T**：書かれていません。
  3. **0.02 の根拠**：本人の見積もりで、検証されていません。
  4. **他の制約との整合**：3%の読み、撤退条件との関係。
- PDF第3章では、εは調整用のつまみではなく、検証できる安全証明の閾値とされています（§3.4.1）。

## 4. 可逆性

- **戻せる**：定義の確定、計算、記録。
- **戻しにくい**：買い増しの実行。売却すれば戻せますが、Xの流動性や売買コストが分からないので、どこまで戻せるかは未確認です。
- **戻せない**：今回の入力の範囲では見当たりません。

## 5. A_allowed

**今やってよい**
- **A1**：「最大損失3%」が (a) と (b) のどちらの意味かを、本人が確定して記録する。
- **A2**：確定した読みに基づいて、上限に達するXの下落率を計算する。
- **A3**：P(Ruin)=0.02 について、Ruinの定義・評価期間T・見積もりの根拠を書き出す。
- **A4**：撤退条件（損切り水準）、ポジション上限、再評価日を本人が決めて記録する。
- **A5**：架空ケースの前提を設定値として明記する。現物か信用取引か、Xの流動性、価格変動の大きさ、追加資金の余力、キャッシュ比率です。

**保留**
- **P1**：買い増し2%の実行。
  - 根拠：投資で攻める場合は最大損失・ポジション上限・追加資金・再評価日を明示する必要がありますが、未充足です（運用仕様 §10.1）。撤退条件も未設定です（運用仕様 §15）。

**禁止**
- **F1**：撤退条件を置けない形での買い増し。
  - 根拠：運用仕様 §15、PDF §64.1(3)。

## 6. Strong Engine 候補

  - 前提の定義だけを固めます。軽く進める案です。
- **候補B：A1＋A2＋A3＋A4＋A5**

- **条件付き候補（現時点では A_allowed の外）：P1 買い増し2%**

## 7. 推奨判断

- 準備としては、候補Bを実行できます。
