## 1. 結論

**準備は今日から進めてよい段階です。ただし、車両・出店・支払いの契約にはまだ進まないでください（hold）。**
初期費用30万円までという上限と、撤退する意思は決まっています。一方で、次の3点がまだ決まっていないか、確かめられていません。

- 損失全体でいくらまで許すか
- 撤退条件の読み方
- 契約を途中で抜けられるか

契約の途中解約ができない場合や違約金がかかる場合は、宣言した撤退が実行できなくなるおそれがあります（PDF §64.1-3）。

## 2. 現在モードと状態

```
Operational Mode   ：VENTURE（提案）
Context Override   ：なし
Type ZERO          ：未判定（不可逆性 IRREV／変動 VOL／負荷 LOAD の観測なし）
現在の記録状態      ：不明
今回の governance result：開始の契約・支払いについて HOLD
MISSION-DEFENSE 拡張：非発動
```

- **VENTURE を提案する理由**：上限と撤退を決めたうえで試す相談だからです。ただし運用仕様 §8.1.3 の条件はまだ揃っていません。
  - 揃っている：初期費用の上限（30万円）、期間（3か月）、撤退の意思
  - 揃っていない：合計損失の上限、撤退条件の読み方、再評価日
  - この提案は「始めてよい」という許可でも、損失上限が決まったという意味でもありません。
- **HOLD にした理由**：大きな支出を固定してよいか判断するための情報が足りないからです（PDF §60.3 の表）。
  - 不足しているのは、契約条件、合計損失上限、生活資金への影響です。
  - 準備行動は止めません。
  - HOLD の解除は、ご本人の明示承認だけで行います。

## 3. 破綻境界

- 投資の相談ではないので、Hard／Soft の区分は当てはめません（N/A、PDF §63.1）。
- **戻れなくなりうる経路**（例であり、今回起こると断定するものではありません）
  - 撤退判定の時点で抜けられない契約。最低契約期間や違約金があり、30万円を超える場合。
  - 必要な許可や届出がないまま販売し、法律上・信用上の損失を負う。
  - 食中毒や事故による健康・信用の損失。
- **今回この境界に届くかどうか**：判断できません。30万円と運営赤字が生活の基盤にどれだけ響くかは、手元資金や本業の有無が書かれていないため不明です。
- **Active Ruin（攻めすぎによる破綻）**：撤退条件が曖昧なまま契約すると、ここにつながる経路になりえます。
- **Passive Ruin（動かないことによる破綻）**：成立していません（PDF §63.2）。準備期間を置いても、何かの機会が閉じるという根拠はありません。

## 4. 可逆性

- **戻せる**：見積もりの取得、問い合わせ、試算、条件の確定
- **戻しにくい（契約条件しだい・未確認）**：車両のリースや購入、出店契約、設備の購入
- **戻せない**：許可なしの営業や事故による法律上・信用上の損失。可否は専門機関に確認が必要で、ここでは断定しません。

## 9. 撤退条件

**ご本人の宣言（原文）**：「3か月やって月の赤字が5万円を超えたら撤退」

読み方が複数あるので、ご本人に選んでもらう必要があります。

- **読みa**：3か月たった時点で評価し、どこかの月の赤字が5万円を超えていたら撤退
- **読みb**：3か月の月平均の赤字が5万円を超えたら撤退
- **読みc**：期間中のどの月でも、5万円を超えた時点ですぐ撤退

あわせて決める必要があること：「月の赤字」に初期費用の按分を含めるか。

- **含める場合**：30万円÷3か月で月10万円になります。この場合、按分前の月次損益で＋5万円以上を出さないと撤退ラインに届きます。
- **含めない場合**：初期費用は別枠として扱います。

**計算例**：30万円＋5万円×3か月＝45万円。これは損失の上限ではありません。読みaとbでは、ある月の赤字が5万円を大きく超えることがありえるため、この計算から合計損失の上限は出せません。

**こちらからの追加提案（まだ採用されていません）**

- 合計損失の上限をご本人が数字で決める
- 単月の赤字がある額を超えたら即停止する線を置く
- 毎月末に再評価する

**再開・解除の条件**

- A1〜A5 と A7 が揃い、F1〜F3 に当たらないと確認できたら、P1 を再評価します。
- HOLD から進める（ACTIVE に戻す）のは、ご本人の明示承認によります。
- 再評価日はまだ決まっていません。上の準備が揃った時点で、ご本人が日付を決めてください。
