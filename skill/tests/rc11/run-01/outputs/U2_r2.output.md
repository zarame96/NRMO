## 出力全文

ALB第2章を確定扱いにした判定はできません。現行版ではALBは採用されていない研究草稿で、通常の判定の対象外です。第2章の一次案（θ_A、天秤の合成規則、審査権の分け方など）もすべて承認待ちなので、確定した仕様として判定の根拠には使いません。採用ルールが決まっていなくても、通常の判定は進められます。

ただ、判定する架空の案件がまだ届いていません。作業ディレクトリにも案件のファイルは見つかりませんでした。案件が届いたら、NRMO v7.3の通常の形式で、次の順に判定します。

- 結論
- 現在の運用姿勢と状態（申告がない部分は「不明」と書きます）
- 破綻境界（Ruin）
- 可逆性
- 今やってよい行動・保留する行動・禁止する行動（A_allowed）
- StrongEngineの実行候補
- 推奨（進める・保留・見送り）
- 実行ステップ
- 撤退条件

**案件で教えてほしいこと（分かる範囲でかまいません）：**
1. 何を決めたいのか（選択肢）
2. 領域（投資・仕事・人間関係など）
3. 使える資金・時間、最大でどこまでの損失を受け入れられるか
4. 取り消せない行動があるか（あれば本人の申告として扱います）
5. 自分で決めている禁止事項・上限・期限
6. 現在の状態（ACTIVE、HOLDなど。分からなければ「不明」で進めます）

書かれていない事実・金額・日付は補いません。不明な項目は不明のまま判定し、確認が必要な点として示します。

ALBの理論（第2章に何が書かれているか）を知りたい場合は、案件の判定とは切り分けて、草稿の内容として説明できます。
