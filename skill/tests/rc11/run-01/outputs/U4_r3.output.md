## 出力全文

## 1. 結論

今の時点では、残るか移るかを決める材料が足りません。このため、**内定の受諾・辞退や退職の申し出はまだ保留**にしてください。先に**回答期限**と**書面での条件**を確かめるのが最初の一手です。期限が分かれば、いつまでに決めればよいかも決まります。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。強い負荷や急な変化の申告がないため、普段どおりの姿勢で進める）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測なし）
現在の記録状態  ：不明
今回の governance result：受諾・辞退・退職の申し出の確定については HOLD
                  （重大な決定を判断する情報が足りない。PDF §60.3・§64.1(2)）
MISSION-DEFENSE 拡張：非発動（相手からの圧力の申告なし。期限を急かされている場合は見直す）
```

HOLD は「確定を止める」という意味です。情報を集めたり整理したりすることまでは止めません。

## 3. 破綻境界

- **Hard / Soft**：N/A（投資以外の相談のため）
- **Active 側の経路（ありうる例で、今回そうなると判断したわけではない）**：条件を書面で確かめないまま現職に退職を申し出ると、内定先の条件が違ったり状況が変わったりしたときに、戻れる場所が狭まるおそれがあります。ただ、撤回できるか、相手がどう対応するかは確かめておらず、法的な判断もしていません。
- **Passive Ruin：未成立。** 回答期限が分からないため、決めずにいることで選択肢がなくなる時点（window）を確かめられていません。期限を確かめること自体が、この確認になります。
- **未確認のこと**：生活資金、現職の状況、内定の条件など。どれも申告がないので不明です。

## 4. 可逆性

- **戻せる**：期限や条件を問い合わせる、判断軸を書き出す、比べて整理する
- **戻しにくい（一般論。今回の撤回の可否は未確認）**：内定を受諾すると伝える、現職に退職を申し出る、現職に転職を考えていると伝える
- **戻せない**：今回の申告からは判断できません

## 5. A_allowed

**今やってよいこと**
- **A1**：内定先に**回答期限**と、**労働条件を書面でもらえるか**を問い合わせる。受諾・辞退・交渉の意思は含めない。
- **A2**：自分で判断軸を書き出す。何を大事にするか（仕事内容、収入、働き方、将来の方向など）は、あなたが決めることです。
- **A3**：現職に残った場合の見通しを、今知っている範囲で書き出す。社内の人への相談は含めない。
- **A4**：A2 で出た不明点を、内定先に質問として確かめる。承諾・交渉の意思は含めない。

**保留すること**
- **P1**：内定の受諾・辞退を伝える。条件・期限・判断軸が揃っていないため（PDF §64.1(2)）。
- **P2**：現職に退職を申し出る。根拠は P1 と同じで、内定条件を書面で確かめられたかも分からないため。
- **P3**：条件交渉。交渉したいか、何を交渉するかが分からないため。A2 と A4 が揃ったら見直します。
- **P4**：現職への引き留め相談。転職を考えていることが現職に伝わるので、あなたの意向を確かめてから扱います。

**禁止すること**：根拠を確認できた禁止事項は、今はありません。

## 6. Strong Engine 候補

- **候補A：A1＋A2**。期限と書面を押さえて、判断軸だけ先に固める。負担は小さめです。
- **候補B：A1＋A2＋A3＋A4**。両方の会社を同じ軸で並べ、不明点まで潰してから決める。

## 7. 推奨判断

- 残るか移るかの確定：**hold**
- 候補Bの実行：**recommend**。ただし進め方はあなたが決めてください。

## 8. 実行ステップ

- **今日やること**：A1（回答期限を確かめるのが最優先）、A2
- **次に確認すること**：書面の条件と、A3・A4
- **記録すること**：回答期限、書面に書かれた条件、判断軸と両社の比較

## 9. 撤退・再評価の条件

- **見直すきっかけ**：書面での条件提示を断られたとき、口頭の説明と書面の内容が違うとき、期限を急かされたとき。どれも「すぐ辞退する」という意味ではなく、A_allowed を見直すきっかけです。
- **再評価日**：期限が分かったら、その前に判断日を置いてください（日付はあなたが決める）。
- **再評価の条件**：A1〜A4 が揃ったら、P1〜P4 を保留から外せるかを見直します。
