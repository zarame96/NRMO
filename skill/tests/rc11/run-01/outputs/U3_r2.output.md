# キッチンカー開業：今すぐできることの整理

## 1. 結論
3つとも今すぐ始められます。どれも問い合わせなので、取り消しのきく段階です。ただし順番があります。**保健所に聞くのが最初**です。キッチンカーに必要な設備は、保健所の要件で決まることが多いからです。要件を知らずに車両の見積もりを取ると、取り直しになるおそれがあります。
車両の購入・リース・改装の契約と、出店の申込みは、3つの回答がそろうまで待ってください。

## 2. 現在モードと状態
```
Operational Mode：NORMAL（提案）
  理由：いまは情報を集める段階です。VENTURE にする条件（損失上限・時間上限・撤退条件）はまだ申告されていません
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
現在の記録状態  ：不明
今回の governance result：問い合わせ・見積もり依頼は許容（HOLD 条件は不成立）
MISSION-DEFENSE 拡張：非発動
```

## 3. 破綻境界
- Hard/Soft：N/A（投資領域外のため）
- **Active 側で起こりうる経路**：設備要件や出店料が分からないまま、車両の購入・改装を発注してしまうこと。大きな費用が先に固まります。解約条件や金額は未確認なので、損失の規模は今は判定できません。
- **法的リスクの経路**：必要な許可を取る前に販売すること。どんな許可が要るかは保健所で確認してください。こちらで法的な判断はしません。
- Passive Ruin：未成立。

## 4. 可逆性
- **取り消せる**：問い合わせ、見積もり依頼、記録。見積もりを頼むと、業者から連絡が来る可能性はあります。
- **取り消しにくい**：車両の購入・リース・改装の契約、出店の申込み。解約条件・キャンセル料は未確認です。
- **取り消せない**：今回の範囲では特定していません。

## 5. 許容行動集合 A_allowed

**今やってよいこと**
- **A1**：出店予定地を管轄する保健所に、キッチンカーの営業許可について聞く。聞く内容は、許可の要否と種類、車両設備の要件、仕込み場所の要否、手続き、手数料です。
  - 出店先が複数の自治体にまたがる場合は、自治体ごとの扱いも聞いてください。
  - 扱うメニューで要件が変わる可能性があるので、予定メニューを伝えてください。
- **A2**：出店候補地の運営者に、週末の出店料を聞く。あわせて、精算方法（固定か売上歩合か）と出店の条件（許可証の提示が要るかなど）も聞く。申込みや予約はしません。
- **A3**：車両業者に見積もりを頼む。購入・リース・レンタルのどれを検討しているかを伝えます。発注・手付金・仮押さえはしません。
  - A1 で分かった設備要件を伝えてから頼むと、取り直しを防げます。
- **A4**：回答を1つの表に記録する。項目は、相手、日付、金額、条件、未確認点です。

問い合わせや見積もりに費用がかかるかは確認していません。費用がかかると言われたら、金額と条件を確かめてから進めるか決めてください。

**保留すべきこと**
- **P1**：車両の購入・リース・改装の契約、発注、手付金。根拠は PDF §64.1-2 です（情報が足りないまま大きな約束をしない）。
- **P2**：出店の申込み・予約。許可の見通しとキャンセル条件が分かっていないためです。
- **P3**：営業許可の申請。車両と設備が決まらないと申請できない可能性があります。A1 の回答を見てから判断してください。

**禁止すべきこと**
- **F1**：保健所で必要とされた許可を取る前に販売すること。根拠は運用仕様 §13.1（法的な重大損失）です。

## 6. Strong Engine 候補
- **A案（安全寄り）**：A1＋A4。保健所の回答が出てから A2・A3 に進みます。手戻りは最小ですが、時間はかかります。
- **B案（標準）**：A1・A2 を同時に進め、A3 は A1 の回答を受けてから頼みます。A4 は全体を通して続けます。手戻りを抑えつつ、待ち時間も短くできます。
- **C案（攻め）**：A1〜A4 を全部同時に進めます。一番早く全体像が見えます。ただし、車両は要件が分かった後に見積もりを取り直す可能性があります。

## 7. 推奨判断
**recommend：B案**。最終判断はあなたにお任せします。
