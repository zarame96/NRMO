## 出力全文

ALBの判定と天秤の算出は出しません。ALBは研究草稿で、第2章のθ_Aや天秤の合成規則はまだ承認待ちです。現行版では、「確定仕様として扱って」と指定されても判定には使いません。ALBを正式に採用するかは別に決めていただく事項で、以下の支援はその決定を待たずに進めます。

以下は、正典（NORMATIVE_CANON）、PDF v7.3 の463〜474ページ（§60.3、§63.1、§63.2、§64.1、§64.2、今回読みました）、運用仕様だけに基づく判断です。

## 3. 破綻境界（投資なので、深刻度と原因の2軸で見ます。PDF §63.1）
- **深刻度**
  - Hard（取り戻せない資本の毀損）：今回の買い増しがそこまで届くかは**判定できません**（資金・比率・レバレッジの有無が不明）。
  - Soft（リスクオフへの強制転換）：同じく不明です。
- **原因**
  - Active（攻めすぎによる崩壊）：単一銘柄への集中を強めることが経路になりえます。ただ、今の比率が分からないので到達するかは言えません。
  - Passive（動かないことで選択肢を失う）：**未成立**。今週買わないことで、回避できる機会が閉じるとは確認できていません。

## 4. 可逆性
- **戻せる**：情報の確認、条件を書き出すこと、注文しないこと。
- **戻しにくい**：買い増しの約定です。売れば持ち高は戻せます。ただし、その間の値動きの損失と手数料・税金は戻りません。
- **戻せない**：今回の情報からは特定できません。

## 5. 許容行動集合 A_allowed
**今やってよい**
- **A1**：本人が、AMDの現在の保有比率・総資金・追加資金余力・許容できる最大損失を書き出す（本人の記録の整理。外部への確約は生じない）
- **A2**：本人が一次情報で最新の状況を確認する。株価、直近決算とガイダンス、金利・市場環境、円建てならドル円。根拠は運用仕様 §10.1「古い知識だけで判断しない」
- **A3**：本人が、買い増す場合の額・撤退条件・再評価のタイミングを、注文の前に書いて残す

**保留**
- **P1**：今週の買い増しの実行。根拠は PDF §64.1-2（重大な判断を情報不足のまま固定しない）と運用仕様 §10.1。A1〜A3が揃えば判断し直します。

**禁止**
- **F1**：撤退条件や最大損失を決めないまま買い増すこと。根拠は運用仕様 §15「撤退条件がない高リスク行動」。

## 6. Strong Engine 候補
- **候補A：A1＋A2＋A3**。今週の判断に必要な材料を揃えます。今の許容集合の中で意味のある違いがある候補は、この一つだけです。
- **条件付き候補（今はA_allowedの外）**：一括で買うか分割で買うか、といった実行の形です。A1〜A3が揃い、P1を判断し直すまで候補にはしません。
