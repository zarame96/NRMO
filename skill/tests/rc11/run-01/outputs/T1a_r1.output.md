## 1. 結論

**今は「残る／移る」を決めないことを勧めます。** 決めるには情報が足りません。今わかっているのは「迷っている」「誘いがある」の2点だけです。比較の材料を集める行動は今すぐ始められます。最終判断はZarameさんが行います。

## 2. 現在モードと状態

```text
Operational Mode   ：NORMAL（提案。差し迫った危険の申告がなく、まず状況を見て前に進める段階のため）
Context Override   ：なし
Type ZERO Mode     ：未判定（IRREV / VOL / LOAD の観測なし）
状態               ：現在の記録状態は不明
governance result  ：HOLD（退職の意思表示・承諾・辞退など大きな決定に限る。情報が実質的に不足しているため。PDF §60.3・§64.1-2）
MISSION-DEFENSE 拡張：非発動（圧力などの申告なし）
```

このHOLDは、大きな決定だけを止めるものです。情報集めは止めません。HOLDを解除して元に戻すには、Zarameさん本人の明示的な承認が必要です。

## 3. 破綻境界

- **Hard/Soft**：N/A。投資以外の相談なので、この正式な区分は付けません（PDF §63.1）。
- **起こりうる経路（Active）**：転職先の条件を書面で確かめる前に、今の会社へ退職を伝えること。収入が途切れたり、条件が食い違ったりする可能性があります。ただ、生活資金などがわからないため、これが取り返しのつかない損失になるかは判断できません。
- **起こりうる経路（Passive）**：誘いに回答期限があれば、期限切れでその選択肢が消える可能性があります。期限があるかはわかりません。
- **Passive Ruin**：成立していません。迷っていること自体は破綻ではありません。

## 4. 可逆性

| 区分 | 行動 |
|---|---|
| 戻せる | 自分の考えの整理、条件の問い合わせ、社内規程の確認 |
| 戻しにくくなりうる | 退職の意思表示、内定の承諾、誘いの辞退 |
| 未確認 | 退職の意思表示を撤回できるか、承諾後に辞退できるか。法律や契約の問題なので、ここでは判断しません |

## 5. 許容行動集合 A_allowed

**今やってよいこと**
- **A1**：自分の判断軸を書き出す。転職で得たいもの、失いたくないもの、譲れない条件。自分だけで行い、誰にも何も約束しません。
- **A2**：誘ってきた会社に、条件と回答期限を問い合わせる。職務、報酬、勤務地、開始時期、書面で示してもらえるか、を聞きます。こちらからは「検討中」とだけ伝え、承諾も交渉もしません。
- **A3**：今の会社の就業規則で、退職の手続きと予告期間を確認する。規程を読むだけで、上司などには伝えません。
- **A4**：生活資金が何か月分あるかを確かめる。自分だけで行います。

**保留すべきこと**（根拠はすべて PDF §64.1-2：情報が足りないまま大きな決定を固めない）
- **P1**：今の会社に退職を伝える
- **P2**：転職先の内定を承諾する
- **P3**：誘いを断る。転職の選択肢がなくなる可能性があるためです。
- **P4**：条件を交渉する。比べる材料と、何を交渉するかが揃ってから改めて検討します。

**禁止すべきこと**：現時点で、根拠のある禁止事項はありません。

## 6. Strong Engine候補

- **候補A（安全寄り）**：A1＋A3＋A4。自分の側だけを整理します。誘ってきた会社とは、まだやり取りしません。
- **候補B（標準）**：A1＋A2＋A3＋A4。候補Aに加えて、誘ってきた会社に条件と期限を確認します。
- **攻めの候補**：今は出しません。今やってよい範囲の中で、これ以上踏み込んだ案は作れないためです。

## 7. 推奨判断

**hold**。残るか移るかの決定は保留します。その間は候補Bで情報を集めることを勧めます。どちらの候補を取るかもZarameさんが決めてください。

## 8. 実行ステップ

- **今日**：A1。判断軸を3〜5個書き出す。
- **次**：A2で回答期限を確認する（期限が最優先です）。続けてA3とA4。
- **記録**：わかった条件を、今の会社と誘ってきた会社で並べて記録する。

## 9. 撤退条件・再評価

- **止める**：問い合わせの場で承諾や即答を求められたら、その場では答えずに持ち帰る。
- **再評価のタイミング**：A2の回答が届いたとき。回答期限があれば、その前に本人が再評価日を決める。
- **HOLDを解除して決定へ進める条件**：両社の条件、回答期限、生活資金、自分の判断軸が揃い、Zarameさん本人が承認したとき。

**判断の精度を上げるため、次を教えてください**：誘いは正式なオファーか（条件や書面はあるか）、回答期限はいつか、今の会社に残りたい理由と出たい理由、転職で実現したいこと（Vision）。
