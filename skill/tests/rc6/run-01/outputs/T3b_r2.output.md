- Ruin の定義が決まっていない。

## 3. 破綻境界
- **停滞の事実**：21日間動いていない（申告）。これだけでは Soft Ruin にも Passive Ruin にも当たりません。
- **悪化の標識**：今回の案件では申告がありません。
- **過去の履歴**：停滞20件中6件が Soft Ruin の標識に至った（申告された履歴）。今回の案件の認定とは分けて扱います。
- **Hard Ruin**：何を「資本の致命的毀損」（§13.1）とするか、まだ決まっていません。Loss_ruin=10 が何を表すか（どの損失の大きさか）も未定です。
- **Active Ruin**：買い増し後は保有比率が 8%＋2%＝10% になり（計算上の仮定）、集中が増します。
- **Passive Ruin**：動かないことの損失。今回の案件で該当すると判断できる材料はありません。

**「最大損失3%」の読み（二通り。こちらでは決めません）**
- (a) X の保有全体の損失を資金の3%以内にする。保有10% なら、現在値から約30%下がると上限に届きます（計算上の仮定：レバレッジなし、既存8%の含み損益は未考慮）。
- (b) 買い増し分の損失を3%以内にする。レバレッジなしの2%買い増しなら、損失は最大でも2%で、この上限には届きません。

**P(Ruin|a) ≤ ε の確認（計算上の仮定）**：0.02 ≤ 0.05 は成り立ちます。ただし次は未確認です。
1. Ruin（τF）の定義
2. 評価期間 T
