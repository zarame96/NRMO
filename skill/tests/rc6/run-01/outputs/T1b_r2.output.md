## 1. 結論

**今は残るか移るかを決めず、退職もまだ伝えない方がいいです（hold）。** 退職を伝えると取り消せません。一方で、転職先の条件、ご自身の判断軸、手元資金、体調がまだ分かっていません。そこで、取り消しのきく情報集めを先に進めることを勧めます（推奨は B 案）。どちらを選ぶかは、最終的にあなたが決めることです。

Context Override ：なし
Type ZERO Mode   ：未判定（VOL の観測がない）
状態              ：HOLD を推奨（情報不足と高負荷のため。§8.4）。確定はあなた
MISSION-DEFENSE  ：非発動（圧力や誘導の申告がない）

## 3. 破綻境界

| 区分 | 内容 |
|---|---|
| Hard Ruin | ① 高負荷が続いて健康を大きく損なう ② 退職後に転職先の条件が合わない・話が流れるなどで収入が途切れ、生活基盤が崩れる |

## 4. 可逆性評価

- **戻せる**：条件の確認、比較表づくり、就業規則と資金の確認、転職先との面談
- **戻しにくい**：内定の承諾（法的にどこまで取り消せるかは要確認。信用は確実に傷つく）、上司への転職の示唆
- **戻せない**：退職の意思表示（あなたの申告）

## 5. A_allowed

**今やってよいこと**（こちらで整理したもの）
- **A1**：転職先に条件を書面で確認する。項目は給与、職務、勤務時間・残業の実態、入社日、試用期間、回答期限。承諾の意思表示は含めない。
- **A2**：比較表をつくる。判断軸（年収・負荷・成長・人など）と、それぞれの重みを自分で書く。一人で完結します。
- **A3**：現職の就業規則で、退職申告の期限、有給の残り、賞与の支給条件を確認する。
- **A4**：手元資金で何か月暮らせるかを確認する。
- **A5**：転職先に、配属予定チームとの面談を頼む。関心は伝わりますが、承諾の約束にはなりません。
- **A6**：睡眠や体調の悪化が2週間以上続く場合は、産業医または医療機関に相談する。根拠は、あなたが申告した高負荷と §13.1 の「健康の重大悪化」です。

**保留すべきこと**
- **P1**：退職の意思表示。取り消せないこと（あなたの申告）と、§15 の「情報不足のまま大きく固定化する行動」が根拠です。
- **P2**：内定の承諾。A1 の条件が揃っていません（§15）。
- **P3**：転職先との条件交渉。何をどこまで求めるか、比較材料がまだ決まっていません。A1 と A2 が揃えば見直せます。

**禁止すべきこと**
- **F1**：A1 と A4 が揃う前に退職を伝えること（§13.3 Active Ruin、§15）。

**追加提案**（条件付きで、今の A_allowed の外）
