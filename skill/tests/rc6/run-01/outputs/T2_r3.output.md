2. **撤退ルールの読み方**：「3か月やって月の赤字が5万円を超えたら撤退」は2通りに読めます。どちらの読み方でも、**累計でいくら失ったら止めるか**が決まっていません。
3. **許可・保険・副業規定**：保健所の営業許可、賠償保険、勤務先の副業規定（会社員の場合）が確認できていません。
