- **Soft Ruin**：好条件の機会をただ逃すこと（Passive）。または、行きたい理由がはっきりしないまま移り、合わずにすぐ辞めること（Active）。
- 誘いには通常、回答期限があります。期限を過ぎても決めないままだと、期限切れで機会が終わる可能性があります。
