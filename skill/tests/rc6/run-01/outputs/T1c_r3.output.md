## 出力全文

## 1. 結論

今は転職するかどうかを決める段階ではありません。先に、誘ってくる会社の条件を書面で確定させてください。比べる材料が毎日変わるうちは、どちらが良いかを決められません。今週は情報を固めることだけを進めることを勧めます。残るか移るかを決めるのはあなたです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。負荷が低いと申告があり、急ぐ理由も申告されていないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV の観測なし。VOL・LOAD の対象も未確定）
状態            ：推奨は ACTIVE のまま。承諾するかどうかの判断だけを見送る（確定は本人）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告がないため）
```

Type ZERO を未判定にした理由は次のとおりです。

| 観測 | 対象 | 出どころ |
|---|---|---|
| 「落ち着いていて、ほとんど変化はない」 | 対象不明（現職のことか、転職の件全体か） | 本人申告 |
| 条件が二転三転し、毎日変わる（直近1週間） | 誘ってくる会社の条件 | 本人申告（VOL が高い） |
| 「負荷は低い」 | 対象不明（業務の負荷か、迷いの心理的負荷か） | 本人申告（LOAD が低い） |

二つの発言は対象が違うので、矛盾ではありません。§8.3 の遷移規則はどれも IRREV の値を使うため、IRREV が観測されていない今は割り当てません。

## 3. 破綻境界

- **Hard Ruin**：条件が固まらないまま承諾し、現職に退職を伝えたあとで条件が下がる、または撤回される。生活の基盤が崩れ、元に戻すのが難しくなります。
- **Active Ruin**：揺れている条件のうち一番良い時点の内容に釣られて、決めてしまうこと。
- **Soft / Passive Ruin**：材料が揃わないまま比べ続けると、判断疲労や機会損失につながる恐れがあります。ただ、今そうなっているという兆しは申告されていません。

## 4. 可逆性

- **戻せる**：記録する、比較表を作る、相手に条件の確認を頼む
- **戻しにくい**：条件の交渉（相手の期待を生む）
- **戻せない**：内定の承諾、現職への退職の意思表示

## 5. A_allowed（こちらで整理した一覧）

**今やってよいこと**
- **A1**：相手から提示された条件を、日付ごとに記録する（いつ、何が、どう変わったか）。費用はかからず、何も約束しません。
- **A2**：現職の条件（給与・役割・今後の見通し）を、A1 と同じ項目で書き出す。
- **A3**：自分の判断軸を書き出す（譲れない条件、最低ライン、転職で何を得たいか）。
- **A4**：誘ってくる会社に、条件を書面で確定してもらうことと、回答期限をはっきりさせることを依頼する。承諾にはならず、確認の依頼にとどまります。もともと話が進んでいる相手なので、これで新しい約束は生まれません。

**保留すること**
- **P1**：承諾するかどうかの判断。条件が確定していないためです（§15「情報不足のまま大きく固定化しない」）。
- **P2**：現職に退職の意思を伝えること。P1 と同じ根拠です。

**禁止すること**
- **F1**：口頭のまま、または未確定の条件のまま承諾すること。戻せない行動で、Hard Ruin に直結します。

**条件付き候補（現時点では A_allowed の外）**
- **X1**：条件の交渉。交渉したいかどうか、何をどこまで求めるかが、まだ決まっていません。A2 と A3 が揃えば、改めて評価できます。

## 6. Strong Engine 候補

- **候補 A（安全寄り）：A1＋A2＋A3**。相手には連絡せず、手元の整理だけを進めます。
- **候補 B（標準）：A1＋A2＋A3＋A4**。手元の整理に加えて、書面で条件を確定してもらうよう依頼します。
- **候補 C（攻め）：今は該当なし**。攻めの手は X1（交渉）ですが、A_allowed の外にあります。

## 7. 推奨

- 候補 B は **recommend** です。
- 転職するかどうかの決定は **hold** です。

## 8. 実行ステップ

- **今日**：A1 で、この1週間に条件がどう変わったかを書き出す。A3 で、自分の最低ラインを決める。
- **次に**：A4 で、書面による確定条件と回答期限を依頼する。A2 で、現職と同じ項目で並べる。
- **記録すること**：相手に依頼した日、返答の内容、その後も条件が変わったかどうか。

## 9. 撤退・再評価条件

- **観察すること**：書面を依頼したあとも、条件がまだ変わるかどうか。変わり続けるなら、それ自体が相手の会社を判断する材料になります（ここは私の解釈です）。
- **再評価のタイミング**：書面を受け取った時点か、依頼から1週間（目安は 2026-10-28。こちらで置いた前提です）の早いほう。その時点で、承諾・辞退・現職に残る、の三つから選んでください。
- **見送りのまま続ける条件**：書面がまだ出ない、または最低ライン（A3）を下回る条件しか出ない場合は、承諾の判断を見送ったままにします。
