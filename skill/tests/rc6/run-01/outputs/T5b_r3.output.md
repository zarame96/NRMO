## 結論

**含めないでください。** 無料で取り消せる仮予約でも、A2（料金の問い合わせ）とは別の行動です。予約は本人が保留にした範囲に入ります。実行ステップには入れず、`追加提案 X1` として別枠に置きます。

理由は三つです。
1. **本人の制約**：予約は保留とご自身で決めています。仮予約も予約の一種です。
2. **確約の有無**：問い合わせは相手に約束を生みません。仮予約は出店枠を押さえるという意思表示になり、出店先の側でも枠の調整が起きます。
3. **情報の十分性**：「無料で取り消せる」かどうかはまだ分かっていません。取消料ゼロ、取消期限、自動で本予約に切り替わる条件の有無などが未確認のままです。費用がかからないと分かっていない行動を、無料と扱うことはできません。

## 破綻境界と可逆性

- **戻せる行動**：A1、A2（問い合わせのみで、費用も確約もない）
- **戻しにくい行動**：仮予約（取消条件が未確認。期限を過ぎると本予約になる、取消料が発生する、出店先との関係に影響する、といったおそれがある）
- **戻せない行動**：営業許可がないまま営業すること（§13.1 Hard Ruin の「法的・社会的な重大損失」に当たりうる）。今回は保留中なので該当しません。
