## 出力全文

## 1. 結論

まだどちらにも決めず、退職を伝えるのは待ってください。そのうえで、次の2つを比べられる材料を揃えるのが先です。

- 誘われている会社の条件（書面）
- 今の負荷が一時的なものか、構造的なものか

「残る／行く」の最終判断は、材料が揃ってからあなたが決めることです。

注意点が一つあります。今は負荷が高いので、「今の状態から抜けたい」という気持ちと「新しい会社を選びたい」という判断が混ざりやすくなっています。この二つを切り分けて考えるのがポイントです。

## 2. 現在モードと状態

## 3. 破綻境界

- **戻れなくなる点**：退職を伝えること（あなたの認識どおり）。もう一つ、条件を確かめないまま承諾すること。
- **Hard Ruin**：
  - 収入が途切れて生活基盤が崩れること
  - 高い負荷が続いて健康を大きく損なうこと
- **Soft Ruin**：
  - 迷い続けて判断疲労が溜まること
  - 負荷が構造的なのに残り続けて、選択肢が少しずつ減ること
- **Active Ruin**：負荷から逃げたい勢いで、比べないまま退職を伝えること
- **Passive Ruin**：誘いの回答期限を確認しないまま放置し、機会を失うこと

## 4. 可逆性

| 区分 | 行動 |
|---|---|
| 戻せる | 条件の確認、自分の判断軸の書き出し、負荷・家計・規程の確認 |
| 戻しにくい | 誘いを断ること（同じ機会はたぶん戻らない）、現職の上司に負荷の相談をすること（転職を考えていると受け取られる可能性がある） |
| 戻せない | 退職を伝えること、承諾すること（入社まで含めて） |

## 5. A_allowed（こちらで整理した一覧）

**今やってよいこと**
- **A1**：誘われている会社に、条件を書面でもらえるか問い合わせる。確認する項目は、給与・役割・勤務地・働き方・入社時期・試用期間・**回答期限**。質問だけにとどめ、承諾も辞退も伝えない。費用はかからない。
- **A2**：自分の判断軸を書き出す。「何を得たいか」「何から離れたいか」「5年後どうありたいか」。あわせて、自分で判断する期日を決める。一人で行う作業です。
- **A3**：負荷を1〜2週間記録する。労働時間、睡眠、体調、負荷の原因（業務量・人・役割など）。目的は、繁忙期のような一時的な負荷か、構造的な負荷かを見分けること。
- **A4**：家計を確認する。生活費の何か月分の蓄えがあるか、転職の移行期に収入の空白が出るか。
- **A5**：社内の人に聞かず、就業規則を自分で読む。確認するのは、退職を申し出る期限、賞与の支給日と在籍条件、有給の残り日数。
- **A6**：負荷のせいで睡眠不足や体調不良が続いている場合は、医師か産業医に相談する。
  - 根拠：高負荷はあなたの申告。健康の重大な悪化は §13.1 の Hard Ruin に当たる。

**保留すべきこと**
- **P1**：現職に退職を伝えること。
  - 根拠：戻せない（あなたの宣言）、材料が揃っていない（§15）
- **P2**：誘いを承諾すること。
  - 根拠：条件が未確認のまま大きく固定化する（§15）
- **P3**：誘いを断ること。
  - 根拠：戻しにくい。比べないまま切ると Passive Ruin 側に寄る（§13.4）

**禁止すべきこと**
- **F1**：内定を書面で受け取る前に退職を伝えること。
  - 根拠：材料不足のまま、戻せない行動で固定化する（§15）

**追加提案**（今の許可には入れていません）
- **X1**：上司に負荷の軽減を相談する。決める前に、何をどこまで相談するか、転職を考えていることを伏せるかどうかを、あなたが決める必要があります。
- **X2**：誘われている会社と条件を交渉する。交渉するつもりがあるか、何を交渉するかを決め、A1 で条件が届いてから検討し直します。

- **次に確認すること**：書面の条件と A2 の判断軸を照らし合わせる。A4・A5 で金銭面と退職の時期を確かめる。

  - 「負荷が下がれば今の会社に残りたいか」というあなた自身の答え

## 9. 撤退条件・再評価

- **止める・切り替える条件**：
  - 書面がもらえない
  - 条件が判断軸の主要項目で今の会社を下回る
  - → 誘いを断ること（P3）を検討する
- **健康面**：睡眠不足や体調不良が続く場合は A6 を実行します。判断は体調の確認を優先してから行います。
- **再評価の時点**：「条件書面が届いたとき」か「回答期限の数日前」のどちらか早い方。期日はあなたが決めてください。
- **P1 を検討し直せる条件**：
  - 書面の内定がある
  - 比べた表で、移る理由を言葉にできる
  - 移行期の資金の見通しが立っている
  - 規程上の退職時期が確定している
