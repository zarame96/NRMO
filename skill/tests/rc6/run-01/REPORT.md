## 何を直したか（rc5 → rc6、SKILL.md のみ。入力ごとの例外ではなく共通規則）

1. **A_allowed 自体の分類の照合**を、候補との照合より先に行う。「今やってよい／保留／禁止」が、本人の制約・正典・明示した前提から導かれているかを確かめる。番号を付けたこと自体は根拠にならない
2. 「今やってよい」に置く前に、**本人の制約・範囲・確約の有無・情報の十分性**を確かめる。揃わない行動は、無条件の許可にも一律の禁止にもせず、追加提案（条件付き）として不足と再評価条件を書く。交渉そのものは禁止しない
3. 保留・禁止にも根拠を添える。根拠不足を禁止に置き換えない。自明でない分類には一行で根拠を書く
4. 今回の行動量（買い増し額など）は、本人が定めた上限ではない。禁止・保留の数値境界は、本人の宣言または明示した前提から導けるものに限る
