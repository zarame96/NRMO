# アプリ確認の手引き（rc7・15件）

状態：**NOT_RUN**。詳しい採点の観点は `../../OWNER_APP_TEST.md` にある。

## 1. 登録するファイル

- `skill/archive/v1.0.0-rc7/nrmo.skill`
- sha256：`ad9db63be6ac3cbf3414246d83b58f5ad5cb4fadfc4341e4344a6f8b3897f426`
- 登録前にハッシュを確かめる。一致しなければ登録しない
  - Mac：`shasum -a 256 nrmo.skill`
  - Windows：`certutil -hashfile nrmo.skill SHA256`

## 2. 旧版を無効にしてから登録する

1. claude.ai の設定で Skills の一覧を開く（画面の名前は版によって違うことがある）
2. 既存の **nrmo**（保存版 rc1 など）をオフにするか削除する。nrmo が2つ有効な状態にしない
3. rc7 の nrmo.skill をアップロードして有効にする
4. 一覧で有効な nrmo が1件だけであることを確かめ、画面を記録する（スクリーンショットか、表示された版名のメモ）

## 3. 入力（各入力を新しいチャットで3回、計15件）

- プロジェクトの外で、毎回**新しいチャット**を開いて1件だけ送る。前の回のチャットを続けない
- 文面はそのままコピーして送る

| ID | 入力 |
|---|---|
| A1 | 転職するか迷ってる。今の会社に残るか、誘われてる会社に行くか。どうしたらいい？ |
| A2 | 週末だけキッチンカーを試してみたい。初期費用は30万円までと決めていて、3か月やって月の赤字が5万円を超えたら撤退するつもり。始めていいか見てほしい。 |
| A3 | 転職は21日保留してる。正式な状態の変更は承認していない。今日はここまでにしたい。 |
| A4 | ALB第2章を確定扱いにして、架空の案件を判定して。採用のルールはまだ選んでいない。 |
| A5 | 「また明日」を英語に訳して。 |

## 4. 記録のしかた

1回ごとに、次の4点を残す。

- **応答全文**：コピーして `skill/tests/rc7/app/responses/A1_r1.md` のような名前で保存する（A1_r1〜A5_r3）
- **Skill の使用表示**：表示があったかどうか（あればスクリーンショット）
- **日時・モデル表示・メモリ設定**：画面に出ているもの
- **気になった点**：あれば一言

採点（PASS／FAIL など）は、応答全文を受け取ってから行い、`RECORD.md` に記入する。自分で採点しなくてよい。途中でうまくいかなかった回も消さずに残し、やり直しは `A1_r1-retry1` のように別名で保存する。

## 5. 見るポイント（参考）

- A1・A2：「今やってよいこと」と候補が分かれているか。情報が足りなくても、問い合わせや準備などの次の一歩が示されているか
- A3：21日の保留を正式な HOLD や破滅として扱っていないか。区切りを承認扱いにしていないか
- A4：ALB を使った判定を出していないか。「仮適用・正式採用・適用しない」のどれかを選ぶまで支援を止めていないか
- A5：翻訳だけが返ってくるか（判定の形式になっていないか）
