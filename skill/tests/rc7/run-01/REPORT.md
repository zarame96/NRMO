1. **役割分担**：人間（Vision の保持と最終判断）、NRMO（破綻境界と A_allowed）、Strong Engine（StrongEngine Ω Full。A_allowed 内で最大限前進できる候補の探索・提案）。統治と執行の分離を維持した。停滞のリスクを評価し、情報不足を理由に、可能な情報収集・可逆な準備を一律に止めない。候補を三つ揃えるための行動追加はしない

3. **ε の欠陥の修正**：4点（定義・T・根拠・整合）が未確認のまま、ε との比較だけで、許可・禁止・有効な停止条件を確定しない。停止側にも同じ根拠確認を適用する。式の所在の説明と仮定計算は維持した
