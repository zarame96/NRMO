今は、承諾するか残るかを決める段階ではありません。先に誘い先の**最終条件を書面で確定させ**、そのうえで現職と比べてください。条件が毎日変わっている間は、比べる相手そのものが定まっていません。

最終判断はあなたに返します。

Context Override：なし

観測値の整理（いずれもあなたの申告）：
- **LOAD**：低い

  - 誘い先の条件：ここ1週間、毎日変わる（高い）
  - 「状況は落ち着いていて、ほとんど変化はない」：**どちらの話か分かりません**。現職のことか、あなた自身の生活や気持ちのことかで読み方が変わります。対象が違うので、矛盾とは扱いません

## 3. 破綻境界

- **Hard Ruin**：条件が定まらないまま現職に退職を申し出て、その後に誘い先の条件が悪くなったり話が消えたりすること。収入と生活基盤を失いかねません
- **Soft Ruin／Passive Ruin**：相手が二転三転するのを待ち続けて、判断疲労が溜まり、期限のない保留になること。今は負荷が低いので、まだ当たっていません
- **Active Ruin**：口頭の好条件だけを見て、勢いで承諾すること

## 4. 可逆性

- **戻せる**：記録する、条件を書面で確認する、自分の判断軸を整理する
- **戻しにくい**：誘い先への承諾の意思表示
- **戻せない（に近い）**：現職への退職の申し出、退職届の提出

条件が二転三転していること自体が、入社後の運営を見る材料になります。書面を依頼したときの反応は、記録しておく価値があります。
