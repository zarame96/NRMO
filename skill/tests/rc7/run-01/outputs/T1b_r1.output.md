## 1. 結論

**まだ退職を伝えない。先に情報を集めて比べる。** これを勧めます（recommend）。
退職の意思表示は取り消せません（あなたの申告）。一方で、相手の条件・回答期限・Vision との整合はまだ分かっていません。この状態で取り消せない決定をするのは、正典 §15 の「情報不足のまま大きく固定化する行動」に当たります。
ただし、止まるのは退職表明や承諾のような取り消せない行動だけです。高い負荷のまま何もせず待つのも、Soft Ruin（判断疲労・健康の悪化）につながるリスクがあります（§13.2）。取り消せる準備は今日から進めます。

## 3. 破綻境界

- **Hard Ruin**：次が決まる前に退職して収入が途切れ、生活基盤が崩れること。高負荷が続いて健康を大きく損なうこと
- **Soft Ruin**：高負荷による判断疲労が続くこと。迷い続けるうちに誘いの期限が切れること
- **Active Ruin**：疲れている勢いで退職を伝えてしまうこと
- **Passive Ruin**：負荷を記録も軽減もしないまま、現状を続けること
- **戻れない線**：現職への退職の意思表示（あなたの申告）。転職先への承諾・辞退も戻しにくい

## 4. 可逆性

- **戻しにくい**：転職先への承諾、または辞退
- **戻せない**：現職への退職の意思表示
