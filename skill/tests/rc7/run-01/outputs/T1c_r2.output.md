## 3. 破綻境界

- **Hard Ruin（取り返しのつかない損失）**：口頭の条件を前提に退職を申し出て、その後に条件が変わったり内定が取り消されたりすること。収入と生活基盤を失います。
- **Active Ruin（動きすぎによる損失）**：書面の条件がないまま承諾してしまうこと。
- **Soft Ruin / Passive Ruin（動かなさすぎによる損失）**：期限も決めずに迷い続けて疲れること、条件のよい機会を逃すこと。今は「迷っている状態が続いている」だけで、悪化している兆しは申告されていません。

- **戻せない（に近い）**：今の会社への退職の申し出、退職届の提出
