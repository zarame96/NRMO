# 転職の判断：今の情報で決めず、まず比べる材料を揃える

## 1. 結論

**転職するか残るかは、まだ決めない方がいいです（hold）。** 今わかっているのは「残るか、誘われた会社に行くか迷っている」ことだけです。判断に必要な条件、期限、判断軸がまだありません。

この状態で残ると決めても移ると決めても、根拠のない賭けになります。ただし、何もしないで止まる必要はありません。誰にも何も約束せずにできる情報集めは、今日から進められます。

## 2. 現在のモードと状態

```text
Operational Mode：NORMAL（提案。急ぐ理由や強い負荷の申告がないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：不明。「迷っている」は日常語の保留で、正式な HOLD ではない。確定は本人
MISSION-DEFENSE 拡張：非発動（圧力の申告なし。即決を迫られている場合は再評価）
```

## 3. 破綻境界

転職でよくある破綻の型です。今回これに当たるかどうかは、まだ判定できません。

- **Hard Ruin（回復が極めて難しい損失）**：次の職が書面で確定する前に辞めて、収入が途切れ生活基盤が崩れること（§13.1）
- **Soft Ruin（長く選択肢を削る状態）**：合わない職場に長く留まって停滞する、または判断疲労で何も決められなくなること（§13.2）
- **Active Ruin（攻めすぎの破綻）**：条件を確かめないまま勢いで承諾すること
- **Passive Ruin（動かないことによる破綻）**：迷っているうちに回答期限が過ぎ、機会を検討もせずに失うこと

## 4. 可逆性

- **戻せる**：自分の判断軸の整理、条件の比較、先方への質問
- **戻しにくい**：内定の承諾、今の会社へ退職の意向を伝えること
- **戻せない（に近い）**：退職届の提出と受理

## 5. A_allowed（今やってよいこと・保留・禁止）

**今やってよいこと**
- **A1**：自分の判断軸を書き出す。3〜5年後にどうありたいか、今の会社の何に不満で何を手放したくないか。本人だけで行い、費用も確約もありません。
- **A2**：両社の条件を一つの表に並べる。年収、役割、働き方、成長機会、安定性、通勤や勤務地などです。不明な欄は「不明」のまま残します。本人だけで行い、確約もありません。
- **A3**：誘ってくれた会社に、条件・業務内容・回答期限を**質問だけ**する。承諾、辞退、交渉はしません。
  - 根拠：本人が禁止している事項はありません。範囲は質問に限ります。関心があることは伝わりますが、承諾ではないので「迷っている」状態と両立します。期限を知ることは、Passive Ruin を避けるのにも必要です。

**保留**
- **P1**：内定の承諾、または辞退。情報が足りないまま大きく固定化する行動だからです（§15）。
- **P2**：今の会社に退職の意向を伝えること。戻しにくい行動だからです（§15）。

**禁止**
- **F1**：新しい会社の条件を書面で確認する前に退職の意思を伝える、または退職届を出すこと。生活基盤の崩壊（Hard Ruin）に直結する可能性があります（§13.1・§15）。

**条件付き（現時点では A_allowed の外）**
- **X1**：条件交渉（年収、役職、入社日など）。
  - 足りないもの：あなたが交渉する意思があるか、何をどこまで求めるか、比較の材料（A2）。
  - これらが揃えば、改めて評価します。

## 6. Strong Engine 候補

- **候補A（先方に連絡しない）：A1＋A2**
  - 手元の情報だけで判断軸と比較表を作ります。
  - 先方に関心を示したくない場合や、期限に余裕がある場合に向いています。
- **候補B（標準）：A1＋A2＋A3**
  - 判断軸と比較表を作り、空欄を先方への質問で埋めます。
  - 期限が不明なら、こちらが妥当です。

連絡するかどうか以外に意味のある違いがないため、候補はこの二つにしています。

## 7. 推奨

- **転職するかどうかの決定：hold**（材料が揃うまで決めない）
- **情報集め：候補Bを recommend**
  - 先方に関心を示したくない事情があれば、候補Aにしてください。

## 8. 実行ステップ

- **今日やること**
  - A1：判断軸を箇条書きで5つ以内にまとめる。
  - A2：比較表を作り、不明な欄に印をつける。
- **次に確認すること**

- **記録すること**

## 9. 撤退条件と再評価

- **止める条件**
  - 先方が即決を迫る、または期限を急に短くしてきた場合。A3 をやめ、P1 の保留は維持します。MISSION-DEFENSE（防衛目的で使える行動の拡張）を発動するかどうかを、改めて評価します。
- **再評価の条件**
  - 比較表の主な空欄が埋まったとき、または条件が書面で届いたとき。
- **再評価日**
  - 期限がわからないので、まだ置けません。期限がわかったら、その1週間前を目安にしてください（計算上の仮定であり、決めるのはあなたです）。

## 情報不足の整理（§12）

- **確定できること**：次の職が書面で確定する前に辞めることは避けるべきです。
- **仮定すれば言えること**：期限が近い場合は、迷い続けること自体が機会損失（Passive Ruin）のリスクになります。
- **追加で必要な情報**
  1. 今の会社に対する不満、または残りたい理由
  2. 誘われている会社の条件（年収、役割、書面があるか）
  3. 回答期限
  4. 収入が途切れた場合に生活費を何か月持たせられるか
  5. 今の仕事による心身の負荷（強い負荷が続いているなら、それを優先して評価し直します）
- **暫定判断**：決定は hold、情報集めは進める。
- **今は避けるべき判断**：期限も条件も知らないまま、「残る」または「移る」と決めてしまうこと。

上の1〜5を教えてもらえれば、破綻境界と候補を具体的にして、もう一度整理します。最終的に決めるのはあなたです。
