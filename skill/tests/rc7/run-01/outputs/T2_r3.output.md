## 1. 結論

**準備は今日から始めてよいです。ただし、お金や契約が確定する「開業」は、下の3点がはっきりするまで待つことを勧めます。**

初期費用30万円の上限、3か月という期間、月の赤字5万円での撤退。この3つが最初から決まっていて、試し方の骨組みはできています。足りないのは次の3点です。

1. **30万円で何を賄うのか分からない。** 車両を買うのか、借りるのか、リースにするのか。営業許可、設備、最初の仕入れまで入るのか。
2. **撤退の決め方が二通りに読める。** どちらかで、損失の合計がどこまで膨らむかが変わります。
3. **合計でいくらまで損してよいかが決まっていない。** 初期費用と赤字を足した上限です。

## 3. 破綻境界（取り返しがつかなくなる線）

- **重大で取り返しがつかない損失（Hard Ruin）**
  - 必要な営業許可がないまま営業する。法律上の問題と信用の失墜につながります。
  - 食中毒などの事故を起こす。
  - 生活資金を大きく削る。ただし生活資金に対して30万円がどの程度の割合なのかは聞いていないので、判断できません。
- **じわじわ選択肢を削る損失（Soft Ruin）**
  - 週末が埋まり続けて疲れがたまり、本業や体調に響く。
  - 撤退したあとも解約できない契約が残る。
- **攻めすぎによる破綻（Active Ruin）**
  - 30万円に収まらない車両購入や長期リースに、条件を確かめないまま進む。
- **動かないことによる破綻（Passive Ruin）**
  - 「試したい」とはっきり言っているのに、準備まで止めてしまう。これも評価の対象です。

**撤退の決め方が二通りに読める点**（どちらかに決めつけません）

- 読み方(a)：3か月やり終えた時点で、月の赤字を見て判断する
  → 1か月目から3か月目の途中では、赤字に上限がありません。
- 読み方(b)：3か月の間に、どれか1か月でも赤字が5万円を超えたら撤退する
  → 撤退条件に一度も当たらずに3か月続いた場合、損失は最大で「30万円＋5万円×3か月＝45万円」です（こちらの試算）。ただし赤字はその月が終わってから分かるので、1か月の赤字が5万円を大きく超えることはあり得ます。また、撤退時に解約金が発生すると、それも上乗せされます。

## 4. 戻せるかどうか

- **戻せる**：見積もりを取る、問い合わせる、収支表を作る、試作する
- **戻しにくい**：リース契約や出店契約。中途解約金がかかる場合があります。
- **戻せない、またはほぼ戻らない**：車両の購入（売れば一部は回収できますが、全額は戻りません）、事故や法令違反による信用の失墜

## 5. 今やってよいこと・待つこと・やめておくこと

ご本人から「ここまでならやってよい」という範囲の指定はなかったので、こちらで整理しました。

**今やってよいこと（どれも費用はほぼゼロで、相手との約束も生じません）**

- **A1**：車両をレンタル・リース・購入した場合の見積もりを集める。中途解約の条件と最低契約期間も確認する。
- **A2**：管轄の保健所に、移動販売に必要な許可、設備の要件、資格を問い合わせる。法規制はこちらで断定できないので、必ず保健所で確認してください。
- **A3**：出店先の候補（イベント、商業施設、出店仲介サービスなど）に、出店料・売上に応じた手数料・キャンセル条件を問い合わせる。予約まではしない。
- **A4**：収支表を作る。固定費、原価率、1日に何食売れば赤字にならないかを計算します。
  - 試算：週末だけなら月8〜9日の営業です。月5万円の赤字は1日あたり約6,000円になります（計算上の仮定）。
- **A5**：本業の就業規則で、副業が認められているかを確認する。
- **A6**：自宅でメニューを試作し、原価を計算する。少額で済みますが、使った分は初期費用30万円の中に入れて記録してください。

**待つこと**

- **P1**：車両の購入やリース、出店の契約を確定させること。
  - 理由：30万円に収まるのか、解約条件が「3か月で撤退」と両立するのかが、まだ確認できていません。ご自身で決めた上限があることと、正典 §15「情報不足のまま大きく固定化しない」が根拠です。
- **P2**：開業し、3か月の判定期間をスタートさせること。
  - 理由：P1に加えて、許可が取れること、合計の損失上限が決まることが先に必要だからです。

**やめておくこと**

- **F1**：必要な許可を取る前に営業すること。法律上の重大な損失につながります（正典 §13.1）。
- **F2**：初期費用が30万円を超える支出。ご自身で決めた上限です。
- **F3**：撤退したあとも費用が続く契約。たとえば3か月を超えて解約できない契約や、解約金を含めると30万円の枠を超える契約です。撤退すると決めても実行できなくなるため避けます（正典 §15）。
