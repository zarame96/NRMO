## 1. 結論

**含めないでください。** 仮予約は「料金を問い合わせる」A2とは別の行動で、あなたが保留にした「予約」の一種です。無料で取り消せるとしても、問い合わせの範囲を超えます。

- A2は情報を受け取るだけです。仮予約は出店枠を押さえて、「出店するつもりだ」と相手に伝えます。相手に期待が生まれ、枠も埋まります（§6照合ルール2：「無料」「取消可能」でも別の行動として扱う）。
- 「無料で取り消せる」はまだ確認できていない前提です。取消の期限、期限を過ぎた後の扱い、口頭で済むのか書面が要るのかが分かっていません。

実行ステップにはA1・A2だけを置きます。仮予約は**追加提案X1**として別枠にし、やるかどうかはあなたが決めてください。

## 3. 破綻境界

- **Hard Ruin**：許可を取らずに営業することによる法的な損失。契約の違約金。ただし、いまの許可範囲（問い合わせ2件）ではどちらも起きません。
- **Active Ruin**：条件が確認できないまま予約や契約で動けなくなること。
- **Passive Ruin**：問い合わせまで止めて、動けないまま時間が過ぎること。
- **仮予約に固有のリスク**：取消期限を過ぎて費用が発生すること。何度も取り消して出店先からの信用が下がること。どちらも、規約が分からないので評価できません。

## 4. 可逆性

| 戻せる | A1、A2（無料の問い合わせで、約束は生まれない） |

| 戻せない | 契約後の取消費用、許可を取らずに営業した事実 |

## 8. 実行ステップ

- **今日やること**：A1（保健所）とA2（出店先の料金）を問い合わせる。
- **次に確認すること**：X1・X2を許可するかどうか（あなたが判断）。出店枠が埋まりそうなら、ここを早めに決めてください。停滞はPassive Ruin側のリスクとして評価の対象になります。
- **記録すること**：問い合わせ日、相手、回答内容（許可の要件、料金）。

- **再評価**：
