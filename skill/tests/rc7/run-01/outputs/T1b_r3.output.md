## 3. 破綻境界

- **Hard Ruin**：
  - 収入が途切れて生活基盤が崩れること。
  - 高い負荷が続いて健康を大きく損なうこと。
- **Soft Ruin**：
  - 高い負荷のまま判断を先送りし続けること。判断疲労や機会損失につながります。
  - 現職の不満から逃れるためだけに移り、条件の合わない職場に固定されること。
- **Active Ruin**：条件を書面で確認しないまま退職や承諾をすること。
- **Passive Ruin**：負荷が構造的なのに観察も比較もせず、動かずにいること。

今の情報では、どれかに当たると認定はできません。
