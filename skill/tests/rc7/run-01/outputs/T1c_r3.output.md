# 転職の判断：NRMO v7.3 で整理

## 1. 結論

転職するかどうかは、今は決めないことを勧めます。代わりに、相手の会社に条件を書面で出してもらい、変更の記録を取りながら自分の判断軸を書き出してください（下の**候補B**）。

理由：

- 比較の材料になる相手の条件が、まだ固まっていません。
- 承諾も退職の意思表示も、一度出すと取り消しにくい行動です。

まず条件を固めること自体が、前進になります。転職するかどうかの最終判断はあなたのものです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。急ぐ理由が見えず、取り消しにくい行動もまだ出ていないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV なし、VOL は対象が未確定、LOAD は対象が不明）
状態            ：正式な状態は不明（「迷っている」は日常語の保留で、HOLD の承認ではない）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告がない）
```

観測値の読み方：

| 観測 | 対象 | 出どころ |
|---|---|---|
| 状況が落ち着いていて、変化がほとんどない | **対象不明**（現職か、生活全体か） | 本人の申告 |
| 条件が毎日のように変わる（1週間） | 誘ってくる会社 | 本人の申告 |
| 負荷が低い | **対象不明**（あなた自身か、仕事の量か） | 本人の申告 |

- 前の二つは対象が違うので、矛盾ではありません。
- どれを VOL とみなすかが決まらないため、Type ZERO は判定していません。

## 3. 破綻境界

- **Hard Ruin**：書面の条件が固まる前に承諾し、さらに退職する。その後に条件が下がったり、話が消えたりすると、生活の基盤を失います。
- **Active Ruin**：条件が揺れている最中に、勢いで固定してしまうこと。
- **Soft Ruin / Passive Ruin**：先方の回答期限が分からないため、機会を逃すリスクは評価できません。ただ、今は現職を失う話ではないので、短く様子を見るだけなら破綻にはつながりません。

## 4. 可逆性

| 区分 | 行動 |
|---|---|
| 戻せる | 記録、判断軸の整理、条件の書面化の依頼 |
| 戻しにくい | 内定の承諾、現職への退職の意思表示 |
| 戻せない（実質） | 承諾と退職を両方済ませたあとに条件が崩れること |

## 5. 許容行動集合 A_allowed

### 今やってよいこと

| 番号 | 行動 | 行為者 | 費用 | 相手への約束 |
|---|---|---|---|---|
| **A1** | 先方の条件の変化を日付ごとに記録する（何が、いつ、どう変わったか） | 本人 | なし | なし |
| **A2** | 先方に「条件を書面（オファーレター等）で出してほしい」「回答期限はいつか」の**2点だけ**を依頼する | 本人 → 先方 | なし | 承諾ではない。検討を続けているとは伝わるが、迷っている今の状態と矛盾しない |
| **A3** | 自分の判断軸と、これを下回ったら断るという最低ラインを書き出す（年収、職務、勤務地、働き方など） | 本人 | 時間のみ | なし |
| **A4** | 現職の条件を、A3 と同じ軸で整理する（現職には伝えない） | 本人 | 時間のみ | なし |

### 保留すべきこと

- **P1**：内定の承諾や、入社の意思表示。
  - 根拠：情報が足りないまま大きく固定することになるため（正典 §15）。
- **P2**：現職への退職の意思表示。
  - 根拠：戻しにくい行動で、比較の材料もまだ揃っていないため（§15）。

### 禁止すべきこと

- **F1**：書面の条件が固まる前に、承諾と退職の両方を済ませること。
  - 根拠：不可逆の損失に直結するため（§13.1、§15）。

### 条件付き候補（今は A_allowed の外）

- **X1**：条件交渉。
  - 足りないもの：交渉するかどうかのあなたの意思と、何をどこまで求めるか（A3 の最低ライン）。
  - A3 が終わり、書面（A2）が揃えば再評価できます。

## 6. Strong Engine 候補

- **候補A（安全寄り）：A1＋A3＋A4**
  - 先方には何も働きかけず、手元の材料だけを整えます。
- **候補B（標準）：A1＋A2＋A3＋A4**
  - 候補Aに、条件の書面化と期限の確認を加えます。揺れている相手から確定した情報を引き出せる、一番効率のよい前進です。
- **攻めの候補**：今の A_allowed の中には、意味のある違いを持つ案がありません。交渉（X1）は、上の条件が揃ってから再評価します。

## 7. 推奨判断

- 進め方：**候補B を recommend**

## 8. 実行ステップ

**今日やること**
- A1：この1週間の条件変更を、思い出せる範囲で日付ごとに書き出す。
- A3：判断軸と最低ラインを書く。

**次にやること**

## 9. 撤退条件と再評価

- **止める指標**：書面を依頼しても出てこない、または書面のあとも条件が変わる場合は、比較の前提が崩れたとみなして、続けるかどうかを見直してください。辞退するかどうかを決めるのはあなたです。
- **再開できる状態**：書面の条件と回答期限が揃い、A3 の最低ラインと比べられるようになったとき。
- **再評価日**：書面が届いた時点、または依頼から1週間後（どちらも私が置いた仮定です）。
