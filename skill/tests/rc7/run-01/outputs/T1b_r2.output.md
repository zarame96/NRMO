## 出力全文

## 1. 結論

**今は退職を伝えない。先に、誘われている会社の条件を確認して比べる（候補B）。**
退職の意思表示は、あなた自身が言うとおり取り消せません。誘い先の条件がまだ分からないので、今伝えると「情報が足りないまま大きく固定化する行動」（正典 §15）に当たります。一方で、迷ったまま何もしないと、高い負荷が続くことによる停滞のリスク（§13.2 / §13.4）もあります。そこで、取り消せる範囲の準備は今日から進めます。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案。負荷が高いという本人申告と、退職表明が取り消せないという本人申告から）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV＝退職表明は不可逆〔本人申告〕／LOAD＝高い〔本人申告。L1/L2 の区分は未確定〕／VOL＝観測なし）
状態            ：ACTIVE を推奨（確定は本人）。「迷っている」は日常語で、正式な HOLD ではない
MISSION-DEFENSE 拡張：非発動（誘い先からの圧力や期限による急かしの申告はない）
```

## 3. 破綻境界

- **戻れない一線**：退職を伝えること（本人申告）
- **Hard Ruin の候補**：
  - 移り先が決まらないまま収入が途絶え、生活基盤が崩れる
  - 高い負荷が続き、健康が大きく悪化する（今は兆候の申告なし）
- **Soft Ruin の候補**：判断疲労。迷った状態が長く続く
- **Active Ruin**：負荷から逃れたい勢いで、条件を確かめないまま退職を伝える
- **Passive Ruin**：迷い続けて誘いの期限が過ぎ、負荷も変わらないまま残る
- いずれも**破滅に至ったとは判断していません**。可能性として挙げています。

## 4. 可逆性

| 区分 | 行動 |
|---|---|
| 戻せる | 条件の問い合わせ、比較表、負荷の記録、資金の確認、就業規則の確認 |
| 戻しにくい | 誘い先への承諾。現職の上司に転職の迷いを話すこと（関係に影響する） |
| 戻せない | 退職の意思表示（本人申告） |

## 5. A_allowed

**今やってよい**
- **A1**：誘い先に条件を問い合わせる（正式オファーの有無、年収、職務、労働時間・負荷の実態、入社時期、回答期限）。承諾の確約はしない
- **A2**：判断軸を書き出し、2社を並べた比較表を作る（あなたが一人でやる。費用ゼロ）
- **A3**：現職の負荷を記録する（残業時間、睡眠、体調。毎日1行）
- **A4**：生活資金が何ヶ月分あるかを確認する
- **A5**：就業規則で、退職の予告期間と有給の残りを確認する（読むだけ。誰にも伝えない）
- **A6**：睡眠・食欲・体調の不調が続く場合は、産業医か医療機関に相談する
  - 根拠：§13.1 の「健康の重大悪化」と、負荷が高いという本人申告
  - 「続く」の目安を2週間とするのは、こちらが置いた前提です

**保留**
- **P1**：誘い先への承諾。承諾すると確約が生まれ、条件もまだ分からないため
- **P2**：退職を伝えること。少なくとも、条件が書面で確定し、P1 を判断した後に再評価します

**禁止**
- **F1**：条件が書面で確定する前に退職を伝えること（正典 §15、本人申告の不可逆性）

**条件付き候補（現時点では A_allowed の外）**
- **X1**：現職で負荷を減らせないか、上司や人事に相談する
  - 未確定の点：あなたがそれを望むか、何をどこまで話すか（転職を考えていることに触れるか）
- **X2**：誘い先と条件を交渉する
  - 未確定の点：A1 で条件が出揃ってから、交渉する項目と上限を決める必要がある
