# 転職判断の整理（NRMO v7.3）

## 1. 結論

**今の時点では、転職するか残るかはまだ決めない方がよいです。**
理由は、決めるための情報（両社の条件、あなたの判断軸、回答期限、生活資金の余裕）がまだ一つも揃っていないからです。ただ、判断を止める必要はありません。戻せる情報収集はすぐ始められます。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。急ぐ事情や負荷が高いという申告がないため）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：ACTIVE を推奨（情報収集を進める）。確定するのはあなたです
MISSION-DEFENSE 拡張：非発動（相手から圧力を受けているという申告なし）
```

「迷っている」という言葉は、正式な HOLD 状態としては扱っていません。

## 3. 破綻境界（一般的な想定。あなたの状況は未確認）

| 区分 | 内容 |
|---|---|
| Hard Ruin | 収入が途切れて生活基盤が崩れる／機密の持ち出しや承諾後の辞退などで信用を大きく損なう／健康の重い悪化 |
| Soft / Passive Ruin | 迷い続けて回答期限が切れる、判断に疲れる、現職での停滞が長引く |
| Active Ruin | 条件を確かめないまま即決する、次の職が決まる前に退職を固めてしまう |

## 4. 可逆性

- **戻せる**：条件の確認、自分の判断軸の整理、資金の試算
- **戻しにくい**：内定の承諾、現職への退職の意思表示、現職への転職オファーの開示
- **戻せない**：退職の確定と後任への引継ぎ完了（法的な扱いは要確認）

## 5. A_allowed（こちらで整理した一覧）

**今やってよいこと**
- **A1**：誘ってくれている会社に条件を問い合わせる。対象は年収・職務・勤務地・働き方・入社時期・回答期限。確約は伴いません（関心がある程度には受け取られます）
- **A2**：現職の棚卸しを自分だけで行う。給与、評価の見込み、不満、残った場合に変わりそうなこと
- **A3**：判断軸を書き出す。「得たいもの」と「失えないもの」をそれぞれ3つまで
- **A4**：生活防衛資金が何か月分あるかを試算する。年収が下がった場合や、転職先が合わなかった場合も含めます

**保留すべきこと**
- **P1**：内定の承諾、入社の意思表示。情報不足のまま大きく固定化する行動にあたるため（正典 §15）
- **P2**：現職への退職の意思表示。戻しにくい行動で、資金余力も不明なため（§13.1、§15）

**禁止すべきこと**
- **F1**：現職の機密情報や顧客情報を持ち出す、相手先に渡す。法的・信用面の Hard Ruin にあたるため（§13.1）

**条件付きの追加案**（現時点では A_allowed の外）
- **X1**：誘われている会社との条件交渉。何をどこまで交渉するかと、A3 の判断軸が決まれば再評価します
- **X2**：現職にオファーがあることを伝えて待遇を相談する。人間関係や評価への影響があるので、あなたが望むかどうかと、A2・A3 が揃ってから再評価します

## 6. Strong Engine 候補

- **候補A（自分側だけ整理する）**：A2＋A3＋A4。相手には接触せず、判断軸と資金面を先に固めます
- **候補B（両方の情報を揃える）**：A1＋A2＋A3＋A4。相手の条件も取り寄せて、同じ基準で比べられる状態にします
- **攻めの案（C）**：今の許容範囲には該当がありません。交渉（X1・X2）は条件が揃ってから扱います

## 7. 推奨判断

- 転職するか残るかの決定：**hold**
- 情報収集（候補B）：**recommend**。回答期限が近い場合は、特に A1 を優先してください

## 8. 実行ステップ

- **今日**：A3 で判断軸を書き出す。誘いの回答期限を確かめる（A1 の一部）
- **次に**：A1 と A2 の結果を、同じ項目で両社並べて比べる。あわせて A4 で資金を試算する
- **記録**：比較表と判断軸を同じメモに残す

- 相手が条件を明かさないまま承諾を急かしてきたら、P1 は保留のままにします。MISSION-DEFENSE 拡張を発動するかを再評価します
- 判断軸と両社の条件が揃った時点で再評価します。再評価日は回答期限から逆算してあなたが決めてください。期限がわからないので、こちらで日付は置いていません
