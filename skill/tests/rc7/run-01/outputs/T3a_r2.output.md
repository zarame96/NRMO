## 1. 結論

**今週の買い増しは hold を推奨します。** 理由は、判断に必要な本人側の数値（保有比率、買い増し額、許容最大損失、追加資金余力）と最新の市場情報が、どちらも手元にないためです。

これは「買うな」という意味ではありません。情報が揃えば今週中にもう一度判断できます。止めるのは買い増しの実行だけで、準備は進めます。

## 3. 破綻境界（§13）

- **Hard Ruin**：生活資金や近いうちに必要な資金を買い増しに回すこと。信用取引なら追証や強制決済による資本の致命的な毀損。
- **Active Ruin**：AMD一銘柄への過剰集中や、撤退条件を決めないままの買い増し。
- **Soft Ruin / Passive Ruin**：検討が止まったまま判断の機会を逃し続けること。ただし、いま見送ること自体は停滞であって、破滅ではありません。
- AMDの保有比率と許容損失が分からないため、「どこを超えると戻れないか」はまだ数値で引けません。

## 4. 可逆性

- **戻せる**：情報収集、自分のポジションの整理、買い増し条件の事前記録。
- **戻しにくい**：現物での買い増し。売れば戻せますが、価格変動・手数料・税金による損失が確定します。
- **戻せない**：信用取引で強制決済されること。

## 5. A_allowed

**今やってよい**（いずれも費用ゼロで、誰にも何も約束しない行動です）

- **A3**：買い増す場合の条件を事前に記録する。記録するのは、金額、買う価格の条件、撤退条件、再評価日です。発注はしません。

**保留**
- **P1**：今週の買い増しの実行。根拠は、§10.1で必須とされる項目（最大損失、集中、追加資金余力、撤退条件）がまだ確認できていないことです。§15の「撤退条件がない高リスク行動」や「情報不足のまま固定化する行動」に当たるかどうかを判定できないため、保留にしています。A2とA3が揃えば再評価します。
