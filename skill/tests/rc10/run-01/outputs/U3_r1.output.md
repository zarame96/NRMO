# 週末キッチンカー：今すぐできることの整理（NRMO v7.3）

## 1. 結論

挙げてくれた3つ（保健所への確認、出店場所への出店料の確認、車両の見積もり依頼）は、どれも情報を集める段階の行動です。今すぐ始めて構いません。

順番は、**保健所への確認を最初か同時に入れる**のがおすすめです。許可の要件（設備やメニューの区分など）によって、見積もりに出す車両の仕様が変わる可能性があるためです。

車両の購入、出店の申込み、各種の契約は、3つの回答が揃うまで保留にしておくのが妥当です。

## 3. 破綻境界

## 5. A_allowed

**今やってよいこと**

- **A1**：質問リストと記録表を作る（自分でやる作業）。
  - 想定メニュー、週末に何回出店したいか、各問い合わせで聞く項目を書き出します。
  - メニューによって許可の区分が変わる可能性があるため、保健所に聞く前に用意しておくと話が早くなります。
- **A2**：出店予定エリアを管轄する保健所に、営業許可の要件を問い合わせる。
  - 質問の例：
    - 必要な許可の種類
    - 車両設備の要件（給排水タンク、シンクなど）
    - 仕込み場所は必要か
    - 複数の自治体で出店する場合の扱い
    - 申請手数料と期間
  - 法規の具体的な内容はここでは断定しません。管轄の保健所の回答を正としてください。
- **A3**：出店候補の場所に、出店料と条件を問い合わせる。
  - 質問の例：
    - 料金の体系（固定か売上歩合か）
    - 出店の頻度・枠
    - 必要書類（許可証のコピーなど）
    - キャンセル規定
  - 問い合わせだけで、申込みはしません。
- **A4**：車両業者に見積もりを依頼する。
  - 比較できるように複数の業者に頼むのがおすすめです。
  - 新車・中古・レンタル／リースの別も聞くと比較の幅が広がります。
  - 見積もりの依頼だけで、発注・手付金の支払いはしません。
  - 見積もりに費用がかかる場合は、金額を確認してから判断してください。

**保留すべきこと**

- **P1**：車両の購入・発注・手付金の支払い
  - 根拠：重要な情報が不足したまま大きな負担を固定することになります（PDF §64.1-2）。
- **P2**：出店の申込み・予約
  - 根拠：許可の取得前で、キャンセル条件も未確認です。
- **P3**：仕込み場所の賃貸契約
  - 根拠：保健所の回答次第で必要かどうかが変わります。

**禁止すべきこと**

- 本人の宣言も、上位資料上の明確な根拠もないため、なし。

## 6. Strong Engine候補

- **候補A（順番に進める）：A1 → A2 → A3＋A4**
  - 保健所の回答を受けて、車両の仕様を固めてから見積もりを取ります。
  - 見積もりの取り直しは減りますが、全体が揃うまで時間がかかります。
- **候補B（同時に進める）：A1 → A2＋A3＋A4**
  - 3つを同時に問い合わせます。
  - 早く進みますが、車両の見積もりは「保健所の要件次第で仕様が変わる前提の概算」として扱い、後で取り直す可能性があります。

## 7. 推奨

**recommend：候補B。** ただし、A4の見積もり依頼では、業者に「保健所の要件は確認中」と伝える形にするのがよいと考えます。週末だけの事業なら、まずスピードを取って全体の費用感を早くつかむ価値があるためです。

最終的に選ぶのはあなたです。

## 9. 撤退条件・再評価条件

- **撤退条件**：本人の宣言はまだありません。以下は**こちらの提案（未採用）**です。
  - 初期費用の上限（車両や許可などにかかる費用）を決める。

  - これらを決めると、次の段階（購入や申込みの判断）で VENTURE の条件が揃います。
- **再評価条件**：3つの回答が揃った時点で、P1〜P3（購入・申込み・契約）を改めて判断します。
- **再開**：保健所の要件、出店料、車両費の3つが揃い、上限を決めた段階で、購入や申込みを検討できます。
