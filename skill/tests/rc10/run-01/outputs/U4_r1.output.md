## 出力全文

## 1. 結論

今の時点では、内定を受けるか断るかを決めるための情報が足りません。本人が決める前に、次の4つを揃えることを勧めます。

1. 回答期限
2. 書面の条件
3. 現職と内定先の比較
4. 自分が何を優先するか

決めるのは本人です。今回の判断の範囲は、承諾・辞退を確定するのを情報が揃うまで止めることだけです。

## 2. 現在モードと状態

```text
Operational Mode   ：NORMAL（提案。負荷・揺らぎの申告がなく、今は情報を集める段階のため）
Context Override   ：なし
Type ZERO Mode     ：未判定（IRREV / VOL / LOAD の観測なし）
状態               ：現在の記録状態は不明
今回の判定         ：HOLD（承諾・辞退の確定について。PDF §60.3・§64.1-2：大きな決定に必要な情報が足りない）
MISSION-DEFENSE 拡張：非発動（圧力などの申告なし）
```

HOLD は「決めずに止まる」という意味ではありません。下の情報収集はそのまま進められます。HOLD を解いて確定に進むのは、本人がはっきり承認したときだけです（§60.3）。

## 3. 破綻境界

- **確定していること：** 誘われていた会社から内定の連絡が来た。今の会社に残るか移るか決めたい。
- **不明なこと：** 条件、回答期限、書面があるか、生活資金、現職ですでに何か伝えたか、移りたい理由と残りたい理由。
- **注意が必要な経路**（今回本当にそうなるかは未確認）：
  - 転職先の書面がないまま退職を伝えると、収入が途切れるおそれがあります。
  - 期限を知らないまま返事をしないと、内定の機会がなくなるおそれがあります。
- **Hard / Soft の区分：** 投資以外の相談なので使いません（PDF §63.1）。
- **Active Ruin（勢いで動いて崩れる型）：** 起こりうるのは、急いで承諾したり退職を伝えたりする場合です。今回そこに達する根拠はありません。
- **Passive Ruin（動かずに機会を失う型）：** 今は該当しません。期限が来ると内定の機会がなくなる可能性はありますが、期限が分からないので判断できません（PDF §63.2）。

## 4. 可逆性

| 区分 | 行動 |
|---|---|
| 戻せる | 情報の確認・質問、比較表づくり、判断軸の書き出し |
| 戻しにくい可能性あり（未確認） | 承諾の意思表示、辞退の意思表示、現職への退職の申し出 |

承諾や退職を後から取り消せるかは、法律や契約の判断になり、確認していません。必要なら専門家に確かめてください。

## 5. A_allowed（こちらで整理した一覧）

**今やってよいこと**
- **A1** 内定先の人事に、条件を書面（労働条件通知書など）で受け取れるか確認する。受け取っていなければ提示を頼む。依頼だけなので、承諾の意思表示にはなりません。
- **A2** 内定先に回答期限を確認する。
- **A3** 現職と内定先の比較表を自分で作る。項目は年収、業務、評価、勤務地、働き方、将来性。移る場合の収入の空白と生活資金も入れる。
- **A4** 自分の判断軸を書き出す。何のために働くか、3〜5年後どうなっていたいか、譲れない条件は何か。
- **A5** 内定先に、配属・業務内容・評価制度・残業などの不明点を質問する。承諾を前提とした質問はしません。

**保留すること**
- **P1** 承諾の意思表示（PDF §64.1-2：情報不足のまま大きな決定を固めない）
- **P2** 辞退の意思表示（同上）
- **P3** 現職への退職の申し出（同上。書面と承諾の前に行うとリスクがあるため）

**禁止すること**
- 該当なし。本人の制約からも上位資料からも、今回禁止を導く根拠はありません。

**追加提案（今の一覧の外。本人の意向を確認してから評価し直す）**
- **X1** 内定先との条件交渉：比較の材料と、何を交渉するかが決まっていません。
- **X2** 現職の上司に処遇やキャリアを相談する：転職の意向が伝わる可能性があります。伝えてよいかは本人が決めていません。

## 6. Strong Engine 候補

## 7. 推奨判断

- 承諾・辞退の確定：**hold**
- 情報収集：**候補 B を recommend**。不明点が多いと感じる場合は候補 C。

## 8. 実行ステップ

- **今日：** A2 で回答期限を確認する。A1 で書面があるか確認する。
- **次に：** A4 で判断軸を書き、それを基準に A3 の比較表を埋める。
- **記録すること：** 期限、書面の条件、各項目の比較、残りたい理由と移りたい理由。

## 9. 撤退条件・再評価（すべてこちらの提案で、本人はまだ採用していません）

- **再評価の条件：** 期限、書面の条件、比較表、判断軸の4つが揃ったら、承諾するか辞退するかを本人が決める。
- **再評価の時期：** 回答期限が分かったら、その数日前に置く（日数は本人が決める）。
- **見直す合図：**
  - 書面の提示を断られる、または口頭の条件と違う場合は、そのまま進めずに評価し直す。
  - 即答を強く迫られる場合は、MISSION-DEFENSE 拡張を発動するかを判断し直す。
