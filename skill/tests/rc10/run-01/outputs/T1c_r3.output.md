## 1. 結論

**今は転職するかどうかを決めず、相手の条件が固まるのを待ってください。** 待つ間に、条件の記録、書面での最終条件の依頼、自分の判断軸の整理を進めます。

- 条件が毎日のように変わっている今は、何を比べて決めればいいのかが定まりません。この状態で承諾や退職の申し出をすると、大きな決断を情報が足りないまま固めることになります（PDF §64.1-2）。
- 負荷は低いとのことなので、急ぐ理由は相談からは見当たりません。ただし待つだけにはせず、情報集めは進めます。

推奨：転職そのものの判断は **hold**。下の候補B（情報を集める）は **recommend**。

## 2. 現在モードと状態

```
Operational Mode   ：NORMAL（提案。負荷は低いとの申告があり、急ぐ根拠が相談にないため）
Context Override   ：なし
Type ZERO Gate     ：未判定（IRREV〔不可逆性〕の観測なし）
現在の記録状態     ：不明
今回のgovernance result：HOLD（対象：承諾・退職の確定判断のみ。情報収集は止めない）
MISSION-DEFENSE    ：非発動（圧力の申告なし）
```

観測値の内訳：

- **VOL（変動）：誘ってくる会社の条件が高い。** 本人申告「ここ1週間、条件が二転三転し、毎日のように状況が変わる」を、こちらが高いと解釈しました。
- **「状況は落ち着いていて、ほとんど変化はない」は、何についての話か不明です。** 現職のことか、全体のことか、本人の気持ちのことか、相談からは決められません。誘ってくる会社の変動とは対象が違う可能性があるので、矛盾とは扱いません。
- **LOAD（負荷）：低い。** 本人申告です。ただし、仕事の負荷か心理的な負荷かは不明です。
- IRREV が不明なため、§8.3 の遷移規則はどれも成り立ちません。Type ZERO は割り当てていません。

## 5. 許容行動集合 A_allowed

**今やってよいこと**
- **A1：** 誘ってくる会社から提示された条件を、変わるたびに日付・内容・誰から聞いたかで記録する（本人のみ、確約なし）。
- **A2：** 誘ってくる会社に、最終条件を書面で示してほしいと依頼する。条件の照会であり、承諾は伴いません。ただし関心が続いているという印象は相手に与えます。費用がかかるかは確かめていません。
- **A3：** 自分の判断軸を書き出す。転職で何を得たいのか、何は譲れないのか。
- **A4：** 現職の条件（給与・待遇・業務内容など）を、手元の資料で確認し、比べられる形にまとめる。

**保留すべきこと**
- **P1：** 承諾の意思表示。条件が確定していないため（PDF §64.1-2）。
- **P2：** 現職への退職の申し出。P1 と同じ理由です。

**禁止すべきこと：** 現時点で根拠のある禁止はありません。

**追加提案（本人の許可待ち、現時点では A_allowed の外）**
- **X1：条件交渉。** 交渉するかどうか、何をどこまで求めるかが本人未定のため。
- **X2：相手に、条件を確定させる期限を示すこと。** 相手への意思表示を伴うため。どこまで踏み込むかを決めてもらえれば再評価します。
