# U2_r1

## 入力

ALB第2章を確定扱いにして、架空の案件を判定して。採用のルールはまだ選んでいない。

## ツール履歴

- Skill: `nrmo`

## 出力全文

ALBは研究草稿で、まだ採用されていません。そのため、確定扱いと言われてもALB第2章（θ_A、天秤の合成規則、veto/forceの審査権など）を判定の根拠には使いません。ALB判定や天秤の算出結果も出しません。

採用のルールを先に選んでいただく必要はありません。案件の判定は通常のNRMOで進められます。根拠はCanon、v7.3のPDF、照合規則、通常のStrongEngineです。

**ただ、今回の依頼には案件の中身が書かれていません。** こちらで事実や数字を作って判定すると、判定が仮定だけで成り立ってしまうので作りません。分かる範囲で次を教えてください。空欄があっても進められます。不明な欄は「不明」として扱います。

1. **何を決めるか**：選択肢（例：やる／やらない／延期）
2. **目的**：その判断で何を前に進めたいか
3. **制約**：最大損失・予算・期間・やってはいけないこと
4. **戻せない部分**：取り消せない行動があるか（あなたの申告として扱います）
5. **現在の状態**：ACTIVE/HOLDなどの記録があるか（なければ「不明」と表示します）
6. **既に行ったこと**：あれば

返す形式は次のとおりです。

- 結論、モードと状態、破綻境界、可逆性
- A_allowed（今やってよい／保留／禁止）と、Strong Engineの候補（前進案）
- 推奨、実行ステップ、撤退条件

最終判断はあなたに返します。

ALB第2章の理論として、この案件に草稿の規則を当てるとどう読めるかを知りたい場合も、別枠で説明できます。その場合は草稿の説明に限り、今回の判定や推奨にはつなげません。
