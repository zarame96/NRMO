## 出力全文

## 1. 結論

今の情報では、残るか移るかを決めるのは早いです。両社のこと、あなたの軸、お金のこと、回答期限のどれもまだ分からないからです。今は、移るとも残るとも約束せずに、情報を集めて整理するところまで進めるのがよいと考えます。決めるのはあなたです。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。差し迫った危険の申告がなく、次は情報集めが中心になるため）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測がない）
現在の記録状態  ：不明
今回の判定      ：転職の承諾・退職の申し出については HOLD
                  （大きな約束を決めるには情報が足りないため。PDF §60.3・§64.1-2）
                  情報集めは下の A1〜A4 の範囲で進めてよい
MISSION-DEFENSE：非発動（相手からの圧力などの申告がない）
```

## 3. 破綻境界

- **Hard / Soft**：対象外です。この分類は投資の場面だけで使います。
- **Active（急いで動いて失敗する経路）**：条件を確かめないまま転職先に承諾したり、今の会社に退職を伝えたりする道です。ただ、それで本当に取り返しがつかなくなるかは、契約の中身や生活資金によります。今は分かりません。
- **Passive（動かずに機会を逃す経路）**：返事の期限があるなら、期限切れで誘いが消えるかもしれません。期限があるか分からないので、これは成立していません。

## 4. 可逆性

- **戻せる**：自分の考えを整理する、条件を聞く、規則を確認する。
- **戻しにくい可能性がある**：承諾の連絡、退職の申し出。取り消せるかどうかは、法律や契約、相手の対応によります。ここは確認していません。

## 5. 許容行動集合 A_allowed

**今やってよいこと**
- **A1**：残る理由と移る理由を書き出し、自分が何を大事にしたいか（例：収入・仕事の中身・成長・働き方・人間関係）に優先順位をつける。自分だけで行う作業です。
- **A2**：誘ってくれた会社に、条件を書面でもらえるか聞く（仕事の中身・報酬・勤務条件・返事の期限）。その際、承諾ではなく検討のための確認だと伝えます。
- **A3**：今の会社の就業規則や雇用契約で、退職の手続きと、何日前までに申し出る必要があるかを自分で確認する。社内には何も伝えません。
- **A4**：生活資金が何か月分あるかを確認する。

**保留**
- **P1**：転職先に承諾を伝えること。
- **P2**：今の会社に退職を伝えること。
- 根拠はどちらも同じで、情報が足りないまま大きな約束をしないためです（PDF §64.1-2）。

**禁止**：根拠のあるものは今のところありません。

**条件付きで検討するもの（今の A_allowed には入れない）**
- **X1**：条件の交渉。何をどこまで交渉するかと、比べる材料（A2 の書面）がそろってから考えます。

## 6. Strong Engine候補

- **候補A：A1＋A4**。社外には出さず、自分の考えとお金の状況だけ先に固めます。
- **候補B：A1＋A2＋A3＋A4**。比べるのに必要な材料を一通りそろえます。
- 「攻め」の案は、承諾や退職の申し出が必要になるため、今は出していません。

## 7. 推奨判断

- 決めることそのものは **hold** です。
- 情報集め（候補B）は **recommend** です。

## 8. 実行ステップ

- **今日**：A1。紙に書くと比べやすくなります。
- **次**：A2・A3・A4 で、条件、期限、手続き、お金の状況を確かめます。
- **記録**：比べた軸、分かった事実、まだ分からないことを残しておきます。

## 9. 撤退・再評価条件

- **再評価のタイミング**：A2〜A4 がそろったとき。返事の期限が分かったら、その前に再評価します。
- **流れを止めて立ち止まる合図**：条件を書面で出してもらえない、または返事を急かされる。その場合は、承諾（P1）の保留を続けます。
