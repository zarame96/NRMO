その代わり、通常のNRMOで判定しました。

- **買い増し2%：hold（保留）**
- 理由1：「最大損失3%」が何に対する上限なのか、読み方が二つあります。
- 理由2：撤退条件がまだ決まっていません。
- 理由3：P(Ruin|買い増し)=0.02 を ε=0.05 と比べるのに必要な4点（下記）が、まだ確認できていません。

## 3. 破綻境界

投資の領域なので、PDF §63.1 に従い、深刻度（Hard／Soft）と原因（Active／Passive）を別々の軸で扱います。

- **Hard（回復不能な損失）**：今回の情報からは到達経路を判断できません。レバレッジ、他の資産、生活資金がいずれも不明です。
- **Soft（原則として回復可能な失敗）**：「20件中6件が標識に至った」は本人申告の過去の履歴として記録します。今回の案件が該当すると認定する材料にはしません。
- **Active（無謀な行動による崩壊）**：買い増しによって、損失が本人宣言の3%を超える経路があるかどうかが論点です。下の試算を参照してください。
- **Passive（停滞による選択肢の侵食）**：**未成立**です。PDF §63.2 では、直前まで開いていた選択の機会（avoidability window）が閉じることの確認が必要ですが、それを確認できていません。τ=21日は停滞の期間であって、破滅の根拠にはなりません。

**計算上の仮定**（価格は一定、手数料は無視、分母の資金も同じとする）

- 「最大損失3%」の読み方は二通りあり、どちらかには決めていません。
  - **読み(a) X全体に対する上限**：買い増し後の保有は10%になります。X価格の下落が30%で、損失が資金の3%に達します。現状の8%のままなら、37.5%の下落で3%です。
  - **読み(b) 買い増し分だけに対する上限**：買い増し分2%が全損しても、損失は2%で3%を下回ります。
- **P(Ruin|買い増し)=0.02 と ε=0.05**：0.02 ≤ 0.05 は成り立ちます。ただし、次の4点が未確定なので、これを許可の根拠にも停止の根拠にもしません。
  1. 何をRuinとするかの定義
  2. 評価期間T
  3. 0.02の推定根拠（本人の見積もりで、検証されていない）
  4. 最大損失3%との整合
- 典拠：PDF第3章の式3.3・3.6・3.11 と、第20章（`ch20_caged_beast.tex`）を確認しました。
