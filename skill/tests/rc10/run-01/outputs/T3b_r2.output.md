## 3. 破綻境界（投資領域なので Hard/Soft の区分も使う。PDF §63.1）
- **本人が宣言した境界：** 許容できる最大損失は資金の3%。意味は二通りに読めます。どちらかは本人が決めてください。
  - **読み(a) Xの保有全体の損失が3%まで：** 買い増し後の保有は資金の10%です（計算上の仮定：手元資金で買い、現時点の評価額を基準にする）。この場合、Xが**約30%下落**すると上限に達します。買い増ししない場合（8%）は約37.5%下落で達します。既存8%分の取得価格や含み損益は、計算に入れていません。
  - **読み(b) 今回の追加分の損失が3%まで：** 現物でレバレッジがないなら、追加分の損失は最大でも2%です。この読みでは、3%の上限は買い増しを制約しません。
- **Hard Ruin（回復できない損失）：** 資金全体の構成、生活資金、レバレッジの有無が不明なため、判定できません。
- **Soft Ruin（強制的なリスクオフ）：** 読み(a)を採るなら、3%に達して撤退を強いられる経路が該当しえます。
- **Active Ruin（無謀な行動による崩壊）：** 撤退条件が未設定のまま買い増して下落する経路です。
- **Passive Ruin（動かないことによる選択肢の侵食）：未成立。** PDF §63.2 の主要判定には、選択の直前まで開いていた回避の余地（avoidability window）が閉じたことの確認が必要です。それは確認されていません。21日という期間は二次的な指標にとどめます。過去20件中6件（30%）が Soft Ruin の標識に至った件は、本人申告の履歴として記録し、今回の認定には使いません。
- **P(Ruin｜買い増し)=0.02、ε=0.05 について：** 0.02 ≤ 0.05 は計算上成り立ちます。しかし、次の4点が未確認なので、許可にも禁止にも使いません。
  1. 何を Ruin とするか（Hard か Soft か）
  2. 評価期間 T
  3. 0.02 の根拠（本人の見積もりで、検証の有無は不明）
  4. 3%上限との整合

  この式の所在は、`ch20_caged_beast.tex` で確認しました。PDF 第3章は今回は読み直していません。
