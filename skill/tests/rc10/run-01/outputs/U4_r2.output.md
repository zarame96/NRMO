## 出力全文

## 1. 結論

まだ「残る／移る」は決められない段階です。今日は返事をせず、内定の条件と回答期限をつかんで、比較の材料を揃えましょう。分かっているのは「誘われていた会社から内定の連絡が来た」ことだけです。条件、回答期限、今の会社への不満や期待、生活資金の余裕は分かっていません。この状態で承諾や辞退を伝えると、大事なことを情報不足のまま決めてしまいます。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。差し迫った圧力や強い負荷の話がなく、まず比較材料を集める段階のため）
Context Override：なし
Type ZERO       ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
                  今回の判定結果：承諾・辞退・退職を伝えることについては HOLD
                  （大事な決定に必要な情報が足りない。PDF §60.3）
MISSION-DEFENSE ：非発動（返事を急かされるなどの圧力の話はない）
```

HOLD をかけるのは「意思を伝える行動」だけです。情報集めと準備は進めてかまいません。HOLD を解除して決定に進むかどうかは、あなたが決めます。

## 3. 破綻境界（後戻りできなくなる線）

- **Hard / Soft（損失の重さ）：対象外。** この区分は投資の判断にだけ使います（PDF §63.1）
- **起こりうる経路（Active：動きすぎて起きる失敗）**
  - 新しい会社の条件を書面で確かめる前に、今の会社へ退職を伝える。収入が途切れたり、条件が想定と違ったりするおそれがある
  - ただし、退職の申し出を取り消せるか（法律・社内ルール）は確認していません。ここは私には判断できない部分です
- **起こりうる経路（Passive：動かないことで選択肢を失う）**
  - 回答期限が過ぎると、内定という選択肢がなくなる可能性がある
  - 期限が分からないので、いまはまだそうなってはいません。「迷っている」というだけでは、選択肢を失ったとは言いません
- **影響の大きさ：不明。** 収入が途切れた場合にどれだけ響くかは、生活資金の状況が分からないので判断できません

## 4. 戻せるかどうか

- **戻せる**：条件の確認、質問、比較表づくり、自分の資金の確認
- **戻しにくい（どこまで戻せるかは未確認）**：内定の承諾、内定の辞退、今の会社への退職の申し出、引き留めの相談（転職を考えていることが伝わる）
- **戻せない**：現時点で確実にそうだと言えるものはありません。上の行動の取り消しやすさは、相手の対応や契約・社内ルール次第です

## 5. 今やってよいこと・保留すること

**今やってよい**
- **A1** 内定先に、条件の書面（労働条件通知書やオファーレターなど）と回答期限を確認する。内定先への問い合わせで、承諾や辞退の意思表示は含めない
- **A2** 内定先に、分からない点を質問する。業務内容、配属、評価制度、試用期間など。こちらから約束することは含めない
- **A3** 両社の比較表を作る。年収・賞与、仕事の中身、成長、働き方、安定性、あなたがこの先どうなりたいかとの合い方。自分だけで行う作業
- **A4** 今の会社の条件を確認する。今後の昇給や評価の見込み、賞与の支給時期、就業規則にある退職の申し出期限など。社内の誰にも何も伝えずに行う
- **A5** 生活資金を確認する。入社日がずれた場合などに、何か月もつか

**保留**（決める材料が足りないため。PDF §64.1(2)）
- **P1** 内定を承諾すると伝える
- **P2** 内定を辞退すると伝える（この内定先からまた声がかかるかは分からない）
- **P3** 今の会社に退職を伝える（新しい会社の条件を書面で確かめていない）

**条件付きの候補**（今やってよい範囲の外。条件が揃ったら改めて検討）
- **X1** 内定先と条件を交渉する。交渉するかどうか、何を求めるかがまだ決まっていない
- **X2** 今の会社に引き留めや条件改善を打診する。転職を考えていることが伝わるので、比べた結果「残る」に傾いたときに検討
- **X3** 回答期限の延長をお願いする。期限が分かり、それまでに比較が終わらないとあなたが判断した場合

**禁止**：該当なし（禁止する根拠になる、あなた自身の制限や仕様上のルールが今はないため）

## 6. 進め方の候補

- **候補A：A1＋A3＋A4＋A5**　内定先には書面と期限の確認だけをし、あとは自分の中で比べる
- **候補B：A1＋A2＋A3＋A4＋A5**　Aに加えて、分からない点を内定先に質問し、比較の精度を上げる
- **より踏み込んだ案**：今はありません。踏み込んだ案になるのは交渉（X1）ですが、まだ条件が揃っていません

## 7. 推奨

- 承諾・辞退・退職の申し出（P1〜P3）：**hold**
- 情報集め（候補B）：**recommend**。選択肢を失わずに比較の質を上げられるため

## 8. 実行ステップ

- **今日**：A1（書面と期限の確認）。期限が分かれば、そこから全体の予定が決まります
- **次に**：A2で質問 → A3・A4で比較表を作る → A5で資金を確認
- **記録すること**：内定先の条件、期限、比較表、判断の軸（何を一番大事にするか）

## 9. 撤退条件と見直しのタイミング

すべて私からの提案で、まだあなたが採用したものではありません。

- **見直すタイミング**：書面と期限が揃ったとき。回答期限より前に、自分で「判断する日」を決めておくと安全です
- **様子を見る点**：書面がなかなか出ない、期限までに比較が間に合わない → X3（期限延長のお願い）を検討する
- **HOLD を解除する条件**：書面の条件、期限、比較表、資金の確認が揃い、あなたが「決定に進む」と決めたとき
