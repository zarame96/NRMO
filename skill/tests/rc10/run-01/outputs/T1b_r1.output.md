## 出力全文

## 1. 結論

**辞めるか残るかは、今はまだ決めないことを勧めます（hold）。そのかわり、比べる材料を集める作業はすぐ始めてください。**
退職を伝えると取り消せない、とあなた自身が書いています。一方で、比べるのに必要な情報（転職先の条件、返事の期限、生活資金など）がまだ書かれていません。取り消せない行動を情報不足のまま決めることは、NRMO では今やってよい行動に入りません（PDF §64.1-2）。ただし、迷ったまま止まる必要はありません。

## 2. 現在モードと状態

```text
Operational Mode     ：SAFE（提案）— 本人申告の高負荷と、取り消せない選択肢があるため
Context Override     ：なし
Type ZERO Gate       ：未判定（LOAD は本人申告「かなり高い」、IRREV / VOL の観測なし）
現在の記録状態       ：不明
今回の governance result：HOLD（対象は「退職の申し出」と「転職先への承諾」の2つだけ）
MISSION-DEFENSE 拡張 ：非発動（周りからの圧力や誘導の申告なし）
```

A_allowed は空ではないので、情報集めや記録は止めずに進めます。HOLD を解いてどちらかに決めるのは、あなた自身の明示的な判断だけです。

## 3. 破綻境界

投資の話ではないので、Hard/Soft の分類は N/A です。

- **Active 側の経路**：転職先の条件を書面で確かめる前に退職を伝える → 収入が途切れる、または条件が想定と違う。どの程度の損失になるかは、生活資金と転職先の条件が分からないので**不明**です。
- **Passive 側の経路**：高い負荷が続いて、体調の悪化や判断疲れが進む。誘いの期限が過ぎて機会がなくなる（期限は**不明**）。
- **Passive Ruin：未成立**。今回、選択の窓が閉じた（機会が失われた）ことは確認できていません。

## 5. A_allowed

**今やってよい**
- **A1**：誘ってくれている会社に、条件（職務・給与・勤務地・入社時期・返事の期限）を書面でもらえるか問い合わせる。行うのはあなた、相手は転職先です。承諾の意思は示さず、問い合わせだけにします。
- **A2**：自分用の比較表を作る。仕事で何を一番大事にしたいかの上位3つ、給与、負荷、成長、生活資金。社外に出さないので確約は生じません。
- **A3**：今の負荷を記録する。何が原因か、週に何時間か、いつから続いているか、一時的か構造的か。
- **A4**：就業規則と雇用契約で、退職の申し出期限と手続きを確認する。文書を読むだけにして、退職の意思は誰にも伝えません。
- **A5**：睡眠や体調の不調が続く場合は、医療機関、または産業医（社内にいれば）に相談する。根拠は、本人申告の高負荷です。

**保留**
- **P1**：今の会社に退職を伝える。本人申告で取り消せない上に、情報が足りないためです（PDF §64.1-2）。
- **P2**：転職先に承諾を伝える。確約が生じ、条件も未確認のためです。

**禁止**
- 現時点ではありません（禁止にする根拠が見つかりません）。

**条件付き候補**（今の A_allowed の外）
- **X1**：上司に業務量の調整を相談する。A3 の記録がそろい、何を頼むかが決まったら再評価します。
- **X2**：転職先と条件を交渉する。A1 の書面と A2 の比較軸がそろったら再評価します。

## 6. Strong Engine 候補

- **A案（安全寄り）**：A2＋A3。社外には連絡せず、自分の判断軸と、今の負荷の実態だけを固めます。
- **B案（標準）**：A1＋A2＋A3＋A4。転職先の条件を書面で取り、両方の会社を同じ軸で比べられる状態にします。
- **C案（攻め）**：現時点ではありません。攻めにあたる行動は P1 と P2 で、どちらも保留中だからです。B案の材料がそろえば、再評価できます。

A5 は、どの案でも条件に当てはまれば行います。

## 7. 推奨判断

- 退職と承諾：**hold**
- B案の情報集め：**recommend**

最終判断はあなたに返します。

## 8. 実行ステップ

- **今日**：A3 で、この2週間程度の負荷を書き出す。A2 で、仕事で大事にしたいことを3つ書く。
- **次に**：A4 で就業規則を確認する。A1 で転職先に条件を書面でもらえるか問い合わせ、返事の期限も聞く。
- **記録**：負荷が一時的か構造的か。転職先の条件と期限。

## 9. 撤退条件と再評価条件

- **再評価のタイミング（提案）**：転職先の書面を受け取ったとき、または返事の期限が分かったときのどちらか早い方。
- **再評価の条件（提案）**：比較表が両方の会社で埋まっていること。
- **B案を見直す条件**：転職先が条件を書面で出さない場合。そのときは承諾の判断材料が足りないままなので、P2 は保留を続けます。
- **体調**：睡眠や体調の不調が続くなら、転職の判断より先に A5 を行います。
