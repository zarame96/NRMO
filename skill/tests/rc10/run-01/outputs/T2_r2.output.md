# キッチンカー週末試行の判定（NRMO v7.3）

## 1. 結論

**今すぐ車両や設備にお金を払って始めるのは、まだ保留です。準備は今日から進めて大丈夫です。**
試しに始めること自体を止める根拠はありません。ただ、次の3点が決まっていないので、「始めてよい」とはまだ言えません。

1. **撤退条件をどう読むか**が決まっていない（下の §9 に4通りの読みを並べます）
2. **合計でいくらまで損してよいか**が決まっていない。決まっているのは「初期費用30万円まで」だけです
3. **収支の見込み**（売上・原価・出店料など）と、**30万円の内訳**（売れば戻る分があるか）が分からない

## 2. 現在モードと状態

```text
Operational Mode：VENTURE（提案）
Context Override：なし
Type ZERO      ：未判定（IRREV / VOL / LOAD の観測なし）
状態           ：現在の記録状態は不明
今回の判定     ：全体はHOLDにしない（今やってよい行動があるため）。初期費用の支出だけ保留（P1）

```

VENTUREを提案する理由は、「上限と撤退条件を決めて試す」相談だからです。ただし運用仕様 §8.1.3 が求める条件は半分しか揃っていません。

VENTUREの提案は、始めてよいという許可でも、損失上限が決まったという意味でもありません。

## 3. 破綻境界

- 投資の領域ではないため、Hard/Softの区分は使いません。

## 9. 撤退条件

**あなたが決めた撤退条件（原文のまま）**
「3か月やって月の赤字が5万円を超えたら撤退する」

この文は次の4通りに読めます。どれにするかはあなたが選んでください（A1）。

1. 3か月の間、どれか1か月でも5万円を超えたら、その時点で撤退する
2. 3か月が終わった時点で、3か月の平均が月5万円を超えていたら撤退する
3. 3か月が終わった時点で、3か月目の赤字が5万円を超えていたら撤退する
4. 3か月が終わった時点で、5万円を超えた月が1か月でもあれば撤退する

**「月の赤字」に初期費用を含めるかどうかも、決まっていません**

- 「月の赤字」は、その月の売上からその月の費用を引いたものです。費用の額だけでは赤字かどうか決まりません。
- 例（こちらの仮定）：30万円を3か月で割ると月10万円です。
  - 月の赤字にこの10万円を**含める**なら、撤退しないためには、初期費用以外の部分で月5万円を超える黒字が必要です。
  - **含めない**なら、運営で出る赤字が月5万円以内であればよいことになります。
  - 同じ「5万円」でも、二つの読みでは求める水準がまったく違います。
- 含める読みの場合、初期費用を合計損失にもう一度足すと二重に数えることになるので、足しません。

**こちらの提案（まだ採用されていません）**

- A2 で決めた合計損失の上限に達したら、読み方に関係なく止める
- 見積もりの段階で初期費用が30万円を超える構成なら、その構成では始めない（あなたが決めた上限から導いたもの）
- 再評価：A3〜A5 が揃った時点で、P1 を改めて判断する。始めた場合は、3か月の時点で判断する。カレンダー上の日付はまだ置いていません。
