# 転職相談の整理：人事への給与問い合わせ（A1）と生活費の集計（A2）の範囲で

## 1. 結論

- 今すぐ実行できる候補は、A1と生活費の集計（A2）を組み合わせた案です。
- ご要望の「A1を使って最終面接と入社日の交渉まで進める案」は候補に入れていません。面接と条件交渉は、あなたが保留にしている行動です。また、A1は「応募や交渉の確約なし」「返信を読むまで」と範囲を限ったメールなので、ここから交渉へ進めると範囲を広げることになります。
- この案は消さずに、下の「条件付き候補」として残しました。保留を解く条件がそろったら評価し直せます。

## 2. 現在モードと状態

```text
Operational Mode：NORMAL（提案。理由：許可されているのが情報収集と自分の集計だけで、攻めた試行を組む段階ではない）
Context Override：なし
Type ZERO Mode  ：未判定（IRREV / VOL / LOAD の観測なし）
状態            ：現在の記録状態は不明
                  今回の判定結果は HOLD ではない（今やってよい行動が空でないため）
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告がないため）
```

あなたの言う「保留」は、個々の行動を保留するという宣言として扱います。正式な HOLD 状態に入った記録としては扱いません。

## 3. 破綻境界

- **Hard/Soft（深刻度の区分）**：投資以外の分野なので N/A。
- **今回起こりうる経路**
  - 転職先の条件や書面が確定する前に退職手続きに入ると、収入が途切れる経路があります。ただし規模は不明です。生活資金や回復の見込みが申告されていないので、これだけで生活基盤の崩壊とは判定しません。
  - 生活費が分からないまま交渉に入ると、受け入れられる条件の下限を示せず、不利な形で固まる経路があります。
- **Active/Passive（原因の区分）**：Passive Ruin（動かないことによる破綻）は**成立していません**。今回の選択で、直前まで開いていた選択肢が閉じるという事実を確認できていないためです。なお、停滞している期間は申告されていません。

## 5. 今やってよい行動（A_allowed）

**今やってよいこと**（あなたが限定した一覧。内容は定義のまま広げていません）

- **A1**：人事に給与条件をメールで問い合わせる。
  - 費用：無料（あなたの宣言）
  - 期間：返信を読むまで
  - 応募や交渉の確約はしない
- **A2**：自分の生活費を集計する。

**保留すること**（根拠：いずれもあなたの宣言）

- **P1**：応募
- **P2**：条件交渉。入社日の交渉もここに含まれます
- **P3**：面接。最終面接も含みます
- **P4**：退職

**禁止すること**：該当なし（根拠となる宣言も規則もないため、作りません）

## 6. Strong Engine 候補

- **候補A（安全寄り）：A2のみ**
  - 外部への接触はしません。
  - 自分にとって必要な給与の水準を数字にして、A1を出すかどうかを判断する材料にします。
- **候補B（標準）：A1＋A2**
  - A1を出し、返信を待つ間にA2で生活費を集計します。
  - 返信の給与条件を生活費の集計と並べて見られる状態にします。
- **候補C（攻め）：今やってよい行動の中には該当なし**
  - ご要望の案は下の別枠に置きました。

### 条件付き候補（今やってよい行動の外。推奨や実行手順には入れません）

**C'：A1の返信をもとに最終面接と入社日の交渉へ進む**

この案に含まれる行動は、応募（P1、面接の前提になる場合）、交渉（P2）、面接（P3）です。入社日を交渉するには退職時期の見通しも必要になるため、退職（P4）にも関わります。

評価し直すのに必要なこと：

1. 応募・面接・交渉の保留を解くかどうか、あなたが明示的に決める。
2. 何をどこまで交渉するかを決める。たとえば A2 の結果から出る給与の下限と、入社日の幅です。
3. A1の返信の内容。
4. 入社日について何を約束できるか。そのために現職の退職条件を確認する必要があります（下の X1）。

### 追加提案（あなたの許可待ち。今やってよい行動には含めていません）

- **X1**：現職の就業規則や契約で、退職手続きの条件（予告期間など）を確認する。C' の入社日交渉の前提になります。

- **止める条件**：返信で応募・面接・日程への回答を求められたら、その場では応じません。A1の範囲はここで終わりとし、あなたが評価し直します。
- **再評価のタイミング**：A1の返信を受け取り、A2の集計が終わった時点を提案します。これは私からの提案で、まだ採用されていません。
- **再評価の条件**：あなたが P1〜P3 のどれかの保留を解くと決めたとき、C' を評価し直します。退職（P4）は、それとは別に評価します。
