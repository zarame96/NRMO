## 1. 結論

今の情報では、残るか移るかは決められません。内定の承諾も辞退も、いまは保留にしてください（**governance result：HOLD**）。理由は、大きな決定を必要な情報がないまま固めることになるためです（PDF §64.1-2）。ただし止まる必要はありません。**回答期限の確認**と**条件を書面でもらうこと**を先に進め、情報が揃ったところで改めて判断します。

## 2. 現在モードと状態

```
Operational Mode   ：NORMAL（提案。今は情報を集める段階で、攻めにも守りにも寄せる理由がないため）
Context Override   ：なし
type_zero_gate     ：未判定（IRREV / VOL / LOAD の観測なし）
現在の記録状態     ：不明
governance result  ：HOLD（承諾・辞退の決定について）。再開(→ACTIVE)にはあなたの明示的な承認が必要です（PDF §60.3）
MISSION-DEFENSE 拡張：非発動（圧力や誘導があるという申告はなし）
```

## 3. 破綻境界

- ruin_severity：N/A（投資の領域ではないため）
- ruin_origin：Active の経路になりうるもの：転職先の条件を書面で確認する前に、今の会社へ退職を伝えること。取り消せるかどうか（法的な可否や会社の対応）は確認できていません。
- Passive Ruin：今のところ成立していません。ただし、**回答期限を知らないまま期限が過ぎ、内定がなくなる**経路はありえます。期限があるかどうかも分かっていません。

## 5. A_allowed

**今やってよいこと**
- **A1**：内定先に、条件を書面（労働条件通知書など）で出してもらうよう頼み、業務内容・配属・給与・評価・入社日について質問する。これは承諾の意思表示ではありません。費用がかかる場合は、その場で確認してください。
- **A2**：内定先に回答期限を確認する。
- **A3**：あなた自身で判断の軸を書き出す（大事にしたい方向性、譲れない条件、移る理由、残る理由）。
- **A4**：手元の情報だけで、今の会社の条件と今後の見通しを整理する（社内への問い合わせは含みません）。
- **A5**：入社日までに収入の空白が出るかと、生活資金を整理する。

**保留すべきこと**（根拠：PDF §64.1-2。大事な情報がないまま大きな決定を固めないため）
- **P1**：内定を承諾する
- **P2**：内定を辞退する
- **P3**：今の会社に退職を伝える

**禁止すべきこと**：今は、根拠のある禁止事項はありません。

**条件付きの候補**（現時点では A_allowed に入れていません）
- **X1**：条件交渉。交渉したいかどうかと、何を求めるかが決まれば検討します。
- **X2**：今の会社に引き留めの条件を相談する。転職を考えていることが社内に伝わります。そのうえで相談したいかどうかを、あなたが決めてから検討します。

## 6. Strong Engine候補

- **A案（安全寄り）：A3＋A4＋A5**。外部には連絡せず、自分の中で整理だけを進めます。
- **B案（標準）：A1＋A2＋A3＋A4＋A5**。期限と書面での条件を確保しながら、比べる材料を揃えます。
- **C案（攻め）**：今の許容範囲には、意味のある攻めの案がありません。すぐに承諾するのは P1 に当たるため外しました。

## 7. 推奨判断

承諾・辞退は **hold** です。B案は **recommend** です（期限を知らないまま選択肢が消えてしまうのを防げるため）。

## 8. 実行ステップ

- **今日**：A2（期限の確認）、A1（書面と質問の依頼）
- **次**：A3〜A5 を書き出し、届いた書面と今の会社の条件を同じ項目で並べる
- **記録**：期限、受け取った条件、判断の軸、迷っている点

## 9. 撤退条件と再評価（どれもこちらの提案で、まだ採用されていません）

- **再評価条件**：A1〜A5 が揃った時点で、承諾・辞退・交渉（X1）を判断し直す
- **再評価日**：回答期限が分かったら、その前に置く
- **見直しの合図**：内定先が条件を書面で出すのを断る、または期限までに必要な情報が揃わない場合

判断を進めるために、分かる範囲で教えてください。
1. 回答期限
2. 提示された条件（年収、職種、勤務地、入社日など）
