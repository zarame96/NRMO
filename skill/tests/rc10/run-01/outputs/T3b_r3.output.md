- **原因（Active / Passive）**
  - Active：撤退条件がないまま買い増し、3%を超える経路。
  - Passive Ruin：**未成立**です。今回の選択で「回避できる期間」（避けられる状態が続く期間）が閉じることを確認できていません（PDF §63.2）。

- **P(Ruin|買い増し)=0.02 と ε=0.05**
