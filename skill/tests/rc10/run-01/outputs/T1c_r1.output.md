## 1. 結論

**今は承諾も退職の意思表示もしないでください。先に、誘ってくれている会社から「最終条件の書面」と「回答期限」をもらってください。**
条件がまだ決まっていないので、今は比べられません。決めるのは、書面が届いてからにするのが妥当です。

ここ1週間、毎日のように条件が変わっていること自体も、判断材料になります。相手の社内で決まっていないのか、交渉のつもりなのか、ほかの理由なのかは分かりません。ただ、書面を頼んだときの相手の対応で、ある程度見えてきます。

迷っている判断（転職するか残るか）は「hold（保留）」です。ただし、情報集めは今日から進められます。

## 2. 現在モードと状態

```
Operational Mode（提案）：NORMAL
  理由：負荷が低く（本人申告）、急いで決める事情も書かれていないため
Context Override        ：なし
Type ZERO              ：未判定（IRREV の観測なし、VOL の対象が未確定）
現在の記録状態          ：不明
今回の governance result：転職の判断（承諾・退職）について HOLD
  根拠：PDF §60.3。重大な判断に必要な情報が足りない（条件が確定していない）
MISSION-DEFENSE 拡張    ：非発動
```

- 「状況は落ち着いていて、ほとんど変化はない」が、今の会社のことか、全体のことかは書かれていません。そのため「対象不明」として扱います。
- 「毎日のように状況が変わる」の対象は、誘ってくる会社の条件です（本人申告）。2つの発言は対象が違う可能性があるので、矛盾とは扱っていません。
- 情報集めや準備は続けられるので、やってよいことは残っています。このHOLDは、承諾・退職を決めることだけに当てはめています。

## 3. 破綻境界

- 領域は仕事です。投資の話ではないので、Hard/Softの区分は当てはまりません（N/A）。
- **無謀な行動で起こりうる経路（Active）**：変わり続ける条件のまま承諾したり退職を伝えたりして、後から条件が下がるケース。
  - 生活への影響の大きさや、どこまで回復できるかは、資金などの情報がないので不明です。
- **動かないことで起こりうる経路（Passive）**：回答期限を過ぎて、オファーという選択肢がなくなるケース。
  - 期限があるかどうかが分からないので、この経路は成立していません。
  - 1週間迷っていること自体は、破綻の根拠にはなりません。

## 4. 可逆性

## 5. 今やってよいこと・保留すること

**今やってよいこと**
- **A1**：条件の変化を記録する（日付、何が、どう変わったか）。自分だけでやる作業で、相手への約束は生じません。
- **A2**：誘ってくる会社に、次の2点を頼む。
  - 最終条件を書面で出してほしい
  - 回答期限はいつか
  - 承諾の意思表示は含めません。費用がかかる場面は考えにくいですが、確認はしていません。
- **A3**：自分の判断軸を書き出す（転職で何を得たいか、譲れない条件は何か）
- **A4**：今の会社の条件を、手元の情報で整理する（給与、仕事内容、今後の見通し）

**保留すること**
- **P1**：オファーの承諾
  - 根拠：PDF §64.1-2（重要な決定を、情報が足りないまま確定させない）
- **P2**：現職への退職の意思表示
  - 根拠はP1と同じです。撤回できるかどうかも確認していません。

**条件付きの追加提案（今は「やってよいこと」に入れていません）**
- **X1**：条件交渉
  - 足りないもの：判断軸（A3）と、書面の条件（A2）
  - この2つが揃ったら、もう一度検討します。
- **X2**：今の会社に相談する
  - 転職を考えていることが伝わる可能性があります。
  - 何をどこまで話すかを決めてから検討します。

**禁止すること**：今の時点で、根拠のある禁止事項は見当たりません。

## 6. 進め方の候補

- **A案（安全寄り）：A1＋A3＋A4**
  - 相手には連絡せず、自分の側の整理だけを進めます。
- **B案（標準）：A1＋A2＋A3＋A4**
  - 自分の側の整理に加えて、書面と回答期限を相手に頼みます。
- **C案（攻め）：今は候補なし**
  - 交渉（X1）は、判断軸と書面の条件が揃ったときに検討できます。

## 9. 撤退条件・再評価

以下は**こちらからの提案**です（あなたが決めた条件ではありません）。

- **再評価のタイミング**：書面を受け取ったとき、または回答期限の前。期限がまだ分からないので、日付は置いていません。
- **書面を頼んでも条件が確定しない場合**：それを判断材料に加えて、もう一度評価します。辞退するかどうかは、あなたが決めることです。
- **HOLDの解除**：解除するのはあなたです。書面と期限が揃って、比較できる状態になったときが目安になります。
