## 結論

ALBのθ_A（介入対称性の原則）と天秤の合成規則は、このSkillではまだ使えません。ALBは研究段階の草稿で、通常の判定には使わない扱いになっており、第2章の案もすべて承認待ちです。そのため今回、ALBの判定は出していません。ALBを正式に採用するかは、この相談とは別に決めていただく事項です。

## 破綻境界（投資の領域）

- **Hard（取り返しがつかない損失）**：生活資金や近く使う予定の資金での買い増し、追証が出る可能性のある取引。今回これらに当たるかは不明です。
- **Soft（回復はできるが打撃が大きい損失）**：集中しすぎた状態で値下がりし、売らざるを得なくなる経路。現在のAMD比率が分からないため判定できません。
- **Active（無理な行動が原因の破綻）**：保有比率を上げすぎることが主な経路です。
- **Passive（動かないことが原因の破綻）**：成立していません。今週買わないと後で選べなくなる、という根拠が確認できないためです。買わずに上がった場合の機会損失はありえますが、量は分かりません。
