# 転職相談の整理：給与問い合わせと生活費集計

## 1. 結論

- いま実行できるのは、あなたが許可した2つの行動（A1：人事への給与問い合わせ、A2：生活費の集計）だけです。おすすめは2つを並行して進めることです（下の候補B）。
- 「A1を使って最終面接と入社日の交渉まで進める案」は、実行候補には入れられません。理由は、あなたが保留している面接と条件交渉を含み、A1の範囲（返信を読むまで、確約なし）を超えるためです。そこで、この案は**条件付き候補 X1**として別枠に置きます。保留を解除するかどうかは、あなたが決めてください。

## 2. 現在のモードと状態

```
Operational Mode   ：NORMAL（提案）— 可逆な情報収集の段階で、攻める・守る理由の申告がないため
Context Override   ：なし
Type ZERO Mode     ：未判定（IRREV / VOL / LOAD の観測なし）
状態               ：現在の記録状態は不明（「保留」は日常語として扱い、正式なHOLDの履歴とはみなさない）
今回のgovernance result：A1・A2 は PASS。応募・交渉・面接・退職はあなたの宣言で保留のまま
MISSION-DEFENSE 拡張：非発動（圧力や誘導の申告なし）
```

## 3. 破綻境界

- **Hard/Soft の区分**：投資以外の相談なので対象外（N/A）です（PDF §63.1）。
- **起こりうる経路（無謀な行動による崩壊）**：転職先の条件や合意が書面で確定する前に退職することです。ただし、退職を撤回できるか、収入が途切れたときにどこまで影響するか（生活資金など）は分かっていません。今回、この経路に到達したと判断する根拠はありません。退職は保留中なので、この経路はいまは閉じています。
- **動かないことによる損失（Passive Ruin）**：成立していません。今回の候補が、それまで回避できた状況を閉じる事実（PDF §63.2）は確認できていません。

## 5. 許容行動集合 A_allowed

**今やってよいこと**（あなたの宣言どおりで、範囲は広げていません）
- **A1**：人事に給与条件をメールで問い合わせる。費用は無料（あなたの宣言）で、返信を読んだ時点で終わりです。応募や交渉は確約しません。
- **A2**：自分の生活費を集計する。

**保留すべきこと**（根拠：あなたの宣言）
- **P1** 応募／**P2** 条件交渉／**P3** 面接／**P4** 退職

**禁止すべきこと**：該当なし（禁止にする根拠になる宣言や規則が見当たりません）

**条件付き候補 X1（現時点では A_allowed の外）**：A1をきっかけに最終面接と入社日の交渉まで進める案
- **含まれる行動**：P2（交渉）とP3（面接）です。さらに、「最終面接」という言葉からは、P1（応募）を済ませているか、選考中であることが前提に見えます。この点は分かっていないので、確認させてください。
- **足りないもの**：
  1. P1〜P3 の保留を解除するあなたの判断
  2. 何をどこまで交渉するか（給与の下限、入社日の幅）
  3. 現職の退職手続きにかかる期間（就業規則。未確認）
  4. A1 の返信内容と A2 の集計結果
- **再評価の条件**：1〜4がそろった時点で、この案を改めて評価します。それまでは推奨にも実行ステップにも入れません。

## 6. Strong Engine 候補

- **候補A（安全寄り）：A2 のみ** — 外部に何も出さずに、判断の基準になる生活費だけを固めます。
- **候補B（標準）：A1＋A2 を並行** — 返信を待つ間に集計を終えます。返信が届いたときに、すぐ生活費と比べられます。
- **候補C（攻め）：今は出せる案がありません** — 攻めの案は保留中の行動を必ず含むためです。保留を解除すれば、X1 として評価し直せます。

## 7. 推奨判断

- 候補B：**recommend**
- X1：**hold**（上の1〜4がそろうまで）

## 8. 実行ステップ

- **今日やること**
  - A2：直近の固定費と変動費を月額で集計します。
  - A1：給与条件だけを尋ねるメールを送ります。質問は給与条件に限ってください。入社日や選考のことは聞きません。
- **次に確認すること**：A1 の返信内容を読むところまでです。返信への対応は、A1 の範囲を超えます。
- **記録すべきこと**：送信日、返信日、提示された給与条件、生活費の月額

## 9. 撤退条件と再評価

- **止める条件（A1）**：給与を聞くのに、応募・面接・登録・費用が必要と言われた場合です。その時点で A1 は終わり、返信には応じずに再評価します。
- **再開の条件**：保留中の行動を動かすのは、あなたが明示的に解除したときだけです。
- **再評価の時点**：A1 の返信を読み、A2 の集計が終わった時点です。日付はあなたが決めていないので、私からは置きません。
