## 出力全文

## 1. 結論

**今はまだ退職を伝えない（hold）。** ただし、何もせず待つわけではありません。転職先の条件を書面で確かめ、自分の判断軸と生活資金を整理してから、もう一度判断することを勧めます。

退職を伝えると取り消せない（あなたの申告）一方で、比べるための材料がまだ揃っていません。このまま決めると、取り消せない決断を情報不足のまま固めることになります（PDF §64.1-2）。

## 2. 現在モードと状態

```text
Operational Mode：SAFE（提案。負荷が高く、取り消せない行動が選択肢にあるため）
Context Override：なし
Type ZERO       ：未判定（LOADは「負荷がかなり高い」との本人申告のみで、L2に当たるかは未判定。IRREV / VOL の観測なし）
状態            ：現在の記録状態は不明
                  今回のgovernance result：HOLD（退職の意思表示・入社承諾について）
MISSION-DEFENSE 拡張：非発動（転職先からの圧力などの申告なし）
```
HOLD を解いて ACTIVE に戻すには、あなたの明示的な承認が必要です（PDF §60.3）。

## 3. 破綻境界

仕事の領域なので、Hard / Soft の区分は使いません（N/A、PDF §63.1）。
- **起こりうる経路1**：転職先の条件を確かめないまま退職を伝える → 取り消せない（本人申告）→ 条件の食い違いや収入の空白が生じる。どの程度の打撃になるかは、生活資金などが分からないため不明です。
- **起こりうる経路2**：高い負荷が続き、健康が悪化する。今のところ体調不良の申告はなく、この境界に届いているかは判断できません。
- **Passive Ruin：未成立**。ただし、転職先に回答期限がある場合、返事をしないまま期限が過ぎると、この選択肢そのものがなくなる可能性があります。期限は不明なので、確認が必要です。

## 4. 可逆性

- **戻せる**：条件を確認すること、判断軸や負荷・資金の記録をつけること
- **戻しにくい（未確認）**：転職先への入社承諾。辞退できるか、法的にどうなるかは確認していません
- **戻せない**：現職に退職を伝えること（本人申告。法的に撤回できるかどうかは確認していません）

## 5. A_allowed

**今やってよい**
- **A1**：転職先に、職務・給与・勤務時間・入社時期・回答期限を書面で出してもらえるか問い合わせる。承諾や入社日の約束はしない。費用がかかる場合は確かめてから行う。
- **A2**：自分の判断軸を書き出す（何が満たされれば移るか、何があれば残るか）
- **A3**：今の負荷を記録する（労働時間、睡眠、体調）
- **A4**：現職の就業規則や雇用契約で、退職の申出期限などを確かめる。会社には伝えない。
- **A5**：収入が途切れた場合に、何か月生活できるかを確かめる
- **A6**：睡眠の乱れなどの不調が続く場合に限り、医療機関（産業医がいれば産業医）に相談する。根拠はあなたが申告した高負荷と、健康悪化の経路です。

**保留**
- **P1**：退職の意思表示（取り消せない＋情報不足、PDF §64.1-2）
- **P2**：入社の承諾（戻せるか未確認＋条件が未確認）

**禁止**：根拠をもって禁止と言える行動は、今のところありません。

**条件付き候補**（今の A_allowed の外）
- **X1**：上司に負荷の軽減を相談する。何をどこまで伝えるかと、職場の関係への影響を、あなたが決めてから再評価します。
- **X2**：転職先と条件を交渉する。A2 の判断軸と A1 の条件が揃ってから再評価します。

## 6. Strong Engine候補

- **候補A（安全寄り）：A2＋A3＋A5**。外部とは接触せず、内側の整理だけを進めます。
- **候補B（標準）：A1＋A2＋A4＋A5**。条件を書面で揃えて、残る場合と移る場合を同じ物差しで比べます。
- **候補C（攻め）：今は該当なし**。A1 の条件と A2 の判断軸が揃えば、承諾と退職通知を判断できる段階に進めます。

## 7. 推奨判断

退職の意思表示は **hold**、候補B は **recommend**。どちらを選ぶかはあなたが決めてください。

## 8. 実行ステップ

- **今日**：A2（判断軸を3〜5項目書き出す）と A3（記録を始める）
- **次に**：A1 で条件と回答期限を確認し、A4 と A5 も確かめる
- **記録**：届いた条件、回答期限、判断軸の各項目をそれぞれの会社がどれだけ満たすか、毎日の負荷
