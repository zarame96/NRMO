- **Hard Ruin（回復できない損失）**：恒久的な資本毀損で、生活の基盤まで届くもの。今回の買い増しがそこに届くかは、金額と総資産に対する比率が分からないため判定できません。

- **Active Ruin（無謀な行動による直接の崩壊）**：起こりうる経路は、一つの銘柄に資金が集中しすぎることです。今の集中度は分かりません。
