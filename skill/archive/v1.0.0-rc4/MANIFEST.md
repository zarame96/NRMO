## rc3 からの変更（SKILL.md のみ）

1. 安全・健康の案内も列外行動の照合から一律に除外しない。受診などを実行指示として勧めるなら、根拠を示して A_allowed を再評価し、番号付きで置いて候補・実行ステップ・撤退条件を整合させる。安全案内を削って照合を通さない。
2. 本人が限定した許容行動は、対象・内容・範囲を本人の定義どおりに保つ。追加は `追加提案` として別枠に置き、候補・実行ステップに入れない。こちらが整理した一覧は、本人の制約内で根拠を示して再評価・更新できる。
3. Type ZERO の矛盾判定の前に、観測の対象・時点・条件を確かめる。対象が異なるだけで矛盾とせず、対象が曖昧な発言を特定の側の話と決めつけない。
4. 本人の数値を宣言された意味のまま扱う（最大損失を保有比率上限に読み替えない等）。

正典・PDF・パッチ・ALB を含む17参照と PDF_CAVEATS.md は rc3 とバイト単位で同じ。

## 再現方法

リポジトリの対象コミットをクリーンに checkout して次を実行する。Python 標準ライブラリのみを使う。

```sh
python3 skill/tools/build_package.py
```

dist/nrmo-rc4/ に nrmo.skill と BUILD_MANIFEST.json を出力する。同梱パス、重複、CRC、全内容のソース一致、同一実行環境内での決定性、内容不一致の拒否を確認する。ZIPの圧縮ライブラリが異なる環境間で同一ハッシュになる保証とは区別する。
