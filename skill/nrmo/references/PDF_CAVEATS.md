# PDF 典拠の版差と実装記述の注意

個人版の補助資料。Normative Canon、v7.3 Publication of Record、保存された運用仕様、パッチ、権限境界の役割を変更する文書ではない。本人が共有した業務版 Skill に同梱されていた PDF_CAVEATS.md と PDF の該当箇所を照合し、版を限定して整理した。会社の Mission・KPI や業務用の判断体系は取り込まない。

## 読む順序

- 個人の相談では、`NORMATIVE_CANON.md`、`RUNTIME_RECONCILIATION.md`、`nrmo_system_v7_3.md` の順に読む。運用 Markdown を単独の正典として扱わない。
- 同梱 PDF は NRMO_Integrated_System_v7_3.pdf（537ページ）。本人が別途共有した v7.2 PDF（511ページ）へ置き換えない。
- 状態遷移、Ruin、`A_allowed`、StrongEngine、破滅確率を出力するときは、`RUNTIME_RECONCILIATION.md` が指定する PDF の該当節を回答前に読む。「必要なら読む」扱いにしない。
- PDF の理論記述と、現行コードの実装状態は別々に確認する。実装について述べるときは対象リポジトリ・コミット・ファイル・検証記録を示す。確認できなければ未確認と書く。

## 共有された旧版注意事項の範囲

共有された注意書きは主に v7.2 PDF を対象とする。次を v7.3 全体の誤りや現行コードの事実に一般化しない。

| 論点 | 扱い |
|---|---|
| 許容集合の凸包 | 行動の制約は `NORMATIVE_CANON.md` §2.3・§8どおり a_t ∈ A_t。a ∈ conv(A) へ置換しない |
| HOLD / EXIT_HOLD | 旧実装の定数表記として紹介されている。現在のリポジトリを確認せず、現行実装の定数・状態遷移を断定しない |
| Norn・adapter のファイルパス | PDF の例示パスを現行ファイルの所在とみなさない。共有注意書きには別のパスの指摘もあるが、その指摘の対象コミットは特定できていない |
| 成功率・弱点・実験件数 | 過去の特定版・条件の報告。現行性能や一般的な保証として引用しない。必要なら同梱 evidence の原報告と対象版を併記する |
| 理論上の性質 | 実装がその性質を満たすことの動作証拠にはならない。コードと試験を別途確認する |

Canon、Publication of Record、保存された運用 Markdown の間に未裁定の不一致を見つけても、独断で原本を書き換えたり補完したりしない。`RUNTIME_RECONCILIATION.md` に裁定済みの事項はその規則を適用し、未裁定なら不一致と出典を示して本人へ返す。この資料は ALB 第2章の承認や T3 の採用ルールを定めない。
