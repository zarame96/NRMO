## (A) 第1章の持ち越し

### 2.1 強制の対象：自分か、相手か

**提案：ALB が強制できるのは、決裁者自身の行動だけである。**

```
A_self  = 決裁者が自分で実行できる行動の集合
r       = 相手の応答（ALB の外にある）

ALB.force : state → a ∈ A_self
ALB は r を目標変数・成功条件にしない
```

**不変条件**

- **A1**：`ALB.force ⊆ A_self`。相手の行動を対象にした force は定義上存在しない
- **A2**：ALB は相手の応答 r を観測の目標にしない。「相手が応じたか」で force の成否を測らない（測れば、相手を動かす設計＝操作に転じる。v7.3 §10.3、§8.5 の禁止と衝突する）
- **A3**：ALB が解消するのは「本人が決めないまま止まっている状態」であって、「本人が動いていない状態」ではない。**「動かないと決めた」は解消された停滞として扱う**

A3 が要点である。ALB が強制するのは行動そのものではなく、**決定**である。連絡する／しないのどちらでもよく、決めずに沈黙が続くことだけを Passive Ruin として扱う。これで、関係領域の force が相手の自由度を侵す経路が構造的に閉じる。

**第1章 §1.8 表の改訂案（人間関係の行）**

| 領域 | ALB の役割 | DefensiveEngine の役割 |
|---|---|---|
| 人間関係 | 本人が決めないまま停滞している状態の検知、**自分の次の一手を決めることの強制**（「動かない」と決めることを含む） | 相手の自由度・可逆性の維持。相手の応答を成功条件にしない |

### 2.2 θ_A の算出方法

NRMO の ε（能動的破滅の許容上限）に対応する、受動的破滅の閾値を定義する。

**(1) 受動的破滅の確率**

停滞の継続時間 τ に対するハザード関数として置く。

```
P_PR(¬a, τ) = 1 − exp( − ∫₀^τ h(s) ds )

h(s) = h₀ · g(ΔO, ΔK, w)
  ΔO : 選択肢数（WorldState.O）の減少速度
  ΔK : 知識・信用（WorldState.K）の減少速度
  w  : 機会の窓（残存期間）。窓が閉じるほど h は増える
```

止まっている時間が長いほど、選択肢と信用が目減りするほど、機会の窓が閉じるほど、受動的破滅の確率は上がる。§13.2 Soft Ruin の列挙（慢性的停滞、機会損失、適応失敗、関係停滞、資本成長停滞、判断疲労、実行不能化）を、O・K・w の減衰として測る構成である。

**(2) h₀ の推定**

外部の正常値を使わない（Norn の設計原則と同じ）。決裁者自身の過去の停滞エピソードのうち、長さ τ 以上続いて Soft Ruin の標識に至った割合から推定する。履歴不足のうちは INSUFFICIENT_HISTORY とし、ALB は INTERVENE を発行しない。

**(3) θ_A の決め方**

θ_A は決裁者が宣言する。ε と同じ扱いである。そのうえで、初期値の決め方を一つ提案する。

> **介入対称性の原則**：過去の判断履歴を再生したとき、ALB の force 頻度と NRMO の veto 頻度が同程度になるよう θ_A を置く。

NRMO と ALB は対等であり、どちらかの声が恒常的に大きい初期値は、それ自体が非対称を持ち込む。初期値で対称にし、その後の調整は決裁者が行う。

**(4) 振動の防止**

INTERVENE の発火（θ_A）と解除（θ_A − Δ）に差を設ける（ヒステリシス）。同日内の発火と解除の繰り返しは、Norn が SIGNAL として記録する。

**(5) 双対性の記述**

```
NRMO : 行動 a が許される   ⇔  P(Ruin | a)  ≤ ε
ALB  : 不作為 ¬a が許される ⇔  P_PR(¬a, τ) < θ_A
```

NRMO は「許容される行動の集合」を、ALB は「許容される不作為の範囲」を定める。θ_A は ε の鏡像である。

### 2.3 DefensiveEngine の連続的な減衰アルゴリズム

第1章 §1.5 の 5 性質（低速・複数目的・連続減衰・単一失敗致命・境界維持）をそのまま実装条件にする。

```
保護対象  q ∈ {資本, 信用, 関係, ...}       （複数目的の保持）
余裕      m_q(t) = 境界までの距離 / 基準距離   （各保護対象ごと）
最小余裕  m(t)   = min_q m_q(t)

防御強度  d(t) = σ( k · (m* − m(t)) )        σ はシグモイド、m* は目標余裕
曝露更新  X(t+1) = X(t) · (1 − κ · d(t))
連続性    |X(t+1) − X(t)| ≤ δ_max            （急停止の禁止）
```

- **連続減衰**：d(t) は滑らかに変化し、X は指数的に減る。閾値で跳ばない
- **予防**：d(t) は ALB が PASS の間も働く。θ_A 到達前の予防行動を保証し、第1章 Failure 1 を回避する
- **単一失敗致命**：候補選択は期待値最大ではなく、最悪ケース損失の最小化（maximin）で行う
- **境界維持**：DefensiveEngine は境界 B を書き換えない。m_q の基準は NRMO の破綻境界と、決裁者の宣言から取る
- **目的の独立**：k、m*、κ、δ_max は DefensiveEngine の内部パラメータであり、ALB は読まず、書かない（第1章 Failure 2 の回避）

**StrongEngine との関係**：StrongEngine 内の Defensive / Recovery モジュールは流用しない（ALB は独立構築）。ただし比較対象として理論実験 E-3 で並べる。

## (B) 統合アーキテクチャ v0.1 の未確定

### 2.5 中間層：名前と合成ロジック

**仮称：天秤（Balance）。** 2026-09-16 の対話で、決裁者の階層図を「両方の皿に乗るのは判断ではなく判断材料」と表現した喩えから取る。正式名は決裁者が決める。

**出力の契約**

```
Presentation = (
  s_N, reason_N,     NRMO の生信号と発火理由（無加工）
  s_A, reason_A,     ALB の生信号と発火理由（無加工）
  L_active,          能動的破滅の期待損失  = P(Ruin | a)     · Loss_ruin
  L_passive,         受動的破滅の期待損失  = P_PR(¬a, τ)     · Loss_PR
  recommendation,    合成した推奨
  trace              合成の全計算過程
)
```

2026-09-16 の合意「NRMO と ALB は同じ一つの目的関数を、逆方向の失敗モードから見ている」に従い、二つの声を**同じ物差し（期待損失）**に載せて並べる。

**合成規則**：`recommendation = 期待損失の小さい側`。重みの学習はしない。Loss_ruin と Loss_PR は決裁者が宣言する。

**不変条件**

- **B1**：天秤は決定しない。決定は常に Human Sovereign
- **B2**：生信号 s_N・s_A と理由は、常に両方が無加工で提示される。要約・削除・並べ替えをしない
- **B3**：合成規則は決定的で公開されている。Norn は trace から推奨を再計算でき、一致を確認できる
- **B4**：天秤はどちらの憲法の閾値（ε、θ_A）も読まず、書かない
- **B5（衝突時）**：NRMO が veto し、同時に ALB が force している場合、推奨を一つに絞らない。衝突を明示し、少なくとも「最小曝露の可逆な一手」を選択肢に加えて提示する

### 2.6 NRMO の veto は ALB の force 行動に及ぶか

v0.1 §6 で未確定のまま残った問い。懸念は「ALB の force に NRMO の veto がかかるなら、NRMO が上位という非対称が入る」ことだった。

**提案：各憲法は自分の失敗モードについてのみ、相手の出力も含めて審査する。上下はない。**

```
最終選択 c ∈ {a, ¬a}

c = a  （行動）   のとき：NRMO が審査する  P(Ruin | a) ≤ ε
c = ¬a （不作為） のとき：ALB が審査する   P_PR(¬a, τ) < θ_A
```

- ALB が強制した行動は「行動」なので、NRMO が能動的破滅について審査する
- NRMO が止めた状態は「不作為」なので、ALB が受動的破滅について審査する

NRMO は ALB の上にいるのではなく、**行動という出力全般**を審査する。ALB も NRMO の上にいるのではなく、**不作為という出力全般**を審査する。審査権は失敗モードで分かれていて、相手の出力にも自分の失敗モードの範囲では等しく及ぶ。これで対称性が保たれる。

**膠着**（全ての行動が veto され、かつ不作為も force される）の場合は、自動解決しない。B5 に従って天秤が衝突として提示し、Human Sovereign が決める。

### 2.7 ALB 側の具体語 — **埋めない**

INTERVENE_MINOR / INTERVENE_MAJOR に相当する具体語は、本稿でも埋めない。

決裁者は「用語は後からついてくる」と明示し、意図的に未定に置いた。さらに、当初 AI が提案した新語（ADVANCE / SEIZE）は、「NRMO を正典、ALB を仮のものとして扱う非対称の入口」として撤回されている。ここで AI が候補語を置けば、同じ誤りを繰り返す。これは「埋められない穴」ではなく「埋めてはならない穴」であり、決裁者の側に残す。

### 2.8 Norn の観測対象の拡張

**提案：拡張する。** 記録対象を次の 4 つにする。

1. NRMO の veto 頻度
2. ALB の force 頻度
3. 衝突（B5）の発生回数
4. 天秤の推奨と、決裁者の実際の決定との一致率

いずれも記録のみで、閾値は置かない（§4.10「監査は秤を持たない」）。

一致率には解釈上の注意を付す。一致率が 1.0 に向かって緩やかに移動する場合、天秤が事実上の決定者になりつつある可能性がある。Norn はこれを DRIFT として、評価せずに事実として記録する。
