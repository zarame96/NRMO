# loom100 — 最大100年 企業経営シミュレーション（NRMO研究付属物）

NRMO MaxForwardEngine が駆動する、円建て・IFRS / J-GAAP 選択可・最大100年（400四半期）の
企業経営シミュレーション。四半期ごとに複式簿記で貸借が一致（残差0円）することを全変更で検証している。

## 位置づけ
出力は**シミュレーションのプロキシ値**であり、実在企業の**実額較正は未実施**。
生存率・寿命・財務数値は構造を全力で組んだ結果であって、特定値への逆算ではない。

## 構成（現行モデル）
1. 資本構成（社債・CB・自己株式・配当、上場後は市場株価で増資）
2. 市場・競合（総需要×シェア、参入退出・革新・破壊的参入、顧客嗜好シフト）
3. イノベーション（R&D実物オプション、新規事業、陳腐化）
4. **株価エンジン（期待・成長・物語で動く市場）**：成長でPER/PSRが急騰、市場心理(sentiment)が実態の上下に乖離しうる（バブル・暴落）。未公開株にも成長評価（プライベートバリュエーション）
5. 操業レバー8種（集客/広告・多チャネル・出店・内製化・工場増設・R&D/トライアル・CS・事業最適化）
6. 業態転換（旧資産減損→新市場移行、確率的成否）
7. **M&A（買う側）**：のれん計上・LBO負債・統合成否・のれん減損
8. **創業者フェノタイプ**：技量(ceo_skill)・破滅回避(ruin_aversion)・判断軸(ceo_bias)・任期。稀に爆発型(Amazon/NVIDIA/UNIQLO型)。破滅回避は低レバ・厚い現金・社債回避・早期デレバで生存を延ばす
9. **成長資本**：高成長企業は未上場・赤字でも成長ストーリーで増資（VC/PE/プレIPO/高成長IPO）を引ける
10. **死に方11種**：資金繰り破綻／黒字倒産／社債デフォルト／コベナンツ違反（期限の利益喪失）／敵対的買収(TOB)／バブル崩壊・資金調達途絶／デススパイラル／テールイベント(リコール/訴訟/災害)／承継失敗／理念崩壊解散／役割終了解散

経営判断（21種以上）は NRMO エンジンが先読み探索で選び、ガバナンス層（憲法的な veto/hold/safe_exit のみ）と分離。**エンジンは一切改変していない（憲法は不可侵）。**

## 会計的厳密性
- 貸借対照表の恒等式：全期間で残差 0.0000円
- 当期純利益 ↔ 利益剰余金の増減が厳密一致
- 有形固定資産（純額）≧ 0／のれん ≧ 0 を保証（除却・減損時に取得原価と償却累計を比例的に処理）

## 実行
```
cd scripts
python3 loom100.py          # 代表パス1本を回して経営史を表示
python3 build_xlsx.py        # /tmp/century_full.json, young_full.json から三表Excelを生成
python3 build_chart.py       # 純資産・株価の推移チャートを生成
```
NRMO エンジンは同梱（DecisionCompass/NRMOIntegrated/.../v7_maxforward）。firm_ifrs.py が相対パスで自動解決。

## ディレクトリ
- `scripts/` … 現行ソース（firm_ifrs.py = 動学/エンジン連携, loom100.py = 100年オーケストレータ, build_xlsx.py, build_chart.py）
- `scripts/dev_history/` … 開発の進行を記録した版（firm_ifrs_L0〜L6 → pre_deaths → pre_growthcap → pre_ruinaversion）。層ごとの構築履歴
- `outputs/` … 成果物（下記の来歴に注意）
- `NRMO_研究開発_提言メモ.md`（outputs内）… 本研究の発展性・改善点・運用安定化・**禁忌**の総括（重要）

## 成果物の来歴（重要）
`outputs/` の Excel・チャート・経営史レポートは、**層6時点（seed19）の代表企業**で生成したもので、
**本セッションで追加した市場リアリズム（株価エンジン作り直し・創業者フェノタイプ・M&A・死に方11種・破滅回避・成長資本）より前**の状態を反映している。
ソースコードは現行最新。フルモデルでの成果物再生成は既知の次工程（提言メモ参照）。

## 最重要ドキュメント
**`outputs/NRMO_研究開発_提言メモ.md`** を必ず参照。今回の中心的発見
「測れないものは黙って切り捨てられる ＝ 目的関数の盲点は暗黙の価値判断」と、
触れてはいけない禁忌（憲法不可侵・数字の逆算禁止・恒等式厳守 等）を記している。
