# NRMO loom100 — 最大100年 企業経営シミュレーション 経営史レポート

## 位置づけ（最初に明記）

本レポートの数値は **NRMO MaxForwardEngine が駆動するシミュレーションの出力** であり、**実在企業の実額較正はまだ行っていないプロキシ値** です。生存率・寿命・財務数値は「現実をそれらしく再現する構造」を全力で組んだ結果であって、**特定の生存率や寿命に合わせて逆算したものではありません**。実額較正は機能組み立て完了後の次工程です。

モデルは **円建て・IFRS / J-GAAP 選択可・最大100年（400四半期）** の企業を、四半期ごとに複式簿記で回します。経営判断（21種の打ち手）は NRMO エンジンが先読み探索で選び、ガバナンス層（憲法的な veto/hold/safe_exit のみ）と分離されています。

## 会計的厳密性（検証済み）

- **貸借対照表の恒等式**: 全期間で 資産 −（負債＋純資産）= **残差 0.0000円**（代表企業 全20期で不一致 **0件**）
- **当期純利益 ↔ 利益剰余金の増減** が厳密に一致
- **有形固定資産（純額）≧ 0 を保証**: 資産の除却・減損時に取得原価と減価償却累計を比例的に落とす正しい処理に修正済み（負の純資産PPEは発生しない）
- Excel 三表は数式で再計算検証済み（**0エラー / 300数式**、検証列が全行ゼロ）

## モデルの構成（6層）

1. **資本構成**: 普通社債・転換社債(CB)・自己株式・配当（上場×黒字は配当性向フロア、アクティビスト圧で増配）。増資は **上場後は市場株価で発行**（株価が安い時の希薄化が罰される＝乱発抑止）
2. **市場・競合**: 総需要（市場規模×自社シェア）、競合の参入退出・革新ジャンプ・破壊的参入、顧客の価格⇄品質嗜好シフト
3. **イノベーション**: R&D実物オプション（成熟8〜16四半期、確率的ヒット）、新規事業、陳腐化
4. **株価・企業理念**: PER/PBRベースの時価総額とセンチメント、デススパイラル/買収退場。**企業理念**（創業者の構えから生成）と理念整合度（持続的に逸脱すると解散）
5. **操業レバー（8種, 各々固有の経済的特徴）**: 集客/広告・多チャネル・出店・内製化・工場増設・R&D/トライアル・コールセンター(CS)・事業最適化。各々が需要・能力・原価・固定費・品質の別々の科目を動かす
6. **業態転換（pivot）**: 主力事業を別業態へ。旧資産を減損し新市場へ移行、確率的に成否（攻撃的経営者ほど成功率が上がる）

すべての打ち手は NRMO エンジンが状況に応じて選択します（21種: 設備投資, 販促, 価格防衛, 資金確保, 借入, 事業売却, 増資, 上場, 新規事業, 試行R&D, 集客, 多チャネル, 出店, 内製化, CS強化, 事業最適化, 業態転換, 社債, CB, 配当, 自社株買い）。

## 代表企業（seed19）の経営史 — 20年・第2代

理念『**顧客価値と持続的成長を両立し続ける**』（最終 理念整合度 0.63）

| 指標 | 値 |
|---|---|
| 生存年数 | 20年（第2代まで） |
| 上場 | あり（TSE・JGAAP） |
| ピーク純資産 | 2,229百万円（17年頃） |
| ピーク株価 | ¥5,783,408/株 |
| 業態転換 | 1回 |
| 新規事業成功 | 2件 |
| 最終チャネル数 | 7 / 最終内製化 80% |
| 最終監査意見 | adverse |
| 退場理由 | 株価崩壊・買収による退場(デススパイラル) |

### 物語の弧


**第1代（均衡, 0→12年）**: 2年 業態転換(累計1)、5年 新規事業成功(累計1)。
**第2代（均衡, 12→20年）**: 14年 新規事業成功(累計2)、17年 IPO上場(TSE/JGAAP)、20年 監査意見『adverse』。

この企業は、創業期に**業態転換**で事業の軸を定め、**操業レバー**（多チャネル展開・内製化・事業最適化）で地道に純資産を積み上げ、新規事業を当てながら成長。17年に **IPO** でピーク（2,229百万円・株価¥5,783,408）に達したが、上場直後に株価が急落、純資産が急速に毀損し、最終的に**監査否認**を受けて**株価崩壊・買収による退場(デススパイラル)**。

成長 → IPO → 過拡大 → 株価崩壊 → 監査否認 → 退場、という**現実的な企業生涯**の一例です。

## 対照: 未上場の零細企業（seed5）

10年で破綻（資金繰り破綻(融資も増資も得られず)）。資本市場アクセスが無く、資金繰りが詰まると立て直せない。**零細が短命なのは当たり前**であり、これも構造の自然な帰結です。

## 全機能を入れた帰結（正直な記述）

6層すべてを実装した結果、**100年生存は稀（厳しい）** になりました。破壊的参入・競合の革新・R&D空振り・資本コスト・株価規律・業態転換リスクが重なるためで、これは**現実的な厳しさ**であって数字合わせの産物ではありません。多くの企業が10〜30年で退場し、上場に到達するのはさらに一部、という分布は実際の企業生態に近い形です。
